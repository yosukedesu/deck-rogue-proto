# B1 状態異常付与の演出 9種

2026-11-08。**18枚の透明PNG**。付与アニメ9枚（各512×64、64×64の8コマ横並び）と、残留印9枚（各64×64）です。大きな生成絵の縮小ではなく、64×64の格子上へ直接描いた原寸ピクセル素材です。

夜硝子の暗い面・真鍮の細線に合わせ、A6と同じ色の系統を使用しました。紙色・クリーム色・太い墨線・文字・数字・共通背景板は焼き込んでいません。

## 取り込みの契約

詳細とファイルごとのSHA-256は `manifest.json` にあります。

- 8コマを左から **index 0–7** に分割。UV/切り出しは各 `(64*i,0,64,64)`。透明余白をトリミングしない。
- 推奨時間は **65 / 65 / 70 / 80 / 85 / 85 / 100 / 70 ms、合計620 ms**。7コマの描画＋index 7は完全透明のクリアコマです。付与アニメをループしない。
- 残留印は独立したPNG。**開始550 ms（index 7の開始）で透明コマへ切り替わるのと同時に表示する**ことを推奨。コマ4〜6と同時に印を重ねると形が二重になるため、重ねません。アニメを消しても印は状態が解消されるまで保持する。状態/札が消えたら即座に印も消す。
- 非カード用の基準点はセル左上から **(32,52)**。そこを対象の足元へ合わせる。印も同じ基準点です。キャラの上に大きな不透明板を置かず、足元/周囲だけに表示する想定。
- `wound` / `scald` は **(32,32)** を対象札の中心へ合わせる。札本体は含みません。描画先の札面でクリップし、文字・数値は上に描いて読める状態を保つ。添付プレビューの暗い札枠は確認用の仮図です。
- Nearest/Point、mipmapなし、通常のアルファ合成を推奨。PNGはstraight RGBA、アルファは0/255。加算合成や全面発光を前提としません。半透明を使うなら実装側の全体不透明度として調整。
- 64×64を1つの解像度単位として、戦闘の既存ドット倍率に合わせる。整数倍拡大を優先し、バイリニア縮小はしない。画像間のドット粒を変えない。
- シートはコマ間の余白なし。フレーム領域を厳密に切り、他のコマをサンプルしない。
- 複数状態の印が同時にある場合の並べ方・最大数・数値は実装側。単純に同じ足元へ9枚重ねない。無条件に全ての印を敵へ付ける実装にはしない。

## 意味を混同しないための決定

- 威圧は `EnemyState.weak`。プレイヤーの弱体 `PlayerState.weak` とはファイル名を分けています。`enemy_weak` はアセット側のキーであり、エンジンのIDを改名する指示ではありません。
- 公開mainでは脆弱・虚弱・拘束・霞み・重りはプレイヤーの状態。敵側に同名があると推測せず、取り込み側の実際の対象へ合わせてください。manifestに確認できたフィールドを記載しました。
- 負傷・火傷は状態札です。永続するプレイヤーカウンターや敵の足元印と扱いません。`scald` は延焼 `burn` と別。A6の火傷アイコンは掌の熱傷、B1は依頼どおり札が焦げる演出です。
- 混乱の旧Unityの表示別名は `confuse`。アセットキーはA6同様 `confusion` に統一しました。
- 旧一覧の「墨の輪」は、最新の夜硝子と真鍮の指示を優先し、藍紫の圧迫輪へ置換しました。色だけでなく輪・ひび・盾・縄・霧・錘・裂け・焦げ・渦で見分けます。
- 新しいランタン/エナジー宝珠、攻撃本体、キャラ素材、B2以降はこの束に含めていません。

## 検証の範囲

`source/verify.py` で寸法、PNG/RGBA、8コマ、アルファ0/255、セルの外周余白、パレット、重複、クリアコマ、印、時間、SHA、APNGの各コマ、再生成のバイト一致を検査します。結果は `qa/verification.json`。原寸・暗/中間/明背景とAPNGを独立に確認した結果は `qa/visual_review.md`。

確認画像:
- `previews/contactsheet_native.png`：64×64原寸で8コマ＋印。
- `previews/readability_2x.png`：ピークコマは2倍Nearest、印は原寸。3つの背景で比較。
- `previews/status_application_preview.png`：APNG。9種を3倍Nearestで同時表示。付与620 ms→印900 ms→リセット220 ms。印は開始550 msから表示しています。

**実ゲーム・現行Godotでの取り込み、実機での色/重なり/表示倍率/速度は未検証です。** この束は素材納品であり、置くだけでゲームの状態イベントに接続されるとはしていません。実装者は付与イベントからの再生、状態解除時の印の削除、対象と状態IDの対応、札のクリップ、重複状態の配置を確認してください。

## 再生成

Python 3 / Pillow / DejaVu Sans（確認画像の英字ラベルのみ）を使います。

```
python source/draw_status_fx.py
python source/build_manifest.py
python source/verify.py
```

新規描画はすべてソース内の整数座標へ直接配置しています。外部画像は入力しません。曲線も原寸キャンバスでラスタライズし、作品を拡大縮小してピクセル化していません。画像拡大は確認画像だけです。`palette.json` に全色を保存しています。
