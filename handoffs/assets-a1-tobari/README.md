## 決めた事

1. とばりの外見: 銀灰〜藤灰の片寄せボブと長めの片側毛束、墨紫の短い外套、生成りの襟と縁、落ち着いた紫の割れた作業衣、黒い不透明レギンス、茶革靴、真鍮の留め具。小さな炭色の術書を持つ。頭の大きい可愛いデフォルメを採用。これは今回の造形判断であり、既存設定の引用ではない。
2. 消滅の札を実物として描かず、骸骨・霊・吸収光も追加しない。攻撃は本を開き空いた手で放つ。防御は本を胸に寄せ、被弾は肩と体を後ろへ傾ける。外套と髪の動きは体に追従する。
3. 待機は生成された8姿勢の胸・袖・髪先と瞬き（5番）。全身の平行移動で水増ししていない。足のちらつき防止のため、実寸y68〜83だけidle0から固定。これは書き出し工程の明示的な補正でありrawは不変。
4. rawは正確な128×84の整数倍ではない。alpha128以上を不透明として外接矩形を取りNearestで指定背丈へ等比縮小、足元を登録。透明RGBを0にする。核の不透明画素からMedianCutで48色を抽出し、各出力をRGB二乗距離の最短色へ写す。ディザ・平滑化・隠れた描き足しはしない。低alphaの周囲の色にじみは閾値で除外される。
5. 推奨時間は待機125ms×8、攻撃130/100/180ms（当たりindex1）、防御300ms、被弾220ms。素材の再生契約であり実イベントの時計を変更する指示ではない。
6. 衣装の細かな画素や髪の形には生成由来の差が残る。原寸と拡大で識別点・手の持ち替わり・足元を確認したが、実ゲームでのちらつきや最終採点の代わりにはならない。
