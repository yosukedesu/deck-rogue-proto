## 内容と決めたこと

坑匠の工房は、宿場跡で札の合成を頼む場所。店主・人物・キャラクターは描かず、炉、金床、工具棚、作業台、小さな歯車式の合成器、鉱石、夜の窓で用途を示しました。日常の木と石と鉄の仕事場とし、近未来の自動機械にはしていません。

既存 `workshop.png` の「工具棚＋作業台＋炉」を参照し、240×132 の絵を引き伸ばさず **400×224 の画面として新規に再構成**しました。既存の `bd_shop.png`・`bd_campfire.png` と、夜の青、暖かい火、暗い余白を比較しています。元の絵の完全な画風再現ではなく、同じ施設群に置ける配色と主題を優先しました。

最新の指定「夜硝子と真鍮」を優先し、青黒い影、冷たい窓、細い真鍮の金具に統一。炉とランタンの周囲だけ暖色を置きました。紙・クリーム色の背景、太い墨の装飾枠、文字、UIパネルはありません。作業台の図面らしい小物も紙ではなく暗い金属板です。

## 本物のピクセルでの制作

`source/draw_workshop.py` で **400×224 の実寸キャンバス上の整数座標と固定パレット**を指定して描いています。画像生成モデルの大きな出力を縮小した絵ではありません。既存素材を拡大・トレース・切り貼りせず、形、面、工具、石の欠け、木目を座標で置いています。

- 本体は最初から最後まで 400×224。
- 本体への補間、アンチエイリアス、ぼかし、縮小、色量子化はなし。
- 実使用色 48 色。半透明なし。
- 3 倍プレビューのみ nearest-neighbor で整数倍拡大。
- 再生成：`python source/draw_workshop.py`
- 確認画像再生成：`python source/prepare_qa.py`
- 検証：`python source/verify.py`

Python 3 と Pillow が必要です。外部フォント・ネットワーク・参照画像の読込みは本体の再生成には不要です。

- 技術検証：寸法、RGB、48色、固定パレット、一致する再生成、ソースの構文、プレビューの整数倍一致、参照画像のハッシュ等を `qa/verification.json` に記録。
