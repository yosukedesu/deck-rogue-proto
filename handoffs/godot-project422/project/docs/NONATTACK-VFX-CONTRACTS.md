# Nonattack presentation contracts

These contracts consume validated engine events; they do not inflict hits,
compute resource gains, change targets, or infer outcomes from card names.

## Defence representative: blue_guard (selected88, bounded QA on89)

An exact CardPlayed-owning action opts in its FIRST positive IceBlockGained
whose player receipt validates and whose IceBlock delta equals Amount. The
event object/reference and numeric schedule remain unchanged. IceBlockGained
has no source UID, so this is an owner-action defensive gain, NOT claimed
direct-card provenance. Later passive gains retain all original numeric/status
cues and event order without a duplicate full protective cast.

The effect assembles receiver-local clipped unequal frosted facets around the body, settles and
dissolves. It follows the actual receiver, has no offensive approach, damage
flash/audio or broad attack crest, and uses ordinary cancellation/drain ownership.
No defence value or lasting immunity is implied by geometry.
