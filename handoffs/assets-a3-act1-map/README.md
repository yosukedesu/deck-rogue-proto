# A3 幕1 地図素材：夜硝子と真鍮

2026-11-08。原寸ピクセルで制作した地図用ミニチュアと節の駒、計12枚です。

## 納品内容

- 大駒4枚：96×96 RGBA。出発点の坑口門、脳筋オーガの巣、血族の儀式場、朧の大鹿の林。
- 節8枚：48×48 RGBA。通常戦闘、強敵、未知、焚き火、商店、工房、宝箱、ボス。
- `manifest.json`：用途、遭遇ID、寸法、推奨原点、配置先、SHA-256。
- `source/`：原寸の座標指定制作ソース、検査スクリプト、参照の由来。
- `qa/`：原寸・3倍一覧、明暗背景、旧新の節比較、検証結果。
- `references/`：確認に用いた既存素材の無改変コピー。**取り込み対象ではありません。**

## 決めたこと

1. 原寸96×96／48×48の格子に、輪郭・面・影・ハイライトを整数座標で直接配置しました。大きな絵を縮めたものではありません。プレビューだけをnearestで整数倍拡大しています。
2. 主光は左上。影は紺〜鋼青、輪郭は選択的な暗色と真鍮の細いハイライト。紙台紙、クリーム色の下地、太い墨の輪郭は使っていません。
3. 「夜硝子と真鍮」という最新指示を採用しました。公開mainで11月5日追補の正確な色番号は取得できなかったため、このセットの色は文意に基づく制作値です。正確な共通UI定数と一致すると主張していません。
4. 大駒は見下ろしの地図に置く小さな立体物として、輪郭で役割を区別します。門＝岩と坑木＋線路、オーガ＝洞と巨大な棍棒、儀式＝三点の祭壇、朧大鹿＝角状の枯木と冷たい露頭です。人物・敵本体は描いていません。
5. 節は既存の意味を継承しました。戦闘＝獣面、強敵＝角頭骨、未知＝疑問符、焚き火、商店＝天秤、工房＝ハンマーと金床、宝箱、ボス＝冠と石台です。
6. 大駒は旧坑口より描き込みを省いたミニチュアです。細部の完全再現ではなく、地図上の可読性とセットの統一を優先しました。節は小さなUI記号として、大駒より真鍮を明るめにしています。

## 再制作

依存はPython 3とPillowです。外部画像を入力して変換する工程はありません。

```sh
python source/draw_landmarks.py /tmp/a3-render
python source/draw_nodes.py /tmp/a3-render
python source/verify.py
```

直接描画ソースが生成する画像のうち、最終取り込み対象はmanifest記載の12PNGです。ソースの表示用一覧やパレット出力は補助資料です。
