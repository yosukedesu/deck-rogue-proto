## 決めたこと

- **A7の不要になったランタン本体やエナジー宝珠は作っていません。** B6 の演出だけです。人形のキャラ絵も置き換えません。
- 夜硝子の暗い舞台に、真鍮の細い輪・小さな火の粉・銀青の光芯。紙・クリーム色・太い墨線はなし。B1〜B5と同じパレット。
- 元の人形は32 px、一部48 pxなので、共通の64 px枠を選びました。人形向けの足元アンカーは **(32,52)**、移動する火の粉は **(32,32)**、放出は光の先端 **(39,32)**。同じ論理ピクセル縮尺で重ね、64 pxを32 px枠に押し縮めないでください。
- **PNGは光・火の粉・足元の跡・灰だけ。** 本体の点灯色、踏み込み、崩壊マスクは `manifest.json` の `sprite_sync` で別に指定。既存キャラを保ったまま同期できます。PNGだけで本体が動く／消えるわけではありません。

## 取り込み

1. manifest の各矩形・各コマの時間で0→7を1回再生。NEAREST、ミップマップなし、通常alpha合成、トリミング・アトラス回転なし。文字や数字は画像へ焼きません。
2. **灯獲得／放出**はPNG全体のルート座標を出どころから確定した対象へ移動。テクスチャには画面全体の経路を描いていません。manifest の進行率を補間し論理ピクセルへ丸めます。index 6で到着。獲得は265 ms、放出は245 msです。残り火は飛ばさず既存ランタンの局所フィードバックに任せます。
3. 放出のうち、**単なる灯の支払い・火種への変換では敵へ飛ばさない**でください。大行列等なら対象は人形です。確定した出どころ・対象がない場合は経路を省略し、勝手にプレイヤーや別の敵を代用しません。量・ダメージ・状態は確定したゲーム処理が正で、粒やコマから算出しません。
4. **号令**は実際の対象人形だけ、同じ開始時刻で各UIDに1回。コスト支払いだけを号令と見なしません。真鍮への色混合の山も同じ時刻。顔と胴体を輪で塗りつぶさない設計です。
5. **点灯**は新規登場だけ。ロード／画面再構築では再生しません。足元の輪＋短い色混合で、元絵の縮尺を変えません。
6. **踏み込み**は右向き。既存本体だけ最大 `(8,-2)` px動かし、必ず元へ。VFXは出発時の足元に固定、移動本体へ追従させません。左向きはPNGを左右反転して本体x移動も反転。表示の座席・当たり判定・札・ラベルは動かさない。推奨の当たりはindex 3（95 ms）ですが、ゲームの確定タイミングを優先します。
7. **崩壊**は確定した破壊／捧げ／期限切れ／退場だけ。人形本体を上からマスクして最大3 px沈め、灰を元の足元基準で散らします。index 7以降は本体非表示を維持。単なる被弾で消さないでください。途中キャンセル時も確定済み退場を復活させません。
8. 既存の輪・飛翔・踏み込み・崩壊演出への**差し替え用**です。併用して二重の飛翔や二重の移動にしないでください。SEは追加しません。動きを減らす設定では移動を省き、局所の短い点灯だけでも可。
9. 表示は数値・札・ツールチップより後ろ。既存人形の小さな枠でVFXを切らず、適切な舞台レイヤーへ。終了・中断・画面破棄では一時VFXを除去し、通常の本体色と位置を復帰。消失だけは確定状態を維持します。
