# A6 視覚検査

確認日: 2026-11-08。32px原寸、4倍Nearest、夜板・青板・明背景の表示を確認。

## 判定

納品可能。暗背景で全14種の輪郭・主記号を判別できます。真鍮の細線と寒色の金属色が共通で、紙地・クリーム地・太い墨輪郭はありません。

- 弱体の二重下向きと、威圧の角頭＋小下向きを区別。
- 虚弱の割れ盾、装甲の胴鎧、延焼耐性の炎を遮る盾を区別。
- 火傷は赤い掌＋熱い水疱＋湯気。延焼する炎そのものではありません。
- 脆弱は割れた心臓、急所は的。霞みは暗色の札と横霧。
- 拘束・重り・負傷・混乱・とげも異なる主シルエットがあります。
- 初版のとげの右下端が枠に接していたため、末端ドットを1px内側へ修正。修正版で四辺1px以上の透明余白と棘の形を確認。

## 制限

この検査は静止画像の意味と見た目の確認です。実機、実際のUI背景、選択枠や数字の重ね合わせ、色覚条件別テスト、16px等への縮小表示は未検証です。状態名と意味の学習を不要にするものでもありません。
