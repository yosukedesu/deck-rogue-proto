# A1-r とばり：攻撃から待機へ戻る3コマ（return2 顔修正版）

攻撃 index15 → return0 → return1 → return2 → 元のidle0 の素材受け渡しです。ゲームへの組み込みは行っていません。

## 今回の修正

旧return2は目・頬・前髪の形が元idleから崩れていました。元idle0を原寸の基準にimagegenで作り直し、小さな目、前髪の重なり、頬の幅を戻しました。顔を大きくした初回案は採用していません。最終案は独立した目視確認を実施し、元idleへの目立つ顔サイズの段差がないと判断しています。

return0・return1は旧版とバイト単位で同一。元の攻撃・待機素材も変更していません。return2は再生成であり、顔部分だけの画素置換ではないため、衣装・鎌などの細部にも旧return2との差があります。

## 規格と時間

3枚とも192×128、8-bit RGBA、右向きから斜め前向き。足元は左上から **(99,116)**。alphaが0より大きい最下行は3枚とも **115**、行116以降は全て透明です。

returnは各100ms、合計300msで変更なし。推奨合計250〜350ms。比較プレビューは攻撃15=350ms、return=100/100/100ms、idle0=500ms。実装ではreturnを1回だけ再生し既存idleへ渡します。Point/Nearest、ミップマップ無効を基本とします。

## 元idleとの接続

提供ZIPの待機は128×84、攻撃は192×128。idle0のalpha範囲は `(25,2)–(91,77)`（右・下は含まない）です。元idleのpivot情報はありません。

比較ではidleの推定足元 `(60,77)` を `(99,116)` に合わせ、元idleを **(+39,+39)** だけ移動しています。**元idleの拡大縮小・描き変えはしていません。** 実装のpivotと縮尺は未確認です。

最終return2は目・前髪・顔幅が元idleに近づきました。元idleより少し強いコントラストと細かい画素差は残ります。return1からの表情変化も完全にゼロではありません。

## 生成と書き出し

return2は原寸idleを8倍表示した参照からimagegenで生成し、背景の透明部分もimagegenで修正。その1536×1024出力をNearestで192×128へ1回だけ縮小しました。旧return2で使った0.9倍参照・1.10倍規格化は今回使っていません。

**alphaの閾値操作、コードによるマスク消去、手描き修正、塗り替えはしていません。** 最終案にも非常に薄いalpha画素が残り、非ゼロalpha全体のbboxは `(9,3)–(128,116)`、alpha>16の参考可視bboxは `(63,42)–(127,116)` です。後者は測定だけで画像には適用していません。通常の白・濃灰色背景への合成では光輪・煙・孤立した効果は見えません。alphaは最大254で、元画像の二値alphaと完全には一致しません。自動bboxをpivotや本体サイズとして使わないでください。
