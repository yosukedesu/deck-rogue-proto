攻撃 index 15 → return 0 → return 1 → return 2 → 待機 idle 0 の素材受け渡しです。ゲームへの組み込みは行っていません。

## 素材

- `leader_black_attack_return_0.png`
- `leader_black_attack_return_1.png`
- `leader_black_attack_return_2.png`
- `contactsheet.png`：攻撃15から**元のidle0を縮小せず**並べた、3倍表示と実寸の比較。

## 規格と時間

3枚とも192×128、8-bit RGBA、右向きから斜め前向き。足元は左上から **(99,116)**、alphaが0より大きい画素の最下行は3枚とも **115** です。

初期値は各100ms、合計 **300ms**。推奨調整範囲は合計250〜350ms。鎌を低い位置から抱える位置へ上げ、最後に既存のidle0へ移してください。光・煙・残像の描き足しはありません。Point/Nearest、ミップマップ無効を基本とします。

## 元のidleとの接続について

提供ZIPの待機は128×84、攻撃は192×128です。元idle0のalpha範囲は `(25,2)–(91,77)`（右・下は含まない）、最下行76。元idleのpivot情報はありません。

比較では足の中間から推定したidleの足元 `(60,77)` を `(99,116)` に置くため、元idleを **(+39,+39)** だけ移動しています。**idle0そのものの縮小・拡大はしていません。** これは比較用の推定で、実装先のpivotを調べて確定した値ではありません。

初期試作ではidle0の0.9倍比較を使いましたが、原寸へ戻る時の大きさの差を隠してしまうため最終比較には採用していません。最終3枚は低い攻撃姿勢から起き上がり、元idleの高さへ寄せています。独立確認では最後のコマの全体の見える高さは73px、元idleは75px。顔や髪・裾の画素には生成差があり、完全な原画一致や実機での無段差は保証しません。

## 生成と書き出し

原画を参照してimagegenで再生成しました。1536×1024の出力をNearestで192×128へ規格化。最終コマのみ、元idleの本体サイズに近づけるため足元を中心に1.10倍の一様な規格化を組み合わせています。プロンプトは `prompts.json`。

**alphaの閾値変更、マスクによる消去、描き足し、塗り替えはしていません。** 生成由来の非常に薄いalpha画素が残っていますが、3枚とも行116以降のalphaは全て0です。通常の合成で見える発光や煙はありません。生成画像は主にalpha252〜254で、元画像の二値alphaと完全には一致しません。必要に応じて実装側の表示で確認してください。
