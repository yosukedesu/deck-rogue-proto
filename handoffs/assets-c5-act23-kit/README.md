# C5 幕2・3の3D部品（16点）

**実モデルの納品です。ゲームへの配置・本番材質の接続は未実装です。**

- 枝: `codex/assets-c5-20261108`
- 16個の独立GLB（主形式）＋同じ16個のFBX（互換用）。各幕8点。
- 原本: `source/build_c5.py`、`source/act2_kit.blend`、`source/act3_kit.blend`。
- `manifest.json`: 実寸・原点・面数・材質・接続位置・取り込み状況。
- `previews/act2_catalog.png`・`act3_catalog.png`: **Blenderのスタジオ見本**。本番Godot画面ではありません。
- 同梱 `project.godot`: 独立Godotカタログ。1キーで幕2、2キーで幕3。GLBと標準PBR材質の見本で、本番ゲームの照明・霧・技の受光ではありません。

## 部品

幕2: 坑木の支柱／梁／筋交い／坑口／レール／巻上機／歩廊／木階段。

幕3: 古代柱／折れ柱／大アーチ／半アーチ／石階段／直線水路／曲がり水路／胸壁。

姿勢・形状・三角形・実寸は同梱manifestが正です。展示用の床・照明・カメラ・ラベルはGLB/FBXに入れていません。

## 座標と寸法

- 1 unit = 1 metre。GLBはY-up、床XZ、右X、前-Z。Blender原本はZ-up。
- 個別GLB/FBXの原点は**外接寸法の接地中央**、最下点Y=0。スケール1で使用。
- 梁・直線レール・直線水路はX方向へ接続。階段は-Zへ上がる。
- 半アーチは半分だけを個別に中心化しているため、大アーチの原点と同じではありません。
- 柱身寸法と台座・柱頭込みの外接寸法は異なります。たとえば古代柱は柱身幅0.85m、柱頭込み幅1.17m・高さ7.8mです。
- 通路のプレイヤー当たり判定・移動経路・物理衝突は付けていません。舞台の背景部品です。

## 決めた事

1. 「2幕×約8」を上記16点に分割。原文指定の主要部品をすべて含め、支柱/梁/レール/巻上機、柱/アーチ/階段/水路を中心にしています。
2. 長さ56/60mの既存レールは舞台全体の長さなので、長さ4m・軌間0.9mのつながる部品にしました。軌間1.0mへの拡縮は枕木まで歪むため、そのままXYZ一括拡大で変更しないでください。
3. 梁4m、歩廊3m、胸壁3.2mを繰り返す単位にしました。巻上機は既存2D小物と用途を合わせた新規3D形状です。
4. 水路は石の床・壁だけ。水面・反射・水shader・流体は含めません。直線と90度曲がりは外幅1.8m／内幅1.4mを共通にしました。
5. テクスチャは既存mainの6枚を**画素を変えずそのまま**使用。既存の木肌・暗鉄・古代石の粒に合わせ、新しい絵の生成や縮小で別の画風にしていません。元Git blobとSHA256は`source/texture_provenance.json`。
6. 新しい形状は原創作、既存ゲームからモデルを抜き出していません。PBRはroughness/metallicを持つ標準材質です。写真のような鏡面、苔一面貼り、焼き込んだ強い光は避けています。
7. 材質UVは原則25texel/m。GLBにNearest+Nearest mipmapを設定。近景/遠景の最終粒度は本番カメラで確認してください。
8. LOD・衝突・アニメーションは未作成。巻上機は静止部品です。Godotのインポート時LODは導入側の判断です。

## Claudeへの取り込み

1. 個別GLBをGodotプロジェクトの専用ディレクトリへ配置し、PackedSceneとして読み込みます。推奨候補は`res://assets/stage/act2_kit/`・`act3_kit/`。**既存の自動読み込み先と確定している訳ではありません。**
2. 旧Unity `CloudKitSetup`はGate/Pillar/Stair/Rockの固定名です。FBXを置くだけでは追加部品を取り込みません。Unity `.mat`もGodot材質へ直接移せません。
3. 確認できたGodot422は幕1だけGLB、幕2/3は`act<N>_layout.json`からprimitiveを生成します。モデル配置用の受け口と、既存block/rail/arch/pillarとの対応をClaude側で追加してください。
4. 既存の道yaw=-22度をモデル自体へ焼き込んでいません。ローカルで作った部品を配置時に回し、Godot/Unityの奥Z符号を二重変換しないでください。
5. 既存材質がGLBのStandardMaterialを独自shaderへ置換する場合はNearest・粗さ・metallic・アルベドの色空間を取り直します。GLB指定だけでは最終描画の粒度を保証しません。
6. キャラの座席帯・足元・意図の札・ボスの頭を塞がず配置し、幕1と旧舞台の見た目を変えないでください。
