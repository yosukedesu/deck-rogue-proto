## 決めた事

1. A1の文章の「待機8＋攻撃3＋防御1＋被弾1」を正本とした。表のファイル名例の攻撃4・防御4とは分け、互換セットの重複で対応する。
2. 黒いボブ、赤い短い外套、生成りの袖、真鍮、黒い長ズボン、赤褐色の靴、魔導書を維持。攻撃は魔導書を支えたまま空いた腕で術を放つ姿勢。炎の粒は別のVFXが出すため描かない。
3. 待機は胸・袖・本の角度・外套の小さな変化と6コマ目の瞬き。全身の平行移動で作っていない。足のちらつきを避けるため、待機だけ実寸PNGのy66〜83を待機0から固定した。
4. rawは要求した128×84の整数倍ではなく、生成器が返した大きなPNG。そのまま保存し、各セルのα128以上の外接矩形を取り、Nearestで指定背丈に縮小。足先下5行の左右中点をx60へ登録、最下行をy76へ置いた。スムージング・ディザは使わない。
5. 出力色の微差を止めるため、実寸のRGBを正本59色のRGB二乗距離の最短色へ写した。透明画素RGBは0にする。rawの色・αは変更しない。全処理の数値はJSONにある。
6. 推奨時間は待機125ms×8（1秒）、攻撃130/100/180ms、防御300ms、被弾220ms。攻撃の当たりはコマ1。**ゲームの実着弾時計を変更する依頼ではなく、素材の再生契約**。
7. コード・既存素材を上書きせず、エンジン非依存の包みとしてこのフォルダに置いた。取り込み時の最終選択・実機での同期は受け入れ側の作業。

## 使い方と現行Unity向け互換セット

推奨時間を扱える取り込み先には `Art/leaders/` を使う。
Point / sRGB / mipなし / 非圧縮 / NPOT無変換、pivotを上記で設定する。目標の取り込み先は `unity/Assets/Resources/Art/leaders/`。
既存 `.meta` のGUIDを無造作に入れ替えない。法線はこの束にはない。古い静止画用法線を新しい姿勢に自動適用しない。

**現行mainの `StageUnits.BindUnit` はこのmanifestを読む実装ではない。** コマを16枚まで名前順で拾うが、ひばな専用の時間表はない。単に正本3枚を写すと現行の4枚用の時間が当たり、推奨の当たり時刻にならない。
コードを変えず現行の既定時間に合わせる場合は、`Art/` と混ぜず **`compatibility/Art/leaders/` 全体を使う**。

| 種類 | 互換ファイルの中身 | 現行mainの既定時間 |
|---|---|---|
| idle 0〜7 | 正本idle 0〜7の写し | 250ms×8、計2秒（みぞれ専用の125msはひばなには適用されない） |
| attack 0〜3 | 正本attack 0,0,1,2 | 50/80/40/180ms、名目上130msで当たり姿勢 |
| block 0〜3 | 正本block 0を4回 | 60/80/100/200ms、計440ms |
| hurt 0〜2 | 正本hurt 0を3回 | 60/160/100ms、計320ms |

互換19ファイルは**13枚からの参照用複製**。別の19枚を描いたのではない。対応とSHA-256はmanifest内に明記。
実イベントの着弾同期、局所停止、カードごとの待ち時間を確認した保証はない。推奨時間と既定互換時間の違いは意図的に残している。
この束は新しい法線・発光・ソケットを追加しない。現在コードにある魔導書の固定発光位置は姿勢に追従する新規契約ではないので、実際に光らせる受け入れ時は別途確認する。

## 確認した範囲

全13コマを実寸と拡大で目視。予備→当たり→戻りの腕・胴・脚の変化、防御の本、被弾の後傾を確認。
待機の順番と7→0のつながりを並べて確認し、足先が全コマ同じことを画素で照合。APNGを再読込して各コマが元PNGと一致することを検査した。
128×84、最下不透明行76、α0/255、透明RGB0、正本59色内、13枚のハッシュが全て異なることを機械検査した。
生成原画のバイト列、切り出し座標、出力ハッシュを記録してある。
