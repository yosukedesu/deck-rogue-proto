# B7 独立視覚QA

2026-11-08。制作担当とは別の視覚確認で、コンタクトシート、原寸シート、10本のAPNGのフレーム数と時間を確認。

- 10種は原寸でも形・色・運動方向で識別でき、夜背景で主動作を読める。
- ドットのぼけ、フレーム端切れ、重大な作画破綻なし。
- 初回指摘: split / transform / rally の index 6 が中明度の輪のまま透明へ切り替わり、末尾が硬い。
- 対応: index 6 をそれぞれ暗い青緑／紫／真鍮に落とし、輪を部分的に消散。全素材とプレビューを再生成。
- 再確認: 透明終端へのつながりが改善、追加の修正指摘なし。
- APNG全10本は制作8コマ＋800msプレビュー休止。技術QAでも各コマ時間と制作PNGとの画素一致を確認。

**未検証:** 実ゲーム内の同期・遮蔽・新旧敵の差し替え、画面端への逃走、分裂後の配置。これらを素材だけの確認から合格とみなさない。
