## 決めたこと

- 夜硝子の舞台と真鍮の細線。B1〜B6共通パレットに沿い、塵・殻は銀青、分裂・回復は青緑、変身・山札喰いは紫、激昂は赤。盗みは袋、応援は太鼓で意味を分けました。
- 山札喰いの札も暗い青＋真鍮枠。紙・クリーム色・太い墨線は使いません。数字・札の文字は焼き込みません。
- 敵本体は描き替えません。PNGは局所VFXのみ。本体を消す・逃がす・新しい姿に替える処理は `trigger_contract.sprite_sync` の同期案を取り込み側で実装してください。PNGだけで敵が移動・分裂・変身するわけではありません。
- 共通64px枠は元絵の枠と独立。敵に合わせて画像を押し縮めず、同じ論理ピクセル縮尺で重ねます。大きい敵は整数倍または局所への配置で扱い、足元アンカーを一致させます。

## 取り込み時の重要な区別

1. **崩壊／分裂／残機変身**は同一の退場で重ねて3つ流しません。確定した `EnemySplit` がある場合、count>1 は分裂、count==1 の残機連鎖は変身を優先。生成先の実体はゲーム側の確定結果を使います。分裂画像の二方向は記号表現であり、2体固定の仕様ではありません。
2. **盗み**は `GoldStolen` amount>0 の確定時に1回。現行エンジンでは宣言時に盗みが成立します。後のsteal-gold行動で再びお金を移動／減算しないでください。袋は局所の知らせで、画面を横切る送金演出ではありません。
3. **逃走**は確定した `EnemyFled` のときだけ。本体を退場方向へ移動し、土煙は元の足元に固定。左向きなら画像と移動xを同時に反転。打ち消し・予告・単なるHP0から逃走を推測しません。
4. **孵化**は `EnemyHatched` の確定後、index 2で旧姿から新姿へ。**変身**はindex 3で旧姿を隠し、4で確定した後継を出す案。実際の提示タイミングがあればそちらを優先。中断しても旧姿や死亡個体を復活させません。
5. **応援**は解決したrallyの出どころに太鼓を1つ。受けた敵それぞれの `StrengthGained` を独立した応援と解釈しません。単なるbuff、攻撃併用の強化、激昂と区別します。対象の淡い点灯は実際に強化された敵のみです。
6. **回復**は `EnemyHealed.targetIndex` に置きます。enemyIndexは回復役なので取り違え注意。amount=0では再生せず、`presentationReceipt` があればそのタイミングを使用。
7. **山札喰い**は解決した敵millの出どころと `CardsMilled` を関連付けます。`CardsMilled` 単独には敵IDがなく、プレイヤーのmillでも出るため単独判定は禁止。出どころを確定できない場合はこの敵演出を省略。札1枚の絵は記号であり、実際に食べた枚数ではありません。
8. **激昂**は `StrengthGained.reason` が enrage-cards / enrage-damage / enrage-phase の場合。mourn、rally、通常buff、山札喰いによる筋力増加には流しません。
9. **通常alpha合成・NEAREST・mipmapなし・トリムなし・回転なし**。数値・ラベル・札・ツールチップより後ろへ。既存の同種演出は差し替え、二重表示しません。終了・画面破棄・中断で一時VFXを除去。音はこの束には含めません。
10. 動きを減らす設定では移動／マスクを省き、短い局所表示だけで構いません。ゲーム進行を画像時間で止めず、ダメージ・枚数・金額・状態変化は常に確定したゲーム処理を正とします。
