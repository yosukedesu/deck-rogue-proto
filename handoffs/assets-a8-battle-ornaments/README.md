# A8 ボス登場・勝敗の飾り

2026-11-08。夜硝子と真鍮のUI用、**原寸格子へ直接描いた透明RGBA PNG 6点**です。紙・クリーム色の面・太い墨線・文字・背景板は含みません。旧「敗北の墨の滲み」は最新方針に従って**割れた夜硝子の紋**へ変更しました。互換のためファイル名 `lose_ink.png` だけ残しています。

## 配置と取り込み

共通: PNGの枠・透明余白を維持、Nearest/Point、mipmapなし、通常のアルファ合成。表示は原寸か整数倍を推奨。横だけ引き延ばさないでください。透明画素はRGBA (0,0,0,0)、可視画素はalpha 255です。半透明のぼかし・発光は焼き込んでいません。

### 名前の帯

- 左右の飾りはそれぞれ64×48。帯の内側端に置き、縦中心を揃えます。本文との空きは8論理px以上。文字は別UI要素のままです。
- 参照mainの `Presenter.NameBandH` は幕ボスでスマホ54、PC62。原寸48pxの絵を入れると上下余白はそれぞれ3/7pxになります。帯の高さを変える必要はありません。
- 元コードの上下レールは別UI要素です。この飾りの線と自動でぴったり連結するとは想定していません。帯幅に応じて飾りを両端に置き、中央の文字領域を確保してください。
- 狭い幅で左右飾り＋本文が衝突する場合、本文幅を測って飾りを隠すか端側へ移動。絵を潰して縮める実装は避けてください。

### 勝敗の紋

- どちらも96×96・pivot (48,48)。勝敗の文字の上、または横に置き、文字と12論理px以上離します。字の背面には重ねません。
- 勝利は閉じた星と月桂樹、敗北は開いた割れ目と下へ落ちる破片で、色だけに頼らず区別します。
- 敗北は暗い青のガラス面と青灰の割れ縁に少量の鈍い赤。真っ黒な染みやクリーム地は使いません。
- 暗板 `#0f1120` / `#20233a` / `#2c3d4b` 上で原寸確認。これは参照パレットの試験背景で、未入手の11/05追補の全トークンとの一致を主張するものではありません。

### 花びら・火の粉

- 左からindex 0〜7、各32×32、pivot (16,16)。セルを自動トリミングしないでください。1枚のコマに1粒だけ描いてあります。
- 花びら: 各90ms、計720ms、ループ可。0→7→0で回転を継続。1回だけ使っても構いません。
- 火の粉: `[70,70,80,80,90,90,100,100]` ms、計680ms、**非ループ**。index 7の後は非表示にしてください。最後に少量の暗い画素が残るのは、コマ切替後に消す契約です。
- 移動・風・落下・出現位置・個数は実装側。絵自体には移動を焼き込まず、固定pivotのまま回転／冷却します。目安は1回4〜12粒で、文字や操作部分を覆わない配置。花びらと火の粉の同時大量散布は不要です。
- `previews/particles.apng` は同じ推奨時間で再生する確認用。花びらは2周、火の粉は1回＋休止を繰り返します。ゲーム素材はAPNGではなく2本のPNGシートです。

## 再現

Python 3 / Pillow / DejaVu Sans（見本の説明文だけに使用）が必要です。

```sh
python source/draw_ornaments.py
python source/verify.py
```

本体素材6点のバイト一致を検証します。再生成後にレビュー記録を更新した場合、最後に `source/checksums.py` を実行してください。
