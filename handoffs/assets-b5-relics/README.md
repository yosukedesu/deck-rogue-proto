## 今回決めたこと

- 夜硝子の暗い板に、細い真鍮の輪とごく小さい青緑の反射。紙・クリーム色・太い墨線は使いません。B1〜B4 と同じパレットです。
- B5 の寸法が未指定だったため、既存の 32×32 遺物に対し **64×64 の透明オーバーレイ**としました。中心 (32,32)。輪は遺物の外側で、兆し→点灯→鎮まる、の一往復です。
- **中央34×34を完全に空けています。** 32×32 の遺物が左右1 px 揺れても輪に覆われません。最終 index 7 は完全透明です。既存の遺物絵は変更・同梱していません。
- 数字の板は文字を焼かず、内側の `(4,3,16,8)` を数字用に空けました。右下への配置例を manifest に記載。1〜2桁を中央配置し、収まらない時は `99+` と全文ツールチップ等で対応してください。正確な値はゲーム側を正とします。

## 取り込みメモ

1. `manifest.json` の矩形と時間で index 0→7 を1回再生。時間は **60 / 55 / 65 / 80 / 80 / 75 / 70 / 65 ms**。NEAREST、ミップマップなし、通常 alpha 合成、トリミングなし。
2. **64×64 の輪を32×32の絵の枠へ縮めない**でください。遺物絵と同じ論理ピクセル縮尺で中央を合わせ、全ての遺物絵より後ろ、数字・ツールチップより後ろへ。列の狭い各セルで輪を切らず、画面端では表示範囲を調整します。既存 PC の42 px間隔を想定した密集プレビュー付きです。
3. **輪の PNG 自体には遺物絵の揺れ・色変化は入っていません。** manifest の `icon_offset_px` と `icon_warm_mix_weight` を、その遺物絵だけへ同期する見せ方を提案しています。振幅は ±1 px、色は真鍮色への小さい混合。輪・数字・当たり判定・隣のアイコンは動かしません。終了・途中キャンセル・画面破棄では必ず元の座標と色へ戻します。
4. 点灯板は index 2〜3 の合計145 msだけ使い、その後は通常板へ。数字の更新はアニメーションから推測せず、ゲーム側の確定値を表示。カウンターを持たない遺物には板を出しません。数字0とカウンターなしを混同しないでください。
5. **確認できた main には、全遺物を一律に識別できる汎用の発動通知がありません。** 現在の実装で「どの遺物が実際に発動したか」を確定できる箇所から呼び出す、エンジン非依存の契約にしています。HP・ブロック変化だけで推測しない、出所が未解決の通知で全遺物を光らせない。残数表示の更新だけも、発動とは限りません。
6. 1回の発動から複数効果が出ても輪は1回。同じ遺物の再発動中は重ね置きせず、実装側で1回だけ再始動またはキュー制御。隠れた遺物の位置が取れなければ輪は省略し、一覧の `+N` をその遺物に見立てて光らせません。光った回数を消費回数として扱わないでください。
7. 動きを減らす設定では絵の揺れを省略し、短い板の点灯だけでも可。画面揺れ・SE・ゲーム側処理は追加していません。既存SEの二重再生も不要です。
