## 判定根拠

1. 真鍮の細い分割輪が弱い予備から伸び、index 2〜3 で明るくなり、縮退・消灯する。夜硝子の暗色上で輪郭を読み取れる。紙面・クリーム地・太い墨線はない。
2. 64×64 内に収まり、最大の有色範囲でも全方向 6 px 以上の透明余白がある。index 7 は完全透明。全コマで中央 `[15,15,49,49)` の 34×34 は完全透明で、32×32 の元絵と ±1 px の揺れを妨げない。
3. 元の遺物画像は維持され、輪が発動を補助する。私的な既存遺物 2 種との比較でも本体の形が隠れない。ダミーの短い明色化も白飛びせず、終了時に元色へ戻る。
4. 数字の板は固定され、揺れる本体と分離されている。24×14 の角落とし・1 px の縁・暗い中央面は、確認した数字例と整合する。数字は production には焼き込まれていない。実際の UI フォントでの桁収まりは取り込み時の確認対象。
5. 改訂後の 42 px 間隔・ダミー本体 5 個・数字板 5 枚の密集比較を再確認。中央のみが発動する例で、輪全体に切れはなく、隣の本体や数字を隠さない。板同士にも隙間があり、全 5 個の数字を読み取れる。輪の下側と中央の板が重なる部分は板が前に出て数字を保護している。これは提示された模擬配置の確認であり、実 UI のフォント・同時発動・画面端・ツールチップとの重なりは引き続き未検証。
6. シートは 512×64 RGBA、8 コマ、alpha は 0 / 255。板は各 24×14 RGBA、外周 1 px の透明余白。APNG の本番時間は `[60,55,65,80,80,75,70,65]` ms、合計 550 ms。前後の 500 / 900 ms はプレビュー専用停止。

## 実装時に残る確認

輪は全ての遺物本体と数字板より下に合成し、ツールチップより下に置く。元絵のみを揺らし、板の文字まで揺らさない。新規の汎用発動イベントが実装済みであるとは本レビューでは認定しない。1 倍・整数倍率・NEAREST を基本とし、実 UI の配置とスマホ縮尺で最終確認する。
