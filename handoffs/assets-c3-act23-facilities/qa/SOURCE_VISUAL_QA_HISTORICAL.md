## 判定

**6 枚とも生成原本候補として採用可。画像自体に、候補保存を止める重大な破綻は見つからない。ただし C3 完了・ゲームへそのまま取り込み可能とは判定しない。**

- 全 6 枚の実ファイルを `view_image` で目視した。比較用の既存 `bd_campfire.png`・`bd_shop.png`・`bd_workshop.png` も目視した。
- `docs/world.md` の「幕の舞台」と光のルールを読んだ。幕2の坑道・宿場跡、幕3の地下古代都市、暖色は灯の範囲だけ、という区別におおむね合う。
- Pillow による読み取りで、全 6 枚 **1676×938 / RGB** と確認した。要求 **400×224** は未達。今回の QA では画像のリサイズ・切り抜き・再保存・画素変更を一切していない。
- **実ゲーム、400×224 実寸 PNG、Unity の import/filter 設定、スマートフォン上の視認性は未検証。** 小サイズへの適性は大きなシルエットからの推定にとどまる。

## 既存 3 枚との比較

- 施設を示す記号は維持されている。焚火＝中央の火と席、店＝庇と陳列台、工房＝作業台と右側の炉・金床。6 枚内部のテイストも揃っている。
- 夜の寒色、少数の暖かな灯、木・石・真鍮という材質の使い分けは既存と連続している。紙の背景、クリーム色 UI 面、文字・札・人物は見当たらない。
- **ドットの粒度は同一ではない。** 既存は 400×224 の粗い画素単位で構成され、新作原本は約 4.19 倍の横解像度で小さな階段状輪郭と滑らかな陰影を含む。新作は高解像度のピクセル調イラストであり、「既存と同じネイティブドット」とは呼べない。
- 新作は既存の焚火・店より環境が豊かで、施設が画面内を占める割合もやや大きい。幕の違いは伝わる一方、最終画面の帯・余白・UI との同居はまだ保証できない。
- 大きな輪郭が明快なため縮小後も施設識別は残りそうだが、工具の隙間、瓶、レール、発光線の潰れ方は未確認。**単に寸法を合わせるだけで既存粒度との整合まで保証できるとは限らない。**

## 最終素材にする前の必須項目

1. 許可された方法で 400×224 の最終 PNG を用意し、サイズを実測する。
2. その最終 PNG を既存場面と同じ表示倍率で並べ、粒度・明度・物の大きさを再評価する。
3. 実ゲームの帯内で UI、文字、画面端と競合しないことを確認する。
4. README と manifest で原本候補と実寸完成品を区別し、今回を実ゲーム検証済みと書かない。
