# C3 / C4 指定サイズ化の独立視覚 QA

2026-11-08。素材生成・サイズ調整担当とは別のレビュー担当による静止画 QA。

## 結論

**9 枚とも BOX による 400×224 縮小を採用することを推奨。再生成を必須とする視覚的破綻は見つからない。**

各画像を左 NEAREST / 中 BOX / 右 LANCZOS、1 枚あたり 400×224 の比較画像で確認し、生成原本 9 枚と既存参考 4 枚も目視した。画像編集・素材再保存・公開はこの QA では行っていない。

- BOX は特に細い線路・木目・金具のまだらな点を抑え、400×224 で物の識別を維持する。
- NEAREST は高解像度原本の色をそのまま選べる一方、非整数縮小で細線の太さ・明るさが揺れる。幕2表紙の金色のレール縁で顕著。既存ドット絵の一貫した線とは異なるので、これを「ドットの忠実保持」と評価しない。
- LANCZOS は輪郭が少し強いが、今回の原寸では BOX より有意な識別性向上が見られない。統一した簡素な BOX が妥当。
- **これは生成イラストの指定サイズ化。既存と同じ低色数・手打ちネイティブドットになったとは判定しない。** 既存は大きな平面と少数色、新作は細部・陰影が多い。縮小だけではこの差は消えない。原寸で読みやすく、色と材質・世界観は連続している。

## 未検証・取り込み先の確認

- Unity / Godot への取り込み、実ゲーム描画、スマートフォン実機は未検証。
- 題字オーバーレイ、追加暗幕、画面比率による cover クロップ、UI との重なりは未検証。
- 極端な横長画面では上下が切れ、C4 の道・線路・機械基部が欠ける可能性がある。400×224 全景を見せる表示を第一候補にする。
- フィルタや色変換を二重にかけず、完成画像をまず等倍で取り込む。既存と同一の手打ちドット粒度を必要とする場合は別の作画工程が必要で、縮小完了をその保証にしない。

- `c4_final_20261108/handoff/qa/contactsheet_native.png`

**最終 BOX 画像 9 枚の静止画品質を承認。** 上述の比較候補から意図しない構図・色・内容の変更は目視上なく、C3 の焚火・店・工房、および C4 の各幕を原寸表示で区別できる。画像内に追加題字が焼き込まれたのは proof のみで、無題字の連絡シートは保持されている。

題字 proof は、幕番号・日本語幕名・真鍮の細線と 20% の夜色スクリーンを重ねた **静的な配置テスト**。25:14 原寸、16:9 cover、20:9 cover の 3 比率 × 3 幕を確認した。

- 9 ケースすべてで幕番号・幕名を読める。最長の「埋もれた古代都市」も機械や街灯に埋もれず、見切れていない。
- 細い真鍮罫は目立ちすぎず、紙色の板や太い墨枠はない。20% スクリーンを通した背景でも森・坑道・地下都市の差は維持。
- 16:9 では重大なランドマーク欠落なし。20:9 では上下が狭くなり、幕1の手前の石段、幕2の手前線路、幕3の石畳と機械基部の一部が切れる。ただし、この proof では坑口・トロッコ・線路の曲がり・大歯車と掘削アームが残り、幕の識別や題字の可読性を損なうほどではない。
- 表紙の全景を優先する場合は contain/余白付き表示が安全。20:9 cover はこの静的条件では許容可能だが、さらに横長・別位置のクロップまで保証しない。

この追加確認により「日本語題字と罫を重ねた静的比較は未実施」という前段の項目を更新する。**実ゲームのフォント・暗幕・アニメーション・端末表示そのものを再現または検証したものではない。** Unity/Godot 取り込み、ゲーム内切替、スマートフォン実機は引き続き未検証。素材技術検査の 27 件通過は制作担当の報告として受領し、この視覚 QA と区別する。
