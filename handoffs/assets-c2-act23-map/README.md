# C2 幕2・3の地図部品：夜硝子と真鍮

2026-11-08。幕2「先代の坑道」・幕3「埋もれた古代都市」の地図素材です。

**新作24枚＋A3の共通節8枚を無改変再利用、取り込みPNGは合計32枚。** 原寸の整数座標へ直接描いたドット絵です。大きい生成画像を縮めたものではありません。ゲーム本体への取り込み・動作確認はこの束に含めません。

## 内容

- `png/`: 最終32PNG。ここだけが画像の取り込み対象です。
- `manifest.json`: 実寸、原点、用途、幕、ボス遭遇ID、推奨配置先、SHA-256、再利用元。
- `source/`: 24枚の再現可能な原寸描画ソース、検査・一覧作成コード、由来。
- `qa/`: 原寸・2倍一覧、明暗背景、タイル混在反復、地図の仮組、検査結果。
- `references/`: 既存舞台4点の無改変参照コピー。**取り込まないでください。**

## 決めたこと

1. 「各幕約12枚」は、地面2＋道1＋環境小物5＋出発点1＋ボス目的地3の12枚にしました。各幕のボス3種を省略しません。節8種はA3と同じ意味・同じ絵を使い、幕が変わるたびに機能を覚え直さずに済む形です。
2. 全てネイティブサイズの格子へ整数座標で直接描画。ぼかし・アンチエイリアス・縮小変換なし。拡大プレビューだけNearestの整数倍です。
3. 最新の「夜硝子と真鍮」を採用。紺～鋼青の影、古い木・石・鉄、局所的な真鍮、左上の光。紙台紙・クリームの下地・太い墨線は使いません。幕2は提灯、幕3は小さな脈の青緑と炉の火に光を限定しました。
4. 公開mainに11月5日のテーマ追補はなく、最新UIの正確な共通色番号は照合できていません。この束はA3の描画色と最新指示に合わせた制作値です。
5. 地図は部品で組みます。固定サイズの完成地図画像、文字、主人公、敵本体、選択輪、経路の点線は描いていません。旧960×1042の一枚絵案は採用していません。
6. 出発点とボスの顔は小さな建物・巣として描き分けます。小物の軌道は装飾用の短い線路で、クリックできる進路線の代用ではありません。
7. `actN_` の新名で分離しました。既存の共通 `map_mine_gate` / `map_cart` を無言で置き換えません。

## 取り込み規格

- 全32枚RGBA。タイル6枚は不透明、透明小物・大駒・節は二値αです。
- Point / Nearest。タイルはRepeat、その他はClamp。sRGB。画像をフレームごとに切り詰めないでください。
- 大駒96×96の原点は、**左上原点の画素境界(48,92)**。最下不透明行は91。小物は(width/2,height−4)、下4行が透明です。
- 共通節は中心(24,24)。これは本素材の座標規約で、Unity側の実際のpivotへは変換が必要です。
- 地面2種は左右・上下およびa/b相互で端が一致します。大きく敷くと反復周期は存在するので、2種を混ぜて使ってください。単一タイルが無限に非反復になるという意味ではありません。
- 64pxタイル・48px節・96px大駒を同じ倍率と決め打ちせず、幕1の地図と同じ粒・読める大きさを取り込み側で指定してください。

## Claude側で必要な接続

参照した実装はmain `114ee430310c5a2df02ea048f23d1f8375c22c66`（2026-11-04）です。

1. 新しい `Art/map/act<N>_*` はまだ読まれません。manifestの用途を見て幕別の読み込みを追加してください。この素材を置くだけで自動反映される形ではありません。
2. `MapForest.Ground` は幕2の `top_earth_a/b`、幕3の `top_floor_seat_a..d` を選びます。一方、幕2/3の `top_path_*` がないので道は幕1へフォールバックします。新しい地面・道の参照を切り替えてください。
3. 新しい絵は**既に夜の色へ整えたsRGB**です。旧 `MapForest.Grade` や `DirtState` の夜色焼き込みを重ねて黒く沈めないよう、まず未加工で確認してください。進路の状態変化はコード側で行い、素材そのものへ固定しません。
4. 上の門・下の荷車・「森の入口」ラベルは旧実装で幕共通です。出発点とボス遭遇ごとの目的地へ切り替えてください。
5. 旧 `Forest` は幕2/3の小物配置をスキップします。新しい支柱・立坑・塔などは道と節を避け、空き列や両脇へ置いてください。小物の線路が「進める道」に見えないことも確認してください。
6. 節は全幕共通の `node_*` にA3を使えます。旧表示枠は通常52・ボス84画面単位なので、48px画像の表示倍率、選択円、タップ範囲を明示してください。

`qa/actN_assembly_study.png` は素材の仮組です。経路・円盤を簡略に描いた検品用画像で、Unityの画面でも実装済みの証拠でもありません。

## 検証と限界

`source/verify.py` は32枚の寸法・RGBA・二値α・透明余白・原点・SHA、6タイルの対向辺、2種の混在辺、6ボスID、共通節の原本一致、新作24枚のソース再描画一致を検査します。335項目が合格、結果は `qa/validation.json`。独立検査282項目も合格。独立した視覚レビューで指摘された地面の反復模様は低コントラスト化して再確認済みです。`qa/independent_review.*` に記録しています。

**未実施**: Unityへの取り込み、実際の地図読み込み、全ラン種の重なり、クリック領域、選択・明滅、Android実機、プレイ検証。立ち絵・BGM・キービジュアル・`src/engine`・`src/data`・Unityコードは変更していません。

Python 3とPillowが必要です。新作24枚は画像入力なしで再現します。共通節8枚はA3の原本をそのまま保持してください。

```sh
python source/draw_tiles.py /tmp/c2-redraw
python source/draw_act2.py /tmp/c2-redraw
python source/draw_act3.py /tmp/c2-redraw
python source/verify.py
python source/build_qa.py
```
