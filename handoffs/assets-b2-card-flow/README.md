## 今回決めた規格

B2 は一覧でサイズ未指定のため、縦長の札を覆える 64×96 とした。基準札は 40×60、セル内 `[12,18,40,60]`、中心アンカー **(32,48)**。アンカーはドローでは到着側のカード中心、その他は出発時点のカード中心。単一の論理ピクセル縮尺で合わせ、横・縦を別々に伸ばさない。

- 本物のネイティブピクセル。最終解像度の整数座標で直接描画。大画像の縮小・画像生成モデル・画像素材の切り貼りを使っていない。
- B1/A6/A8 と同じ限定色。夜硝子の暗色、真鍮の細線、青鋼の筋。炎のみ朱〜琥珀色。紙・クリーム色・太い墨線なし。
- 一覧の「紙が舞う」は**夜色の札がひるがえる**へ翻訳。捨てるは冷たい弧と折れ片、失効は砂時計が尽きて落ちる、消滅は札を上へ燃やし切る、くべるは下の受け火へ札を投入。行き先と意味を混同しない。
- alpha は 0/255。透明ピクセル RGB は 0。NEAREST、ミップマップなし、通常 alpha 合成、トリミングなし。加算合成やぼかしは不要。

## 取り込み

1. 実際のカードを下、該当する VFX を上に重ねる。**PNG にカード本体は入っていない。** プレビュー中の札は説明用の新規ダミーで、取り込み対象ではない。
2. 各コマの矩形・開始時刻・時間は `manifest.json`。カード本体の推奨 offset / scale / 回転 / opacity も各コマに収録。演出用のローカル移動量であって、実際の山札・捨て札の座標ではない。山札・捨て札の場所は現在の UI から求める。
3. **VFX のアンカーは固定**。動くカードの子にして一緒に回転・移動すると、筋や炎の位置が二重に移動してしまう。カード本体の動きとオーバーレイの動きを分ける。
4. 消滅はカード alpha に同じコマの保持マスク alpha を乗算する。マスクは上側の未燃焼部分を保持し、index 6/7 で空になる。元のカード形状の alpha も維持する。マスクを使えない場合は manifest の opacity fallback で札を薄くできるが、プレビューの「燃え進む切り口」までは再現しない。
5. `CardsDrawn` の `cards[]` が得られる場合は新たに入る札にだけ適用。枚数だけの通知では UI 側の新規カード実体に対応させる。カード全体の描き直しや、複数通知での重複再生はしない。
6. **`ImpulseReturned` は失効して捨て札へ戻る通知。消滅ではない。** `ImpulseKept` は保持された札なので失効演出を出さない。同じ移動の通常 discard 通知があれば失効側を 1 回だけ出す。
7. **`ImpulseKindled.cardIds[]` が燃料の札。`cardId` は追加コストを払ってプレイした札。** 同一演出処理内で同じカード実体に `CardExhausted` も届く場合、くべるを優先し、通常の消滅を二重再生しない。他の消滅まで抑止しない。現行の通知／カード実体 ID の具体的な対応は実装側で確認する。

## プレビュー・検証

- `previews/card_flow_contactsheet.png`: 2 倍 NEAREST、5 種×8 コマ。各コマ時間と移動先付き。
- `previews/card_flow_native.png`: **等倍**の透過 VFX を 2 種の夜色背景に重ねた比較。
- `previews/card_flow_playback.png`: APNG、5 種を順に再生。各演出のコマ時間は manifest と同一。各演出の冒頭 350 ms と最後 700 ms の確認用停止のみ追加。短すぎる APNG コマがビューアで引き延ばされないよう、5 種同時の時間境界合成はしていない。APNG が静止表示になるビューアでは contactsheet を参照。
- `qa/verification.json`: 画素規格・色・alpha・全コマ矩形と時間・終端透明・マスク・再生成一致・APNG デコード照合。
- `qa/visual_review.md`: 別担当による等倍／拡大／再生確認。

プレビューの札の透明度・回転・縮尺は、上記の推奨値を模擬したもの。**PNG 単独を再生しただけで、ゲームのカード本体が勝手に移動・消滅するものではない。**
