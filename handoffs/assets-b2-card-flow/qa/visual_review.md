# B2 独立視覚レビュー

- レビュー日: 2026-11-08
- 担当: 制作担当と別の QA サブエージェント
- 対象: `Art/fx/` 6 PNG、README、manifest、等倍／拡大 contactsheet、APNG のデコード時系列
- 判定: **アート／仕様整合／修正後 APNG のフレーム時間は合格。実ゲーム組み込みは未検証。**

## 実際に確認した方法

`card_flow_native.png` を等倍で、`card_flow_contactsheet.png` を拡大で閲覧。修正後の `card_flow_playback.png` を Pillow で 50 フレームすべてデコードし、各フレームの duration を独立取得した。5 種それぞれの開始・中盤・火の粉／終盤・終了 hold の合計 20 時点を並べた画像で視認し、各効果の 8 コマ全体は contactsheet と照合した。制作描画関数は呼び出さず、完成 PNG を読み取って検査した。

## 観察結果

- **消滅**: 札の下から上へ燃焼線が進み、最後に火の粉だけとなって透明になる。保持マスクで実札を消す必要が明記されており、単なる炎の重ね合わせとは区別されている。
- **捨てる**: 冷たい弧、薄い折れ片、札の横縮みと傾きでひるがえりが読める。燃焼・破壊には見えない。終盤は目立たず消える。
- **ドロー**: 左下から右上へ進む青緑の筋と着地時の角飾りが、退場する札と反対方向に読める。終端は VFX のみが消え、札は残る。
- **衝動失効**: 初動の真鍮色砂時計が時間切れの識別点。砂時計が途切れ、札は暗くなって下へ抜ける。炎なし。manifest の `ImpulseReturned` → `discard`、README の「消滅ではない」は適切。`ImpulseKept` 除外も明記。
- **くべる**: 札そのものが下の炎へ縮小投入され、炎のピークが後から来る。消滅の「燃焼線が上がる」と判別可能。対象は `ImpulseKindled.cardIds[]`、`cardId` は支払い側という記載が正しい。通常消滅との重複抑止も同一処理・同じカードに限定されている。
- **テーマ**: 両方の夜色背景で線・形が見える。真鍮は細線で使われ、紙色・クリーム色・太い黒輪郭・ぼかしは見当たらない。暗い札本体の主役を奪わない抑えた量。
- **枠**: 元アトラスから全 8 セルの不透明 bounding box を独立取得。VFX はセル外へはみ出さず、境界の切り落としは見えない。ドロー初動は x=1、失効末期は最下 y=94 と端に近いが、1 px の余白が残る。トリミング禁止の指定を維持すること。
- **終端**: 5 演出とも index 7 は透明。消滅保持マスクは index 6/7 が透明。プレビューでも最後に残る札はドローだけで、意図と一致。
- **時間**: 本体 520〜630 ms、1 コマ 45〜95 ms の設定は短い UI 演出として妥当。各演出の待機確認用 350 ms／終了 hold 700 ms は production timing と分離されている。

## APNG 修正確認

初稿の並列版には 5 ms／10 ms のフレームがあり、ビューアの遅延補正で設定時間より遅くなる懸念を制作担当へ伝えた。制作担当は **5 種を順に再生する版**へ修正。再デコードし、各 10 フレームのまとまりが `350 ms ready → manifest と一致する 8 コマ → 700 ms hold` であること、最短 duration が 45 ms であることを確認した。初稿の短すぎるフレーム問題は解消済み。終了した演出は消え、ドロー札だけが残る累積プレビューも正常。

全体は 8,140 ms（演出合計 2,890 ms + 確認用停止 5,250 ms）。**デコードした時系列の検査であり、ゲームまたは特定ブラウザのリアルタイム性能保証ではない。**

## 未確認範囲

現行ゲーム画面、実際の札のサイズ／形状／UI の山札位置、同時発火時の視認性、Godot・Unity のフィルタ設定、イベントとカード実体 ID の結び付けは確認していない。PNG のみではカード本体が動かないため、README のレイヤー分離と manifest の本体姿勢指定を実装側で適用する必要がある。
