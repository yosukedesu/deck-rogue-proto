# C1 幕2・幕3の遠景3層ずつ

**実寸素材6枚は納品可能。ゲームへの取り込み・GPU/Android確認・GitHub公開は未完です。**

`assets/act2/` と `assets/act3/` の `far_0.png`〜`far_2.png` が取り込み対象です。すべて **960×270 RGBA**、横方向の周期は **960px**。far 0 は不透明の基底、far 1・2 は本物の透明層です。`source/` は制作記録であり取り込み対象ではありません。

## 中身と重ね順

| 幕 | far 0 / 奥 | far 1 / 中 | far 2 / 手前 |
|---|---|---|---|
| 2 先代の坑道 | 岩天井と青灰の坑内霞 | 坑木の支柱・小さな暖色灯 | 薄い青灰の霧 |
| 3 埋もれた古代都市 | 天蓋・暗い青緑の地平 | 崩れた遠い街並み | 塔影・水道橋 |

目標パスは `Art/stage/act2/far_0.png` 等です。`manifest.json` に全6枚のSHA-256、パス、画素数、alpha、順序、周期、推奨opacityと視差係数を記載。

## Claudeへの取り込み要点

- 描画順は **far 0 → far 1 → far 2 → 既存3D地形**。3層の原点・高さ・スケールを合わせる。
- 横はrepeat、縦はrepeatしない。全層同じ高さ270、横周期960を使う。透明PNGは通常の **source-over / straight alpha**。additive、screen、乗算、二重premultiplyはしない。
- 推奨opacityは幕2 **[1, 0.65, 0.18]**、幕3 **[1, 0.55, 0.82]**。PNGそのものにはこのopacityを焼き込んでいません。とくに幕2の霧をopacity 1で重ねない。
- 推奨視差係数は両幕とも **[0.04, 0.12, 0.21]**。カメラが右へ動いたら背景は左へ。`x = -(camera_x * factor) mod 960`を基準にできます。
- 画像座標 **y >= 248** の範囲は不透明な舞台地形の後ろへ隠す。とくに幕3の建築基部の水平な切れ目を露出させない。`qa` の暗い水平帯は、この条件を検査するためだけの仮遮蔽物で、納品PNGや本番地形には含みません。
- linearフィルタを確認用の初期値にしています。ここでの絵は**生成原画を整形したHD2Dのドット調**で、1ドットずつ手打ちした低解像度絵ではありません。キャラのドット規格と同一だとは表記しない。
- 実機では地形・UI・戦闘キャラと重ね、基部の遮蔽、地平の高さ、遠景の明るさを最後に確認してください。今回はゲームコードを変更していません。

## 今回決めたこと・修正

1. ユーザーの「サイズ調整とC1の継ぎ目修正をプログラムで実施してよい」という承諾に基づき整形。
2. 生成原画2172×724を直接960×270へ引き伸ばさず、全層共通の原画範囲 `(0, 48, 2172, 658.875)` を使い、縦横とも `960/2172` の同じ倍率で縮小。天井と下の余白だけを整理し、支柱・塔は縦につぶしていません。
3. premultiplied-alphaのLanczos縮小で透明縁を処理し、保存はstraight-alpha RGBA。alpha 0のRGBのみ0にして隠れ色の縁汚れを防止。
4. 不透明2層の左右16pxだけをコサイン重みで微小補正。中央928pxは縮小結果から変更なし。RGBの最大修正は幕2 **2/255**、幕3 **3/255**。左右の最外列は全RGBAが完全一致。4透明層は左右最外列alpha=0。
5. **実寸合成で旧霧が黒い帯になることを発見したため、霧だけimagegenで生成修正。** 淡い青灰の透明霧へ直し、opacity 0.18で静かな霞にしました。プログラムで色を書き換えたものではありません。旧6原本は無改変のまま保持し、修正版を`source/raw/act2/far_2_source_v2.png`へ分離。
6. 元の素材と同じ幕の色設計を維持。暖色は幕2の小さな灯のみ。幕3は紺・暗い青緑。プレビューのUIだけ「夜硝子と真鍮」に合わせています。

## 再生成

Python 3、Pillow 13.0.0、numpy、ffmpegが必要。

```sh
python3 tools/build_assets.py
python3 tools/render_qa.py
python3 tools/validate.py
python3 tools/build_delivery.py
```

原画は無編集で保存済み。生成プロンプトを`source/prompts/`へ同梱。旧候補のmanifestは`source/source_manifest.json`に履歴として保存され、最終結果はルートのmanifestが正です。
