## 幾何＋gdshader＋絵

- `Geometry/enemy_<属性>_contact.json`: 不透明な画素の横方向連続区間に沿う、添字付き三角形メッシュ。全8コマの位置・UV・添字を保持。
- `godot/enemy_contact.gdshader`: nearest・sRGB・通常alpha合成の独立マテリアル。時計やゲームルールを持ちません。
- `godot/enemy_contact_sampler.gd`: 外部から渡した接触後ageによりメッシュを選択する独立サンプラー。
- `Art/fx/*.png`: メッシュが使う色/alphaのアトラス。PNGだけのフォールバックにも使えます。

**422の連続的な手続き幾何と同じものではなく、固定コマの形状メッシュです。422既存クラスへそのまま差せるコードではありません。**移植側が各コマの位置・UV・添字をNativeBatch相当に写し、既存の所有権と接触クロックにつなぎます。422 Layerの512頂点固定の器へ移す時は、添字を展開した三角形頂点数で判定し、1バッチ最大510頂点で分割してください（indexed unique頂点数ではありません）。酸・吠え・鈴・冷気の最大コマは2バッチ、残りは1バッチです。ポリゴンの削除や切り詰めは禁止です。PNG版とメッシュ版の同時表示はしません。

ローカル座標はx＝攻撃者側、y＝画面上、z＝0。全体幅1を受け手の見えている本体高さに掛け、固定した接触位置へ置きます。左右反転でy軸を反転させません。絵の幅に合わせて敵やリーダーを伸縮させません。mesh/textureはnearest、mipmapなし、トリム・回転・ぼかしなし。原寸プレビューでは1倍・2倍の整数倍率です。

## 決めたことと取り込みの注意

1. 夜硝子の暗い背景＋細い真鍮。酸は重い緑の飛沫、毒は紫/青緑の上昇煙、呪いは非対称の壊れた封印、吠えは開いた圧力線、鈴は多角の共鳴輪、歌は2本の波、冷気は結晶面、雷は枝分かれ線で区別。紙・クリーム背景・太い墨線・文字は使いません。
2. 全て**受ける側の局所の当たり**。敵の予備動作、武器、発射物、舞台全体を横切る光線は追加しません。画像時間からダメージ/回数/状態を決めません。
3. 実行済みの敵個体・技・実行順・分岐・有効な受領情報を確認してから選びます。技名一致は候補検索にすぎません。中断・対象の再利用・古い所有権ではVFXを破棄します。
4. ダメージ系は実際の接触にage=0を合わせます。全防御・氷壁・無効化は既存の防御表現を維持し、HP被弾が起きたようにこの絵を重ねません。確認できない場合は既存表現のまま。
5. **呪い・吠えはhex型**。通常ダメージがないため、DamageDealtだけを入口にせず、実行と実際の状態付与を確定した時点で1回表示します。狼のhowlや筋力buffを吠えの被弾に置き換えません。状態付与のB1演出と重なるなら主従を決め、同じ通知を重ねません。
6. 歌・鈴・雷の連打は確定した各contributionに同期。集約結果と個々の当たりを二重再生しません。連打を素材8コマの明滅から推測しません。
7. 酸と一部の鈴には既存のneutral接触ルートがあります。置き換える場合だけ旧VFXを抑止します。
8. **毒・冷気は素材のみで未割当**。確認できたmainでは対象技を確定できないため、類似色の敵に推測で割り当てません。新しい定義を取り込み側で確認した時に割り当ててください。
9. 環境光・床光・カメラ・bloom・全画面閃光は追加していません。音は別のB9。既存の数値/ラベル/UIより後ろへ。中断・終了時に一時素材を除去し、ゲーム進行を演出時間で止めません。
10. 動きを減らす設定では短い1コマ表示または省略。雷は単発で減衰し、白い全画面ストロボを作りません。
