## 4. 設問への回答

### Q1. 「取りたい札が無い提示」は何回あったか

**14回中1回（7%）。**

- **#8: 増える蔦 / 嵐の角 / 突進の助走** — 実際にスキップした。成長軸のデッキに勢い札が2枚、残り1枚は既に持っている0E札。
- 惜しかったのは **#6**（見切り撃ち／根張り／棘の蔓）と **#1**（深根／深緑の刻／若幹の一撃）で、どちらも1枚が救った形。

**旧プールとの体感差ははっきりある。** 「同コストで数字だけ違う梯子」を引く回数がゼロだった。以前このプールを触った時の「荒角の一撃と打撃、木陰の守りと巨木の盾のどっちを取っても同じ」という無感動な提示は一度も出ていない。撤去13の効き方は**枚数が減ったことより「見分けがつかない2枚が同時に出なくなった」**ことに出ていると思う。

ただし**軸のミスマッチによる死に札は残っている**。うちの14回のうち勢い札が出たのが5回（嵐の角×2・突進の助走・疾駆・薙ぎ角・根付く勢い・風渡り）で、成長デッキにとっては全部ノイズだった。これは「退屈な札」ではなく「**別のデッキの良い札**」なので、性質が違う。プールの質としてはむしろ健全に見える（本家も3割は他アーキの札）。

**所見**: 置物は「提示されれば強い」というより **提示された時点でデッキに前提が要る**。棘の蔓と樹皮の芽が刺さったのは*無条件のper-attack*だから。逆に条件つき（根張り・芽守り）と枠系（罠師の茂み）は、その時点のデッキで読み切れず全部見送りになった。**新カードの風の棘（勢いを得るたび2ダメ）は14回の提示で一度も出ず**、勢い軸のランでないと評価できない。

### Q3. レアの提示回数と「方針が変わる」感

**★レアのカード提示は4回（天蓋の実り・昂ぶる角笛・風渡り・ショップの大角の群長）。取得0枚。**

**「方針が変わる」とは一度も感じなかった。** 理由がはっきりしていて、**エリート報酬のレア確定枠3回が全部「勢い or ランプ」で、成長デッキには文字通りゼロ価値**だった。レアが方針を定義する札であるほど、方針が違うと完全な死に札になる——設計どおりではあるが、**エリートを倒したご褒美が3回連続で「見えているだけの札」**になるのは体験として弱い。

対照的に、**方針を変えたのはレアではなくアンコモンの樹皮の芽（#10）だった**。これを取った瞬間から「安い攻撃を並べる」がデッキの唯一の正解になり、以降のピック基準（丸呑み3Eより若幹1E、双牙、小枝の一打）が全部それに従った。レアが担うはずの役割を◆が担っている。

なお **★レアのレリック（不動の根＝HP半分以下でブロック10）も死に枠**で、最後まで一度も発動しなかった。前ランの所見「★レアは死に札になりうる」はここでも再現している。

### Q4. 焚き火の「鍛える」で魅力的でなかった札

**名指しは1枚だけ: 打ち据え+（4ダメージのまま／急所+2→+3）。**
- 単位+1が先に取られてダメージ4が動かないので、鍛えても**基本札の打撃6より打点が低いまま**。焚き火で2回このリストを見て、2回とも即座に候補外にした。急所+1の価値は「次の1発が×1.5になる回数が増える」だが、うちの打点だと+3〜5相当で、他の候補（真・打撃15→23、若幹×2→×3）と2桁違う。本家Bashが+で打点も伸びる（8→10）ことを思うと、**参照/単位を持つ札でも量が5未満なら量も伸ばしてよい**気がする。

それ以外は総じて「鍛えたい」と思えた。特に良かったもの:
- **樹皮の芽+（成長+1→+2）** — 単位+1が実質2倍。触りたくてたまらなかった（今回はHPを優先して見送り）
- **若幹の一撃+（上限×2→×3）** — 参照倍率+1で8→12。倍率が伸びるのは分かりやすく強い
- **木漏れ日+（ブロック7→11・1ドロー→2ドロー）** — 量と単位が両方伸びる当たり枠
- **真・打撃+（15→23）／育つ牙+（6→9・+4→+6）／双牙の蔦+（3→5×3）** — 素直に嬉しい
- 年輪+（成長+2→+3）と道行きの選択+（成長+2→+3）は「悪くないが地味」の帯。1枚しか鍛えられない中では最後まで残らなかった。

## 5. 不具合・表示の嘘

### 【表示の嘘・確定】潜伏（burrow）中の敵に対する実値表示が実処理と一致しない
幕2行2、殻20の岩皮の甲虫に対して手札の三連の角+が
`［実値: 敵0:10(成長+2・貫通(ブロック無視))。先頭ヒット基準］`
と表示された。**実際にはHPは1も減らない**（殻が貫通も吸うため）。

`src/engine/effects.ts` の `damageBreakdown()`（608行〜）に潜伏の分岐が一切なく、`blocked = pierce ? 0 : min(block, amount)` / `hpLoss = amount - blocked` で計算している。一方の実処理 `dealDamageToEnemy()`（735行〜）は
`shellUp = burrowActive && block > 0` → `blocked = pierce && !shellUp ? 0 : ...` → `hpLoss = burrowed ? 0 : ...`
と潜伏を見ている。エンジンで実測した乖離:

```
殻12 / HP30 の岩皮の甲虫
  貫通10   表示hpLoss=10  実処理hpLoss=0
  非貫通20 表示hpLoss= 8  実処理hpLoss=0
```

`enemies.test.ts` の damageBreakdown テストは装甲・貫通は固定しているが**潜伏を見ていない**。CLAUDE.md の「表示と実処理の一致をテストで固定」の穴。ホバー内訳（ブラウザ）も同じ関数なので同症状のはず。

### 【バグ・確定】ショップの「レア枠（6枠目）」の価格に会員証の割引が掛かっていない
`src/engine/run.ts` 569行:
```ts
cards.push({ id: def.id, price: 120 + pricedCost * 10 })   // ← shopPriceRatio(run) が無い
```
通常5枠は561行で `Math.floor((40 + cost*10 + roll) * shopPriceRatio(run))`、レリックは580行で掛かっているのに、レア枠だけ素通し。会員証（ショップの全価格が半額）を持っていても大角の群長は永久に140Gのまま。

### 【体感の嘘】会員証を買った店では、在庫カードの値段だけが半額にならない
同じ画面内で **除去50G→25G・強化100G→50G** は即座に半額になったのに、カード6枚の値段は1Gも動かなかった（在庫価格が入店時に確定しているため）。説明文が「ショップの**全**価格が半額」なので、**買った直後の画面が説明と矛盾して見える**。仕様なら「次のショップから半額」等の文言が要るし、そうでなければ表示時に ratio を掛けるべき。実害として、150Gを払った直後に「140Gのレアが買えない」状態になり、購入判断を誤らせた。

### 【表示の小さな不整合】焚き火のヘッダが「排他三択」のまま
```
🔥 焚き火: 「休む/鍛える/除去」から1つ選ぶ (排他三択。現在 56/80)
  ...
  除去はショップのみ (2026-09-03 焚き火の「取り除く」は廃止。休む/鍛えるの二択)
```

### 【設計上の気付き・不具合ではない】呪い/負傷/火傷が spell 扱いなので年輪の0E条件を壊す
年輪の【手札の他の札がすべて物理なら0E】は、**呪いの烙印・負傷・火傷が全部 spell** なので、それらを引いたターンは自動的に有料になる。「汚染札を引く」→「実質もう1枚ぶん損する」の二重の罰で、しかも手札を見ないと気付けない。狙いどおりかもしれないが、体感としては理不尽寄りだった（CLI は ⚠実コスト0E の表示があるので気付けたが、逆の「今回は1Eです」は目立たない）。

### 【バランス監視】工房×鍛えるが per-trigger 置物に乗ると跳ねる
棘の蔓（1E・攻撃ごとブロック2）×2枚 → 工房で **真・棘の蔓（ブロック5）** → ショップの鍛えるで **真・棘の蔓+（ブロック8）**。1Eの置物1枚で毎ターン24〜32ブロックが出て、幕2の被ダメがほぼゼロになった。工房プレミアム×1.25と「量+50%」が同じ量に二重で乗るのが原因に見える。**工房産の per-trigger 置物は鍛える対象外**（三連の角+や合成産の一部が既にそうなっているように）にするのが素直だと思う。
