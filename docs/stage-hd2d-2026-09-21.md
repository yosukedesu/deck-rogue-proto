# 舞台を HD-2D の作法へ（2026-09-21）

ユーザー「マップ背景の3Dが結構荒いのでハイクオリティなHD-2Dゲームくらいのディテールにしてほしい。全体的にHD-2Dに」。
裁定4件（ask_user）: **大物は一枚絵のドットに描き直す／地面だけ細かく（1ドット=2px・64ドットのタイル）／幕1で作法を固めて見せる→幕2/3／光は SSAO・光の筋と光溜まり・幕3の水面（反射）・ティルトシフト の4つ全部**。

## 診断（作り直す前の3幕）
1. 地面が 32 ドットのタイル 1 種の敷き詰め（幕2/3 は同じ石タイルが画面いっぱい＝ノイズ）。道の縁がタイル単位で角ばる
2. 木・茂みがコードで球を積んだ塊。オクトラは一本一本が描かれた大きな絵
3. 幕2の柱・梁が無地の箱
4. 地面の上が空っぽ（落ち葉・苔・ひび・瓦礫の「敷物」が無い）
5. 光が暗く平坦（根元の影が無い・光の筋が弱い）

## 作法（3幕共通・`Stage.cs`）
- **地面のアトラス** `Ground(act, kind)`: `Art/tiles/act<N>_<kind>_{a,b,c,d}.png`（64×64・2px/ドット）を 2×2 に束ね、タイル（2 セル＝1.28 unit）単位で種と向きを選ぶ。種ごとの平均色を a に揃え、彩度 −22%。明度→Sobel の**ノーマルマップ**（`NormalFromLuma`）で点光源と月光の陰影。バイリニア＋ミップ（点サンプル×ミップの遠くのちらつきを消す）。`Cell` 0.5→0.64（タイルの半分）。1 種だけなら Repeat。**幕2/3 は向きを回さない**（煉瓦の目地が揃う。回すと継ぎ目）
- **敷物** `MaterialPatch`/`PatchSet`: PixelLab に「地面に寝かせた板」を頼むと浮島・台座・皿になるので、材質だけをタイル（`act<N>_m_<name>.png`）で描かせ、コードで不定形（楕円＋ノイズ・縁は1ドットのディザ）にくり抜く。道の縁は草タイルから「上が草・下がぎざぎざ」の帯（`edge=true`）＝セル単位の段が消える。夜の色に寄せる（彩度 −30%・明るさ −12%）
- **一枚絵** `SpriteH(name, tex, pos, 世界の高さ, 接地影の係数)`: 絵のドット数と実物の大きさは揃わないので高さ (units) で置く。透明率 45% 未満の絵は `PropTex` が捨てる（風景ごと描かれた絵）。大物（門・機械・館）は `PutRaw`
- **水面** `StageWater.shader` + `Stage.Reflection`（主カメラを水面で折り返した鏡像カメラ・斜めクリップ・半解像度・ポスト処理なし・Water 層と UI は映さない。スマホは作らない）
- **光**: SSAO（`URP-Renderer.asset`: 半径 0.7・強さ 1.4・AfterOpaque・Source=Depth＝StageUnit の板にも掛かる）／DoF Bokeh 90mm F4.5・焦点 = 場の中心（`LayoutCamera` の `_dist+1`）＝ティルトシフト。座席は鮮明／露出 幕1 +0.12・幕2 +0.32・幕3 +0.22／光の筋は `Px.Beam` の板＋足元の光溜まり `Pool`
- **幕2/3 の地形**: `_flat` のまま高さは帯 `H2/H3`（道の座標 s の帯＝道と平行の段。境界は t のノイズで揺らす）。材質 `BandMat`（床/土/水底）。段は平らな天面＋隣が低い辺に垂直の面 `AddStepFaces`（cliff a〜d のアトラスをタイルの上端から切る）。水底のセルに水面 1 枚

## PixelLab（pixflux）の勘所（2026-09-21 実測）
- 上限 400×400 だが**透明背景が効くのは面積 ≈30,000px まで**（160×192 は可、192×224・256×320・320×160・400×112 は灰色の背景が付く）
- 描写に「forest」「night」「moonlight」「scene」を入れると木・月・風景を描く。小さな物を大きなキャンバスに頼むと周りに風景を描く
- **「地面に寝かせた敷物」「水たまり」は頼めない**（浮島・台座・皿になる）→ 材質タイルをコードでくり抜く／水たまりは `Px.Puddle`
- タイルは "flat seamless repeating texture of <材質>, extreme close-up, uniform all over, fills the whole frame edge to edge, no vignette, no objects, no border, lineless" で 96×96 を作り中央 64 を切る（縁の額を外す）。「dirt」は段丘や丸い塊（lumps）を呼ぶ＝土は**コード生成の静かなノイズ**（`scripts` 無し・このセッションの python）が最も滑らか。「moss green」の語は土まで緑にする
- **等間隔に粒が並ぶ絵（花の茂み・クローバーの絨毯・藁・泡状の石）はユーザーが「集合体恐怖症を煽る」で却下**＝捨てる。縄の輪（cable_hang）も捨てた
- 生成は 1 枚 ≈10〜20 秒。`fetch failed` で途中で止まることがある（再実行は既存をスキップ）
