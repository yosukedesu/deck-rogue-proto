## 4. 設問への回答

### T1. 工房を必ず踏めたか
**2回とも踏めた**。幕1は行11の工房を目指して分岐を選び、到達時180G（合成100G）。幕2は行9の工房を目指し、到達時225G。
- **金は一度も足りなかったことがない**。むしろ幕1では「?イベントで胞子を45Gで売る（HP-8）」を取らなくても足りていた。今回のルートは戦闘が多め（幕1で工房前に7戦）だったので、`docs` にある「幕1の工房は払えない（J/K）」問題は**行5以降ルールで解消済み**と見える。ただし**工房を目指すと他の選択肢が犠牲になる**のは効いていて、幕1では行12のエリート（歩哨の双子）を降りた（HP55では126HP×がらくたを受け切れない）→**幕1本編はレリック0個**（ボス報酬まで手ぶら）という代償になった。工房のコストは金ではなくルートだった。

### T2. 悩ましさ（「最強札を素材にする」以外の悩みは発生したか）
**発生した。しかも工房②は今回のランで一番長考した場面**。具体的には4系統：

1. **軸一致のおまけを取りに行った**（工房①）。三連の角+ × 荒角の構え／× 疾駆 はどちらも「トランプル軸同士」で勢い+2が乗る。**おまけがあると分かった上で、どちらの相方を残すかを選んだ**（0Eの疾駆を手札に残す＝勢い12の2段構えを作る）。おまけの存在自体が「同じ軸で溶かそう」という新しい引力になっていて、これは前の版の「1E札を重い札にタダで貼る」一択より確実に面白い。
2. **鍛え済み札を素材にした**（工房①で三連の角+＝焚き火の鍛えを投入）。「せっかく鍛えたのに溶かすと損では？」→**結果も鍛えられて出る**ので損しない、と preview で確認して踏み切れた。ここは設計の狙いが素直に効いている。**ただし例外がある（不具合④）**。
3. **置物化を本気で検討して却下した**。荒野の呼び声 × 角牙の乱撃+ の preview（毎T 8貫通＋勢い+4＋ブロック2）はワクワクしたが、**÷3でコストは上がる**ので、バースト札を置物にするのは構造的に損だと preview の数字で納得できた。「置物化が魅力的なのは、元から毎ターン仕事する札（置物×置物、置物×小さい誘発）だけ」という理解に自力で到達できたのは良い。
4. **一番の悩みは「合成＝引ける確率が半減する」だった**。真・疾駆+(0E 勢い+10)・真・双牙の蔦(1E 6貫通×3) はどちらも1枚あたりの性能では明確に上なのに、**2枚を1枚にすると毎ターンそれを握っている確率がほぼ半分になる**。この「濃くするか、広く持つか」の悩みは合体モデルの中心にあって、価値保存モデル時代には無かった悩みだと思う。

一方で**悩みが起きなかった軸**もある：**リアクションへの合成は毎回「伏せ枠が1つしかない」で即却下**になった。棘牙の罠+（返し39）も角牙皮の罠+（ブロック27＋45ダメ）も数字は凄いのに、枠1つと「敵が殴ってこないターンがある」で選べない。⭐茨の砦（レシピ）だけが「枠1つに2つの仕事」で理屈が通っていた。**リアクション合成は今のところ全部ハズレ枠**に見える。

### T3. 合成品の強さ
**1ターン最大与ダメ**:
- 合成前（幕1の6戦）: 15 / 19 / 25 / 18 / 27 → **ピーク27**
- 合成①直後の1戦目（泥まとうもの）: **58**（1ターンで76HPが消えて2ターン決着）
- 幕1ボス: **119**（疾駆+ → 角牙の乱撃+ → 若幹 → 打撃 → 絡み蔦。オーガ176HPの2/3が1ターンで飛んだ）
- 合成②（砥石の巨像）: **93**（疾駆+ と 角牙牙の乱撃+ の**2枚だけ**で65HPを消し、予告されていた断頭32-37を発生前に無効化）

つまり**合成1回で1ターン火力が約2.2倍**になり、そこから先はレリック（成長の種）と置物（荒野の呼び声）が乗って伸び続けた。**工房は「ワクワクする目玉」として明確に機能している**。金100Gは安いと感じた（幕2では「レリック/カード/除去」と競合せず、単に払えた）。

**敵ギミックの無効化**:
- **敵ブロック**: 8貫通×3が全部素通し。見習い巨像(開幕8)・砥石の巨像(開幕10＋毎T+14)・梟(構え8-12) は**合成後は存在しないのと同じ**だった。
- **装甲25（オーガ）**: 実ヒットが16〜23で**上限25に一度も触れなかった**。多段側の1ヒットが小さいので、装甲の「一撃デッキへの問い」は緑の多段には最後まで効かない（既知の構造非対称の再現）。
- **潜伏の殻（岩皮の甲虫）**: **貫通も殻に吸われる**ので1ヒット目（12〜15）が丸ごと無駄になる。ただし**多段なので2・3ヒット目がそのままHPに入る**＝合成品は潜伏をほぼ無視できた（ソロの甲虫は殻12＋HP32を1ターンで消した）。潜伏は単発デッキにだけ効く。
- **重り(slow)／鏡（手数の罰）**: ここだけは**合成が正面から刺さる**。大顎の狩人の重り2は「今ターンのプレイ枚数×10%」なので、**5枚打つ代わりに1枚打つ**合成品は被ダメを構造的に下げる。1枚に集約する工房は、手数罰の系譜（重り・写し身の鏡・拘束）への**カード側の解答**になっている。これは面白い相互作用で、狙って設計されているなら良い噛み合わせ。
- **虚弱**: 合成品のブロック9が6に落ちた程度。影響小。

### T5. 評点
- 各戦闘は §2 の表のとおり（強さ平均 2.9 / 面白さ平均 3.4）
- **全体の面白さ: 4**。工房の2回はどちらも long thinking になり、ランの山場として機能した。軸一致ボーナスと鍛えの引き継ぎで「何と何を溶かすか」に自分のデッキの型が出る、という狙いは達成できている。
- **テンポ: 3**。幕1前半は2〜3ターンで健全だが、**合成①以降は通常戦が1〜2ターン**（泥まとうもの2T・岩皮の甲虫1T）になり、敵のギミックが鳴る前に終わる戦闘が増えた。合成は「ランの目玉」であると同時に**戦闘長の物差し（通常4〜6T）を1回で壊す**大きさがある。エリート・ボスだけは4〜5Tで良い帯だった。

## 5. 不具合・表示の嘘

**① 名前が壊れる（角牙**牙**の乱撃+）** — 工房②の産物が `角牙牙の乱撃+`。語幹の連結で同じ字が重なる。工房①の産物（角牙の乱撃）に「牙」がもう1つ足されている。3回合成すると更に伸びるはず。語幹の重複除去が要る。

**② `合成不可: 合成は同じ色のカード同士のみ` が誤解を招く** — 負傷／がらくた（状態異常札）は工房のリスト（[20] 負傷）に**素材候補として表示される**のに、選ぶと「同じ色のカード同士のみ」と言われる。プレイヤーは「負傷は緑じゃないのか？」と読む。「状態異常・呪い札は素材にできない」と出すか、そもそもリストから外すのが正しい。（「負傷を溶かして消す」は誰でも一度は試す操作だと思う）

**③ 鍛えが別の軸に振り替わり、鍛えた数字が素に戻る** — 「素材のどちらかが鍛え済みなら結果も鍛えられて出る」は**合体後のカードのティアで鍛え直す**実装なので、合体でティアが変わると鍛えの行き先が変わる。実例2つ:
   - `若幹の一撃 × 三連の角+` → **樹牙の乱撃+**(2E) **上限×3ダメ＋5貫通×3**。三連の角+ で鍛えた 8貫通×3 が **5に戻り**、鍛えは 上限×2→×3 に移った（per-EnergyMax参照があるとティアが `mult` になり、`amount` 系は一切上がらないため）。
   - `陽光の恵み × 角牙の乱撃+` → **角牙樹の乱撃+**(**2E**) ブロック**6**・勢い**+5**・**5**貫通×3。ティアが `cost` になり、**鍛えがコスト−1に化けて数字は全部素**。3E→2Eなので損ではないが、名前は「+」なのに全数字が素、という状態になる。
   preview は正直（本当の数字が出る）ので「嘘」ではないが、**「+」の表示だけ見て溶かすと鍛えが消えたように見える**。「鍛えはコスト−1になります」等の一行があると事故らない。

**④ 同じ理由で、量4未満の行だけ鍛えが乗らない** — `双牙の蔦 × 三連の角+` → 勢い+4・**8**貫通×3・**3**貫通×2。5→8 は上がるのに 3→3 は据え置き（`boost50` の下限が4）。同じカードの中で伸びる行と伸びない行が混在し、理由は画面上どこにも出ていない。

**⑤ 置物化の誘発トリガーの扱いが揺れる** — `荒野の呼び声 × 角牙の乱撃+` は「**登場時**:勢い+4」＋「毎T:勢い+4」の2本になるのに、`根源の泉 × 角牙の乱撃+` は登場時が消えて「毎T:勢い+1」だけになる。素材の onPlay 勢いが、片方では登場時に残り片方では毎ターンに畳まれる。どちらが正なのか文面から読めない。

**⑥ モードの片方が黙って消える** — `絡み蔦 × 守りの蔓` → 樹皮の罠(1E) 被攻撃前ブロック19。絡み蔦の「7ダメージ」側が消える（規約どおり「モードは最初の1つ」）が、preview に注記が無いので、モード札を素材にすると気づかず半分捨てることになる。

**⑦ ルール外だが工房と噛み合う穴：読み手の梟の setAlt が「1Eで大技を消すスイッチ」のまま** — 梟の talon_dive(18-24＋霞み1) は伏せ札があると `伏せ破壊+がらくた1`（**ダメージ0**）に化ける。しかも表示に「(破壊分岐は見切りを無視する=置きっぱなしでも壊しに来る)」とあるとおり**鮮度を問わない**ので、余った茨の返しを1枚伏せておくだけで、エリートの看板技が「がらくた1枚」に変わった（実測: 被ダメ0）。2026-09-03 の「弱腰型 setAlt の廃止／罰型に揃える」裁定から漏れているように見える。罰型に見えて実質は弱腰分岐。

**⑧ 0E×0E は完全な純益になる** — `疾駆 × 小枝の一打` → 0E で「勢い+5（軸ボーナス込み）＋3貫通」。0E素材は値引きにならない＝**高い方のコスト（＝0）**なので、**2枚ぶんの効果＋軸ボーナスが0Eで手に入る**。デッキは1枚薄くなるだけでデメリットが無い。0E札を複数持つデッキでは常に正解の合成が存在してしまう（今回は引ける確率の低下を嫌って選ばなかったが、枚数に余裕があれば無条件で得）。

**⑨ 参考: 潜伏の殻と貫通** — CLAUDE.md の「潜伏…貫通は通る」に対し、実装／表示は「**貫通も殻に吸われる**」。表示と挙動は一致しているのでプレイ上の嘘は無いが、ドキュメントとは逆。裁定待ちの項目が残っているだけかもしれないので念のため。
