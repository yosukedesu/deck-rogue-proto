## 1. 本家の参照の型と、緑の現状

| 型 | 本家の例 | 緑の現状（87種） |
|---|---|---|
| 意図参照 | Spot Weakness | 0（意図表示と set-confirm が核なのに、カードが意図を読まない） |
| 手札参照 | Clash・Sever Soul・Fiend Fire | 0（物理/呪文の分割は「将来の参照余地」のまま未使用） |

| 攻撃数参照 | Conflagration・Perfected Strike・Rage | 棘の蔓（攻撃ごとブロック2）のみ |

緑は成長・勢い・ランプの「生成→倍加→刈り取り→接着剤」は揃っているが、参照の器がほぼ無い。
加算が全部ヒットごとに乗る以上、参照の網が無いと多段へ収束する（Opus G/I/K の実測どおり）。

## 4. エンジンの追加（小）

- 条件: `enemyIntent`（対象の意図の種別）／`handAllPhysical`／`enemyExposed`／`perfectBlockLastPhase`（直前の敵フェーズで攻撃を受け、HP損失0）
- 効果: `dealDamagePerAttackPlayed`（このターンにプレイした攻撃×N）／`growthMultiplier`（ダメージに成長を×Nで乗せる。放出しない）／
  `extraHitIfExposed`（対象が急所持ちなら+1ヒット）／コスト条件 `freeIfHandAllPhysical`
- トリガー: `onKill`（プレイヤーのカードで敵が倒れた時。獲物・根張りの姉妹用）
- 置物トリガー: `onPerfectBlock`（攻撃を完全に凌いだ時）
- 表示: 条件の成否を手札のホバー/CLIの注記に出す（上限参照の実値注記と同じ器）
