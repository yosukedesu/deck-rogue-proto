# カードパワー指針 v1（2026-08-24）

多色複合（イゼット＝青赤、グルール＝赤緑など）を見据えた全色共通のコスト査定基準。
**エナジーは無色**のため、混色デッキはどの色のカードも同じコストで使える。
したがって「同じ役割なら得意色が最高レート」を厳守しないと、混色時に強いカードだけが
つまみ食いされてカラーパイが崩壊する。新カードは必ずこの表で査定してから追加する。

## 0. カードタイプ（2026-08-24再編、定義固定は同日）

区分は機械的な挙動で切る4タイプ: **physical（物理）/ spell（呪文）/ reaction / permanent**。
攻撃・防御・ドロー等の「役割」はタイプではなく効果から読み取る（ボットも効果から導出）。
物理/呪文の分割は現状表示のみだが、「物理耐性」「呪文数参照」等の将来デザインのための予約。
タイプ自体はコストに影響しない（reactionは条件係数、permanentは置物原則で査定）。

**物理/呪文の判定基準（2026-08-24定義固定）**:
- **物理 ＝ 武器・道具・身体による行為**。銃・弓・爆弾・投擲もすべて物理。
- **呪文 ＝ 魔力の行使**。媒体が何であれ、効果の源が魔力なら呪文（例: 魔法の剣で「斬る」のは物理、剣から「炎を放つ」のは呪文）。
- 際どいカードはここに判例を追記して運用する。

| 判例 | 判定 | 理由 |
|---|---|---|
| 銃・弓・爆弾 | 物理 | 道具による行為 |
| 魔法の剣で斬る | 物理 | 行為は斬撃 |
| 歌・祈り・呪い | 呪文 | 効果の源が魔力（超常） |

## 1. 基準通貨（VP: Value Point）

**1エナジー(E) ≈ 6VP** を基準とし、カード1枚の機会費用（手札消費）として+2VPの札束補正を置く。

| コスト | 許容VP（報酬カード=100%） |
|---|---|
| 0E | 4（**消滅必須**） |
| 1E | 8 |
| 2E | 14 |
| 3E | 20 |
| 4E | 26 |
| 5E | 32 |
| 6E | 38 |

- **基本札**（スターターの打撃・防御類）は **75%**（弱いのが仕様。報酬で上書きされる楽しさのため）
- **シグネチャー/アーキタイプ札**は **110%** まで
- **参照スケーリング札**（詠唱数×N・霊気×N・上限×N等）は典型値で **150%** まで。
  超過分は「デッキ構築を歪めるアーキタイプ税」を支払っているとみなす

### 報酬札は基本札の完全上位互換でよい（2026-08-26 制定・ユーザー方針）

**「初期デッキのカードはあくまでベース。ピックから完全上位互換が出ても問題ない」**（ユーザー）。
本家StSがそうなっている——Strike（1E・6ダメージ）に対して **Pommel Strike（1E・9ダメージ＋1ドロー）**、
Defend（1E・ブロック5）に対して **Shrug It Off（1E・ブロック8＋1ドロー）** が普通のコモン報酬として出る。
基本札は「上書きされる快感」を作るために弱く置いてあるのであって、報酬側を基本札に遠慮させる理由はない。

したがって**査定の下限は「基本札より強いこと」ではなく「定価100%であること」**。
報酬プールの札が許容VPの100%に届いていないなら、それは調整不足であって設計上の慎ましさではない。

**禁止されるのは上位互換そのものではなく、①コスト帯を無視した効率（許容VPの超過）
②カラーパイの侵犯（他色の得意分野を同レートで奪う）③無限ループ**の3つだけである。

#### 監査で判明した「基本札以下の報酬札」（2026-08-26）

機械査定で、報酬プールの11枚が基本札の75%ラインを下回っていた。ピックすると
**デッキが弱くなる**札が報酬に混ざっていたことになる（`docs/card-power.md` §21 で是正）。

| カード | 実質 | 基本札で同じことをした場合 |
|---|---|---|
| 牙の一撃（緑2E） | 10ダメージ | 打撃×2 = 12ダメージ（**完全な下位互換**） |
| 亡者の壁（黒2E） | ブロック8 | 骨の盾×2 = ブロック10（**下位互換**） |
| 大樹の怒り（緑4E） | 18ダメージ | 打撃×4 = 24ダメージ（**下位互換**） |
| 樹皮の鎧（緑2E） | ブロック10 | 防御×2 = ブロック10（同値・枠を1つ節約するだけ） |

**注意**: 機械査定は参照スケーリング・多段ヒット×成長・置物の生涯価値を見られない。
数値が低く出た札でもアーキタイプ内では働いていることがある（蔦の乱舞の5ヒットは成長デッキで化ける）。
是正時は必ず「そのアーキタイプの中でどう働くか」を確認してから数値を動かすこと。

## 4. リアクションの条件係数（同コスト攻撃カード比）

| 誘発条件 | 効果倍率 |
|---|---|
| 緩い（被攻撃後・無条件） | 100〜125% |
| 中（被攻撃前の軽減） | **150%まで（2026-08-26 上限を明文化）** |
| 中（敵行動時の打ち消し） | 打ち消し=12VP固定 |
| きつい（HP半分以下・被ダメ10以上・敵の特定行動） | 150〜300% |

**設計方針**: 条件がきついほど派手に、緩いものは控えめに（2026-08-24決定済み）。

### pre窓軽減の上限を150%に固定した理由（2026-08-26）

人間プレイテストの指摘「**リアクション防御が通常防御より強くて、同時に引いたら通常防御は使わない。
特に伏せておけるので予告系の敵に対して強いと感じた**」による。同コストで並べると差は歴然だった。

| コスト | 通常防御 | 軽減リアクション | 倍率 |
|---|---|---|---|
| 白1E | 白盾 5 | 護りの聖印 **14** | 2.8倍 |
| 緑1E | 防御 5 | 守りの蔓 **12** | 2.4倍 |
| 青1E | 氷盾 5 | 霜の帳 **8** | 1.6倍 |

§4は pre窓軽減を「個別査定」とだけ書いていて**上限が無かった**のが穴。査定時に「伏せ枠の占有」と
「空振りリスク」を実コストとして計上していたが、**本作は敵の意図が常に見えている**ので、
攻撃してくる敵に対して軽減リアクションはほぼ確実に仕事をする。伏せ枠のコストを過大評価していた。

**是正したのは上限超過の2枚のみ**（機構の派手さを壊さないため）:

| カード | 変更前 | VP | 変更後 | VP |
|---|---|---|---|---|
| 護りの聖印 1E | ブロック14 | 14.0 = **175%** | ブロック12 | 12.0 = 150% |
| 聖域 1E（HP半分以下） | ブロック20＋回復5 | 27.5 = **344%** | ブロック16＋回復4 | 22.0 = 275% |

守りの蔓（緑1E ブロック12 = 150%）・白光の壁（2E = 129%）は上限内なので据え置き。

**数値だけで解かない**: 根本原因はレート差より「伏せることにリスクが無い」ことなので、
敵側に伏せへの罰を増やす処方と対で扱う。1〜3戦目のプールには伏せ罰を持つ敵が皆無だった。

## 5. その他の原則

- **0マナは消滅付きのみ**（0マナ＋ドロー使い回しは無限詠唱ループになるため禁止）
- **ランダム火力**: 期待値 ≤ 同コスト定価×1.1（分散のリスクプレミアム分だけ上振れ許容）
- **置物**: 毎ターン効果は「1E相当効果の40〜50%/ターン」、標準コスト2E
- **消滅付き**: 定価の150%まで許容
- **多色の代償はエナジーではなくデッキ一貫性**（シナジー枚数の希釈）。
  将来ギルド（イゼット等）を作る場合、2色参照カード（例:「詠唱数×延焼」）が複合の報酬になる

## 11. 全アーキタイプ一斉調整（2026-08-25 第1〜2波）

16デッキ×12敵×100戦の総当たり測定に基づく調整。**主犯はカードでなく「対低速3敵」**
（門番=激昂無上限・狼=持続DPS最高・苔=再生5）で、低速アーキタイプ7種が0〜16%に全滅していた。

敵側（構造修正）:
- 門番: 激昂に累積上限+6を導入（無上限→8→6。長期戦アーキタイプのフィルタ化を解消）、HP170→155
- 狼: 連撃6-8×3→5-7×3・咬み裂き5-7×4→4-6×4・遠吠え2-3→1-2（多段×強化の相乗が過大）

カード側:
- 火弾 7→6（基本札75%則違反の是正。赤スターター90%の一因）
- 業火 延焼10→8（バーン100%は据え置き=ボットが最適プレイする天井。人間基準で再判定）
- 青ガード 4→5・黒ガード 4→5（基本札の横並び。赤の4は「防御は薄い」の柱で正当化される例外）
- 亡霊の槍: 消滅×1 → **3+消滅×1**（序盤の死に札解消。墓地型27%→37%）

プリセット:
- ストームに嵐の残響×2を追加→**撤回**（ボットのエナジーを食い80.7%→74.1%に悪化。プールには残す）

残る外れ値: バーン100%（人間基準待ち）・ビッグマナ53%・青/黒スターター48〜50%（プール拡張で救済予定）・墓地37%（ゲートA後の構造調整枠）。
ラン走破率はボット0%継続（ピック方針が単純すぎるため下限値。色勾配 緑4.4>青4.2>イゼット3.5>白3.5>赤2.6>黒2.2 は監視対象）。

## 12. 黒の拡張査定（2026-08-25 +19枚 = 38枚。各色38枚化の第1弾）

設計方針はユーザー指示3点を反映:
①自傷のうまみ増額 ②0マナは追加コスト必須 ③**コスト再利用ハックを黒の楽しさの核に**。

レート改定:
- **自傷の対価: HP-1 ≈ +2.5VP**（旧-1.5VP換算から増額）。例: 血の代償 2E=HP-4で24ダメ、影の刃 0E消滅=HP-2で8ダメ
- **消滅コスト > 捨てコスト**: 手札1枚消滅 ≈ +5VP（供物の火 1E=11ダメ）。ただし墓地燃料になるため帳簿・槍と組むと実質軽くなる（それがハックの楽しさ）
- 0マナ規約強化: 0Eは消滅+追加コスト必須（影の刃=自傷、墓暴き=消滅コスト）

コンボの三角形（起動役→接着剤→ペイオフ）:
- 墓地軸: 墓暴き/深き忘却/消滅コスト → 亡者の合唱（消滅ごと1ダメ） → 饗宴（消滅×2ドレイン）/槍/行進
- 自傷軸: 影の刃/血の代償/死の風/儀式 → 苦痛の芯（HP損失ごと2ダメ） → 背徳の収穫（失ったHP×2）
- 回復軸: ドレイン7枚+とばりパッシブ → 血の月（回復ごと2ダメ） → 血染めの刃と重ね掛け
- エナジー軸: 血の儀式（0E:+2E/-2HP/消滅） → 死者再生（2E消滅: 直接プレイ）で買い戻し。再生自身が消滅するため無限ループなし

置物レート注記: 接着剤置物は2E統一。誘発頻度×効果 ≈ 40〜50%/T の置物原則内（合唱1/回・芯2/回・月2/回・帳簿1ドロー/回）。
sim実測: コスト再利用型（冥府の取引）75%・墓地爆発型（合唱エンジンで再構築）40%・他デッキへの影響なし。

## 23. 敵の強化を「時喰らい型」に再設計（2026-08-26）

### 問い: 本家は防御の線形性をどう解いているか

ユーザーの問い「防御の線形について本家StSではどのような設計になってる？」への調査結果。

**StSは4つで防御を線形から外している。**
①**敏捷（Dexterity）**＝ブロックカード全部に+X（「枚数×敏捷」の掛け算）
②**ブロックの持ち越し**（Barricade / Blur / Calipers）＝フローをストックに変える
③**Intangible**＝全ダメージを1に
④**弱体と筋力減**＝和ではなく乗数を殴る。**サイレントのスターターには Neutralize（弱体1）が最初から入っている**

本作の実装状況を数えたところ、敏捷とIntangibleは**存在せず**、持ち越し（氷壁）は**青のみ12枚**、
筋力減（威圧）は**白のみ5枚**、**赤と黒には対抗手段が1枚も無かった**。

### さらに、敵側の上限が非対称だった

`enrage`（自動）だけ +6 の上限があり、`buff`（敵が撃つ強化）と `rally`（応援）は**青天井**だった。
慎重派（防御全振り・エリート全回避）が7戦目で死んだのはこれが原因で、**腕でどうにかなる問題ではなかった**。

### 「上限」は本家に無い概念だった

本家は上限ではなく、①**誘発をプレイヤーの行動に紐づける**（時喰らい=12枚プレイで強化 /
グレムリンノブ=スキルを撃つと強化 / 目覚めたもの=パワーを撃つと強化）②**自動で積む敵は短命**
（カルティストは毎ターン+3だがHP50で3〜4ターンで死ぬ）③**筋力を剥がす手段が全キャラにある**、で抑えている。

### 実測: 威圧を配るだけでは足りなかった

まず ENRAGE_CAP を撤廃し門番のHPを下げ、全色に威圧を1枚ずつ配って測定した。結果は**要塞0%・打ち消し0%**。
威圧札を3枚差し込んでも 0%・0% のまま。**+2/フェーズという時間比例の成長に、
一回きりの減算では原理的に追いつかない**（威圧3枚 = 1.5ターンぶんの猶予にしかならない）。

**プレイヤーの累計詠唱数が規定枚数に達するたび強化する。時間では鳴らない。**
門番は HP155据え置き・**8枚ごとに+2・上限なし**。低速デッキは枚数を撃たないので誘発が遅く、
高速デッキは誘発が早い代わりに早く倒せる＝**自己調整するタイマー**になる。

| バーン | 68% | **93%** |

**全アーキタイプが改善した。** 要塞だけ下がったが、旧90%は**34ターンかけて勝つ膠着**であり、
守り切れば必ず勝てる状態のほうが不健全だった。

**副次的な発見**: 威圧札を足すと勝率が下がる場合がある（要塞93%→55%）。

### 最大の発見: 要塞42.9ターンの主因は「測定器」だった

カードでなく `sim/run.ts` の問題。**`PLAY_PRIORITY` が attack を defend より先に見る**ため、
盾の乙女2体がターン開始で置くブロック4で `isWorthPlaying(block>=4)` が通り、
**城壁砕きが壁を積む前に4ダメージで空撃ち**していた。加えて城壁砕きの効果順が
`[ダメージ → ブロック]` で、**自前の+3ブロックが自分のダメージに乗っていなかった**。

この2点を直しただけで、`loop.test.ts` に既知として登録していた
**deck_fortress vs 苔まといの主の329ターン膠着が消滅した**（既知の膠着0件）。

**教訓: アーキタイプの数値を疑う前に、測定器がそのアーキタイプを正しく操縦できているかを確認する。**

### 罠だった新カード: 大潮の否認

「実値15以上でのみ打ち消し」という条件付きリアクションを理想形に**1枚入れただけ**で、
パーミッションが **87%/13.5ターン → 75%/111.1ターン** に崩壊した。

原因は**伏せ枠が1つで、自分では解除できない**こと。低打点の敵に対して条件が成立しないまま
伏せ枠が永久に塞がり、本命の対抗呪文を一切伏せられなくなる。**カードごと撤去**し、
確定済みルール表に「条件付きリアクションの罠」として明文化した。

**条件は「その敵との戦闘中に高確率で1回は満たす」ものに限ること。**

### 追加した機構

| 機構 | 内容 | 何を解いたか |
|---|---|---|
| **onBlockGained** | ブロックを得るたび誘発（置物） | 要塞の出口を「ペイオフ札を引けたターンだけ」→「守るたび」に。StS Juggernaut型。氷壁は別経路なので青を侵さない |

**却下した最短案**: `TRIGGER_AXIS` に `onAttacked:'wrath'` を追加する案。
`axesOf()` は色に依存しないため、**緑の茨の茂み・白の護りの聖印・黒の怨嗟まで一斉に憤怒になり**、
ギルドの2色プールが汚染される（白の要塞デッキが赤の憤怒札を重み5で引く事故）。
色固有の柱は色非依存の軸表に載せず、カード個別の `axis` で解決する。

## 26. クリア可能性の検証と、供給の「アクセス権」問題（2026-08-26）

### 発端

LLMプレイテスト26ランでクリア0。**誰もボスに到達しておらず、ラン全体の4割が一度も遊ばれていない**状態だった。

HP経済を測ると、15戦の総需要**268HP**に対し供給は初期HP80＋焚き火4回×24＝**176HP**。**92HP（35%）の構造的赤字**。

### 敵はStS水準だった

| 段階 | 本作（深度倍率込み） | StS |
|---|---|---|
| 1〜5戦目 | HP 50〜61 / 攻撃 5〜16 | Act1通常 HP 40〜54 / 攻撃 5〜13 |
| 6〜10戦目 | HP 76〜84 / 攻撃 11〜19 | Act2通常 HP 68〜99 / 攻撃 12〜21 |
| 11〜14戦目 | HP 100〜142 | Act3通常 HP 48〜176 |
| ボス | HP 130〜155 | Act1ボス 140〜250 / Act3ボス 250〜456 |

**通常敵はほぼ同水準、ボスはむしろ本家より小さい。** StSにあって本作に無いのは
**カード強化・ポーション・レリック数・ピック回数**の4つ＝**プレイヤーの天井だけが低かった**。

ユーザー方針「システムを変えずにプレイヤー側のシナジーで底上げする」に沿い、
敵とHP経済には触れず供給側だけを足した（焚き火の強化・レリック上限3→5）。

### 実測: 供給を足しただけでは届かなかった

| リーダー | 到達 | 強化 | エリート挑戦 | レリック |
|---|---|---|---|---|
| **ひなた（白）** | **15/15 走破** | **3回** | 4/5 | **5個** |
| とばり（黒） | 14/15 | 1回 | 4/5 | 4個 |
| このは（緑）×3シード | 11・11・12 | **0回** | 1〜2/5 | 1〜2個 |
| ひばな（赤） | 6/15 | **0回** | 2/5 | 2個 |

**強化回数・レリック数・到達戦闘が完全に連動した。** 分かれ目は焚き火到達時のHP——
ひなたは 61%/53%/55%/**96%**、このはは 41%/26%/21%。

**足した供給が「回復と排他」だったため、余裕のある者しかアクセスできなかった。**
HPがある → 強化とエリートを取れる → さらに強くなる、の**勝者総取りスパイラル**。
供給を増やしたつもりが、格差を広げる装置になっていた。

### 是正: 回復を排他から外す

**焚き火は到達した時点で自動的に回復し、その上で「鍛える／取り除く／何もしない」を1つ選ぶ。**
悩みは「回復を諦めるか」から「**どの札を鍛えるか・抜くか**」へ移った。
HP供給の総量は変えていないので「システムを変えずに」の範囲内で、プレイヤーの天井だけが上がる。

### 設計則として

**供給側の機能を「既に余裕のある者だけが使える」形にしてはならない。**
救済・成長の手段は、それを最も必要とする状態から手が届くこと。
今回は「回復と排他」という一見自然な二択が、実測で完全な死に機能を生んでいた。

## 33. タイプ跨ぎ合成 = 支配順位（2026-08-28 承認）

「違うカードタイプとの合成も可能にしてほしい」（ユーザー）を受け、計算合成の同タイプ制限を撤廃。

### 規則

- **支配順位: 置物 ＞ リアクション ＞ 呪文 ＞ 物理**。結果はより「持続する」側のタイプになる。
  呪文＞物理は §0 の定義（呪文＝魔力の行使）と整合——魔力が混ざれば呪文。
- **リアクション化**: onPlay 効果が支配側の主窓トリガーに吸収される。
  例: 打撃×茨の返し → 被攻撃後6ダメ＋返し9 の罠（2E）。名前は「〜の罠」。
- **置物化**: 一回きりの量 **÷3（切り上げ）** で毎ターン化。
  例: 打撃6×年輪の大樹 → 毎ターン2ダメ＋成長1（2E）。名前は「〜の大樹」。
  ÷3 は既存ラダー（従者の少年 = 1E・毎ターン2ダメ ≒ 打撃6の1/3）から採った換算率。
  置物にディスパッチされない窓（onEnemyAction 等）は onTurnStart に落とす。

### 値付け

- **置物は寿命込み VP×3** で査定してからコスト逆算。
  副産物として同名置物の「真・」化に空いていた穴（真・年輪の大樹＝毎ターン成長+2 が
  一回きり価格で1Eになっていた）が塞がり、3E になった。
- 置物化の禁則: ①帯超過（VP > 許容×1.5）は消滅で払えないため合成不可
  （巨獣の踏みつけ40×大樹 → 「強力すぎて置物に収まらない」）
  ②量を持たない効果（negate 等）は毎ターン化できず合成不可。

### 実装メモ

- ÷3 は「素材が一回きりか」で判定する（支配側かではない）。同名置物×置物は両方すでに
  毎ターン型なので割らない（二重割引の防止）。置物側の dealDamage も特性パイプラインに吸わない。
- 異名リアクション同士も解禁。**条件の異なる同種効果は合算しない**
  （無条件 counter9 と「HP半分以下」counter20 は別効果のまま並ぶ）。
- タイプ跨ぎレシピ2本追加: 荒ぶる群長（打撃×大角の群長。毎ターン3ダメ＝計算値2の上振れ）・
  宿茨の生垣（守りの蔓×茨の茂み。ブロック5/返し5＝計算値4の上振れ）。

gainEnergyMax の量は UPGRADABLE / UNIT のどちらにも入れない＝**複利安全弁は「量を強化しない」形で維持**。

### 補充参照札2枚（青） = 同軸おまけの手書き例外表（新ティア④ BONUS_UPGRADES）

②コスト-1が「0E+補充=消滅必須」規約に違反し、③の対象効果も持たない札の受け皿。
おまけは**札自身の軸から外れない**（カラーパイ・報酬抽選の軸判定を動かさない）。

検討済み・不採用: 消滅を対価にコスト-1（使い回せる札が1回きりに変わる＝強化が罠になりうる）、
倍率+1（×2ドローは危険地帯）、氷壁のおまけ（ドロー軸の札に氷壁軸が混ざり軸判定を汚染）。

## 41. Xコストの査定基準（2026-08-29 ユーザー指摘「蔦の連撃が糞弱くない？」）

**Xコスト札の対抗馬は「同じエナジーを1E札に使った場合」**——Xは全エナジーを食うので、
そのターン防御も撃てない。しかも**手札は毎ターン全捨てなので「1枚で済む」カード節約に価値が無い**
（節約した札は次ターンに残らない）。したがって **1エナジーあたりの効率が基準を上回らないと存在意義が無い**。

基準: 緑の1E札は 打撃6 / 絡み蔦7 / 荒角の一撃8貫通（コモン報酬）/ 防御5。**基準を6/Eとする**。

| カード | 変更前 | 実効/E | 変更後 | 実効/E |
|---|---|---|---|---|
| 蔦の連撃（コモン） | 4/hit | **67% ❌** | **7/hit** | 117% |
| 大角の暴走（アンコモン） | 6/hit貫通 | 125% | 据え置き | 125% |
| 樹皮の重鎧（アンコモン） | 6ブロック/X | 120% | 据え置き | 120% |
| 森羅の大嵐（レア・全体） | 3/hit全体 | **50%（1体） ❌** | **5/hit全体** | 83%/167%/250%（敵1/2/3体） |

蔦の連撃は**基本札の打撃をX枚並べるより弱く**（成長を積んでも常に負ける）、撃つだけ損だった。
森羅の大嵐は全体化の2倍補正を掛けても基準ちょうどで、レアとしては薄かった。
**Xの唯一の本質的な利点は「手札に攻撃札が何枚あるかに関係なく全エナジーを火力へ変換できる」こと**で、
これは状況限定の利点なので、効率は基準の115〜125%に置く。全体X札は敵1体では基準割れを許容する（AoEの宿命）。

## 44. 工房（合成）の値付け崩壊とその修正（2026-08-30 実プレイのログ解析で発覚）

ユーザーの実プレイ（このは・30戦全勝・被ダメ合計66・完封18戦）のログを解析して発覚した、
**このプロトで最大級のバグ**。

### 症状
幕1の行10で作られた合成カード **牙蔦の嵐（3E消滅・39ダメージ・貫通・全体）** が、
**残り23戦のうち18戦で最大与ダメージを記録**し、ランを事実上乗っ取っていた。
合成前の最大与ダメは18〜55、合成後は62〜118と明確な断絶がある。

### 原因（2つ重なっていた）
1. **伝播が無料だった**——「多段・貫通・全体の3特性が伝播する」の実装が、**伝播後の効果からVPを計算**
   していたため、素材の大きなダメージが全体化（×2）・貫通（×1.25）で無料で価値を増やしていた。
   実測: 素材68VP（巨獣の踏みつけ50 + 薙ぎ払い18）→ 結果101.5VP。**価値+49%・コスト-57%**
2. **コストが3Eで頭打ち**——`Math.min(3, ...)` により、7E相当の素材が3Eで出る効率2.3倍が発生。
   さらに帯超過は `discounted > ALLOW[cost] * 1.5` で**消滅を付けるだけ・上限なし**で合法化されていた

### 全ペア監査（緑の合成可能ペア全数）
| 定価比 | 修正前 | 修正後 |
|---|---|---|
| 165%以下（設計帯内） | 65% | **89.5%** |
| 166〜250% | 23% | 9.9% |
| 251〜500% | 12% | 0.6% |
| 501%以上 | 3ペア（最悪590%） | **0** |
| 300%超のペア数 | 44 | **1** |

### 修正
- **価値の保存**: 素材の合計VPに合うようダメージ量を逆算する（伝播の対価をダメージ量で払う）。
  「特性の掛け合わせ」という設計思想は保つ
- **コスト上限 3E→5E**（緑は5E札を素で持つので帯としては既存の範囲）
- **合成不可は一切増やしていない**（ユーザー方針）。むしろ置物化の「帯超過で合成不可」は
  価値保存で解消され、合成できるペアが739→817に増えた
- 「合成ボーナス15%引き」は**コスト逆算側だけ**に適用（価値は削らない）。
  ユーザー指示「同名カードは倍率上げて強いカードが生成されるべき」と整合（真・打撃=12ダメで不変）

### 残る過剰（許容と判断）
最悪は 真・巨獣の踏みつけ（5E・100VP・313%）など**「5E札2枚→5E札1枚」の圧縮**のみ。
2枚→1枚でコストが合算されない以上、構造的に効率は上がる。素材2枚を消費する対価として許容する。

## 46. 合成コストの契約「圧縮なのに重くなってはいけない」（2026-08-30 合成ラボが可視化）

デバッグ用の**合成ラボ**（セットアップ画面で任意の2枚を選んで結果を見る）を入れた直後、
最初に選んだ 打撃(1E) × 牙の一撃(2E) が **4E** と表示された。素材を別々に撃てば 3E で 23 ダメージ、
合成すると 4E で 22 ダメージ ——「2枚を1枚に圧縮したのに、素直に損」になっていた。

### 原因: VP表の +2 は「カード1枚ぶんの機会費用」

`ALLOW = 6×コスト + 2`。2枚（`6a+2` と `6b+2`）を1枚（`6(a+b)+2`）にすると、許容VPが**必ず2減る**。
価値を保存したまま定価100%で値付けし直すと、この2VP=約0.33Eぶんコストが押し上げられ、
丸めで +1E になるペアが出る。**全ペア監査で 1009/3008（34%）**が該当した。

### 対処（2段構え）

1. **定価125%帯で値付けする**。合成札は報酬札と同じ「115〜135%」の枠に置く（§本文の報酬札方針と同じ）。
   `cost = round((VP / 1.25 - 2) / 6)`。これで 34% → 24%。中央値は 123% → 129%。
2. **なお超える場合は出力を削って払う**。`cost` を素材コストの合計にクランプし、
   その帯（`ALLOW[cost] × 1.25`）に収まるよう**量**を割り付け直す。24% → **2.8%**。

削れる「量」は**焚き火の『鍛える』が触れるのと同じ集合**に揃えた
（`dealDamage` / `gainBlock` / `gainIceBlock` / `counter` / `gainHp` / `applyBurn` / `dealDamageDrain` /
`dealDamageRandom`）。ドロー・成長・勢い・霊気などの単位効果と参照スケーリングには触らない。

### 例外は2つだけ

- **置物**: 値付けが寿命込み（×3）なので、素材より重くなるのが正しい姿。契約の対象外
  （テストも `def.type !== 'permanent'` で除外している）。
- **削れる量を1つも持たない合成**（成長のみ・ドローのみ等）: 構造的に払えないので超過を許容する。

### 副作用の是正: 置物の帯超過は「合成不可」にしない

`ALLOW` に 4E/5E の行が無く、4E以上の合成では帯超過判定が `NaN` で常に false になっていた。
行を足したところ 巨獣の踏みつけ×年輪の大樹 が「強力すぎて置物に収まらない」に落ちた——
**ユーザー方針「合成不可は増やさない」に反する**ので、置物の帯超過は
①量を圧縮 → ②それでも収まらなければコストを上げる（〜5E）→ ③5Eでも無理なものだけ合成不可、
の順で解消するようにした。結果、実際に合成不可になるのは
「量を持たない効果（negate等）の置物化」という構造的なケースだけになった。

### 監査結果（全色・全ペア）

| 色 | ペア数 | 中央値 | 165%超 | 最大 |
|---|---|---|---|---|
| 緑 | 810 | 130% | 89 | 313%（真・巨獣の踏みつけ 5E） |
| 赤 | 804 | 129% | 22 | 231% |
| 青 | 425 | 129% | 7 | 204% |
| 白 | 463 | 129% | 7 | 188% |
| 黒 | 496 | 129% | 15 | 206% |

165%超の件数は修正前（緑86）とほぼ同じで、**帯の健全性を落とさずに契約だけを足せた**。
なお「コストを素材合計に単純クランプする（量を削らない）」案も試したが、赤の165%超が 1→81・
最大463% と崩壊したので不採用。**クランプは出力の圧縮とセットでなければ成立しない。**

## 47. 猛り火の査定と、機械査定スクリプト（2026-08-30）

## 49. per-X 参照の査定は「典型的な参照量」を明示する（2026-08-30）

赤の軸の穴埋めで per-X 参照の新効果を2つ足した際、`scripts/card-audit.ts` が
これらの札を丸ごと「査定不可」として飛ばしていた（緑の茨の報い・痛みを喰う根も同様）。
参照量の典型値を表に書くことで査定対象に入れた:

| 効果 | 典型量 | 根拠 |
|---|---|---|
| `dealDamagePerDamageTaken` / `applyBurnPerDamageTaken` | **4** | 1ターンあたりのHP損失の実測 2.5〜5（ブロックで防いだ分は数えない） |
| `dealDamagePerRandomPlayed` | **3** | 1戦闘で撃つ乱数札の枚数 |

**この前提は査定を大きく動かす**。最初 被弾の典型を6 と置いたところ 火だるま193%・業腹169%・
痛みを喰う根171% と全部が壊れて見えたが、実測に合わせて4にすると 129%/131%/129% に収まった。
per-X の札を刷る時は、**まず参照量を実測してから**数値を決めること。

### カオスの査定は「ロール」でなく「枚数」を参照する

`dealDamagePerRandomPlayed` は撃った**枚数**を数える。ロールの結果を参照する設計
（「最大値を出したら追加効果」など）にしなかったのは、査定が分散に依存して定まらなくなるのと、
プレイヤーが学習できないため。枚数参照なら「3枚撃ってから刈る」と計画が立つ。

## 50. 全体化係数の色レート化（2026-08-30 ユーザー指摘「全体火力とか低くない？」）

査定の全体×2係数は「敵2体」想定だが、実測は**平均1.44体・ソロ率60%・ボスは常にソロ**
（幕1 1.33体 / 幕2 1.50体 / 幕3 1.45体）。帯どおりに刷った全体札の実効価値は
9×1.44/14 ≒ **93%** に沈む——しかも赤を「全体火力の色」にした矢先に、
一番重いボス戦が常にソロという逆風構造だった。

### 裁定: 全体化係数は色レートにする

色レート表（得意色が最高レート）の思想をそのまま使う。

| 色 | 全体化係数 | 意味 |
|---|---|---|
| **赤（本家）** | **×1.5**（実測1.44の丸め） | 1体あたりの数値を高く刷ってよい |
| 他色 | ×2（据え置き） | 全体は割高＝§42「全体調整は不要」を維持。緑白黒の全体札には触らない |

`scripts/card-audit.ts` の `AOE_MULT` が実装。**fusion.ts の VP 表は×2のまま**
（合成の値付けは自己整合しており、触ると回帰リスクの方が大きい。合成で全体化した赤札が
やや安く出る誤差は許容——監視項目）。

### 適用（赤の全体札14枚・すべて引き上げ）

炎の波 9→12 / 火の粉の雨 延焼6→8 / 燎原の火 4+3→5+4 / 紅蓮の薙ぎ 6+猛4→8+猛6 /

業火の炉 延焼2→3 / 燠火の心臓 猛5→6。改定後の赤全体: 中央125%・165%超2（既知の限界のみ）。

sim実測: ボス戦（常にソロ＝全体札が最弱の環境）でも deck_blaze 幕3 70→78%・deck_gamble 82%

## 51. 赤の工房対応（2026-08-30 ユーザー依頼「赤の工房設計も見てほしい」）

工房の合成は緑v1のまま全色開放されていた。赤×赤の全3570ペアを機械で洗うと、赤特有の穴が4つ出た。

### 発見と修正

| 穴 | 実測 | 修正 |
|---|---|---|
| **猛り火条件の平坦化** | 423ペアで条件付きダメージが無条件に合算され、条件が消えていた（紅蓮の追撃 12+{猛}12 → 無条件24 = 価値の水増し＋らしさの消失） | 無条件ダメージだけを抽出し、条件付きは条件ごと引き継ぐ |
| **乱数札の最小値査定** | 火運の賭け（乱2〜16）が「2」で値付けされ、**350%の1E札**が生成可能だった | amountMax持ちは平均値で数える（audit と同じ） |
| **新効果が合成不可** | 546ペア（爆熱の解放・火移し・余勢の構え・一擲乾坤・業腹・火だるま・玉突き） | VP表に典型参照量で登録（§49と同じ前提値） |
| **名前が緑語彙** | 赤の合成が全部 樹/牙/蔦（「樹樹の祝福」等） | 焔（applyBurn）・賭（乱数）・閃（衝動）・熾火（延焼のみの接尾）を追加 |

あわせて**条件付き効果の期待値係数0.6**を合成の値付けにも導入した（auditと同じ前提）。
3効果の枠にあぶれた条件付きダメージは無条件ダメージへ換金されるが、満額だと
「条件の対価がタダで外れる」水増しになる——0.6掛けなら公正な換金になる。
副作用として緑の条件付きリアクション合成の圧縮が浅くなる（茨の返し×窮鼠の大牙 = 6/12 → 8/16。
条件付きが安く数えられるぶん帯に余裕ができる = プレイヤー有利方向のみ）。

### 修正後の全景（赤×赤 3570ペア）

- 合成可 **3279**（旧2756）。合成不可はモード札249（レシピのみ=既存規約）と
  「5Eでも収まらない置物」42件のみ
- 条件消失は147ペアに残る（3効果の枠あぶれ。0.6掛けの公正レートでダメージに換金されるため許容——派手枠の割り切り）
- 5E帯の200%超（大花火×紅蓮の終焉 等）は既存契約どおり**消滅付き**で出る（帯超過は消滅で払う）

### 未対応（記録）

- fusion の全体化係数は×2のまま（§50の赤×1.5とズレる。合成の赤全体札がやや安く出る誤差 = 監視項目）
- 赤の手書きレシピ（fusions.json）は0件。緑は6件ある。体感で「⭐レシピ発見」の喜びが
  赤に無いので、面白さ再測の結果次第で数件足す価値がある

### §50追補（2026-08-30 基本2体化に伴う前提変更）

赤の全体化係数×1.5は「平均1.44体・ソロ率60%」の実測が根拠だったが、基本2体化で
**平均1.68体・ソロ率36%**に変わった。×1.5査定のまま実効価値は上振れる（1.68/1.5≒112%方向）。
引き上げ方向の誤差なので措置しないが、次に全体札の帯を確認する時はこの前提で読むこと。
