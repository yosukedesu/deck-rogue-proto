## 4. 設問への回答

### F1. 戦闘の長さ

| 区分 | ターン数 |
|---|---|
| 幕1 通常戦（7戦） | 2,2,2,3,3,3,3 → **平均 2.57T** |
| 幕1 エリート（2戦） | 3T, 3T |
| 幕1 ボス | **6T** |
| 幕2 通常戦（4戦・完走分） | 4,4,4,5 → **平均 4.25T** |

「2ターン目以降に何かが起きた戦闘」＝**11/15（73%）**。ただし中身に段差がある:
- **幕1前半(#1〜3)は「同じ攻撃をもう一度受ける」だけ**で、T2は実質T1のやり直し。装甲8も虚弱も、鳴る前に敵が死ぬ
- **#7以降で質が変わる**。歯車の箱兵の開幕ブロック13、大喰らいの蟲の山札喰い、灼き虻の火傷、探り屋の伏せ分岐反転——**幕2は4〜5Tになったぶん、敵のギミックが1周する**。幕2の4戦は全部「T2以降に盤面が変わった」
- 一言でいうと**幕1前半＝2.5Tで問いが立たない／幕1後半〜幕2＝4Tで問いが立つ**。境目は「敵の実効HPが自分の1ターン出力を超えるか」で、うちの出力が 20(T1)→40(T2以降) と跳ねるので、**敵HP 60以上から急に戦闘が戦闘になる**

### F2. 初期デッキとパッシブ

- **打撃3・防御3の10枚は「ちょうど」寄りの弱すぎ**。T1に 打ち据え→打撃×2 で22出るので、幕1前半の34〜36HPの敵は**2Tで割り切れる**＝手応えは薄い。ただし「弱くて負けそう」ではなく「作業に近い」方向の物足りなさ。#2の小泥×3（9HP×3を打撃6で1体も落とせない）が、この帯で唯一**構成に文句を言わせた**エンカウントだった
- **絡み蔦・蔦の楔がスターターに入っているのは効いている**。蔦の楔は歯車の箱兵・岩皮の甲虫で「最初から持っている解答」になり、絡み蔦のモード選択は毎戦2〜3回悩んだ。**素の打撃/防御が退屈でも、この2枚が判断を作っている**
- **2ターン目からの上限4は明確に体感できた**。T1が3枚・T2以降が4枚＝「T1は仕込み、T2から本番」というリズムが自然に生まれる。使い道は圧倒的に**4枚目の攻撃札**（例: #8で 二連+16 → 打撃6 → 打撃6 の28で探り屋を1体まるごと落とす）。**「4枚目に伏せる」も同じくらい使った**——3枚攻撃+1枚伏せ が幕1のほぼ定型になり、伏せがテンポ損でなくなったのが大きい
- 副作用: **パッシブが成長+1でなくなったので、緑の成長軸カードが提示で全部ハズレになった**（戦2の3枚が全滅・スキップ）。成長は「種を引いてから」の軸になっている

### F3. ピック

- **悩んだ回数: 14回中6回**（戦3・戦4・戦6・戦7・戦11・戦13）。残り8回は「1枚だけ明らかに強い/使える」か「全部ハズレ」で即決。**3枚提示は"悩む"より"引きの当たり外れ"が前に出る**——特に戦2の全ハズレ（成長ペイオフ3枚）は3枚だと救済がない
- **軸は戦4（大角の群長）で決まった**。1E札が多いデッキに「攻撃ごと勢い+2」が乗ると、二連の蔦打ち+（2ヒット）とX札（Xヒット）が全部掛け算になる。以降のピックは全部「勢いが乗るか」で判断できた＝**軸が決まると3枚提示でも迷わない**
- X札の所感は §3 末尾。要点は「**払う量の判断は生まれるが、それは"余りエナジーの受け皿"という消極的な判断**」「5×Xは素だと通常札に負け、勢い前提の札」「全体X（大嵐）のほうが素直に強い」

### F4. 敵

**面白かった3つ**
1. **鞭打ちの鬼軍曹（#6）** — ブロックを得るたび筋力+1。防御3枚が全部死に札になり、「殴り切るしかない」に一本化される。問い→解が1本の線で、**手札の意味が敵によって書き換わる**唯一の体験
2. **血族の儀式（#10・ボス）** — 弔い+2で「踊り手を倒すほど司祭が育つ」。**倒さない選択**が生まれた（実際、残り2HPの踊り手を放置してターンを組んだ）。6Tかけて最後3HPで勝ったのはこのランの山場
3. **用心深い影（#11）** — 攻撃13-17／防御6-9 の伏せ分岐。**押したら本当に切り替わった**うえ、翌ターン「見切られ中＝このターン伏せ直せば変わる」と明示されて**家賃の存在が読めた**。set-confirmが一番よく回った戦闘

**退屈だった3つ**
1. **鉄殻の溝貝（#3）** — 装甲8は「1ヒット上限」なので、打撃6の私には**存在しないのと同じ**。2Tで終わり、装甲を意識した瞬間がゼロ
2. **汚泥紡ぎの蜘蛛（#1）** — 単体・攻撃のみ・2T。急所の順番以外に決断がない
3. **岩皮の甲虫×3（#12）** — 貫通/粉砕が解答なのは分かるが、毎ターン盾を積み直すだけなので**同じ操作を4回繰り返す**。解答を持っていると単調、持っていないと詰み、の二値になりやすい

**伏せ分岐（両分岐予告）について**
- **「押せるスイッチ」に見えた**。用心深い影で実際に押して、攻撃13-17を防御6-9に変えられた瞬間に「これは操作できる」と理解した
- ただし**押せない場面が半分**。#8（探り屋の二人組）は分岐が見えているのに手札にリアクションが1枚も無く、**予告が「今日は無理」という通知**になっていた。伏せ枠1・リアクション3枚のデッキでこれなので、リアクション0〜1枚のデッキだと分岐表示はほぼノイズになりそう
- **賭けとして読めたのは一度だけ危険側にも振れた**。#14（探り屋の三人組）で、同じ敵の分岐が**ローテーションの途中で反転した**（T2は「伏せると11-15／なしで3-5」、T4は「伏せると3-5／なしで11-15」）。HP7で伏せた瞬間に大技に化けたのは「賭け」としては正しいが、**同じ敵カードで方向が入れ替わるのは1回見ただけでは学習できない**。ここは要注意
- 副次的に効いたのが**静かな鈴（伏せ札がある間 敵の攻撃-1）**。#15で「返しを撃つと鈴が切れるので温存する」という**リアクションを撃たない理由**が生まれた（結果は死んだが、判断としては面白かった）

### F5. 経済

- **ショップ2回（幕1 行5 と 行10の?→ショップ）**。品揃えは6枠+レリック+除去+強化で**見る楽しさは十分**
- **値段の所感: カードが 43〜75G、初回所持113Gで「2枚は買えない」刻みが良い**。実際に「薙ぎ角64 + 荒角の一撃54 = 118 で5G足りない」という**惜しい買い逃し**が起きて、これは気持ちの良い足りなさだった
- **レリック150G / 除去75G / 強化100G は高すぎて一度も触っていない**。幕1のゴールドは戦闘12〜18G＋エリート30〜40Gで、**ショップに着く頃の所持金がだいたい110〜120G＝カード2枚か、サービス1回**。デッキ25枚に膨らんだのに除去を一度も検討しなかったのは、**除去75Gがカード1.5枚分の値段**だから
- **最終的に243G死蔵**。理由は「幕2のショップが行13にしかなく、行5で死んだ」。幕1で金を使い切る設計になっていない一方、**幕2前半に金の吐き先が無い**のはもったいない
- 総評: **金は余った。足りなかったのは"1回目のショップでの金"だけ**

### F6. 曲線は変わったか

**変わった。ただし「幕1前半が平坦になり、幕2で急に立つ」形に見える。**

- **初手火力の帯**: 前回までの「幕1中盤で37〜55」に対し、今回は**幕1を通して 4〜28（中央値 12〜18）**。上限4のぶん4枚目は増えたが、**T1は3E固定なので初手が跳ねなくなった**のが一番大きい。「T1に全部出して終わり」は一度も起きていない
- **通常戦のターン数**: 前回2.5〜2.9T → 今回**幕1 2.57T / 幕2 4.25T**。幕1は据え置きだが、**幕2で明確に伸びた**。伸びた理由はカードでなく敵側（開幕ブロック・装甲・とげ・盾積み・61〜89HP）で、**うちの出力の伸び（20→40）を敵HPが追い越した**
- **X多段への収束は起きていない**。X札を2枚（うち1枚は75Gで購入）持っていたのに、実戦の主役は 幹撃(上限×4)・二連の蔦打ち+・牙の一撃 の**固定値組**だった。X札は「余りエナジーの受け皿」に落ち着き、**軸ではなく潤滑油**になった。これは前回からの明確な変化
- **代わりに立った収束先は「1E札を並べて置物で掛ける」**。大角の群長・棘の蔓×2 が入ってから、**毎ターン4〜5枚プレイ＝勢い+8〜10／ブロック+8〜10**という形になった。曲線の主役が「1枚の大技」から「枚数×置物」へ移っている
- **HP曲線が厳しくなった**。幕1は焚き火25%回復2回で 80→3 まで落ち、ボス全回復で救われたが、**幕2は80→5を4戦で使い切った**。緑は回復が無いので、**幕2に入った瞬間の"1戦あたりHP-15〜20"が構造的にきつい**。死因も「HP5で通常戦に入らされ、T1に打てる手が無い」という**選択のない死**だった（敗因を選ぶなら「構築の失敗」寄り——防御をもっと早く厚くすべきだった。ただしT1に最大5ブロックしか出ない盤面は理不尽側にも半歩ある）

## 5. バグ・表示の違和感

1. **同じ敵の伏せ分岐の向きがローテーション中に反転する（探り屋）**。#14 T2 は「【伏せ札あり】攻撃11〜15 ／【なし】攻撃3〜5」、同じ個体の T4 は「【伏せ札あり】攻撃3〜5 ／【なし】攻撃11〜15」。仕様（行動ごとにsetAltを持つ）なら正しいのだが、**プレイヤー側は「探り屋＝伏せると殴られる敵」と1回で学習してしまう**ので、2回目に逆を踏む。行動名が違えば納得できるが、表示上はどちらも「攻撃N〜M」で見分けが付かない
2. **育つ牙の「プレイするたび与ダメ+4(この戦闘中)」が読み取れない**。1枚しか持っていないので2回目のプレイが起きず、**+4がこのカード限定なのか全体の成長なのか、10戦以上プレイして最後まで分からなかった**。文面だけだと「与ダメ」が誰のものか曖昧
3. **戦闘記録の「完全に凌いだ7回」（#14）** — 5ターンの戦闘で7回はヒット単位のカウントに見える。ターン単位/行動単位/ヒット単位のどれかが分かりにくい
4. **エラー文（1件）**: 敵を倒したあとに続けてカードを投げた時 `エラー: 戦闘中ではない`。挙動は正しいが、**「その攻撃で敵が全滅したので残りは打てません」のほうが親切**
5. 良かった表示: 装甲の`【装甲で1切り捨て=本来9】`、伏せの`【見切られ=敵は反応しない。破壊は来る】`、X札の`［X=1〜5を xAmount で指定 (省略=全部)。全部なら計25］`。特に見切られ表示は**家賃の存在を1行で説明できていた**
