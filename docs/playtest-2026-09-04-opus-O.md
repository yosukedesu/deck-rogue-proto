## 3. 設問への回答

### O1. 因縁の亡霊
**無形ターン(奇数)にやったこと**は、4ターンとも全部「備え」だった。
- T1: 芽吹き（ランプ）／T3: 大角の群長＋守りの蔓を伏せる＋三連の角で3チップ
- T5: 樹皮の鎧14＋2枚目の大角の群長（＝置物2枚目をここで置けたのが後の86ダメの土台）
- T7: 樹皮の鎧＋突進の助走×2＋三連の角（ブロック14＋7チップ）

**実体ターン(偶数)に叩き込んだもの**は、T2=20、T4=42、T6=**86**（樹液2枚→突進の助走→二連の蔦打ち→踏み荒らし→大地の唸りの順で勢いを19まで積む）、T8=とどめ。
戦闘記録の「最大ターン126」はT6の実ダメで、**片方のターンにしか価値が無いので、その1ターンに全部を寄せる並べ替えパズルが自然に発生した**。

**リズムは緊張。ただし尻すぼみ。** 面白かったのは前半で、「今日は置く日／明日は殴る日」が置物・ランプ・伏せの置き場を作ってくれた。緑のように "置物とランプが強いが置く暇がない" 色にはご褒美として効く。
退屈だったのは終盤で、**T7に敵HPが15しか残っていないのに無形なので殺せず、丸1ターン待つだけ**になった。これは「読み合い」ではなく「待ち」で、set-confirmの緊張とは別種の停滞。**残りHPが低いときほど無形ターンが理不尽に長く感じる**。

**被ダメ1固定は理不尽に見えなかった。** ヒットごとに `与ダメ6(HP損失1)【無形で5消滅=1固定】` が出るので、消えた数字が毎回目に見える。敵カードの「因縁」タグも常時出ていてフェアネスは満点。

**多段でも1固定は効いた（＝多段は救いにならない）。** 正確には *多段のほうがマシ* で、三連の角=3ダメ、二連の蔦打ち=2ダメ、巨象の突進+(52)=1ダメ。**無形ターンだけは多段が単発の3倍効率という逆転**が起きるが、絶対量が最大でも7〜9なので戦術にはならず、「無形ターンは何をやってもゼロ」という結論は変わらなかった。ここは意図どおりだと思う。

**数字の所見**: 実効HPが約2倍（169→実質338）。これは幕3ボス三の相(168)と同じ体格で、**通常戦ノードに置くには重すぎる**。無形を「奇数ターン」でなく「3ターンに1回」にするか、HPを130前後に落とすのが良い。もう一段良い案は、**無形中に当てたヒット数を実体ターンの最初の攻撃に還元する**（例: 無形中の1ヒットにつき次の実体ターンの攻撃+2）で、無形ターンに"攻めの選択肢"が生まれる。今のままだと無形ターンはプレイヤーが完全に受け身。

### O2. 潜行する大地虫
**殻30は一度も"割っていない"。** 理由が2つ重なった。
1. **貫通は殻を素通しする**ので、緑トランプルは殻を壁として認識しない。T1の踏み荒らし16貫通がそのままHPへ通った。割らないので**大顎18〜22も一生来ない**。
2. **殻はこちらが何もしなくても、最初の敵フェーズ開始時に0になる。** T1に殻へ一度も触れていないのに、T2の盤面表示は `潜伏中(殻0)`。そこに1Eの突進の助走を当てただけで `🪺潜伏の殻が割れた!` が出て大顎に切り替わった（→バグ欄1）。

したがって **「割るタイミング」は決断にならなかった**。割ったターンに倒すも何も、割れた時点で敵HPは110/120で、そのまま大顎21を受けた。これは判断の結果ではなく「1Eの余りで事故的に割れた」だけ。

**幕2の甲虫(殻12)より問いの質は下がった。** 甲虫の12は「1ターンぶんの出力で割り切れる量」なので、*割って殴りにいくか/貫通で無視するか* が実際に天秤になる。大地虫の30は1ターンでは割れない量なので、割る側の選択肢が消えて「無視する（貫通）」か「勝手に消えるのを待つ」の二択になり、**量を増やしたぶん問いがむしろ痩せた**。

**処方案**（優先順）:
1. 殻を敵ブロックと別枠（氷壁式の持ち越し）にして、敵フェーズの block=0 掃除に巻き込まれないようにする。これをやらないと良し悪しの評価自体ができない。
2. そのうえで「貫通はHPに通るが殻は削れない＝大顎を起こさずに倒しきれる」を貫通の正当なご褒美として明示する。緑=起こさない／他色=割って大顎を受ける、の色差が立つ。
3. 殻の量は 30 のままでよいが、**割った瞬間に「今ターン中なら大顎は来ない」ことを盤面に一行出す**と、割る決断が締切として立つ（巨面の「⚠今ターン倒せない」と同型）。

### O3. 幕3の長さ
| 区分 | ターン数 |
|---|---|
| 通常戦 | 罠壊し4 / 蛙鬼6 / 亡霊8 → **平均6.0T** |
| エリート | 不滅の骸兵 5T |
| ボス | 8T（敗北） |
| 参考・単発 | 大地虫 6T |

- **「2ターン目以降に何か起きた」割合＝5/5（100%）。** 今回のランは2〜3ターンで終わる戦闘がゼロで、これは物差し（通常戦4〜6T）にきちんと乗った。**幕3に関しては「戦闘が短すぎる」問題は解消している**と言ってよい。通常戦の平均6.0Tは上端で、亡霊の8Tが引っ張っている。
- **長さの出どころは、ほぼ全部「拍」であって「厚み」ではない。**
  - 厚みだけで伸びたのは罠壊し(4T, HP108)のみ
  - 蛙鬼6T=分裂／骸兵5T=残機3段／亡霊8T=無形の空ターン／ボス8T=残機3段
  - これは設計として正しい方向。ただし **同じ「残機」の拍が行5エリートと行14ボスで連続した**のは体験が重複した。骸兵とボスは削り方が同じで、2回目は「またこれか」になる。幕内で拍の型（分裂／残機／無形／ターン装甲）が被らないようにする配置制約があると良い。
- 汚泥の大暴れ・巨面は**評価不能**。汚泥は大地虫と同じ枝、巨面は亡霊直前の行9にいたがHP61で挑むのは自殺だったので回避した。**「ターン装甲の器がまた1ランで一度も鳴らなかった」**のは記録しておく価値がある（人間ラン#2と同じ症状。行9の巨面は亡霊と択一で、亡霊を見るなら踏めない配置だった）。

### O4. 完走と収支
HP推移: 80 →69(罠壊し) →53(蛙鬼) →37(骸兵E) →[焚き火=鍛える] →[宝箱] →61[焚き火=休む] →**5(亡霊)** →29[焚き火=休む] →0(ボス)

**死因はHP収支。** 単独の犯人は因縁の亡霊で、**1ノードで61→5（-56）**。構造的な理由がはっきりしていて、
> 支払い（被ダメ）は全ターンに比例するのに、回収（与ダメ）は半分のターンにしか比例しない

亡霊は8ターン戦で8回ぶん殴られ、削れたのは4ターンぶん。**「実効HP2倍の敵」ではなく「実効HP2倍かつ被弾も2倍の敵」**になっている。ここを通ると次の戦闘に持っていくHPが残らず、焚き火1回(+24)では埋まらない。ボスに29HPで入った時点で詰んでいた。

構築の失敗も少しはある（貫通の大型札に寄って無形ターンに撃つものが無かった）が、**多段を積んでも1固定なので亡霊に対する構築上の正解が存在しない**——つまり構築では解けない。焚き火の「鍛える」を巨象の突進+(48)に使ったのも、亡霊の無形ターンには1ダメしか出ない札を太らせたことになり、結果的に外した。

理不尽感の投票としては **「構築の失敗」ではなく「HP収支」**。理不尽(即死・ハメ)ではなかった。

### O5. 総評
**因縁 = 本家並みの良いギミックと言ってよい。ただし「無形ターンの攻めの選択肢」が1つ足りない。**
拍そのものは Time Eater / Awakened One と同種の良さで、置物・ランプ・伏せの置き場が生まれるのが緑にはご褒美。表示のフェアネスも満点。減点は2つだけで、(a)残りHPが少ないときの無形ターンが「待つだけ」になる (b)実効HP338は幕3通常戦の器として重すぎる。**HPを130前後へ、または無形を3ターンに1回へ**を推す。加えて「無形中のヒット数を実体ターンに還元」を入れると、無形ターンが受け身でなくなる。

**潜伏 = 現状の実装では成立していない。** 殻がT1の敵フェーズで自然消滅するため、「30を割る」という体験が発生しない。バグを直すまで良し悪しの判定はできない。直したうえでも、貫通が素通しする限り緑では問いが立たないので、**甲虫(12)が良かったのは「1ターンで割り切れる量」だったから**という点を踏まえて量を再設計してほしい（30のままなら「2ターンかけて割るか、貫通で無視するか」を成立させるために、殻の持ち越しが必須）。

**次に入れるなら「バランス崩し（完全ブロックでスタン）」が欲しい。**
理由: 今回のランで防御は最初から最後まで「被ダメを減らすだけ」の受け身の行為で、ブロックを積む判断に上振れが1回も無かった（樹皮の鎧14で18を受けて4通る、の繰り返し）。完全ブロックにご褒美が付くと、**常時出ている「最悪被ダメ予測」と確認ウィンドウの実値公開が、そのまま"目標値"に変わる**。set-confirmの「実値を見てから決める」と同じ土俵の計算パズルになり、既存のUIが全部そのまま活きる。守りの蔓12を「あと2足りない」ために温存する、といった判断も生まれる。
**私設の巣（被弾ヒットごとに使えない札を山札へ）は要らない。** すでに がらくた／火傷／負傷／烙印 と札汚染の器が4つあり、5つ目は識別が付かない。

## 4. バグ・表示の違和感
1. **[重大] 潜伏の殻が敵フェーズ開始時に自動で0になる。**
   `src/engine/combat.ts:1314`「敵ブロックはこのタイミングで失効」が全敵の `block` を0にするが、`combat.ts:163` で殻は `def.burrow?.block ?? def.startingBlock` として**敵ブロックと同じ器**に入っている。結果、殻30は**自ターン1回ぶんしか存在しない**。実測: T1に殻へ一度も触れずEndTurn → T2の盤面が `潜伏中(殻0)` → 1Eの突進の助走1枚で `🪺潜伏の殻が割れた!` → 大顎へ切替。設計文（「殻30が尽きるまで通らない」）と実挙動が乖離している。
   ついでに `burrowActive` が true のまま `block:0` になるので、**「潜伏中(殻0)」という矛盾した文字列**が出る（割れてもいないのに殻が無い）。
2. **手札のダメージ内訳(実値)に無形が反映されない。** 無形ターンでも `踏み荒らし … ［実値: 敵0:17］` と出る（実際のHP損失は1）。装甲・ターン装甲は上限として内訳に出ているので、無形も同じ扱いにすべき。**窓が嘘をつく**類の表示。
3. **無形の実効HPがどこにも出ない。** 巨面のターン装甲には「⚠今ターン倒せない」の予告が付いているのに、亡霊には「今ターンは1ヒット=1」の注記が敵タグの説明文にあるだけ。奇数/偶数のどちらかを盤面に大きく出す（例: 意図行に `👻無形` バッジ）と、殴る/備えるの切り替えが読みやすくなる。
4. **ショップの `ShopLeave` に確認が無い。** 在庫を最後まで見る前に退店すると二度と戻れない（幕3はショップが実質1回）。今回250G抱えたまま使い道を失った。自分の操作ミスだが、CLIでもUIでも一発退店は事故りやすい。
