## 3. 設問への回答

### 3-1. テンポ

**幕1は 5.1T、幕2は 4.0T。**「物差し」（通常4〜6T・ボス6〜10T）の帯には入っている。
旧 A/B/C（幕2 5.0〜6.5T・ボス 7〜11T）より明確に短く、白スターターの 11.41T とは別ゲーム。
体感としても**幕2の3戦（3T／3T／6T）は白で初めて「回っている」**と感じた。灯が育ってからは
「溜める→1枚で全部持っていく」が成立し、旧白の「ブロックを積んで人形の2ダメを待つ」は消えた。

ただし**間延びは2か所に残る**。

- **幕1の前半（行1〜2）**：灯の収入がひなたのパッシブ+1/ターンだけなので、灯5のしきい値に
  T5まで届かない。灯の矢は T1=2ダメ・T2=4ダメで、**灯火の一撃5より弱い札が3ターン続く**。
  「灯の教材」として初期デッキに入れた札が、教材の期間中ずっと最弱という倒錯がある。
- **強個体 歩哨の三つ子の11T**：がらくた2枚×複数が5枚の手札を埋め、3ターン目は
  「がらくた3・白盾・一撃」で実質1手。灯も人形も増えないターンが2回あり、ここは完全に作業だった。
  白の「灯を溜める」は手札を要求しないので相性が悪いわけではないが、**手札破壊は灯の加速を止める**。

### 3-2. 灯の決断（号令に使うか、放出のために溜めるか）

**「号令 vs 放出」の二択が立ったのは 1回だけ。**（幕2行5 走竜戦 T6・HP15・被ダメ予測34）
そこでは**号令を選んだ**。理由は、放出（大灯の祝福 灯23→24×5＝120）の対象が庇う持ちの母鳥
（残り22HP）にしか向かわず98が捨てられるのに対し、号令は人形6体で**12ダメ＋ブロック8**を同時に
出せたから。つまり選んだ理由は「灯の使い道」ではなく**対象制限とブロックの有無**であって、
資源の交換レートを比べた結果ではない。

二択が立たなかった理由は3つ、いずれも構造的。

1. **号令（点灯の合図）の入手が遅すぎた。** 13戦目（幕2行1）の報酬でようやく取れた。
   幕1行2で一度提示されたが、そのとき従者は0体で**プレイ不可の表示が出ている札**であり、
   取る判断にならない。号令は「盤面ができてから」しか価値が読めないので、
   ドラフトの前半で提示されても死に札に見える。
2. **交換レートが盤面の大きさに完全に従属する。** 灯2の対価で号令が出すのは（人形の数×効果）。
   人形5〜6体の終盤なら 12ダメ+ブロック8 で圧勝、人形2〜3体の序盤なら 4〜8ダメで、
   同じ灯2を大灯の祝福（×5）に回した10ダメに負ける。**盤面が育つと灯も同時に育つ**ので、
   どちらか一方が明確に上、という状態が長く続き、迷う帯が薄い。
3. **放出と号令が同じターンに両方撃てる。** 1E＋灯2の号令は軽く、4エナジーあれば
   「号令→放出」の順で両方入る（走竜戦T6で実際にそうした）。灯は号令に2しか使わないので、
   放出の×5が実質1割しか減らない＝**選ぶ必要がない**。

一方、**「いま吐くか、もう1〜2ターン溜めるか」の二択は何度も本物だった**（下は代表例）。

- 幕1行1 T3：敵ブロック9。灯3を吐けば6ダメだが全部ブロックに吸われる → 溜めてT5に灯5×2＝10で撃破。
  「ブロックの上から吐くのは損」という算数が1戦目で立つのは良い教材。
- 幕1行7 T3：灯6＝12ダメが敵の大技持ち（残12HP）をちょうど落とす → **吐く**。
  「放出で敵を1体落として被ダメを消す」は白で初めて味わう快感だった。
- 幕2行1 T4〜T6：灯13→18→22。毎ターン「いま撃てば65／待てば90」を数えながら我慢した3ターンが
  このランで一番面白い。

つまり**灯の経済は「溜める／吐く」の軸では完全に成功しており、「号令／放出」の軸だけが未成立**。

### 3-3. 置物を出したターンの空白

**人形については完全に消えた。** 点灯（1E）でも灯りの行列（2E）でも、出した瞬間に
①灯が増え ②その人形が動く（剣＝殴る・盾＝守る・灯芯＝灯）ので、「置いただけのターン」が無い。
幕1行4 T1に 灯りの行列＋点灯 で3体を並べたターンは、灯1→4・6ダメ・ブロック2が同時に出て、
旧白の「T1は召喚だけで終わる」とは完全に別物だった。**この裁定は効いている。**

**ただし人形でない置物は空白のまま。** 灯の弩（灯を得るたび全体1）は登場に何も起きず、
幕1行12では「敵が全員防御して被ダメ0のターン」を選んでやっと置いた。灯の捧げ（アンセム）も同じで、
さらに人形を1体壊すので出したターンは盤面がマイナスになる。
人形だけが点灯の定義の恩恵を受け、**灯の置物（弩）と強化の置物（捧げ）は旧白のままの手触り**。

### 3-4. 山（1ターンの最大与ダメ）

**123ダメージ（幕2行1 用心深い影 T6）。**
内訳＝大灯の祝福（工房産＝灯の矢×光の奔流）で **灯22→+1して23×5＝115** ＋ 剣の人形2体×4（アンセム込み）。
残りHP51を1枚で消し飛ばした。

**爽快感 5/5。** 白で「1枚で戦闘が終わる」を初めて体験した。6ターン我慢して数字が育つのを
見ていたので、撃った瞬間の気持ちよさは緑の成長デッキと同格かそれ以上。

他の山：幕2行4 インプ戦 71（灼く光16＋大灯の祝福55）、幕1行9 狂信者 66、幕1行5 46。
**「最大ターン火力が総与ダメの7〜8割」という戦闘が幕2で3本**あり、これは旧白では起きなかった形。

**ただし装甲が山を丸ごと食う。** 幕1ボス 脳筋オーガ（装甲25）では
`与ダメ25（装甲で65切り捨て=本来90）`。灯18を溜めた対価が25で、**灯を6以上に育てる意味が消える**。
オーガ戦では結局「灯の集い（置物数×4）も25で頭打ち」「灼く光16が最良レート」という
逆転が起き、**灯のデッキは装甲持ちの前でだけ旧白に戻る**。
（一撃装甲＝大型単発の墓場、の既存裁定どおりの挙動ではあるが、白の新しい柱が丸ごと
その墓場に置かれている点は設計判断として記録しておきたい。）

### 3-5. 提示と見送り

→ 「## 4. 提示と見送り」に一覧。
**灯の札は取りたくなったか＝強く取りたくなった。** 13回のピックのうち**11回が灯に関係する札**で、
うち灯の収入を増やす札（灯芯の人形×2・灯りの行列×2・白光の壁・灯守りの壁）が6枚。
理由ははっきりしていて、**このデッキのボトルネックは放出の倍率ではなく灯の収入**だったから。
ひなたのパッシブ+1/ターンだけだと灯5のしきい値に5ターンかかるので、
「灯が2増える札」はどれも即ピック。灯芯の人形（毎T灯+1）は**灯の捧げ（アンセム+2）で
毎T灯+3になり、2体で+6/ターン**＝幕2行1で灯22に届いた直接の原因。

逆に見送った灯の札：
- **点灯の合図（幕1行2）**：従者0体で「プレイ不可」の表示が出ており取れなかった（§3-2）。
- **光の奔流（強個体報酬で取得）以外の放出札**：放出は1枚あれば足りる。灯は1回で全部無くなるので
  **2枚目の放出は完全に腐る**（工房で灯の矢と光の奔流を合成して1枚に畳んだのはこの理由）。
  これは「放出を厚く刷る」方向が効かないことを意味する。

### 3-6. 表示の嘘・不具合

1. **放出札に実値予告が無い（最大の問題）。** 提案書 §3-5 の「[現在 灯N → Mダメ]」が CLI に出ない。
   手札の表示は最後まで `灯の矢(1E/spell) 灯×2ダメ(全消費・灯0なら不発)` のままで、
   灯22のときに大灯の祝福が何点出るのかは**自分で掛け算するしかなかった**。
   通常のダメージ札には `［実値: 敵0:6(敵ブロック-2)］` が出るのに、放出札だけ出ない。
   「溜めるか吐くか」が本作の新しい決断なのに、その決断の数字が画面に無い。
2. **灼く光のしきい値の2発目が実値に出ない。** 灯7のときの手札表示は
   `［実値: 敵0:6(敵ブロック-2)。先頭ヒット基準］` だが、実際は `与ダメ8＋与ダメ8` で16。
   「先頭ヒット基準」の注記があるので嘘ではないが、**条件が成立していることが手札から読めない**
   （灯5以上なのか未満なのかが分からない）。幕1行2で「いま撃つか灯5まで待つか」を
   数えたときに一番欲しかった情報。
3. **号令のログ文面が古い。** `📯号令: 従者6体のターン開始効果を今すぐ解決` と出るが、
   実処理は旗の人形（攻撃プレイごと:ブロック2）も鳴っていた（ブロックが4→12に増えた）。
   裁定は「トリガーを問わず」なので、文面だけが旧 triggerRetainersNow のまま。
4. **点灯の定義のログが「🏇駆けつけ」のまま。** 新語彙は「点灯」。
   `🏇駆けつけ: 剣の人形が登場してすぐに動いた`。
5. **灯が増えた理由のログが無い。** 提案書の「灯+1（回復）」「灯+1（人形）」「灯+1（灯匠）」が
   出ないので、資源欄の数字が飛んだ理由を出来事から逆算するしかない。
   灯りの行列で灯が+2されるのか+1なのかを、実際に撃って資源欄を見るまで知らなかった。
6. **号令札の「[人形N体]」予告も無い**（提案書 §3-5）。何体ぶん動くかは置物欄を自分で数える。
7. 良かった表示：`装甲で65切り捨て=本来90` は明快。
   点灯の合図の `〈従者が場にいないのでプレイ不可・灯不足(灯2が要る)〉` は2つの理由を
   両方出していて親切。資源欄の `灯 N` も読みやすい。
8. エラー・クラッシュは無し。`エラー: 対象 0 はすでに倒れている` の案内（生存: 1,2）は正しく出た。

### 3-7. 直すなら1つ

**放出札と号令札に実値を出す（`灯22 → 110ダメ` / `人形6体が動く`）。**
灯の経済の核は「いま吐くか、もう1ターン溜めるか」で、それは**毎ターン掛け算を比べる決断**。
その数字が画面に無いと、決断が「面白い計算」ではなく「暗算の義務」になる。
通常ダメージ札には既に実値が出ているので、同じ器に載せるだけで済むはず。
（次点は §3-2 の号令＝**点灯の合図を1E・灯1にする**。灯2は放出×5に換算して10ダメ相当で、
盤面が4体を超えないと割に合わない。灯1なら「盤面3体から号令が勝つ」帯ができて二択になる。）
