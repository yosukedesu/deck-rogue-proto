- **「2ターン目以降に何か起きた」は 10/19＝53%**。起きなかった9戦は、すべて「T1〜T2で敵が死んだ」戦闘

### H2. 溝貝と混成編成

**鉄殻の溝貝（装甲8→5）＝発火した。今回いちばん効いた数値変更。**
- 初戦のHP36に対し**全ヒットが5で頭打ち**＝最低8ヒット必要。ログの「【装甲で1切り捨て=本来6】」が毎回出るので、切り捨てが**目で見えた**
- 生まれた判断は3つ: ①**絡み蔦のモードが反転**（7ダメ→5に削られるので、満額のブロック7を選ぶ＝「大振りを控える」がモード札の中で起きた） ②**打ち据えの急所+2が完全な死に札**になる（6→9→上限5で+0）＝「装甲相手に急所は買わない」を初戦で教えられた ③3ターンかかるが被ダメは1＝**長いのに痛くない**ので、退屈でなく「編み物」の手触りになった
- 面白さ4。**幕1の1戦目にこれが来るのは教師として理想的**（装甲25のオーガ、装甲30の大亀へ一直線につながった）

**甲虫と用心深い影（新混成）＝2つの問いが同時に立った。**
- 甲虫＝開幕ブロック12+HP19（殻を割る問い）／影＝HP54+**伏せると12-16が17-22に化ける罰型**（伏せない選択の問い）。**しかも解き方が違う**（甲虫は多段/貫通、影は殴り合い）ので、T1に「突進の助走で殻12をきっちり剥がしてから森羅の大嵐X=3で殻ごと焼く」というキル順が要った。**通常戦でキル順に悩んだのは本ランでここだけ**
- ただしT2に影が**弱腰分岐（伏せ札あり→防御6〜9）**へローテーションし、「1Eの札を1枚伏せるだけで攻撃が消える」が見えていた（手札にリアクションが無く押せなかった）。**罰型と弱腰型が同じ敵の別ターンに同居している**のは読みの筋が通らない
- 道化と妖術師と太鼓は**未遭遇**（マップに出たが経路外）

### H3. 経済

- **除去50Gは幕1で買った**（行9・187G所持）。抜いたのは**打撃（1E・6ダメ）**。理由は上記のとおり「真・打撃+が同コストで23出す＝完全な下位互換」「15枚デッキの7%」で、**50Gなら考える時間もいらない**。ここは価格改定が完全に効いている
- **足りなかった時期**: 幕1前半のみ（戦5時点で125G＝除去1回か報酬札1枚のどちらか）。**余った時期**: 幕1のショップ以降ずっと。終了時238G。**2回目の除去100G・3回目150Gという逓増が正しく機能して、金の使い道が消えた**
- **強化100Gが鍛冶の砥石で無料になった瞬間、ショップの2大サービスの片方が死んだ**。以後ショップは「カード5枚を眺めて1枚買うか買わないか」だけになり、170G持って56Gの置物1個だけ買って出る、が2回起きた
- 品揃えの所感: **上限参照/ランプ札（深根67G・天蓋の実り77G・大樹の岐路80G）が繰り返し並ぶが、2ターン戦では買えない**。値段でなく**商品と戦闘長のミスマッチ**

### H4. ピック

- **3枚提示で本当に悩んだのは4回**（戦2の蔦の陣vs突進／戦6の大幹の構えvs牙の一撃相当／戦8の守り手vs牙の一撃／戦14の荒野の呼び声vs二連2枚目）。残り15回は**10秒で決まった**か**全部見送った**（見送り3回）
- **軸が決まった瞬間**: 戦4の二連の蔦打ち。ここから「1ヒットが小さく、本数が多い札」だけを見るようになった。決定づけたのは**戦6の成長の種（開幕成長+1）**で、以後すべての加算がヒット数ぶん増えることが確定した
- **前回所見の再現**

## 5. バグ・表示の違和感

1. **【見切られ＝敵は反応しない】の表示が罰型の敵と矛盾する（要修正）**
   幕1ボス戦T3で、伏せ場の表示は
   `大樹の守り手 …【見切られ=敵は反応しない。破壊は来る】`
   なのに、同じ画面の意図行は
   `【伏せ札あり】攻撃14〜18 ／【なし】攻撃11〜15 → 今は「攻撃14〜18」 (伏せ札は見切られ中=このターン伏せ直せば変わる)`
   と**伏せ札あり分岐で解決されている**（オーガ激怒は ignoreFreshness のため仕様どおり）。幕2ボスでも同じ矛盾が出た。
   さらに括弧の「**このターン伏せ直せば変わる**」も、ignoreFreshness の敵に対しては嘘（伏せ直しても罰分岐のまま）。**罰型（ignoreFreshness）の敵に対しては伏せ札のタグを「見切り無効＝伏せている限り反応する」に切り替える**必要がある。

2. **エネルギー不足のプレイが無言で失敗する**
   幕2 #16 のT3で、`SetCard`(2E) の後に `PlayCard 木漏れ日`(1E) を投げたところ、4E使い切っていたため**エラーも出さず（少なくとも tail に出ず）盤面のブロックが0のまま**進んだ。cmd単体では exit 1 で「エラー: …」が返る仕様のはずなので、複数コマンドを連続で流したときに気づけない。実害は自分のミスだが、`〈エナジー不足〉` の状態で PlayCard を投げたときのエラー文が他のエラーと同じ1行なので**見落としやすい**。

3. **X札の「全部なら計N/体」表示が急所・勢いを含まない**
   `森羅の大嵐 … ［X=1〜4を xAmount で指定 (省略=全部)。全部なら計20/体］` は成長のみ反映で、急所（×1.5）や勢いは入っていない。実際は幕1ボスT5でX=3が27ダメだった（表示は「計15/体」相当）。**上限参照札には実値注記が入ったのに、X札の予告値は素のまま**なので粒度が揃っていない。

4. **弱腰分岐と罰型分岐が同じ敵に同居している（設計の違和感）**
   用心深い影は、あるターンは `【伏せ札あり】攻撃17〜22 ／【なし】12〜16`（罰型＝伏せると損）、次のターンは `【伏せ札あり】防御6〜9 ／【なし】攻撃12〜16`（弱腰型＝伏せると得）。**同じ敵で伏せの意味が正反対に切り替わる**ので、「この敵は伏せていい敵か」の学習が成立しない。

5. **「岩皮の甲虫」がソロと編成でHPが違う（32 / 19）**のは編成補正だと思われるが、**単体版のほうが強い小物**なので「固い小物の教師」としては編成版のほうが先に出てほしい（今回は編成→単体の順で、単体は完全な消化試合になった）。
