## 2. 一致点

### 2-1. 延焼は幕2/3 の硬い敵への万能の答え（3本一致・良い所）
- 装甲・ターン装甲・開幕ブロック・無形・潜伏の殻・延焼耐性（燻り）を延焼が素通しする。幕3の防御ギミックは赤には問いにならなかった（A「ほとんど問いにならない」）。
- 被ダメ予測の「延焼で行動の前に焼け落ちる」で、大技を撃たれる前に焼き殺す計算ができる。**3本とも最高の手触りに挙げた**。表示の嘘は見つからなかった。
- 灰かぶり（延焼×1のブロック）が「積むほど守れる」赤の守りとして A・C の生命線になった。

### 2-2. チェインが延焼を全消費する札に当たる事故（A・C の独立2本＝作り直し基準）
- A: 双つ火のチェインが爆熱の解放に当たり、延焼18を勝手に全消費した。しかもターン装甲で 57→35 に切られた。
- C: 守りのつもりで撃った連火の盾のチェインが火掻きに当たり、延焼16が消えて装甲25で切られた。同じことが2回あった（3回中2回が裏目）。
- 自分で撃った火掻き・爆熱の解放は「最高のとどめ」で、チェインで撃たれると「最悪」になる。差が大きすぎる。
- `docs/balance-policy.md` の作り直し基準（構造の報告が独立2本一致）に該当する。

### 2-3. 衝動の失効＝消滅の自食い（3本一致・3回目）
- A: 全てを燃やせ（3E）を衝動で引いて払えず消えたのが5回、真・刹那の焔が2回。「手順を守っても防げない」「強い札ほど戦闘から消える」。
- B: 幕1ボスで燠火の心臓+、亡霊戦で火掻柱の一撃と火の海が消え、最後に11足りずに死んだ（敗北の決め手）。
- C: 炎の波・棘火の帳・火纏いが失効して消えた。
- 段1（10/10）と段2チェックポイント（10/12）でも最悪に挙がり、どちらも「据え置き・監視」で裁定している。**3回連続の一致**。
- 良い面もある。衝動で引いた呪い・がらくた・負傷が失効で消える（A・C）。燃え残りがあると失効は燃料になる（B の奴隷商戦）。

### 2-4. 刈る札のダメージが装甲に切られることが読めない（3本とも言及）
- 刈りのダメージは1ヒット扱いで、装甲とターン装甲に頭打ちされる。延焼のままなら素通しだったので二重に損をする。
- B は「装甲の有無で刈るか待つかが分かれる」を良い判断として楽しんだ。C は「札の文から読めない」を不満に挙げた。
- 不満は規則そのものより、表示に出ていないことに向いている。

### 2-5. 残機・分裂で延焼が引き継がれない（B・C）
- 蛙鬼の幼体・斧兵の再起・幕3ボスの合成獣（合計 702〜720HP・三つの相）は、相が変わるたびに延焼が0に戻る。
- C の敗因の半分はこれだった（納得3）。A は爆熱の解放 296 で三の相を一撃で越えた。
- 「別の体なので延焼は消える」は規則として妥当だが、図鑑にも敵の説明にも書かれていない。

### 2-6. 幕3の守りはチェインのくじとギア（A・C）、立ち上がりの T1〜T2 が薄い（B）
- C は23戦で被ダメ0の戦闘が1つも無い。山場は全部「連火の盾のチェインが守りに当たるか」で決まった。
- A はギア（惑わし・時の歯車・錆びた鎖×2・血の発条・掘り出し）が5回守りの穴を埋め、「ギアが無ければ死んでいた」。
- C は合成獣戦の途中で魔素が尽き、最後の2ターンはギアも守りも無かった。
- 守りの C 札（灰の帳・熾の衝立）は B だけが出会い、2枚とも良好だった。A・C は一度も取っていない（C は灰の帳を1回見送り）。供給は足りてきたが、引けるかどうかの揺れが大きい。
