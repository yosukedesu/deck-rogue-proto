## 3. 設問への回答

### 1. テンポ

幕1通常戦 4.5T・幕2通常戦 6.25T・幕ボス 9T。通常戦8戦のうち帯（4〜6T）が5戦、7Tが2戦（砥石の巨像・大顎の狩人＝どちらも「タイマー型の大技を受けてから人形で削る」形）。物差しの上端に寄っているが「間延び」は感じなかった——**人形が毎ターン9〜19点を自動で出すので、灯を溜めているターンも敵のHPが減り続ける**（旧・白Aの「ボス後半で同じ手を4回」は今回一度も起きなかった）。

作業を感じた場面は2つ。
- **戦闘2 酸吐きの蛞蝓（6T）**: 人形がまだ1体も無く、弱体2が灯の矢を「2ダメ×6回→1×6」に半減させる。灯を溜める意味が薄いのに撃つものも無い＝初期デッキ×状態異常の敵は今も平坦。
- **戦闘10 砥石の巨像のT1〜T2**: 開幕ブロック10の前で打撃が0点、灯4の眩光も2点。大技を受けるまでの2ターンは置くだけ。

### 2. 灯を人形に注ぐか、放出に残すか

**二択が立った回数: 10回。うち本物（即答でなかった）: 3回。放出を撃ったので人形が出せなかった: 1回。人形に注いだので放出が細った: 1回。**

**二択が本物になった条件は3つとも同じで、「放出札が今の手札にあり、その放出が今この瞬間に別の仕事（威圧・分割）をする」時だけ。** それ以外は人形が勝つ——理由は灯の収入にある。灯芯の人形が輝き増しで毎T+3、旗灯の祭壇（点灯×灯芯の合成）が毎T+3、攻撃ごとに燭+癒しで+2、人形の登場で+1。**戦闘中盤の収入は毎ターン6〜8**で、篝火の灯4は「次のターンには戻る」額だった。灯コストの重さは払う瞬間だけ存在し、1ターン後には消えている。

旧A（灯の再設計・seed5201）で立っていた「今撃つか、もう1ターン溜めるか」は今回も同じ頻度で立ち（矢/眩光を持った11ターン中、溜めたのは3回）、**「人形に注ぐ」がその二択の第三の選択肢として入った**という手触り。人形と放出は反目せず、「注いでから残りを吐く」で両立してしまう。反目するのは灯の収入が細い序盤（幕1の行1〜7）だけで、そこには灯コストの人形がまだ無い（大鐘は見送った）。

### 3. 灯コストの人形のピック

| 札 | 提示 | 取/見送り | 理由 |
|---|---|---|---|
| 大鐘の人形（1E・灯2） | 2回（行2・行7） | 見送り×2 | 「置物登場ごとブロック2」がデッキの人形2種では戦闘に2〜3回しか鳴らない。灯2＝眩光+なら全体6ダメぶんに釣り合わない。**重さでなく型が理由** |
| 癒しの人形（1E・灯2） | 1回（蟲の報酬） | 取 | 攻撃ごと回復2＝攻撃ごと灯+1。灯2は「翌ターンに戻る」＝2E時代より明らかに軽い |
| 灯篭の人形（1E・灯3） | 1回（ショップ130G） | **13G足りず** | 一番試したかった札。所持117G |
| 篝火の人形（2E・灯4） | 2回（大鴉・魔人＝どちらも強個体のレア確定） | 取×2 | 毎T全体3+ブロック3、アンセムで5+5。迷わず |

- 「1E＋灯2」は**得に感じた**。エナジー1は毎ターン枯れる資源、灯2は毎ターン6〜8入る資源＝交換レートが自分に有利。ただしそれは灯芯・祭壇・燭を積んだ後の話で、幕1の前半（灯の収入が毎T1〜3）なら「1E灯2」は2Eより重い。
- **手札にあるのに灯が足りず出せなかった: 3回**（大顎T4 篝火＝灯3／魔人T1 篝火＝灯1／従士T1 癒し＝灯1）。3回とも旗灯の祭壇（1Eで灯+3）を先に置いて同じターンに出せたので「出せなかったターン」は0。**灯コストは出す順番のパズルになった**（「灯を産む札を先に」）。これは面白い側の手触り。エラー文「灯が足りない: 篝火の人形 (灯4が要る)」は明快。
- 「登場の灯+1が無い」は**ログで読めた**——「🕯️灯+1（人形の登場）」の行が出ない。ただし癒しの人形は点灯で回復2が鳴って「🕯️灯+1（回復）」が出るので、**実効の灯コストは1**（払う2・戻る1）。篝火は戻らない。文面（【灯コスト2】）には「登場の灯+1は無い」の注記が無く、keywordHelp の「灯」を読んで初めて分かる。

### 4. 灯篭の人形・篝火の人形

- **灯篭**: ショップ（幕1行9）に130Gで1回だけ。117Gで届かず、以後は提示なし。「灯を溜めるほど明るく殴り、放出すると暗くなる」の反目は今回**未検証**。
- **篝火**: 2枚取得、6戦で使用（ボス・写し道化・巨像・大顎・魔人・従士）。**このデッキの背骨**——アンセムで毎T全体5+ブロック5、分列で2体になると10+10。ボス戦の後半4ターン、大顎の7ターンが「作業」にならなかったのは篝火と剣の人形が毎T削っていたから。文面の実値表示（登場時の3ダメ・毎Tの3→5）は正しかった。
- 篝火は灯を参照しないので「放出を見送って灯を保つ」瞬間は**一度も無かった**。灯4は入場料で、払った後は放出と無関係。灯篭が来ていれば「放出すると篝火…でなく灯篭が暗くなる」が立ったはずで、**R2枚のうち反目を作るのは灯篭だけ**。篝火は「強い人形に灯コスト」の裁定Bの、反目しない側の見本。

### 7. 表示の嘘・不具合

実処理と食い違う「嘘」は**0件**。エラー・例外も0件。気づいた点:

1. **分列で複製された灯コストの人形は灯を払っていないのに登場の灯+1を産まない**。写し身の魔人T4・従士T3の分列で、篝火の人形（トークン）の登場に「🕯️灯+1（人形の登場）」が出ず、癒しの人形（トークン）は点灯の回復で「灯+1（回復）」だけ。実装は `effects.ts` の `if ((entered.def.lightCost ?? 0) <= 0) gainLight(...)` ＝定義に lightCost があれば産まない。§74 の文言「灯コストを払って出した人形は産まない」とは食い違う（払っていない複製も産まない）。どちらが正か裁定が要る。再現: `phase=combat` で 篝火の人形 と 人形の分列 を持って分列をプレイ。
2. **癒しの人形の実効灯コストは1**（点灯の回復2で灯+1が戻る）。文面からは読めない。仕様なら文面か keywordHelp に一言（「回復する人形は点灯の回復で灯が1戻る」）。
3. **灯コストの人形の文面に「登場の灯+1は無い」が無い**。【灯コスト2(エナジーと別に払う。足りなければプレイ不可)・従者】だけで、keywordHelp「灯」まで読まないと分からない。
4. **眩光の大放出の威圧1は複数体戦でどの敵に付くか表示が無い**（インプと写し道化ではインプ＝敵0に付いた）。プレイ前に分からない。
5. 弱体が灯の矢を半減する（2→1）のは CLI の実値予告どおりで嘘ではないが、**放出だけ弱体の効きが2倍**（-25%が切り捨てで-50%）。設計上の注記として。
6. 自分のミス: ギアを1ターンに2個使おうとして2個目（歯車）が空振り、エナジー不足で篝火が出せなかった。CLI は「いまは組めない」を出していたはずで、パイプで捨てたのは自分。表示の問題ではない。

### 8. 直すなら1つ

**アンセム（輝き増し）を灯の量つき効果（addLight）に乗せない。**

今回、灯コストが決断にならなかった直接の原因は灯の収入で、その半分以上がアンセム由来だった——灯芯の人形 毎T+1 が +3 に、旗灯の祭壇（点灯×灯芯の合成）の +1 も +3 に、分列で複製されるとさらに +3。中盤の収入 毎T6〜8 のうち 4 がアンセムの上乗せで、篝火の灯4も癒しの灯2も「1ターン後には戻る額」に落ちた（§3-2）。アンセムが乗らなければ収入は毎T2〜4で、灯4は2ターンぶん、灯コストの人形を出した次のターンは放出が細る＝§74 の狙った反目が立つ。輝き増しの他の仕事（剣4・篝火5・回復4）はそのままなので、アンセムの魅力は落ちない。

副案（併記）: 灯篭の人形をショップ専売に近い供給（今回130Gで届かず）から報酬のレア枠へも出す——R2枚のうち反目を作るのは灯篭だけで、篝火は反目しない側（§4）。

## 4. 不具合・表示の嘘

§3-7 に書いたとおり。嘘0・例外0。裁定待ちは「複製された灯コストの人形の登場の灯+1」1件、文面の不足は3件（実効灯コスト1／登場の灯+1無しの注記／眩光の威圧の対象）。
