## ① 結論3行

1. **残す。ただし「引く」系ではなく「取りに行く」系だけ**。掘り出し・目当ての品・歯車は死に札ではなく、7回中5回が「手札かエナジーが宙に浮いた局面」を殺し切りに変えた。他に選択肢が無い状態で、この3つは確かに仕事をした。
2. **油差し（3ドロー）と貯め置き（エナジー持ち越し）は差し替え推奨**。1ランを通して一度も使い所が無かった。理由は運ではなく構造で、**このゲームは常に「カード不足」ではなく「エナジー不足」**だから（詳細は④）。
3. **ただしカテゴリ全体に、もっと重い疑いがある**。このランで提示された報酬札のうち3枚（樹液＝歯車／森の導き＝目当ての品／風駆け＝ドロー）が**同じ効果の札版**だった。実際に取った森の導き（1E・毎戦引ける・成長+1つき）はギア版より明確に強く、ボス戦の勝ち筋を作ったのもそちらだった。**「1回きり・魔素1・ターンのギア枠を食う」が、「1E・何度でも・デッキに入る」に構造的に負けている。**

## ③ 実際に勝ちに変わった局面（盤面つき）

「引ければ勝てる」を実際に勝ちに変えたのは **2回**。どちらも**目当ての品／掘り出し**で、**油差しは0回**。

### 1) 大苔スライム T3 — 目当ての品が戦闘を1ターンで畳んだ

```
自分: HP 40/80 | エナジー1/4 | 勢い27 | 手札: (なし)
敵2: 苔スライム HP30/30 → 意図: 防御4
山札: 角の一突き / 樹皮の鎧 / 大角の群長 / 追い風 / 追い風 / 嵐の角
```

手札が尽きて**エナジーが1だけ余っている**状態。ここで **目当ての品 →「追い風」を指名**。
追い風は【勢い5以上なら0E】なので、**エナジー1を使わずに**撃てて `6 + 勢い27 = 33` → 30HPを撃ち抜いて戦闘終了。

> 放置した場合: 翌ターンから子スライムが攻撃12を撃ち始め、2ターン延びる（推定 −12〜24 HP）。
> 戦闘記録は **3ターン / 総与ダメ176 / 被ダメ11**。

### 2) 焚きつけのインプ T1 — 掘り出しが2ターン戦を1ターン0被弾にした

```
自分: HP 40/80 | エナジー0/4 | 勢い14 | 手札: (なし)
敵0: 焚きつけのインプ HP15/69 → 意図: 攻撃14+火傷1
捨て札: 疾駆 / 追い風 / 追い風 / 突進の助走
```

**エナジー0・手札0**。ここで **掘り出し →「追い風」**。勢い14なので0Eで撃てて `6+14+2 = 22` → 撃破。
宣言済みの **攻撃14＋火傷1 が丸ごと消えた**。

> 戦闘記録は **1ターン / 総与ダメ74 / 被ダメ0**。

### 3) ボス戦 T2 — 歯車が両エンジンを1ターン早く並べた（＝最大の仕事）

```
自分: HP 76/80 | エナジー4/4 | 敵の意図: 防御12（ボスは2ターン甲羅にこもる＝無償の設置ターン）
手札: 風の壁 / 荒野の呼び声(2E) / 森の導き(1E) / 樹皮の鎧(2E) / 角の一突き(2E)
```

やりたいのは `荒野の呼び声(2E) → 森の導き(1E)で大角の群長+をサーチ → 大角の群長+(2E)` ＝ **合計5E**。手持ちは4E。
**歯車で+2E**し、無償ターンのうちに**エンジン2枚を両方**設置。

結果、**T4（次の備えで手札8枚）に233ダメージ**が出て、331HPのボスを **5ターン・被ダメ24** で畳んだ。


**最終ターンは4枚とも0Eの札だった**。この事実が、このカテゴリの効き方の正体そのものである（⑦で述べる）。

## ④ 使われなかった2個の理由（分析）

### 油差し（3ドロー）— 0回。運ではなく構造

見送った理由は毎回同じで、**このゲームで枯れるのは手札ではなくエナジー**だから。

- 通常のターンは **手札5枚 / エナジー3〜4**。5枚全部を払える局面がそもそも稀で、**手札は常に余っている**。
  このランで最高の山場だったボスT4は **手札8枚に対してエナジー4**で、猛進の角と年輪を打てずに捨てた。
  **いちばん豪華なターンでこそ、ドローは完全な死に札だった。**
- 逆に「手札が空」になる局面（＝ドローが欲しい局面）は、**必ずエナジーも0になっている**。
  手札が空になるのは全部払い切った時だからで、そこで3枚引いても**払えない札が3枚増えるだけ**。
  実際、掘り出し・目当ての品が刺さった2局面はどちらもエナジー0〜1で、**「0Eで撃てる特定の1枚」でなければ意味が無かった**。
  3枚ランダムに引く油差しは、その1枚を引ける確率が約50%の劣化版でしかない。
- 明確に検討して見送った局面がもう1つある。**用心深い影 T1**で、HP102に対し手札で**ちょうど100**出た。
  2足りない。油差しなら約52%で仕留められた。**だが使わなかったのが正解だった**——敵の次の意図は攻撃だが、
  **自分のターンは敵フェーズより先に来る**ので、翌ターン頭に0Eの1枚で殺せば被弾は0。
  「今殺す」価値がゼロだった。結果は **2ターン / 被ダメ0**。
  → **ドロー系ギアは「今殺せないと損をする」局面でしか価値が無いが、その局面はターン順のおかげで滅多に発生しない。**

### 貯め置き（余りエナジーを次ターンへ）— 0回。惜しい局面は2回あった

- **岩皮の甲虫 T2**: 殻を割ると宣言済みの意図が噛みつきに差し替わるため、「何もしないのが最善」の無償ターンが発生した。
  2E余る＝理論上の使い所。だが**手札は毎ターン全部捨てられる**ので、エナジーを温存するより
  手札を使い切る（樹皮の鎧で成長+1を取る）方が得だった。**カードが持ち越せないのに、エナジーだけ持ち越しても噛み合わない。**
- **ボス T2**: エンジン2枚を置いた後、**1E＋使い道のない風の壁だけ**が残った。これは教科書どおりの貯め置き局面だったが、
  **同じターンに歯車を使っていたので「1ターン1個」で使えなかった**。
- 根本の理由: エナジーが余るのは「手札が尽きた時」だけで、**その時に持ち越せる量は1〜2**。
  翌ターンは元から4E＋新しい5枚が来るので、+1〜2Eの限界価値は小さい。
  一方で歯車は**同じ1枚を使って同じ+2Eを、必要なターンに好きに撃てる**。**貯め置きは歯車の完全な下位互換**になっている。

### 「1ターン1個」が2回、はっきり噛んだ

- **火薬樽かつぎ T2**: 歯車+2Eで猛進の角を撃ったが **3ダメージ足りず**に撃破を逃した。
  もう1個（油差しで0E札を探す）を切れれば届いた可能性があった。結果、宣言済みの攻撃12を受け、
  癒し手に+12回復され、**大爆発（攻撃32+火傷2）のターンまで持ち込まれた**（T3に0E札3枚で殺して事なきを得た）。
- **ボス T2**: 上記のとおり歯車と貯め置きが排他になった。

死の淵ではなく「あと一歩で殺し切れるターン」で効くので、この制限は**緊張というより取りこぼし**として体感された。

### 魔素は一度も制約にならなかった

開始4/5 → 終了4/5。**途中2回、上限5に張り付いて勝利ぶんを捨てている**。
7回組んでなお余った。詰まったのは魔素ではなく**ギアの回数**で、これは §4 の想定どおり。
ただし裏返すと、**「魔素1」は使用の判断に一度も出てこなかった**（J/M/L ランの所見と同じ）。

## ⑤ 差し替え案

### 残す（3つ）: 掘り出し・目当ての品・歯車

3つに共通するのは「**指名できる**」こと。手札もエナジーも尽きた局面で、
**0Eで撃てる特定の1枚**、あるいは**払えなかった1枚を払う2E**という、はっきりした穴を埋める。
このランの効き方は全部これだった。**ただし歯車は装甲持ちに弱い**——ボスは装甲30（1ヒット上限）なので、
単発札に+2Eしても上限で切り捨てられ、ボスT1では「+1ダメージと引き換えに1回分」でしかなく見送った。
**歯車が輝くのは「置物・エンジンを無償ターンに前倒しする」時**で、火力の前借りではなかった。

### 差し替え（2つ）

**油差し（3ドロー）→「引いた札がこのターン0Eになる」系に変える。**
- 案: **潤滑油**「このターン、次に使う札1枚のコストが0になる」。
  ドロー3枚が死ぬ理由は「払えない札が増えるだけ」なので、**手札の枚数ではなくコストを触る**べき。
  歯車が+2Eなのに対しこちらは1枚だけ0E＝重い札1枚に効く。役割が分かれる。
- あるいは素直に **枚数を減らして質を上げる**（例:「山札の上3枚を見て1枚を手札へ、残りは戻す」＝目当ての品の下位版）。
  ランダムに3枚引くよりは、確実に1枚選ぶ方がこのゲームの解像度に合っている。

**貯め置き（エナジー持ち越し）→ 撤去、または「手札の持ち越し」に変える。**
- 歯車の下位互換なので、同じ台帳に両方あると貯め置きは永久に選ばれない。
- 変えるなら **エナジーでなく札を残す**方向。台帳には既に**挟み紙**（このターンは手札を捨てない）があり、
  そちらの方が「カードは捨てられるがエナジーは持ち越せない」という本作の非対称に正面から効く。
  **貯め置きを消して挟み紙をコモンに残す**のが素直だと思う。

### 台帳全体への所見（このランの範囲で言えること）

- **「次のターンへの投資」は使う気になる。ただし条件つき。**
  次の備えを切れたのは、**ボスの潰し40を受け切る純防御ターン＝他のどのギアも仕事を持たないターン**だったから。
  攻めのターンに「今の1個」を次ターンに投資する気には一度もならなかった。
  → 投資系は**「守るしかないターン」が定期的に来る敵（ボスの甲羅2ターン、樽の3拍子）とセットで初めて生きる**。
  これは残す理由になるが、**枚数を増やす理由にはならない**（1ランに1〜2回しか窓が来ない）。
- **カード版との共食いを直視した方がいい。** このランの報酬で樹液（1E・一時マナ+2）・森の導き（1E・サーチ+成長）・
  風駆け（1E・勢い+4+1ドロー）が出て、**森の導きを取ったらギア版の目当ての品より明らかに強かった**
  （毎戦引ける・成長+1がつく・魔素もギア枠も食わない）。
  テンポ系ギアを残すなら、**カードには無い形**（例: 消滅置き場から拾う／敵ターンの前に仕込む／コストを0にする）に寄せないと、
  「札で足りている」が理由でずっと選ばれ続けない。

## ⑦ 体感の一行

**この6個は「手札を整える道具」としては働かなかった。働いたのは「勢いが乗った0Eの1枚を、手札にもエナジーにも無い所から引っぱり出す道具」としてだった。**

勢いの網は 追い風【勢い5以上なら0E】・疾駆・小枝の一打 という**0Eで撃てる札**を持っていて、
勢いが14〜27まで乗ると、その0E札1枚が **22〜33ダメージ**になる。
掘り出しと目当ての品が戦闘を畳めたのはこれが理由で、**ギアの強さではなくデッキ側の0E札の存在**に完全に依存している。
0E札を持たないデッキ（重い札中心の構築）なら、この2つはエナジー0の局面で**ただの紙**になっていたはずだ。

→ 人間ランで死蔵を測る時は、**デッキに0E札が何枚あるか**を必ず一緒に記録した方がいい。
テンポ系ギアの当たり外れは、たぶんギアの側ではなくそこで決まっている。
