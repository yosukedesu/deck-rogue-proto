# 出立の支度（ラン開始時の祝福）— 提案（2026-09-24）

経緯: Opus ひなた4本（`playtest-2026-09-24-opus-hinata-synthesis.md`）で幕1の面白さが4本とも 3.1〜3.3。序盤は「初期デッキを回す作業」になっていた。
本家（Neow・StS2 の古き者）は「戦闘の前に自分で選んだ強みを1つ持って入る」ことで序盤を「新しい持ち物を試す場」にしている。
ユーザー裁定（ask_user）: **形 A「出立の支度（師匠の餞）」／選ばなかった支度は行商が幕1の店に並べる／中身は3種類を1つずつ／前借りの代償は既存の代償／遺物・ギア・レア札は名指しで見せる／店に並ぶのは身支度と持ち物だけ／数字は提案書のとおり**。幕2・3の頭（宿場の行商・古代の門）は形が固まってから。

**→ 2026-09-24 ユーザー提案「初期お金を持たせて特殊商店スタート。買わない選択肢もできる」で形を変えた＝「出立の店」（ask_user: 出立の店／5品・150G）。以下は店の形で書き直してある（無料で1つ選ぶ旧案の記録は §8）。**

**同日夜の追補（ユーザー「ツケって要素いらない。全てお金でいい／買わなかったら並ぶの表記もいらない／値段高ければレアも出していいよ」→ ask_user）: 前借り（ツケ＋代償）は撤去して値段つきの持ち物に・売れ残りが幕1の店に並ぶ仕組みは残して画面の予告だけ消す・買える数の上限なし。§1〜§2 はその形。**

## 1. 流れ

1. ラン開始 → **新フェーズ「出立」（坑口）**。工房の師匠が**路銀 100G** を持たせ（所持金 50→150G）、坑に住み着いた行商が店を広げている。画面には師匠の一言と、行商の店の品が5つ。
2. **買っても買わなくてもよく、上限は無い**（資金だけが制約。`BuyDeparture`。除去・鍛えは対象の札を選ぶ）。買い終えたら「店を出て坑へ」（`LeaveDeparture`）→ 地図へ。
3. 買わなかった品は行商が担いで降り、**幕1のショップの棚に同じ値段で並ぶ**（`ShopBuyDeparture`。物価が乗る。幕2以降は消える）。**画面には予告しない**（知っている人だけ得をする）。
4. 幕2・3のチェックポイント開始（デバッグ）と `createRun(…, { departure: false })` には出立の店も路銀も無い。

- 「路銀」の品は無い（路銀そのものが初期資金 +100G になった）。前借り（0G のツケ＋烙印1／最大HP−7）は撤去＝全部お金で買う。
- **数字の意味**: 1つ買う（50〜100G）→ 残り 50〜100G＝今までの開始とほぼ同じ経済。何も買わない → 150G＝幕1の工房（100G・行5以降）に初見で届く／除去2回。2つ買う（荷ほどき＋薬草＝110G）→ 残り 40G。レアの遺物 150G＝全額＝「大物1つか小物2つか」。
- 遺物・ギア・札は**出立の画面で中身を見せる**。抽選はランRNG＝リプレイ再現。遺物はランのレリック候補列から（重複しない・色ゲート・幕の制約）、札は自分の色の報酬プールから（2品で同じ札は出ない）、ギアは抽選台帳から（C/U）。
- 除去・鍛えの対象は ?イベントと同じ選び方。坑口の店で買っても大口の貯金箱は壊れない。

## 4. 本家との違い（パクリにしないための形）

- 本家（Neow・古き者）は「無料の祝福を1つ選ぶ」。うちは**「師匠が持たせた資本金で、行商の店から自分で買う」**＝個人事業主の一攫千金という世界観そのもの。決断の種類も違う＝本家は「どれが一番効くか」の比較、うちは「今使うか、取っておくか」（貯めれば幕1の工房や除去に届く）。
- 買わない自由がある（本家は必ず1つ取る）。上限なく買える（本家は1つ）。
- 残りの行方: 本家は消える。うちは**行商が担いで降りて幕1の店に並ぶ**＝「今要るか、後で買えばいいか」の二段。
- 中身が名指し（どの遺物・どのギア・どの札か）。代償つきの賭けは無く、高い物（レアの遺物 150G）は資金の全額で買う。

## 5. 実装の範囲

- engine（TS/C#）: フェーズ `departure`・`RunState.departure`（offers 5つ〔身支度2・持ち物3〕＋bought＋leftovers）・コマンド `BuyDeparture{index, cardIndex?}`（買った後も店に留まる）／`LeaveDeparture`（→地図）／`ShopBuyDeparture{index, cardIndex?}`・ショップの棚 `shop.departures`（幕1だけ。`shopPriceRatio` が乗る）。所持金は `STARTING_GOLD`(50)＋`DEPARTURE_PURSE`(100)。EventChoiceDef に `gears/mana/addCardIds` を足して支度の効果は ?イベントと同じ `applyChoiceDef` で解決。抽選は `rollDepartureOffers`（`DEPARTURE_COUNTS`＝身支度2・持ち物3 を重複なく→遺物はレリック候補列から〔レア度・色・幕〕・ギアは抽選台帳から重複なし・札は自分の色の報酬プールから `cardPick{rarity,count}`）。`createRun` の opts `{ departure: false }` で旧来の起点（テスト・チェックポイント）。
- ボット（sim・ゴールデン・Unity の自動操作）: 身支度を1つ買って店を出る（`defaultDepartureCommand` を phase が departure の間繰り返す）。ゴールデン13本は再生成（ランRNGの消費が増える）。
- 画面: Web・CLI・Unity（出立の店＝店の形: 所持金・値段のボタン・「店を出て坑へ」。売れ残りの行方は書かない／幕1のショップの棚「行商が預かった支度」）。レポートの選択履歴に「出立の店: 〜を N G で買った」「出立: 店を出て坑へ（買った: 〜／行商が担いで降りる: 〜）」「ショップ: 行商が預かった支度「〜」を N G で買った」。
- テスト（`src/engine/departure.test.ts`）: 5品の並びと所持金150／中身の名指し（同じ遺物・札は2品に出ない・レアの遺物も出る）／買う・上限なし・買わずに出る／行商の棚は幕1だけ／ボットの既定／ジャーナルから再現。旧セーブ（departure 無し・phase が map 以降）はそのまま読める（departure は任意項目）。

## 6. 測ること（次の人間ラン・Opus）

- 幕1の面白さ（Opus 3.1〜3.3・人間#17 4.2）が上がるか。坑口で何を買うか（0個／1個／2個以上の割合・150G の秘蔵品が取られるか・貯めて工房へ行くか）。
- 幕1の店の棚（売れ残り）が買われるか（買われなければ「担いで降りる」は飾り）。
- ロールバック: 「買わない」が3本連続で最適解なら路銀を 100→80G に（貯める側を弱く）。秘蔵品（150G）が3本連続で取られなければ 130G に。店の棚の売れ残りが一度も買われなければ仕組みごと撤去。

## 8. 旧案の記録（同日の第1版「師匠の餞」＝実装後に店の形へ置換）

師匠が3つ（身支度・持ち物・前借りを1つずつ）差し出し、無料で1つ選ぶ（見送りなし）。選ばなかった身支度・持ち物は行商が幕1の店に並べる。前借りの代償は既存の代償。路銀（+80G）は身支度の1つだった。
ユーザー「初期お金持たせて特殊商店スタートはどう？ 買わない選択肢もできるし」→ 無料の1つは「どれが一番効くか」の比較で形が本家に近く、店は「今使うか取っておくか」の比較で世界観（資本金）とも合う、として店の形を裁定（5品・150G）。
