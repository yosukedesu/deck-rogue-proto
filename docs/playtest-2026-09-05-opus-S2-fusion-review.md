## 4. 合成したくなる型／しない型

**まず全体の骨格**（緑・異名3916ペア）:

| 区分 | 件数 | % |
|---|---|---|
| A 明確に得（結果コスト ≤ 素材の高い方・効果の欠落なし・0E素材でない） | 2453 | **63%** |
| B 0E素材（エナジーの得ゼロ） | 513 | 13% |
| C 結果コスト > 素材の高い方（テンポ悪化） | 729 | 19% |
| D 効果が黙って落ちる | 306 | 8% |

**そしてAの95%（2334件）は「片方が1E」**（内訳 1+2E:997 / 1+1E:749 / 1+3E:466 / 1+4E:82 / 1+5E:40）。
残り119件は 2E上限で切り下げられたリアクション。つまり —

> **「コスト−1」だけで人が合成するのは、実質「1Eの札を重い札にタダで貼り付ける」1パターンしかない。**
> それ以外の魅力（多段の積み上げ・2E上限・5Eクランプ・モード平坦化）は、**全部いま名指しした抜け道**である。
> 抜け道を塞ぐと、同名以外の合成は「1E札の無料相乗り」だけが残る。

### 合成したくなる型（3つ）
1. **1E多段 × 1E多段** — `二連の蔦打ち×双牙の蔦` 1Eで5ヒット。per-hit の成長・勢いが回数ぶん乗るので、
   成長5で 36ダメ/E（素材最良20）。実測 +20%かつデッキ2枚減。**いちばん指が伸びる型で、いちばん壊れている型**。
2. **1E置物 × 置物**（120件） — `年輪の大樹×狩人の眼光` 2E置で両方の効果を丸ごと保持（÷3が掛からない）。
   盤面を1枚にまとめて1E安い。**唯一「素直に良い圧縮」で、抜け道でもない型**。ここは残したい。
3. **重い札 × リアクション**（2E上限）と **4〜5E同士**（5Eクランプ） — 2-2 / 2-3。**穴だが最も強い**。
   `真・巨獣の踏みつけ` はT3勝利で「工房はランの目玉」の方針に合致するが、レートが素材の2倍。

### 誰も合成しない型（3つ）
1. **0E素材を含む**（513件） — 値引きゼロ。しかも 3-1 の順序事故と重なると素材より弱い（`二連の蔦打ち×疾駆`）。
2. **効果が死ぬ素材を混ぜる**（306件、うち64件は厳密に劣化） — ドロー・一時マナをリアクションへ、
   倍化・放出を置物へ。`開花の儀×置物`58件は「100G払って置物のコストを+1Eする」だけの罠。
3. **中量級同士（2E+2E / 3E+3E）**（729件） — 結果コストが上がってテンポが落ちる。同名の2〜3E帯も同じ谷。

## 5. ルール提案

工房は1幕1回・100G＝**1ランで3回**しか合成できない。したがって直すべきは「平均が強すぎる」ことではなく、
**3回の選択が「どの抜け道を突くか」のクイズにならないこと**と、**選ばなかった側が理由なく損しないこと**。優先度順。

### 提案1（最優先・3-1）: 効果の順序を「意味」で決める
- **現状**: 素材IDのアルファベット順。183件で付与がダメージ行の後ろへ落ち、その多くは**素材のまま撃つより弱い**。
- **案A（推奨）**: **素材ごとの効果列を1つの塊として保ったまま、塊の順序だけを規則で決める**。
  ①ダメージ行を含まない素材が先 → ②ダメージ行を含む素材（元の順を保つ）。
  さらに「素材の先頭にある付与（成長・勢い・急所・上限）は結果の先頭へ繰り上げる」。
  → `二連の蔦打ち×疾駆` = 勢い+3 → ダメ5 → ダメ5、`急所突き×三連の角` = 急所2 → 5貫×3 → ダメ6。
  **塊を保つので 2-6（蔦の乱舞の交互構造）も同時に直る**（下の提案6と一本化できる）。
- **案B**: 工房のプレビューで「A→B / B→A」をプレイヤーに選ばせる。決断が増えて面白いが、UIと保存フォーマットが増える。
- **ロールバック条件**: 案A適用後に「同じ2枚なのに結果が読めない」の指摘が出たら案Bへ。

### 提案2（2-1 / 2-2）: リアクション2E上限は「一律の比例縮小」で払うか、そもそもリアクション化しない
- **現状**: `boostLargest(-6)` が QUANTITY 効果しか削らないので 29件（青126件）で支払い0〜半額。
  払えている場合でも交換レート（6/E）が大型バニラの実レート（10ダメ/E）より安く、**削るほど得**。
- **案A**: 切り下げ1Eにつき、結果の**すべての量つき効果を比例縮小**（4E→2E なら全部 ×1/2。切り捨て・最低1）。
  量を持たない効果しか無いなら**その効果を1つ落とす**（打ち消し2つを1つに畳むのと同じ扱い）。
  漏れは消えるが「大型を伏せられる」魅力自体は残るので 2-2 は半分しか直らない。
- **案B（推奨）**: **素材の合計コストが3Eを超えるならリアクション化しない**（支配順位を飛ばして呪文/物理で出す）。
  実装1行・説明1行（「重い札は伏せられない」＝リアクション2E上限の趣旨そのもの）。
  今回の実測（44ダメの2E罠が110HPエリートをT3で落とす／被ダメ22）を見ると、**レートの調整では収まらない**と判断する。
- **ナーフではない理由**: 素材の価値は保存される（案A）／結果タイプが変わるだけでコストも効果も減らない（案B）。

### 提案3（2-3）: 5Eクランプの無償値引きをやめる
- **現状**: 4E+5E→5E（−3E）・5E+5E→5E（−4E）。**重いほど得**の逆進性。真・巨獣の踏みつけ 5E 100ダメ。
- **案A（推奨）**: **クランプで超過した1Eにつき、提案2案Aと同じ比例縮小を掛ける**。
  真・巨獣の踏みつけ = 5E・100→**56ダメ**（9E相当を5Eに詰めたので ×5/9）。法体系が「切り下げは出力で払う」の1本で済む。
- **案B**: 合計−1が5を超えるペアは合成不可（「重すぎて1枚に収まらない」）。緑63ペア=1.6%だけだが「全ペア合成可」に反する。
- **案C**: 上限を6E・7Eまで開ける。**非推奨**（エナジー上限5では撃てない札が生まれるだけ）。
- **ロールバック条件**: 案Aで「工房の大型合成が地味になった」が2本一致したら、縮小率を ×(5/合計) から ×(5/合計)^0.5 に緩める。

### 提案4（2-5）: モード札は合成しても「選ぶ」を保つ
- **現状**: 置物・リアクション結果でモードが平坦化して**両方乗る**（緑96・赤48件）。1Eで ブロック19＋7ダメ。
- **案A（推奨）**: 平坦化する時は **1モードだけを採る**。どれを採るかは決定的な規則で
  （効果数が多い方 → 同数なら量の合計が大きい方 → 同値なら定義順の先頭）。
  「モードは1つしか選べないので、合体しても1つ」で説明が閉じる。
- **案B**: 両モードを乗せるが各量を ÷2（切り上げ）。「2つとも起きるが半分ずつ」。読みにくいので非推奨。

### 提案5（3-2 / 3-8）: 効果が落ちるペアは合成不可にして理由を出す
- **現状**: 306件で効果が黙って消え、**64件は素材そのものより弱い**（コストタグだけ残る）。青は78件。
- **案A（推奨）**: **素材の効果が1つでも落ちるペアは「合成不可＋理由」**。
  「ドローは敵ターンには残らない」「倍化は場に出た時点で参照が0」「サーチは窓では解決できない」。
  合成可率は 3916→3610（**92%**）に下がるだけで、「全ペア合成可」の趣旨（査定不能で不可になる札を無くす）は保たれる。
  **「なぜ弱くなるか」がその場で読めることが最大の価値**——今は 100G を払った後にしか分からない。
- **案B**: 落ちた効果ぶんを他の量効果に振る（提案5-5の拡張）。振り先が無い札（真・根の紡ぎ）は救えない。
- **併せて**: 落ちる効果が無くても**結果が素材と同一なら合成不可**（3-2の核）。

### 提案6（2-6）: 同種効果のマージは「間にダメージ行が無い時だけ」
- **現状**: `成長+1,ダメ2` ×5 が `成長+5, ダメ2×5` に畳まれ、実効ボーナスが **+15→+25**。
  「1枚の中で雪だるま」という 蔦の乱舞 の設計文と逆の札になる。71件。
- **案（推奨）**: 同一トリガー内で、**間にダメージ行を挟む同種効果はマージしない**（並びを保つ）。
  提案1案Aの「素材の塊を保つ」と同じ実装で両方直る。

### 提案7（3-3・任意）: 0E素材に別の対価を与える
- **現状**: 513件（13%）が「エナジーの得ゼロ・カードが1枚減るだけ」。前回の是正が効きすぎた。
- **案A（推奨）**: 0E素材は**コスト据え置きのまま、効果を半分（切り上げ）で足す**。
  「タダの札はタダぶんしか足せない」。`疾駆×角の一突き` = 2Eのまま 勢い+2。万能クーポンには戻らない。
- **案B**: 0E素材を含む合成は工房価格を半額（50G）。ゲーム側の値付けで釣り合わせる。
- **案C**: 現状維持。緑の0E札は6枚しかないので実害は小さい——**提案1〜6を先に入れて再測してからで良い**。

### 提案8（2-4・要裁定）: 1E×1E の per-hit 積み上げをどう扱うか
- **現状**: いちばん指が伸びる型（1E×1E多段）が、いちばん高いレート（成長5で36ダメ/E＝素材の1.8倍）。
- **これは「穴」ではなく「コスト式 `合計−1` の帰結」**なので、直すなら式に触ることになる。
- **案A（推奨・様子見）**: **触らない**。工房は1幕1回・100G、1ランで3回しか使えず、
  「安い多段を2枚持っていた人が報われる」は工房を目玉にする方針（2026-08-30/09-01）と整合する。
  実測も +20%（96 vs 80）で、レリック1個ぶん程度。**提案1〜6を入れた後の人間ランで再判定**。
- **案B**: 結果のダメージ行の総数に上限（5行）を置く。前モデルの「多段合算・上限5」の名残を並べるモデルに移すだけ。
- **案C**: コスト式を **`max(a,b) ≤ cost ≤ a+b−1`** にする（前回の参考案）。1E+1E→1E は据え置き（ここは楽しいところ）、
  2E+2E→3E も据え置きで、**1E+2E→2E のような「安いほうに寄る」ケースだけが締まる**……が、
  今回の実測では A区分の95%がまさに「1E＋重い札」なので、これを締めると**合成の魅力そのものが消える**。**非推奨**。
