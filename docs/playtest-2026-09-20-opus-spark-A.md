## 3. 設問への回答

### 1. テンポ

幕1通常戦 5.29T・幕2通常戦 5.5T・幕ボス 8T・強個体 6/10/5/8T。通常戦11戦は**全部が物差しの帯（4〜6T）**で、2T決着も7T超もゼロ。ただし帯の上端に寄っている。理由は白の火力の形＝「溜める番（防御・弱体）→吐く番（放出）」の2拍子で、放出を引いたターンに一撃で終わる代わりに、引くまでの2〜3ターンは人形と砂時計の自動火力（毎T6〜12）で削るだけ。

間延び／作業の場面:
- **戦闘8 歩哨の三つ子（10T）**: 単体放出（矢+）は3体戦で「1体を倒した余りのヒットが消える」ので、44・60の放出を1体ずつに撃つしかなく、がらくた4枚が手札を濁らせた。全体放出（眩光）は行11時点では未所持。
- **戦闘14 罠壊し（6T）**: ターン装甲35が矢+36を29に切り捨て（「量の器」が放出の一撃を殺す）。人形を1体ずつ狩らせている間は無傷だが、こちらも4ターン同じことをする作業。
- **戦闘1 蜘蛛（6T）**: 初期デッキ×弱体。矢が半減し、溜める以外にやることが無い。

### 4. 火種

- **撒いた札**: 0枚。火種撒き（C）を取ったのが最後の戦闘（2-6）の報酬で、一度も引いていない。火守りの盾・火花散らし・大焚き付け・灯火の炉・火起こし・灯の火床・火種の嵐・灯の継ぎ手は**一度も提示されなかった**（報酬約55枠＋店6枠＋星読みの変成3枚）。
- **撃った枚数**: 12枚（全部が火種の祈り由来＝1戦に1枚。16戦中12戦で祈りを引いた）。
- **手触り**: 祈り→火種の2枚で「0E・回復2・灯+2・1ドロー・消滅」。**0Eで引いて撃つ回転は気持ちいい**——大喰らいの蟲の山札喰いの前に「祈り→火種→手帳」で山札を掘って守った場面、こそ泥の逃走前に「祈り→火種で灯7＝矢+5ヒットぴったり」の場面は、火種が「灯1と1ドローの端数合わせ」として決断に載った。走竜T5の致死回避も「祈り→火種で灯12→14」が眩光+の43×3（14×3+1）を作っている。**山札が太る感覚は無い**（撒く札が0枚）。火種の嵐の実値・火の粉・継ぎ手は鳴らなかった（火の粉は2-3で取り、梟のT4〜T6に手札にあったが「火種が1戦1枚では1Eで2点」と読んで置かなかった）。**手数の罰は受けていない**（写し身・鏡・拘束・投げ刃に遭遇せず）。
- **本家 Soul との違い**: Soul は「2ドロー」で手札を進める札、火種は「1ドロー＋灯+1」で灯の経済に繋がる札。1枚だけ見ると Soul より地味だが、白では「灯+1」が矢+の4点・壁の1.5ブロック・眩光の3×体数に化けるので、ドローより灯の側で価値を感じた。**Soul Storm 相当の火種の嵐が無いと「撃った数」に意味が無い**ので、今回は火種＝「0E の灯り溜めの小型版」以上にはならなかった。
- **取らなかった理由**: 火の粉（1-9）は撒く札が祈り1枚の時点では死に札（1戦に2ダメ）。2-3で2回目が来た時は「工房で溶かす種」と割り切って取ったが、結局撒く札の方が後だった。**供給の順序（撒く札が先、鳴る札が後）が逆に来ると軸に入れない**。数字で言うと、撒く札6枚（C2/U4）は1枠あたり約8%＝61枠で期待5回だが実際1回。運も悪いが、2枚コンボ（撒く＋刈る）を幕1〜2の40〜50枠で揃える前提としては薄い。

### 8. 表示の嘘・不具合

実処理と食い違う「嘘」は1件（放出の予告）、エラー・例外は0件。

1. **開幕の成長+1がT1の毎T開始トリガーに乗らない**（`成長の種`×`水銀の砂時計`）。T1のログは `LightGained(passive)` → `DamageDealt 3（砂時計）` → `EnemyIntentDeclared` → `GrowthAdded 1` の順で、砂時計のT1は3。置物行の注記は【いま誘発したら3→4ダメ=成長込み】と出る＝**表示と実処理の食い違い**（T1だけ）。再現: 成長の種と砂時計を持って任意の戦闘の開始ログ（1-13 蛞蝓）。処方: onCombatStart（開幕）を最初の onTurnStart より先に解決する。
2. **単体放出の予告「先頭ヒット基準」が敵ブロックの前で ≈0 になる**。泥まとうもの T3（ブロック8）で「灯の矢+ 3ダメ×灯6回 → 敵0:0×6回≈0」と出たが、実際は先頭2ヒットがブロックを剥がして残り4ヒット16が通った。多段の見積りは「先頭ヒットにだけブロックが乗る」注記どおりの計算だが、放出は「ブロック−先頭ヒット」を引いた残りのヒット数で読むべき。歩哨 T5（ブロック0の敵1に44・ブロック6の敵2に≈0）でも同じ。処方: 放出の予告だけ「ブロックを吸った後の総ダメ」に（`damageBreakdown` を灯回ぶん回す）。
3. **弱体中のギアの実値が出ない**。血族T3、弱体1の下で火薬樽を組んだら「敵全体に16ダメージ」の表示のまま12が出た（16+成長1＝17×0.75）。カードは［実値: 4(弱体-25%)］を出すのにギアの行は素の16。`gearLiveDamage` に弱体を通すか、行に「（弱体-25%）」を添える。
