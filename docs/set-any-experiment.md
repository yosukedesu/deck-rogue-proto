# 実験: 全カード伏せ可（2026-09-02）

出自: 「伏せによる読み合いは面白いか」の議論（Opusラン3本・人間ラン2本の観測）。面白さは「敵が伏せに反応する」側にあり、
カード層は枠1・返しN・伏せる価値の固定で腐っていた。ユーザー案「通常カードも伏せられる。伏せは1E、伏せから使う時は通常コスト」。

## ルール（`engine/setany.ts`）

| | 伏せる時 | 伏せから発動する時 | 解決する窓 |
|---|---|---|---|
| 通常カード（物理/呪文） | **1E** | **印字コスト**を敵ターンに持ち越したエナジーから払う。払えなければ窓は開かず温存 | 防御系（ブロック・氷壁・粉砕・威圧）を含む札=被攻撃前／それ以外=被攻撃後 |
| 専用リアクション | 印字コスト（従来） | 無料（従来） | 各札のトリガー |

- 対象外: Xコスト・モード・追加コスト（捨て/消滅/亡骸）・ドロー/マナ/割引/カード操作/召喚/回復/打ち消し/混乱を含む札・置物・リアクション以外のトークン
- 変換はトリガーだけ。効果は onPlay のまま、行動してきた敵を対象に解決（全体は全体）。成長・勢いの加算則は通常どおり
- 通常札の伏せ発動は onReactionFired（狩人の眼光など）を誘発しない＝換金は専用札の特権
- 伏せた時点で敵の伏せ分岐（setAlt）・見切り・回収（1E）・伏せ直し0E・破壊・手数の鏡のカウントはすべて共通

## 有効化

- ブラウザ: セットアップのデバッグ枠「🃏 全カード伏せ可」
- CLI: `npx tsx src/sim/play.ts new-run <leader> <seed> <file> "" 3 set-any`（`reveal` と併用可）
- ジャーナル origin に `setAnyCards` が入り、リプレイで再現される

## 検証計画

同seedで現行と全伏せを並べる: Opus 2本（現行／全伏せ）＋人間1本。見るもの=面白さ評価、伏せた回数と読み勝ち回数（撃破サマリー）、
「今撃つか構えるか」で迷った回数、蓋（同じ札を伏せ続ける）の発生、防御札の伏せ率。
壊れ方の予告: 防御札が常に伏せられる（→変換率7〜8割の第2つまみ）、弱腰型分岐の1Eボタン化（→罰型への揃え）。

## 調整したカード

この段階では無し（値付けを変えずに機構だけ足して測る。専用リアクション13枚の整理は結果を見てから）。
