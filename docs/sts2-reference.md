# StS2 本家対照リファレンス（敵バランス・敵設計）

**一次資料**: ユーザー所有の Slay the Spire 2 (v0.103.3, 2026-05-29ビルド, Godot+C#) を
ローカルでデコンパイルして全敵121体・全編成88・パワー262・幕/マップ生成を抽出（2026-09-02）。
Web調査（wiki・パッチノート・コミュニティ）で補完。コードの転載はせず数値・構造のみ記録。
詳細な生データは `docs/sts2/` の4ファイル（acts / monsters-a-l / monsters-m-z / powers）。

**注意**: StS2はEA中で敵が頻繁に作り直されている（手元のv0.103以降、v0.106でエリート2種リワーク・
v0.109で幕3ボスDoormakerが「Aeonglass」として全面作り直し等）。本書の数値はv0.103.3時点。
**「数値」より「設計の文法」を学ぶのが本書の目的**——文法はパッチをまたいで安定している。

## 1. 幕・マップ構造

| 項目 | StS2本家 | うち |
|---|---|---|
| 幕数 | **3幕**（幕1のみOvergrowth/Underdocksの2バイオーム択） | 3幕 |
| 部屋数/幕 | **15/15/14/13**（幕が進むほど短い） | 16行×3幕（均一） |
| ボス前 | 最終行=全ノード休憩 | 同じ（行14全焚き火） |
| 宝箱行 | ボスの7行手前=全ノード宝箱 | 行8全宝箱 |
| 行1 | 全ノード戦闘（初戦は必ず戦闘） | 行0=戦闘 |
| エリート | 目標5/幕（配置制約で調整） | 4/幕 |
| ショップ | **固定3/幕** | 重み5% |
| ?マス | ガウス分布 平均12（幕2/3は-1） | 22%≈14 |
| 休憩 | 幕別乱数 5〜7/幕 | 8% |
| マップ生成 | 7列グリッド×**7本**パス乱歩・交差防止・親子/兄弟同タイプ禁止 | 7列×6本（本家StS1式）・同制約 |

**編成の抽選が根本的に違う**: StS2は**幕頭に「Weak→Normal」の出現順リストを一括生成**し、
戦闘部屋を踏むたび先頭から消費する（GrabBag方式・直前と同タグ回避・使い切ったら周回）。
フロア毎の動的抽選ではない。Weak戦は幕1=3回・幕2/3=2回で、**「最初のN戦だけ弱い敵」を
リスト構造そのもので保証**している。うちは行の帯＋直前2行回避の動的抽選——本家StS1式。
どちらも成立するが、StS2方式は「序盤に強敵が事故で出る」ことが構造的に起きない。

**初回ラン限定のチュートリアル導線**: Overgrowthのみ、初回は Normal/Elite/Event の先頭数枠を
固定順に差し替える（易しい敵→ギミックの教師の順）。ボスも未撃破優先の固定順
（幕1: Vantom→CeremonialBeast→TheKin）。「初見の体験を設計で保証する」手当て。

## 3. 行動設計の文法（最大の学び）

121体を通して見えた本家の書き方。うちの実装と同じものには◎、無いものには★。

1. **固定ローテが主流、確率分岐は制約付き** ◎ — 完全ランダムはほぼ無い。確率分岐には必ず
   `CannotRepeat`（直前と同じ技禁止）・`UseOnlyOnce`（戦闘1回きり）・重み、が付く。
   「読める揺らぎ」だけを許す。
2. **初手固定が非常に多い** ★ — HauntedShip(初手Dazed5枚)・HunterKiller(初手デバフ)・
   TheInsatiable(初手で沼+専用札6枚注入)など、**その敵の問いを最初のターンに必ず見せる**。
   うちはローテの頭がそれを兼ねるが、「初手だけ別」の器は無い。
3. **群れの位相ずらし** ◎+★ — StarterMoveIdxで開始位置をずらす（=うちのpatternOffset）に加え、
   **スロット位置で役割が変わる**（Exoskeleton: 1体目=多段/2体目=単発/3体目=バフ、
   PhantasmalGardener 4体編成も同様）。同じ敵が並んでも初動が全員違う。
4. **フェーズ変化の条件が多様** ★ — HP半分（うちと同じ）以外に:
   **発動回数カウンタ**（KnowledgeDemon: 呪い付与3回で行動テーブル恒久切替）/
   **味方の生死**（Queen: 随伴が死んだ瞬間、次の予定行動を強制差し替えて激怒/
   LivingShield: 味方全滅で盾役→無限自己強化の殴り役に転職）/
   **睡眠パワー残量**（Lagavulin型×2）/ **外部トリガー**（蒸気圧、Plow破壊）。
5. **ほぼ全敵が開幕パワー持ち** ★ — AfterAddedToRoomでArtifact・装甲・Ritual・固有スタックを
   付与。**素のHP/打点でなく常在パワーが難易度設計の主軸**。うちの静的性質
   （startingBlock/armor/thorns）は同じ方向だが、本家は配布率がほぼ100%。
6. **Ritual（毎ターン筋力+N）には初回スキップガード** ◎思想 — 付与直後のターンは発動しない
   （無償の初回トリガー防止）。うちの「ランプ即時利用廃止・上限は次ターンから」と同じ裁定を
   本家は敵側バフにも適用している。
7. **1体で完結しない敵が多い** — 召喚エコシステム（Fabricator: 味方4体未満なら防御ボット+
   攻撃ボットを補充、満杯なら素の攻撃に転換）・増殖（TwoTailedRat: 条件成立で75%重みの
   自己召喚、個体3回まで）・死亡時召喚（PhrogParasite: 死ぬとWriggler4体）・
   残機（Axebot: Stock2=倒すと弱い個体が再出現）・多節（Decimillipede: 3節が個別に死んで
   自動再接続、Reattach25回分）・合体ボス（KaiserCrab: 左腕+右腕の2パーツ+挟撃）。

## 4. デバフ体系

**コア3種はStS1と完全に同一**（Weak=与ダメ-25% / Vulnerable=被ダメ+50% / Frail=ブロック-25%、
敵ターン終了時に1減衰）。うちの弱体/脆弱/虚弱は本家準拠で正しい。その上に:

- **リソースゼロ化の劇薬**（1ターン限定）: NoDraw / NoEnergyGain / NoBlock。-25%の上に
  「完全に0」の段が別にある。
- **行動数制限**: Sloth(4枚目以降プレイ不可)・Ringing(1枚だけ)・Smoggy(スキル1枚まで)・
  Normality(呪い札版)。**「何枚プレイできるか」がデバフの主戦場**。
- **メタ増幅**: Debilitate（保持者のWeak/Vulnの効果量自体を増幅）・Cruelty（付与側の増幅）。
  基幹デバフの倍率に外部フックが刺さる。
- **手札滞留ダメージ札**: Burn(2ダメ)・Infection(3)・Toxic(5+消滅)・Beckon(6)——
  **うちの火傷(scald)と同じ「手札にあるとターン終了時ダメージ」の共通API**
  (OnTurnEndInHand)が汎用化されている。注入先は捨て札が多い（Slimed・Dazed・Wound）。
  SlimedBerserkerは1技で**Slimed10枚**を捨て札に注入。
- **選ばせる呪い** ★: KnowledgeDemonは「Disintegration(毎T6-8ダメ) vs MindRot(ドロー-1)」等の
  **2択を3回プレイヤーに選ばせて**デッキに入れる。呪いの押し付けでなく「どの毒を飲むか」の決断。
- **Afflictions（システム丸ごと新規）**: カード1枚単位の呪い状態。敵Powerが生きている間、
  デッキ全カードに自動配布（攻撃だけコスト+1=Tangled、全カードEthereal化=Hexed、
  プレイでExhaust付与=Devoured、二重コスト=Weighted等）、**敵が死ぬと全部剥がれる**。
  「この敵が生きている限りルールが歪む」を汎用レイヤーで実装。
- **SlowPower** ★: カードをプレイするたび被ダメ+10%（毎ターンリセット）——
  **手数への罰**をダメージ側でなく被弾側に付けた形。うちのmirrorHits(手数の鏡)の親戚。
- **Doom**: 「ターン終了時HPが閾値以下なら即死」の常時監視型処刑ライン（主にプレイヤー側の攻め筋）。

**幕1から普通にデバフが飛ぶ**（VineShamblerのTangled・FlyconidのVuln2/Frail2・スライムのSlimed注入）。
StS1の段階的導入は廃止されている。うちの敵圧監査（幕1にデバフの教師を置く）と同じ方向。

## 5. 意図表示

- **実値表示**（弱体・脆弱の補正まで計算した正確なダメージを表示。StS1と同じ）。
  アイコンの絵柄だけ5段階（<5/<10/<20/<40/40+）。**うちの幅あり表示は本家2作に無い独自要素**
  ——退屈診断④（幅表示が計算パズルを曖昧化している疑い・未決）の直接証拠。
- 意図タイプ15種: Attack/Buff/Debuff/**DebuffStrong**(強デバフ専用アイコン)/Defend/Escape/Heal/
  Hidden/Summon/**Sleep**/**Stun**/StatusCard/**CardDebuff**(カード汚染予告)/**DeathBlow**(致死級
  大技の専用予告)/Unknown。「予告してから殺す」を専用アイコンで制度化。
- 複数の意図は合成せず並べて表示（StS1から変更）。

## 6. アセンション（難易度）

10段・累積式。**1〜7段は全部「経済税」**: エリート増→行商減→金減→ポーション枠-1→呪い札→
物価上昇→報酬減。**敵の数値は8段目(HP)と9段目(打点)でようやく触り、しかも薄い**
（実測: HP 60→63=+5%・打点 8→9=+12%程度）。10段=幕3にダブルボス追加。
うちの難易度ラダー（段10で打点×3.0）は本家に存在しない水準——「ベース再設計後につまみを
薄いスパイスへ再校正」方針（例: 段10で×1.5+経済税）の物差しがこれ。

## 7. コミュニティの教訓（Web調査）

- **タイマー即死ボス（TheInsatiable）は恒常的に燃えている** — 「Xターン以内でないと即死」は
  予告しても、解決手段（専用札FranticEscape）がデッキに薄まる構造だと「デッキ構築の失敗」と
  「理不尽」の区別がプレイヤーに付かない。毒とタイマーの解決順の噛み合わせで
  特定アーキ（純毒）が構造的に間に合わない穴も指摘された。
- **特定アーキだけ詰むボスは統計が良くても作り直しになる**（Doormaker→Aeonglass）。
  開発が「データ上は幕3最弱ボス」と説明しても不満は消えず、最終的に全面リワーク。
  平均勝率でなく**分散（どのデッキが詰むか）が炎上の火種**。
- ナーフパッチのたびにレビュー爆撃（1日8千〜1.5万件）。Mega Critは「Steamレビューより
  インゲームのフィードバックツールとテレメトリが調整の指針として役立った」と明言——
  うちの戦闘評価バー+プレイメモ+提案JSONの方向性はここと一致。
- 「幕1から敵が強い/デバフが多すぎる」論争は本家でも起きている（開発者は「ベース難易度は
  意図的に高め・調整中」とコメント）。

## 8. うちへの示唆（CLAUDE.mdの行との対応）

1. **敵の数値基準**: 幕1増強は打点でなくHP上端（本家 幕1normal上端74）+質の圧で。
   幕ごとに部屋数を減らす（15/14/13）のも「終盤は1戦を重く」の本家式レバー。
2. **状態異常**: コア3種の値は本家一致で正しい。次の拡張候補は
   ①行動数制限系（1ターンN枚まで＝手数デッキへの新しい問い）
   ②「選ばせる呪い」（KnowledgeDemon式2択）
   ③「この敵が生きている間ルールが歪む」常在デバフ（Afflictions式。打ち消し・キル順と好相性）。
3. **敵ギミック第1波との対照**: 分裂◎（本家は死亡時召喚+残機+再接続と3変種持ち）・
   庇う◎（本家はLivingShield=味方全滅で転職、まで付けた）・火傷◎（本家はBurn/Toxic/Beckonの
   3段ラダー+共通API）・烙印◎（呪い札16種。Guilty=5戦で自然消滅、Debt=金を削る等の変種）。
4. **行動文法**: 「初手固定」「スロット役割分化」「回数カウンタのフェーズ変化」「味方生死の
   強制差し替え(SetMoveImmediate)」は未実装の器。単調さの処方として数値より効く。
5. **難易度**: アセンション対照は§6。つまみ再校正時は「経済税を先に、数値は最後に薄く」。
6. **幅あり意図**: 本家2作とも実値。幅表示を守るなら「本家に無い独自の読み合い」としての
   価値を人間ランで立証する必要がある（退屈診断④の判定材料）。
7. **タイマー敵の設計規約（新規候補）**: 解決手段が「専用札を引けるか」に依存するタイマーは
   作らない。うちの猛り火式（しきい値・全札共通）か、砥石の巨像式（数えられる死）に限る。
