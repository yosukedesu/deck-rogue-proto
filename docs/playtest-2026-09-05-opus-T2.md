## 4. 設問への回答

### T1. 工房は必ず踏めたか / 比較したか
**2回とも踏めた**（幕1行9・幕2行6）。**計38ペアをプレビュー**（訪問1で20、訪問2で18）。金は幕1でギリギリ（161G→61G、行8の宝箱イベントで確実な30Gを選んでいなければ足りなかった）。**「工房を踏むために戦闘ノードを選ぶ」という経路設計が実際に発生した**のは良い。幕2は258Gあり金の緊張はゼロだった＝100Gの重さは幕1限定。

### T2. 悩ましさ（「最強札を素材にする」以外の悩み）
**発生した。しかも3種類とも。**

- **軸一致のおまけ**: 訪問2の `真・深緑の刻`（成長条件札×2 → 成長+1が乗る）と、訪問1の `角牙の乱撃+`（勢い+3が鍛え+軸おまけで**+7**まで伸びた）で明確に体感した。「同じ方向を向いた2枚を混ぜると1+1が2より大きくなる」がプレビュー数値で見えるので、**わざと軸を揃えた候補を探しに行った**。
- **鍛え済み札を素材にした**: 訪問1で三連の角+（焚き火で鍛えた札）を素材にした。**結果が「+」で出るので焚き火の投資が溶けない**と分かった瞬間、「鍛えた札は合成に出せない」という無意識の抵抗が消えた。これは設計として非常に良い。逆に**合成後は【鍛えられない】表示**になり、焚き火の選択肢からは外れる（＝二重取りはできない）のも納得できる。
- **置物化を検討した**: 訪問1で `角牙の大樹+`（毎T8貫通）を最後まで比較。取らなかったのは「毎ターン8」が「今2Eで42」に速度で負けたから。**置物化は÷3で毎T化なので、実質「3ターン以上戦う相手にだけ得」**という判断軸が自然に立つ。幕1ボス（4T）ならギリギリ、通常戦（2〜3T）では損。この損得計算は面白い。
- **想定外の悩み**: 訪問2の決め手は火力でも軸でもなく**「伏せ枠1つに対してリアクションが2枚ある」という枠の会計**だった。合成が「デッキ圧縮の道具」として機能した瞬間で、ここがいちばん歯応えがあった。

一方で**「最強札を素材にする」誘惑は依然として一番強い**。訪問1は結局それを選んだし、訪問2も最強候補は 大牙の乱撃+ 絡みが上位を独占していた（大牙×深緑=135／大牙×若返り=回収+盾+42）。**主砲がある限り「主砲＋何か」が常に最良候補に並ぶ**構造は残っている。

### T3. 合成品の強さ（前後の1ターン最大与ダメ / ギミック無効化）

**1ターン最大与ダメの推移**（戦闘記録の「最大ターン」）:

| 時点 | 最大ターン火力 |
|---|---|
| 合成前（幕1行1〜7） | 15〜28 |
| 大牙の乱撃+ 直後（行11） | **36** |
| 幕1ボス（成長6・勢い4が乗った状態） | **112** |
| 幕2（成長10まで乗った状態） | 51〜54 |

大牙の乱撃+ 単体の実効は「6+8×3」の30だが、**急所+3が自分の3ヒットに乗るので素で42**、成長・勢いが per-hit で乗ると跳ね上がる（成長6/勢い4で97）。**合成品は「素材の合計」ではなく「素材が互いを増幅する係数」を作る**——これが工房の面白さの核心だと思う。

**敵ギミックとの噛み合い**:
- **装甲（鉄殻の溝貝5／オーガ25）**: 大牙の乱撃+ は多段なので装甲に強い。**オーガ装甲25に対して1発25×3=75**を通し、装甲が「大技を封じる」意図に対して合成品が正面から答えになった。逆に踏み荒らし（16貫通の単発）は溝貝の装甲5で**5に潰された**。同じデッキ内で「装甲に効く札／効かない札」がはっきり分かれたのは良い体験。
- **アーティファクト（金切り顎2）**: 合成品の急所+3が**弾かれた**（`🔮アーティファクトが急所を弾いた`）。**合成で獲得した掛け算が敵ギミックで無効化される**という設計上正しい打ち返しで、ログも明快。ただし急所を失っても8×3の素の貫通は残るので詰まなかった＝ちょうど良い罰。
- **とげ（栗鼠2）**: 多段の合成品は**とげと最悪の相性**（8×3で反射2×2＝4）。踏み荒らし19で一撃キルするほうが正解、と実際に選択が割れた。合成品が万能でないのは健全。
- **弱体**: 未遭遇（幕1の蜘蛛のweak1のみ、影響軽微）。
- **封蔦の罠**は読み手の梟の「見抜き（伏せ破壊）」を**打ち消しで消し**、金切り顎の「9×2」を**打ち消しで消した**。1枚で2種類の脅威に答えている。

### T5. 各戦闘の評価 → §2 の表。**全体の面白さ 4 / テンポ 4**

- **面白さ4**: 工房のプレビューを20ペア並べて比較する時間が、この run でいちばん楽しかった。「効果の合体」モデルは**読める**（コストは合計−1、効果は全部乗る）ので、**プレビューを開く前に結果を予想できて、予想を裏切られる（急所の並び順、置物化の÷3、リアクションの2E上限）**という良いループがある。5にならないのは、候補の上位が常に「主砲＋X」で埋まること、そして合成品が強すぎて以後の報酬ピックが薄味になること。
- **テンポ4**: 幕1通常戦2〜4T・幕1ボス4T・幕2通常戦2〜3T。物差し（通常4〜6T）から見ると**幕2の通常戦が短すぎ**（2〜3T）。原因は合成品ではなく成長×多段×レリック3種の積層。ただし砥石の巨像・読み手の梟・オーガのように「拍のある敵」は3〜4Tになり体感が別物だった。

## 5. 不具合・表示の嘘

**A. 合成リアクションは1回の発動で全ウィンドウの効果が解決される（要裁定・おそらく設計外）**
`封蔦の罠`（敵行動時:打ち消し+成長+3 ／ 被攻撃前:ブロック12+成長+2）を**敵行動時の窓で発動したところ、成長が5増えた**（5→10）＝**被攻撃前側の成長+2も一緒に解決された**。つまり異なるウィンドウの効果が窓を無視して全部乗る。ブロック12も同時に付いていた可能性が高い（打ち消し後に自ターン開始でリセットされるため確認できず）。
これは**リアクション同士の合成を無条件に得にする**（モーダルなら「どちらか選ぶ」だが、実際は「両方もらえる」）。2E上限と組み合わせると、2E+2E=3E→**2Eに切り下げ**られるので、**コストも下がって効果は全部もらえる**という二重の得になっている。リアクション×リアクションは工房の最適解に固定されかねない。

**B. 「打ち消し」が合成でダメージに化ける／黙って消える（同じ効果で挙動が2通り）**
- 三連の角+ × 根の紡ぎ → `封牙の乱撃+` 3E `成長+3、**26ダメージ(貫通)**、8貫通、8貫通`。8貫通の1発目だけが26に化けた。**打ち消しが18ダメージに換金された**としか読めず、フレーバー的にも「根の紡ぎを混ぜたら1発目が3倍になる」は意味が通らない。
- 荒野の呼び声 × 根の紡ぎ → `角封の大樹` 3E `毎T勢い+3、登場時成長+2`。**打ち消しが跡形もなく消えた**上に、コストは2E→3Eに上がっている。**荒野の呼び声(2E)の完全下位互換を100G払って作れてしまう**。合成不可にするか、価値を別の形で返すべき。

**C. 同じ名前の別カードが生成される**
訪問1で `三連の角+ × 打ち据え` と `三連の角+ × 打撃` が**どちらも「大牙の乱撃+」**という同名で出た（中身は 6+急所3+8×3 と 9+8×3 で別物）。デッキ一覧・ログ・工房の素材リストで区別できない。さらに訪問2では `大牙の乱撃+ × 蔦の乱舞` と `大牙の乱撃+ × 大樹の守り手` が**どちらも「大牙蔦の乱撃+」**だった。**同名2枚＝真・化の判定**も名前ベースだとすると事故りうる（実際 `打撃×打撃` は真・打撃になった）。

**D. 「効果の合体」と言いながら量が黙って減る**
- `大牙の乱撃+ × 疾駆` → 急所+3 が **急所+2** に。
- `大牙の乱撃+ × 大樹の守り手` → 同じく **急所+2**。
- `大牙の乱撃+ × 風の棘`(訪問1の三連の角+ × 風の棘) → 毎T**5**貫通、`三連の角+ × 荒野の呼び声` → 毎T**8**貫通。同じ素材（三連の角+ = 8×3 = 24 ÷3 = 8）なのに相方によって5と8に変わる。
- `大牙の乱撃+ × 荒野の呼び声` → 6ダメージが **毎T1ダメージ**（÷3なら2）。
プレビュー下部の注記は「効果の合体：コストは合計−1、同名は量を合算」としか言っておらず、**「コスト帯に収まらない分は量を削る」ことがどこにも書かれていない**。プレイヤーは「全部そのまま乗る」と読む。注記に1行足すだけで解消できる。

**E. プレイログでカードの「+」が落ちる**
`大牙の乱撃+` をプレイすると、ログは `プレイ:大牙の乱撃`（+なし）。手札・デッキ表示は `大牙の乱撃+` なので、ログだけ別カードに見える。

**G. 体験上の指摘（不具合ではないが体験を壊した）**
