## 設計判断（変更しないこと）

- 世界観は**普通の王道ファンタジー**の枠内。差別化は世界観ではなくメカニクス（set-confirm＝からくり）で行う。
- **カードは説明しない**（2026-09-10 決定。本家 Slay the Spire 準拠）。本家では札＝そのキャラの技・構えの抽象で、
  物として世界に存在しない。切り直し・消滅・トークン札・除去にフィクション上の言い訳を与えない。
  **実物として存在させるのは からくりの匣・置物・レリック・素材・ゴールド だけ**。
  匣は舞台（3D）にリーダーの足元の木の匣として置き、仕込むと蓋が開き、動かすと閃く（2026-09-10 裁定。UI のポケットはクリックの的として残す）。
- カード名・キーワード・敵名は現行の語彙を維持。**一括リネームはしない**——直すのは世界と正面衝突する札だけ
  （「日」の札＝陽光の恵み・木漏れ日 など。2026-09-10 裁定）。
- AI生成イラストは**不採用**。

## コンセプト一行

夜ごとマナ脈の坑に潜る若い職人たちの、一攫千金と生還のデッキ構築ローグライク。

## 世界の骨格（2026-09-10 決定）

**マナは地を流れる脈から湧く。** 世界の動力はこれひとつで、人の術も職人の機械も同じマナで動く。
脈には満ち引きがあり、**夜のあいだだけ濃く湧く**——だから職人は夜に潜り、魔物も夜に活発になる。

- **機械と術は同じマナの二つの出口。** 機械＝道具にマナを通す。**術＝道具を介さず自分の体からマナを通す技**。
  工房では機械と術を同じ師匠から教わる——だから「魔法使い」と「機械職人」は別の職業ではなく一つの職業（2026-09-10）。
  4タイプの読みもここに乗る＝物理（得物へ通す）／呪文（体から直に）／仕込み札（匣へ）／置物（地へ据える）。

- **良い素材は深いところにしかない。** マナを濃く含んだ鉱＝**レアアースの塊**は、脈に近い深部でしか採れない。
  深く降りるほど良い鉱が出る（＝幕が進むほど報酬が強い、の理由）。
- **底には古代都市が埋まっている。** はるか昔、誰が作ったかも分からない都市が坑の底にある。
  その採掘機械が今も止まらずに掘り続けている（＝幕3の機械の敵）。**なぜ滅んだかは今は決めない**。
- **幕3の主（門番・蘇る合成獣）は一番濃い脈の上に座っている**（2026-09-10）。何を守っているかは語らない。
  ただ「そこに座っているから、一番良い鉱はその下にしかない」＝倒す理由が一攫千金と直結する。
- **昼はある。** 里には普通の昼があり、工房は昼に動いている。夜は仕事の時間——脈が濃く湧くから潜る
  （旧世界の「永い夜」は破棄。**この裁定でカード名のリネームは0枚**になった＝陽光の恵み・木漏れ日はそのまま使える）。
- **トーンはライト寄り。** 人間側（工房・行商・イベントの住人）は明るく軽口。坑の深部と古代のものは静かで少し不穏。
- **4人は出会わない。** それぞれ独りで潜る。ランは一人の道。

## 主人公たち

**ギアウィッチ**（正式名）＝魔法使いと機械職人が合体したような職業。里の人間は**坑匠（こうしょう）**と俗称で呼ぶ
（現実の職業と同じで、看板の名と現場の呼び名が違う）。

- **工房を出た独り立ちの職人。** 腕はあるが後ろ盾がない。師匠の下を出て自分の看板で潜る。
- **一攫千金の個人事業主。** 依頼で潜るのではなく、自分の儲けのために潜る。
  独りなのは、他人の手が入ると自分の仕事と言えないから。
- **動機の型は「金＋自分の看板を立てる」**（2026-09-10）。深い鉱を持ち帰ることは金であり、同時に
  「師匠の名でなく自分の名で仕事を取れる」証。15人共通の型で、何のための看板かは個別の物語で後から足す。
- 場所と物の呼び名は**和語**（坑・脈・鉱・工房・行商）。横文字は職名だけ。**例外（2026-09-17）: 匣に入れる消耗品は「ギア」**＝ギアウィッチの道具として職名の語を流用。動力は「魔素（まそ）」＝魔物の体から漏れるマナの固まらない分（G＝固まった粒）。

## マナ（世界の側の説明）

- **UI表記は「エナジー」のまま**（本家 Energy に合わせる。2026-09-10 裁定）。世界の地の文では「マナ」と呼ぶ。
- **毎ターン全回復** ＝ 坑の中は脈が近いので、息を整えれば体に満ちる。
- **戦闘が終わるとリセット** ＝ マナは体に置いておけない。汲んだぶんは抜ける。
- **マナ上限** ＝ その体に一度に通せる太さ。緑のランプ札は戦いのあいだだけ通り道を増設する無理な手なので、
  使えば継ぎ手ごと焼き切れ（消滅）、戦いが終われば元の太さに戻る。

## 戦いの言葉（からくり）

2026-09-10 決定。看板機構 set-confirm の呼び名。**からくり**＝坑匠が足元に据える小さな木の匣で、
**工房で作る普通の道具**（どの流派も作る）。ぜんまいを巻いて一手を**仕込み**、魔物の出方を見てから自分で**動かす**
（巻いたまま待ってもよい）。

- からくりは自動人形ではなく、糸と発条で**人が動かす**もの。だから「敵の実値を見てから決める」と嘘がない。
- **どの流派の道具でもない。** 15人全員が携える。「仕込む」は何でも仕込めるので、茨も呪文も聖印も呪詛も同じ動詞で入る。
- 敵《絡繰の斧兵》《歯車の箱兵》とは漢字/かなで書き分ける（坑じゅうが作り物、の共鳴として許容）。

| 現 | 新 |
|---|---|
| 伏せ札 | 仕込み札 |
| 伏せ場 | からくり |
| 伏せ枠 | 仕込み枠 |
| 伏せる | 仕込む |
| 発動 | 動かす |
| 温存 | 巻いたまま |
| 回収 | 取り出す |
| 伏せ破壊 | からくり壊し |

**「発動」の全置換は禁止**——置物のトリガー説明（毎ターン開始時に自動で発動する等）は一般語として据え置き。
「引き順は伏せたまま」は別義（山札の並び）なので「引き順は分かりません」。
