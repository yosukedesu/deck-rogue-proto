# 白の再設計 — 「灯」の経済（2026-09-20）

ユーザー「白って戦闘が間延びして爽快感もないし退屈な時間も多くない？ 一度白の再設計を行いたい」→ ask_user 5ラウンドで収束。
本書が一次資料。数値の査定は `docs/card-power.md` §72。

## 0. 結論（先に）

白に固有の蓄積資源 **灯（ともしび）** を置く。回復・人形の登場・パッシブで溜まり、**号令（全人形がいま動く）** か **放出（灯×Nダメージ）** で吐く。
柱は「回復＝灯の燃料／人形＝灯で動く盤面／灯の放出＝山」の3本に組み替え、威圧と要塞（ブロック換金）は小さく残す。
**点灯の定義**（人形は灯が入った瞬間に1回動く＝旧・ひなたの駆けつけ）は白共通のルールに格上げし、ひなたのパッシブは「毎ターン開始に灯+1」。

## 3. 灯の経済

### 3-1. 規則（engine。戦闘内持続・戦闘開始で0）

| | 規則 |
|---|---|
| 供給①（パッシブ） | ひなた: 毎ターン開始に灯+1（`leaders.json` passive `onTurnStart: addLight 1`。T1 から） |
| 供給②（回復） | **回復するたび灯+1**（`gainHp` の回復効果が解決するたび。過剰回復でも溜まる。回復量0の効果〔与ダメ0のドレイン等〕は不可＝onHealed と同じ判定。どのリーダーでも溜まる） |
| 供給③（人形の登場） | **人形（retainer）が場に出るたび1体につき灯+1**（プレイ・点灯・罠の条件召喚・分列・トークンすべて。innate〔あさひの開幕人形〕は「登場」ではないので不可） |
| 供給④（明示） | 効果 `addLight N` |
| 消費①（号令） | `CardDef.lightCost: N`＝追加コスト。足りなければプレイ不可（エナジー不足と同じ）。コスト玉の隣に「灯N」。割引の対象外 |
| 消費②（放出） | 効果 `dischargeLight N`＝灯×N のダメージを与えて灯を0に（`target:'all'` は最初の解決で生存全体へ一括。霊気放出と同型）。**灯0なら不発（消費しない）** |
| 倍化 | 効果 `doubleLight`（消滅必須の規約に加える＝doubleGrowth と同じ） |
| 条件 | `minLight: N`（解決時判定。onPlay／置物／窓すべて） |
| トリガー | `onLightGained`（灯を得るたび1回。誘発の中の加算は再誘発しない＝1段） |
| 乗るもの | 放出のダメージは「カードのプレイで与えるダメージ」＝成長・勢い・弱体・急所・装甲が乗る（霊気放出と同じ） |

### 3-2. 点灯の定義（白共通ルール。旧・駆けつけ）

**人形（retainer・innate 除く）が場に出た時、その人形の効果（登場ごとを除く全トリガー）をすぐに1回ずつ解決する。** 1登場＝1回。
`activateEnteredRetainer` をリーダーのパッシブから engine の `onPermanentEntered` 直後の規則へ移す。ギルド（あさひ・わかば・あかり・なぎ）の人形も同じ。
supply③ と重なるので、**人形を出したターンは「動く＋灯+1」＝空白のターンが消える**。

### 3-3. 号令の定義

`triggerRetainersNow` を拡張＝人形の効果を**トリガーを問わず**1回ずつ解決（点灯の定義と同じ集合。登場ごとは除く）。旧は onTurnStart だけだった。

### 3-4. 典型値（査定と CLI/UI の表示に使う）

- 収入 ≈ 2〜3/ターン（パッシブ1＋回復か人形が1〜2）。4ターン目の灯 ≈ 8。
- 放出×3（U2E）で 24。号令（1E・灯2）は盤面3体で 6〜8＋ブロック。
- 査定の典型値: **灯6**（勢いと同じ）。灯+1 ≈ **1.2VP**（霊気の3.0は放出×7・供給が妨害成功に限られる希少資源。灯は毎ターン湧くので安い）。

### 3-5. 表示

- 資源チップ「🕯 灯 N」（Web／CLI／Unity の資源の札）。
- 放出札の文面に「[現在 灯N → Mダメ]」（霊気と同じ `effectText` の実値）。号令札は「[人形N体]」。
- 灯コストはコスト玉の隣の小さな札「灯2」。足りない時は手札で沈み、押すと理由「灯が足りない」。
- ログ「灯+1（回復）」「灯+1（人形）」「灯+1（灯匠）」「灯8を放出→24ダメージ」「号令: 人形3体が動く」。

## 6. 査定の要点（`card-power.md` §72 に転記）

- 灯+1＝1.2VP（典型6）。放出×N＝6N VP を「参照スケーリング 150%」の帯で読む: ×2（1E C）＝12VP≒定価110%、×3（2E U）＝18VP≒135%。
- 号令＝人形3体×2（6VP）＋ブロック・回復（可変）を 1E＋灯2（2.4VP）で読む＝定価帯。盤面5体なら 160%＝盤面を作った報酬。
- 灯火の大行列 R2E＝灯6×3体＝18回の誘発 ≒ 36ダメ＝派手枠（装甲・ターン装甲が受ける）。
- 点灯の定義は全白リーダーの上振れ（旧はひなた専用）＝ギルドの人形札は再査定せず監視。
- 回復札は「回復N＋灯1（1.2VP）」で読み直す＝回復札の定価が一律 +1.2VP 上がる。既存の回復札は数値据え置き（引き上げ方向）。

## 12. 追補（同日）: 回復の回し封じ

§1 の症状「守りと回復のループが長い」は灯（見返り）で短くしたが、**ループを止める側**は触っていなかった。ユーザー「人形でブロックを固めた勝確の盤面で、全回復まで回復カードを回せる」→ HP は戦闘をまたぐ唯一の資源なので、勝確盤面の回し（+5〜6HP/T＝1戦で焚き火2〜3回ぶん）は白のラン経済を壊す。敵85体中45体は時間で強くならず、エンジンにターン制限も無い。

裁定＝**「回復は一度きり（消滅）か、殴った分だけ（攻撃に付く・放出が敵を削る）。添え物の回復は灯に。毎ターン回復する置物は作らない」**の3分割（単純に全部消滅は「弱すぎ」で不採用。敵側の普遍タイマーと戦闘ごとの回復上限は見送り）。札の一覧と査定は `card-power.md` §73、機械固定は `white-heal.test.ts`。§2 の供給②（回復するたび灯+1）は不変＝正直な戦闘（山札1周）では灯の供給もほぼ不変。

## 13. 追補（同日夜）: 灯と人形の結び

ユーザー「灯と人形の関連付けが薄い気がする」→ 棚卸し（灯→人形の矢印は号令2枚だけ・人形の効果が灯を参照する札0・灯の出口10枚のうち人形経由2）→ ask_user 3ラウンド。
裁定＝**案B「強い人形に灯コスト」**: 癒し・鐘・大鐘＝1E・灯2／新規R 灯篭の人形（1E・灯3・毎T全体に灯2につき1＝`dealDamagePerLight`。灯は失わない）／篝火の人形（2E・灯4・毎T全体3＋ブロック3）。
**灯コストを持つ人形は登場の灯+1を産まない**（灯を吸って点灯）。裁定11（人形を出すのに灯）はコモンの人形では不変＝初期デッキの収入は痩せない。
人形は溶かしても人形（合成で retainer 継承）。詳細は `card-power.md` §74・CLAUDE.md「白の柱」。
