## 3. 設問への答え

### 設問1: 合成の触媒

**結論: 触媒は全ラン通して1回しか提示されず（胞子の風・幕1行14）、ピックしなかった。**

- 提示は**幕1行14＝工房(行13)を通過した直後**だった。幕1の工房は「全ルート1幕1回」なので、
  その時点で触媒を取っても**使える工房が幕2まで存在しない**。しかも次のノードは焚き火→ボス。
  「今の3択で勝てる札」と「2幕先の投資」を比べさせられ、迷う余地なく前者になった。
  → **触媒は"工房の手前"で出ないと選択肢として成立しない**。供給側（工房ノードに隣接する報酬での出現率）か、
  触媒自身を持ち越し価値のある札にする（本体が弱すぎる）かのどちらかが要る。
- 同時に提示されたのが 大地の唸り（2E・全体6、勢いが対象ごとに乗る）で、次がボス＝3体編成。
  **触媒の本体（1E・3ダメ）は、勢い軸から見ても「1枚ぶんの仕事をしない札」**。
  查定上は触媒価値ぶん本体が削られているのだと思うが、**プレイ中は「使うまでずっと弱い札」**にしか見えない。
  ⚗タグは読んだ上で見送っている＝見落としではない。
- **工房のCLI表示について**: 触媒を1枚も持ち込めなかったので直接の検証はできていないが、工房画面には
  `⭐ レシピ候補 (手書きの一品が作れる対): [0]打撃×[4]防御→素振り / …` という**専用行が出る**のに対し、
  デッキ一覧はカードの素の文面が並ぶだけで、**「この札は触媒だ」「素材にすると結果がこう変わる」を示す行が無い**。
  ⭐と同じ粒度で `⚗ 触媒: [n]胞子の風 → 素材にすると結果の単体ダメージが全体化` の行が欲しい。
  今のままだと、⭐レシピだけが視界に入り触媒は埋もれる（デッキ19枚をスクロールして⚗を探すことになる）。

**実際に何を選んだか（比較の過程）**
`FusePreview` で9ペアを見比べた。主な候補:

| ペア | 結果 |
|---|---|
| ⭐打撃×防御 | 素振り(1E・手札が全部物理なら0E・ブロック5+7ダメ) |
| ⭐防御×疾風の蔓+ | 風受けの蔓(2E置物・登場時ブロック5/攻撃ごと勢い+1/勢い獲得ごとブロック2) |
| 打撃×打撃 | 真・打撃(1E・12ダメ) |
| 牙の一撃×追い風 | 大牙の乱撃(2E・勢い5以上なら0E・勢い+2/17貫通/6貫通) |
| 茨の返し×先制の蔦槍 | 牙棘の罠(1E反応・被攻撃前16貫通＋返し10) |
| **荒野の呼び声×疾風の蔓+** | **大角の大樹+(2E置物・登場時勢い+2/攻撃ごと勢い+3/毎T開始勢い+5)** |

選んだのは最後。理由は3つ:
1. **2枚のエンジンを1枚に畳める**＝「両方引かないと始まらない」を「1枚引けば始まる」に変えられる（19枚デッキでは死活）。
2. **鍛えの引き継ぎ**が効いて 毎T開始+3 が **+5** になった。焚き火1回の投資が工房で二重取りになる感覚が良い。
3. 勢いは**全ヒットに乗る**ので、連なる角(3ヒット)・蔦の連撃(Xヒット)・大地の唸り(対象ごと)が全部跳ねる。

結果は想定どおりで、直後の裂け口の獣を **1ターン63ダメで2T撃破**、ボス戦は **1ターン114ダメ**で4T撃破。
ただし裏返すと**工房1回でゲームが終わる**（設問4に続く）。
なお ⭐レシピ2種（素振り・風受けの蔓）は見えていたが、素材がどちらも基本札／エンジンで、
「基本札2枚を1枚にしても山札は良くならない」「風受けの蔓は疾風の蔓+を食う」で落とした。
**⭐の提示自体はとても分かりやすい**（対の一覧が出るので探さなくていい）。触媒に同じ扱いが無いのが惜しい。

### 設問2: レリック

3択は3回（エリート2回＋ボス1回）。宝箱行（幕2行8）には到達できなかった。

| 供給源 | 3択 | 取った理由／見送りたかったか |
|---|---|---|
| 👑金羽の大鴉 | ★算盤(切り直しごとブロック6) / ◆二重の符(仕込み枠+1) / ★重石(焚き火で鍛錬) | **二重の符**。手札にリアクションが2枚ある時に1枚が確実に腐っていたので、悩まずに刺さった。**良い3択**（守り／読み／育成の3方向） |
| 👑血族の儀式（ボス） | 融合の鎚(上限+1・焚き火で鍛えられない) / ルーンの角錐(手札を捨てない) / 空の鳥籠(2枚除去) | **一番迷った。最良の設問。** 3つとも別の軸（エナジー／手札／デッキ）で、しかも**税があるのは1つだけ**。融合の鎚を取ったが、後で「鍛える」が全部消えるのは想像以上に重かった |
| 👑鎖持ちの奴隷商 | 成長の種 / 水銀の砂時計 / 赤面の面 | **一番つまらなかった3択。** 3つとも「戦闘開始時／毎ターン」の小さい置物で、方針が1つも変わらない。成長の種を機械的に取った |

**層タグ（◆/★/👑/🛒/❓）は判断にほぼ効かなかった。**
決め手は毎回「今のデッキに噛むか」で、★が付いていても（算盤・重石）見送っている。
逆に**👑だけは効いた**——「ここは税つきの大物が並ぶ枠だ」と身構えられ、実際そうだった。
また奴隷商の3択は**タグが1つも付いていない（＝コモン3枚）**のに気づけたのは後からで、
プレイ中は「タグが無い＝表示漏れ？」と一瞬迷った。コモンにも `・コモン` のような無地タグがあると読みやすい。

**取得時に何かが起きるレリック**は一度も出なかった（翼の靴・円蓋・呼び鈴・鳥籠・星読みの盤・祈りの車輪はいずれも未遭遇。
空の鳥籠はボス3択に並んだが選ばなかった）。**焚き火の第3選択肢も一度も出ていない**——
出す条件のレリック（重石）がエリート3択に出た時、私は二重の符を優先したため。
「焚き火の選択肢が増えるレリック」は、**焚き火を何回踏めるか分からない時点**で価値を見積もれないのが辛い。
重石は「以後の戦闘開始時の成長+1・3回まで」で、3回とも休む/鍛えるを捨てる必要がある＝HP34の時には選べなかった。

**融合の鎚の手触り**: エナジー4→5は明確に別ゲーム（蔦の連撃X=5＝1枚25ダメが常設される）。
税のほうは**死ぬまで一度も焚き火に着かなかったので発火していない**。
気になったのは**ショップの「カード強化サービス 100G（焚き火の『鍛える』と同じ）」が普通に並んでいたこと**——
鎚を持っている状態でこれが買えるのか買えないのかが画面から読めない（試していない）。どちらでも良いので明記が要る。

## 4. 表示・説明で嘘/分かりにくいと感じた点

1. **伏せ札の返しダメージに弱体が乗るのが表示に出ない。**
   弱体1の状態で 茨の返し（文面「返し10」）を発動したら実値**7**だった。
   手札の札には `［実値: 敵0:4(弱体-25%)］` が出るのに、**伏せ場の札と確認ウィンドウには実値行が無い**。
   set-confirm は「実値を見てから決める」機構なのに、**自分側の実値だけが見えない**のは筋が通らない。
   確認ウィンドウの発動候補に `[green_reaction_thorns#0] 茨の返し ［実値: 返し7(弱体-25%)］` が欲しい。
2. **伏せ分岐の"見切り"（鮮度）がどこにも書かれていない。**
   伏せ札に `【見切られ=敵は反応しない。破壊は来る】` は出るが、
   ボス戦では踊り手の意図が T1〜T3 は `【伏せ札あり】…／【なし】…` の二段表示なのに、
   T4 は分岐が消えて `攻撃6〜7` の一行になった。何が起きて分岐が消えたのかプレイ中は分からない
   （たぶん単独時テーブル／ローテ切替だが、表示は同じ「攻撃」なので区別がつかない）。
3. **逆に、確認ウィンドウの分岐反転警告は今回のMVP。**
   `⚠ 発動すると伏せ枠が空く: 血族の踊り手の行動が【伏せなし】分岐 (筋力+2〜2) に変わる`
   ——これがあったから「返し10を捨てて、踊り手を殴らせ続ける」という選択ができた。嘘が無く、決断が生まれる。
4. **大地の唸りの条件表示が"今どちらなのか"を言わない。**
   `[ターン開始時の上限5以上なら]敵全体に6ダメージ` は文面にあるが、実値行は `敵0:11(勢い+5)` の1行だけで、
   **後半が発火するのかしないのかが読めない**。融合の鎚で上限5になった後も、T1は上限3扱いなので発火しない——
   この「T1だけ読む値が違う」は盤面行（`上限参照は3を読む`）を見れば分かるが、カードの実値行には反映されていない。
5. **連なる角のキルログが二重に出る。** `☠敵1を倒した` が2回（残りヒットぶん）。害は無いが、
   撃破サマリーの与ダメと突き合わせる時に混乱した。
6. **こそ泥の盗みは1回目が構造的に防げない。** 防御→盗み(即成立)→逃走 の3拍なので、
   最速でも「盗まれてから1ターン」しか猶予が無い。ヘッダの `💰105G(うち32G盗まれ中・実損は所持105Gが上限)` は
   とても分かりやすかったので、**意図表示の段階で「次の宣言で逃げる」まで予告**してくれると race が race になる。
7. **ショップの「カード強化サービス」と融合の鎚の関係が読めない**（設問2に既述）。
8. 細かい: 工房の `⭐ レシピ候補` 行は打撃×防御の組み合わせを9通り全部列挙するので長い。
   `[0/1/2]打撃×[4/5/6]防御→素振り` のように畳んでほしい。

## 5. 総評

| 軸 | 点 | 理由 |
|---|---|---|
| **面白さ** | **4 / 5** | ボス戦（弔い×伏せ分岐警告）と栗鼠のとげ、大鴉の締切、物真似の鏡——「問いが1つ立っている戦闘」は3ターンでも面白い。工房のFusePreviewで9ペアを比べる時間が、このランで一番長く考えた時間だった（良い意味で） |
| **納得感** | **3 / 5** | 死に方が半分納得・半分不満。脆弱2が「大技と同じターンに乗る」ので、予告を読めた時点で既に詰んでいた。嘲る道化の伏せ分岐が「伏せられないプレイヤーを二重に罰する」形なのも、set-confirm の思想（伏せる/伏せないは選択）とずれて感じた。一方で「54HPでエリートに行った自分が悪い」も同じくらい本当 |
| **テンポ** | **3 / 5** | 3ターン決着が6戦。工房前は「短いが密」で許容範囲だが、工房後は1ターンで100超えて別ゲームになった。テンポの数字より、**戦闘は短いのにHPは削られ続ける**（3Tで26〜38被弾）という非対称のほうが気になる |

### 一番言いたいこと
- **工房1回の重みが他の全要素を足した以上にある。** 焚き火の鍛え1回＋工房1回で、
  「毎T勢い+5・攻撃ごと+3」が2Eの1枚になり、そこから先の戦闘の答えが全部同じになった。
  100Gという値段も、エリート1体ぶんの報酬でほぼ払える。
- **触媒は「工房の手前で出会う」設計になっていない。** 全ラン1枚しか見ず、しかも工房の直後だった。
  工房ノードの手前（同じ行〜2行以内）の報酬で触媒の重みを上げるか、
  工房画面に ⭐ と同格の ⚗ 行を出すかしないと、この機構は存在に気づかれないまま終わる。
- **レリックの3択は「👑ボス > ◆エリート1回目 >>> コモン3枚」**。
  コモン3枚の3択（成長の種/砂時計/赤面の面）は、どれを取っても方針が変わらないので、
  エリート報酬としては薄い。エリートの3択には**必ず1枚は「型を変える札」**を混ぜてほしい。
