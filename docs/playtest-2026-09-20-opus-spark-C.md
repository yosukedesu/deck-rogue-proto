## 3. 設問への回答

### 1. テンポ

幕1通常戦 4.38T・幕2通常戦 5.75T・幕ボス 10T（帯の上端）。通常戦12戦のうち帯（4〜6T）が8、3Tが2（溝貝・こそ泥）、7Tが2（大蛇と小泥・道化と妖術師）。

間延び／作業の場面:
- **歩哨の三つ子（12T）**: 門柱で4〜5の光線が全部1になり、10〜12の光線だけ白盾＋灯印で受ける形が固まった後は同じ手の反復。がらくた4枚で火種が2回がらくたを引いた。犬のランダム対象が2回とも死にかけの個体を外して1HPで生き残らせ、1〜2ターン延びた。
- **大蛇と小泥（7T）**: 拘束1（3枚まで）が2回。火種（0E・1ドロー）が枠を食う札になり、矢も大行列+も引けず灯12が余ったまま終わった＝「灯があるのに出口が無い」の間延び。
- **オーガ後半（T7〜T10）**: 大行列+で灯を吐いた後、灯1から積み直す4ターン。人形4体と水銀が無いので毎ターン14〜16点を打撃で刻む作業（ただし T8 の三つ巴〔下〕があったので退屈ではない）。

- **人形の登場で灯が増えないことには初戦から気づいた**（犬の点灯のログに「灯+1」が無い。旧Aでは「🕯️灯+1（人形の登場）」が出ていた）。変わったのは**灯の入口が「回復する人形」に一本化されたこと**——このランの灯の35%は癒しの人形1体の「攻撃ごと回復2→灯+1」で、癒しが手札に来ない戦闘（甲虫・大蛇・物真似）は灯匠の+1と火種だけになり、矢+が「端数合わせ」（甲虫T3 灯2＝6）に落ちた。癒しを引いた戦闘は毎T4〜5、引かない戦闘は毎T1.5〜2＝入りの分散が人形1枚に掛かっている。
- **「灯が余る」と「足りない」が両方あった**。余る＝出口（矢+・大行列+・閃光）が手札に無い時（大蛇 灯12・箱兵・甲虫）。足りない＝灯コストの人形を出したいのに灯1〜2（箱兵T3 癒し・甲虫T1 癒し・道化と妖術師T1 鐘）。**灯篭の人形は3戦持って0回プレイ**（灯2を払う瞬間はいつも大行列+か閃光の方が価値が高く、灯2につき1の毎T全体は人形の頭数を増やす方が速い）。
- 1ターンの入りの概算＝**灯匠1＋攻撃×1（癒し人形あり）＋火種0.35**。旧C（登場+1あり）の3.5/Tより細く、§74追補の見込み2.3/Tより少し太い（回復の人形を序盤で買えたため）。

### 4. 火種

- 撒いた: 火種撒き/+で山札へ**32枚**（鍛えた後は1枚2火種）、火種の祈りで手札へ**11枚**＝生成43。撃った**34枚**（80%）。残りは戦闘終了で消えた。
- **手触り**: 0Eで引いて撃つ回転は気持ちよく、祈り→火種→火種の3枚連鎖（栗鼠戦・樽戦）で灯+3・3ドローが1E以下で回った。ただし**「山札が太る」感覚は薄い**——撒くのは1戦1〜2枚（鍛えて2〜4枚）で、22枚デッキの中に2〜4枚混ざっても引く頻度は1ターン1枚程度。本家の Souls（Reave で毎回2枚・Grave Warden で2枚）ほど密度が無い。
- **火種の嵐は未提示**（刈り取りが無いので「撃った枚数」は表示以外の意味を持たなかった）。**火の粉**は幕2の店で買い、樽戦3回・梟戦5回で全体1×8。**灯の継ぎ手・灯火の炉・火起こし・大焚き付け（買えなかった1回）は未取得**。
- **手数の罰**: 拘束（大蛇×2）で火種が「1ドローに1枠払う札」になり撃たなかった（T5）。物真似の道化（5×手数）では火種1枚＝+5被ダメで、T5に2枚撃って12受けた。写し身・投げ刃・鏡型の重りは遭遇せず。
- **本家 Soul との違い**: Soul は「消滅・2ドロー」で手札を増やす純粋な燃料だが、火種は「1ドロー＋灯+1」で**灯の入口を兼ねる**ので、火種を撃つ＝放出の準備になる。その分1枚の満足感は小さく（1ドローは引いた札次第）、Soul Storm 相当の嵐が来ないと「撃った枚数」を意識する場面が無い。撃つか撃たないかの決断は手数の罰の敵にしか立たなかった。
- 取らなかった札: 大焚き付け（幕ボス報酬。X で火種X枚。眩む閃光を優先。CLI の文面が「火種1枚」で X が読めなかったのも一因）。

### 8. 表示の嘘・不具合

1. **【不具合】鎮めの錘がHP半分の豹変を止めない**。オーガ戦T1に組んだ（ログ「⚙ 鎮めの錘 を組んだ」・敵の `interruptBlocked=true`）が、T6に84（半分89未満）まで削った直後の宣言で第2形態（7〜9×2）に入った。`effects.ts applyInterrupts` は `interruptBlocked` を見るが、**`combat.ts:351` の宣言時 `applyInterruptsTo`（次の宣言でカーソルを飛ばす経路）は見ない**。結果、ギアは「その場の差し替え」を止めるだけで次の宣言で豹変する＝文面「この戦闘中起こさない」と食い違う。`EnemyInterrupted` の出来事も出ないので「HPが半分を切った！行動が変わった」のログも無い。再現: `phase=combat;enemy=enemy_brute;gears=gear_stilling_weight` で錘を組み、HPを半分未満にしてターンを終える。
2. **鎮めの錘を組んだ後も敵の行に「HPが89以下になると: …」の予告が出続ける**（1の派生。効いていれば消えるべき、効いていないなら1の証拠）。
3. **大焚き付けのCLI文面が「火種1枚を手札に加える」でXが読めない**。定義は `addCardToHand … xHits:true` だが、`play.ts fx()` の addCardToHand は `xHitsSuffix` を付けない。ピックで見送った一因。
4. **火種・灯の手帳・大光の祝福・鐘の人形のドローが「直近の出来事」に出ない**。火種を撃つと「プレイ:火種／🕯️灯+1（カード）／消滅:火種」だけで「1ドロー」が無い（`CardsDrawn` を CLI が印字するのはターン開始だけ）。ジャーナルには載っているので山札の枚数で追えるが、火種のログとしては欠けている。
5. **号令のログ「人形27体がトリガーを問わず今1回ずつ動いた」**＝3体×9回を体と数えている（`RetainersTriggered.count` が延べ回数）。「人形3体が9回ずつ」が正しい。
6. **育つ技の「いまは+4」が宣言直後に出るが、今の宣言には乗っていない**（大鴉T2: 急降下14〜18の宣言が「もとは17」なのに「いまは+4」。+4が乗るのは次の宣言）。1回ずれて読める。
7. **身代わりの符を組んだ後の被ダメ予測が変わらない**（道化と妖術師T1: 組んだ後も「受けるダメージ 15」のまま。実処理は0だった）。
8. 鍛えた札の「プレイ:」ログに「+」が付かない（「プレイ:火種撒き」）。軽微。
9. （仕様の記録）**人形の単体ダメージがランダム対象**で、こそ泥T3（矢14＋灯盾で20ちょうどのはずが犬の2発が両方隣へ飛び1HP残し・29G喪失）と歩哨T6（同じ形で1HP残し）でキルの算数が壊れた。犬の「攻撃ごと2」は自分の攻撃と同じ的に飛ぶ方が読める（§74追補の裁定④への逆風の実測）。

### 9. 直すなら1つ

**鎮めの錘の宣言時経路（`combat.ts:351`）にも `interruptBlocked` を通す**。魔素10のギアが幕ボスで何もしなかったのは、このランで唯一「システムに騙された」と感じた瞬間で、納得感を4→3に下げた本体。処方は1行（`if (enemy.interruptBlocked !== true)` で `applyInterruptsTo` を飛ばす）で、あわせて組んだ敵の行の「HPが半分になると」の予告を「（鎮めの錘で起きない）」に差し替える。

副案（設計側・併記）: **灯の鍛冶を「灯4を払う」に**（全部失うのでなく灯コスト4）。灯を全部失う形だと「灯が溜まったターンほど撃てない」逆転が起き、店で買った1枚が2幕で0回だった。灯4固定なら閃光（灯3につき1）・癒し（灯2）と同じ天秤に乗る。
