## 3. 設問への答え

### 設問1: 構えの拍は「休符」「仕込む窓」「間延び」のどれになったか
**三つとも起きたが、比率は「殴り得の休符」＞「仕込む窓」＞「間延び」。**

- **仕込む窓**として成立したのは 4回（#4 果実T1・#9 鬼軍曹T3・#11 オーガT2雄叫び・#16 梟T2）。手札にリアクションがあれば構えのターン＝仕込むターン、は毎回迷わず正解だった。**迷いは無い＝決断ではなく手順**。
- **殴り得の休符**が最多。#3 溝貝T3・#5 大鴉T1・#11 オーガT4（61ダメのターン）・#13 岩虫T2（大樹の怒り36）。敵の構えのブロックは**私の攻撃が解決した後**に積まれるので、構えの宣言ターンはむしろ無防備な殴り放題。「守るターン」の圧は**次のターン**に来る（果実のブロック3〜4・溝貝6・罠壊し7・オーガ10 が翌ターンの計算を削る）。蔦の楔・根喰らいの蔓の価値がはっきり上がった。
- **間延び**は #4 噛みつき果実×3 だけ（45HP級が3体で4T・面白さ3）。3体が交互に構えるので毎ターン誰かのブロックを剥がす作業になる。
- **一番気になったのは「瀕死の敵が構える」**。新設の構え16回のうち **6回は宣言のターンに私が倒した**（小泥HP2・探り屋HP19・大鴉HP16・茸HP5・蛞蝓HP9・オーガは違う）。固定ローテの末尾に置いた構え（探り屋・蛞蝓）は「4拍目まで生きていない」ので、**構えが来た＝もう死ぬ、の合図**にしかなっていない。
- 探り屋の4拍化は3Tで終わったので見えず。二人組はoffsetで1体がT2に本気を出すので「三度目が本気」の読みも薄い。雷球・彫師（幕3）は未遭遇。
- ターン数: 幕1通常 **3.5T**（Z は≤2Tが43%、今回17%）。**1〜2T決着が消えた**のは確か。構えの拍が1拍足したぶん＋構えのブロックが翌ターンを削るぶんで、体感は「+0.5〜1T」。物差し4〜6Tには幕1でまだ届かない（4〜6Tは12戦中7）。

### 設問2: 筋力+1付きの構えは圧として読めたか
**読めない。気づいたのは「筋力の数字が勝手に増えている」ことから逆算した時だけ。**
- CLI の意図は「防御7〜10」としか出ない（`+筋力1` が付かない）。溝貝の筋力+3→+4、鬼軍曹+1→+2、オーガ+1→+2、コボルト0→+1 と、**結果からしか分からなかった**。
- 圧としては +1 が乗る前に敵が死ぬ（残り1〜2T）ので、決断を変えた場面はゼロ。溝貝だけは 噴射8〜10→12〜14 と重くなったが、それは加圧+3の方が主。
- 「守るターンも少し育つ」の狙いは分かるが、**+1では「無償ターンではない」という帳簿上の言い訳にしかなっていない**。見せるなら意図に「+筋力1」を必ず出す（Unity は吹き出しがあるが CLI は無い）。

### 設問3: HPの幅は計算パズルに影響したか。表示で幅が読めたか
**影響はほぼ無し。害も無し。**
- 幅が「見えた」のは同種の並び（小泥9/8/8・探り屋22/24・果実16/17/18・**こそ泥28/33**・幕1ボス171）。こそ泥の 28/33 は「28の方をT3までに倒して14G取り返す／33は諦める」の判断材料になった＝**幅が意味を持った唯一の場面**。
- 「ぴったり倒す」は現在HPが数字で出ているので普通に計算できる（探り屋を打撃6+6+絡み蔦7=19で丁度、果実を打ち据え+打撃+楔で18丁度）。幅は**戦闘前の計画**にしか効かないが、そもそも戦闘前に「小泥は8だから打撃+2」のような計画は立てていない。
- 表示: CLI には図鑑が無いので「min〜max」は一度も見ていない。HPバーは「現在/最大」でその戦闘の実値＝十分。

### 設問4: 罠モデル×枠2——重ねは起きたか・温存/期限切れ・構えに仕込む
- **「前ターンの罠＋今ターンの仕込み」の重ねは1回**（#11 オーガ: T1共鳴する茨→T2守りの蔓）。それ以外の枠2の使い方は**「構えのターンに2枚まとめて仕込む」**（#9・#13・#16）。枠2は「時間差」より「まとめ置き」に使った。
- **温存0／期限切れ1／不発6**。温存が0なのは、確認窓に出た時点で「撃つ」が常に正解だったから（被攻撃前ブロックは撃って損がない）。**迷ったのは2回だけで、どちらも「1行動1リアクション」の壁**——#9 鬼軍曹T4「守りの蔓で完封するか、温存して弾け実の返しで倒すか（HP11払う）」／#13 岩虫T3 も同型。どちらも前窓を撃った。**単体の敵に対して2枚目の罠は、1枚目が撃たれた行動では鳴れない＝2枚目は「囮」か「期限切れの弾け」にしかならない**。弾け実だけがこの構造で仕事をした（#13 の全体19が今日の最高の絵）。
- 不発6のうち5は「窓が来る前に倒した」、1は「盗人が逃げた」。眼光＋符師の懐で仕込み＝成長+1と2ドローだったので、不発の痛みはほぼゼロ。**この2枚が無ければ不発6は「1E＋1枚を6回捨てた」税として効いていたはず**。
- **構えのターンに仕込む**: 成立している。ただし上に書いたとおり「迷わず正解」なので新しい決断というより**新しい手順**。決断が生まれたのは、構えのターンがそのまま殺せるターンだった時（#11 オーガT4＝リアクションが無く61ダメを選ぶ）と、**罠壊し**（構えのターンに仕込むと「伏せ破壊」に化けるので仕込めない）だけ。
