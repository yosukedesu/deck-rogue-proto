### 5-2. 自動レビュー（6 観点 → 反証 2 人 → 確かな物だけ。`juice-review-2026-11-04.json`）

見つけた 39 件のうち 28 件が確か（重複を除くと約 20 件）。全部その夜に直した:
- **二重の音**: 消滅（表と札の崩れ）・エナジー（Presenter と玉の着地）・からくりの発動（ボタンと着弾）・幕ボスの登場（boss_start と act_start）・幕の題字（ui.act_start と act_title）・敗北（PlayerDied と defeat_fall）・敵の意図の宣言（EnemyIntentDeclared を表で鳴らすと全部の宣言で鳴り敵フェーズも伸びる → null に戻す）。
- **差分の二重**: 勝利の硬貨を飛ばした後、報酬の画面でもう一度「+N G」（Remember が演出の後回しで、飛ばすと取り消される → 同期で先に覚える）。ギアでとどめを刺すと魔素の増分が −10 される（PrevRun に支払いを足し戻す）。
- **入力が塞がったまま**: 鍛える・遺物・合成の演出の途中で組み直しが入ると LockInput が解けない（null の枝で解いて then を一度だけ）。出来事→戦闘・回復しない「休む」で 1.1〜1.2 秒の空の待ち（CancelHold・回復する時だけ窓を取る）。
- **評価の窓**: 報酬で 1.2 秒以内に手を進めると二度と出ない（同じ相に居る限り出す・相を離れたら地図で一度出す）。
- **紙を染める**: 意図の札の紙を真鍮に Flash（→ 輪に）・被弾のビネットが上部バーと手札に乗る（→ 紙の下の FieldLayer に）・とどめの白が強い（→ 0.3×0.08 秒＋Linear の写し）。
- **時機**: 札で付けた急所・延焼の札が着弾の前に跳ねる（→ 着弾の後に）。報酬の札の返りが幕の下で終わる（→ 幕が開いてから）。HP バーの残像が回復の後に浮く。
- **重さ**: 札を引いている間、見込みの計算を毎フレーム（→ 同じ札・敵・盤面なら飛ばす）。
