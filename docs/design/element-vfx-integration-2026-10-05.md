# 9属性VFX・表示漏れ対策（2026-10-05）

独自素材の火・水・氷・雷・闇・光・回復・蔦・土を通常カードの確定イベントへ統合した。承認済みの森、物理斬撃、結晶ガード、カメラと入力操作は維持。ゲームのカード性能や計算式は変更していない。雷は blue_aether_burst × leader_izzet の表示だけを変更。

## 表示漏れへの対策

旧来の一部の効果名による攻撃分類を、実際のプレイ結果に変更。DamageDealt、BurnTick、ScaldTick、ThornsReflected、HpLost と回復3種を共通の確定イベント経路に接続し、演出前の対象位置を保持する。次のカード操作で遅延ヒットを消さず、同一チケットは一度だけ表示する。通常カード、定義済み合成、手続き合成、未知カードにも既定演出を用意。ガード・無効・HPコストは命中と区別し、キャンセルは命中を捏造しない。

専用シートは4列2行、左上から0〜7の順。素材1774×887からシート全体を1024×512へ一括縮小し、個別フレームは切り詰めていない。straight alpha、Clamp、mipmapなし。仕上げ済みの色を白Tintで表示。UVの端を画素単位で内側へ寄せ、隣接フレーム混入を防ぐ。専用属性の接触光と白フラッシュを抑えて形を読みやすくし、回復に重なる大きな旧ハートを撤去。原寸・生成プロンプト・manifest・SHAは Editor/ElementVfxSource に保存。
