魔物はその揺れ＝気配に気づいて動きを変える。だが夜が一巡すれば揺れはおさまり、もう誰も気づかない（＝置きっぱなしの札に敵は反応しない）。蓋をし続けたいなら毎ターン隠し直して、夜を揺らし続けるしかない。ただで滑り込ませた一手（0E）は夜を揺らさないので最初から気配が立たず、一度戻して同じ場所へ置き直し
月へひと掲げした直後の札は、まだ月あかりに馴染まないので縁が跳ね返して揺れる——魔物が見ているのはこの揺らぎ。ひとめぐり経てば札は馴染んで静まり、座の景色になる（＝置きっぱなしの札に魔物はもう反応しない）。だから蓋をし続けるには毎ターン預け直して揺らす家賃が要る。掲げずにそっと差し入れた札（0エナジー）は、はじめから揺れない。一度引き取って預け直した札も、もう月を知っているので揺れない。ただし揺れていなくても座は座なので、乱されはする（＝破壊は鮮度を問わない）。気配は置いたターンだけ立つ
粒は降りたてが宙で小さく揺れ、地面に細い光の輪をひとつ広げる（＝気配が立つ）。次の自ターンには揺れが収まり、粒が地面に馴染んで道端の粒と同じ明るさになる＝敵はもう振り向かない（置きっぱなしの一手は風景になる）。**ただし馴染んだ粒は消えたわけではない——敵の足は止めないが、踏み込まれれば破られる**
気配は、隠したばかりの粒にだけ立つ。夜の生き物は「そこにあり続けるもの」にすぐ慣れてしまうので、一晩置かれた粒は夜の色に馴染み、もう誰も見ない。蓋をし続けたければ毎ターン隠し直して気配を立て直す家賃が要る。手間をかけずに（0Eで）そっと隠した粒は、最初から音を立てない。一度でも夜に見せた札は、隠し直しても新しくは匂わない。──ただし疑い深い相手は気配が消えても懐を睨む＝「気配を問わない」。
ブラフ魔物に届くのは「夜が揺れた」ことだけで、中身までは届かない。何を隠したかを知っているのは隠した本人だけなので、使い道のない札でも、夜を揺らしさえすれば魔物は半歩下がる。座で待っている札は翳っていて、絵柄がまるで読めない。魔物に見えているのは札の中身ではなく、座の月あかりが揺れていることだけ。だから何も起こらない一枚でも、揺れてさえいれば魔物の手は変わる。何を預けたかを知っているのは、預けた本人だけ。敵が見ているのは中身ではなく気配だけ。だから空振りの札でも、置けば粒は灯り、敵は踏み込みきれない。「何かある」と思わせること自体が一手の仕事で、合わせずに見送り続けるのも立派な使い方。はったり
