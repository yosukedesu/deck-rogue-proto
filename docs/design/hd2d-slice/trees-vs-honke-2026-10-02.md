# 背景の木の本数 — 本家と比べる（2026-10-02）

ユーザー「背景の木の数、本家より少なくない？」への調べ。3つの方法（画素で数える・目で数える・配置と霧から見積もる）を並列に回した（ワークフロー wf_e40feb99-cca）。
本家で夜の森は `ot_921570_16` の1枚だけ（`_7` は洞窟、`_11` は昼の村）なので、比べる本体はこの1枚。うちは三周目の既定（UI なし・5場面とも背景は画素一致）。

## 結論

**見立てどおり、少なく見える。置いた本数は足りているが、霧の奥に淡く立つ幹の層がほぼ見えていない。**

| 層 | 本家（ot16） | うち |
|---|---|---|
| 近い（画面の端・額縁） | 1〜2 | 2 |
| 中（座席の帯の後ろ・形がはっきり） | 5 | 6〜8 |
| 遠い（霧の中で淡い） | 4〜7 | 0〜2 |
| 合計 | 12〜14（怪物が左から中央を隠すので下限。見えていれば 16〜18 の見込み） | 10〜12 |

3人の数えは「近い・中は同じくらい、遠いが本家の半分以下」で一致した。

## 少なく見える理由

1. **遠い木を置いた場所が悪い**。設計図（`act1_layout.json`）には幹のある木が 34 本あるが、PC 16:9 で幹が別々に見えるのは 10 本。
   - `r3-far-tree-1〜4` は帯の木と同じ x の真後ろ（段2 で、二重の太い柱に見えたので動かした）＝幹が隠れて枝だけ。`far-tree-5`・`6` も手前の幹と重なる。
   - `r3-enemy-thin-1〜4`・`r3-farthest-1〜3` は霧 end 28 の時の深さ（視線 61〜74）に置いたまま。今は end 40＋2段目の霧（強さ 0.5）で掛かりが 0.91〜1.0 になり、画では地と区別できない。本家の奥の木の霧の掛かりは 0.67／0.75／0.83 の3段で、うちのその深さ（視線 50〜57）には見える木が1本も無い。
   - 21:9 の余白用の5本と左の木立は 16:9 では画面の外。
2. **幹が太い**。うちの中・遠い幹は 48〜65px、本家は中 24〜50px・遠い 12〜40px（1.5〜2.5 倍）。奥ほど細くならないので遠近も本数も読めない。
3. **並べ方が偏っている**。中の幹 5本が x600〜1100 に同じ太さでほぼ等間隔（柵に見える）。敵の後ろ x1100〜1690 は幹が無く、密な針葉樹3本が1つの塊。
4. **上が開いている**。上から 16〜30% の帯で「周りより明るい隙間」が占める列は 本家 4%・うち 23%。本家は樹冠が上を埋め、霧は下の帯だけに光る。うちは幹の間から霧が上まで抜けるので、本数以上にまばらに見える。

（三周目の物差し T1「暗く見える幹」は本家 7・うち 8 で並んでいた＝この物差しは遠い淡い層を数えていなかった。）

## 直す案（どれも PixelLab なしで今できる）

> **裁定（2026-10-02 ユーザー「木は pixellab 解禁時にやろうか」）: 10/7 に PixelLab が使えるようになってから、四周目の森の絵（細い針葉樹・霧に溶ける列）と一緒にやる。** 案1 の置き場と案2 の細い幹は、その時に PixelLab の絵で置く（絵が間に合わない木だけコード生成の w12/w14 で）。

推奨は **案1＋案2** を一緒に。霧の値は変えない。

- **案1（設計図だけ）**: `r3-enemy-thin` ×4 と `r3-farthest` ×3 を、今の霧で掛かり 0.67〜0.83 になる視線 50〜57 まで手前に出し、帯の木と重ならない隙間に置く。解いた置き場（PC）:

  霧の芯の列（x880〜1060）には足さない（帯の頂点 G1 を守る）。暗い画素 G3 への影響は模型で +0.002〜0.003。主人公の後ろの2本（360・505）は「主人公の後ろの窓」の規則（霧 end 45 の時の書き方のまま）と食い違うので、窓に木を置かないなら外して4本に。スマホはカメラが近く同じ置き場でも濃く写るので3本までか、phone の t で寄せる。
- **案2（`gen_art.py r3`）**: 細い針葉樹 `conifer_w12`・`w14` を作る（`R3_CONIFERS` に2行）。案1 の木はこれで置き、中の霞んだ2本（`band-tree-4`・`8`）と敵の後ろの密な針葉樹1本（`haze-1`）も細い開いた枝の木に替えて、柵と塊を割る。
- **案3（霧の値・任意・撮って決める）**: `far2.start` 24→30（同じ淡さのまま木を少し奥へ）／`lobe.powerH` 100→70（霧の帯を横に広げ、敵の後ろの淡い幹を読めるように）。`fog.end` を伸ばす案は採らない（帯の木も濃くなり G3 が上がる）。
- **案4（コード・任意）**: 部品ごとに霧を足すキー（頂点の UV2→StageModule）。木の淡さを深さと切り離せる。案1 で足りなければ。
- **10/7 の PixelLab へ**: 発注書の霧に溶ける針葉樹の列（far・mid）を先に描き、置く深さを視線 50〜57 に書き直す。幹 10〜14 ドットの細い針葉樹・右端の大きなトウヒ。
