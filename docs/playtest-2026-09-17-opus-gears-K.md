# ギア対照実験 K（ギアなし側） — 幕2・難易度6・HP48/80スタート

- 実施: 2026-09-17 / seed 9001 / このは（緑）/ deck_momentum 19枚 / レリック0 / 120G
- 条件: `new-checkpoint leader_green 9001 … 2 deck_momentum 0.60 120 6 - - 0`（ギア0・魔素0）
- テスター人格: 先を惜しむ職人（資源を大事に使い、無理をしない）
- **結果: 幕2 行5「大顎の狩人」のターン2で敗死。2戦（1勝1敗）で終了。幕2ボスには到達していない。**

## ① 結論3行

1. **60%スタートは「最初の1戦」で決まる。** 1戦目の初手が被ダメ39に対しブロック6しか無く、そこで48→15（19%）に落ちた。以後のランは全部その1ターンの後始末で、判断の余地はほぼ無くなった。
2. **死因は引きではなく「答えの単価」。** 死んだターンに必要だったブロックは17、手札にあった最大のブロック札は樹皮の鎧の14。**2HP足りずに死んだ**。しかも重り（プレイ枚数×10%で被ダメ増）のせいで、追加で札を打って埋めようとするほど必要量が増える構造で、**カードだけでは原理的に埋められない穴**だった。
3. **緊張の質は「理不尽」ではなく「作業」寄りの詰み。** 予告は全部正直（実値公開・固定ローテ）で、何が来るかは分かっていた。分かった上で手段が無い。悩む場面ではなく、計算して「無理だ」と確認する場面が2回あった。

### 何をしたか（要約）
- 1戦目: 甲虫の殻を割る＝意図が噛みつきに悪化するので、割るなら同ターンに殺す、を守ってT2に一括処理（助走→追い風→助走で殻12+HP20を処理、余った2Eを角の一突きで影へ32）。3ターン勝利。
- 工房: 連なる角×角の一突き→**大牙の乱撃（2E・勢い+2・8貫通×2勢い・2貫通×3）**。ブロック札を1枚も潰さない合成を選んだ（防御密度6/19を維持したまま火力だけ上げる狙い）。号砲（勢い2倍）は単体で残すほうが後続全部に乗るので素材にしなかった。
- 経路: 行5は「大顎の狩人」を通らないと **焚き火4回（行7・9・11・14）＋宝箱** の枝に入れない。迂回枝は焚き火2回に対し戦闘5回で、HP収支が先に破綻する。**15HPで重い単体と殴り合う以外に勝ち筋が無い盤面**だったので突っ込んだ。

## ③「手札に答えが無い」局面 3つ

### 局面1 — 1戦目 T1: 被ダメ39に対し、手札のブロックは6しかない
```
自分: HP 48/80 ブロック0 エナジー3/4（T1は3）
⚠️ このターンに受けるダメージ: 39（防御0を差し引いて39 / HP 48）
敵0 岩皮の甲虫  HP20 殻12  → 意図: 攻撃16
敵1 用心深い影  HP62 ブロック6 → 意図: 攻撃23
手札: 疾風の号砲 / 疾駆 / 大角の群長 / 追い風 / 荒角の構え(ブロック6)
```
- ブロック札は**荒角の構え1枚（6）だけ**。3Eをどう割っても最大ブロックは6で固定。
- 敵を減らして削る手も無い。影は68（HP62+ブロック6）で1ターンでは落ちない。甲虫は殻12+HP20=32だが、**殻を割ると意図が攻撃16→噛みつきに悪化する**ので中途半端に割るのは損。
- 結論: ブロックが6で確定している以上、残り3Eの使い道は「置物を置いて将来を買う」しか無かった。33を素で受けて **48→15**。
- ここは「選択が無い」というより**選択肢が全部同じ結果に収束する**局面。職人としては将来（群長）を取ったが、取っても取らなくても被ダメは33だった。

### 局面2 — 2戦目 T2: 必要ブロック17、手札の最大ブロック14。2HP足りずに死亡
```
自分: HP 15/80 エナジー4/4  重り2（被ダメ+10%×プレイ枚数）
⚠️ このターンに受けるダメージ: 29（防御0を差し引いて29 / HP 15）
敵0 大顎の狩人 HP101/133 → 意図: 攻撃29（育つ技・いまは+2）
   行動: 🧿重り2→⚔️15〜19(使うたび+2)→⚔️6〜8×3→🛡️13〜19→…
手札: 大角の群長 / 嵐の角 / 疾駆 / 樹皮の鎧(ブロック14) / 疾風の号砲
```
- 樹皮の鎧を打った実測: `⚠️ 31（防御14を差し引いて17 / HP 15）` `意図: 攻撃31(もとは29・重りで+10%)` → **17ダメージ、HP15。−2で死亡。**
- 全部の線を数えた:
  - 0枚プレイ = 29素通し → 死。
  - 樹皮の鎧だけ（1枚）= 31−14 = 17 → 死（**最小被ダメがこれ**）。
  - 樹皮の鎧＋疾駆（2枚）= 34−14 = 20 → 死。埋めようと札を足すほど悪化する。
  - 殺し切り: 残り2Eの最大火力は9（疾駆+号砲）。敵HP101。論外。
- **重りは「カードを打つほど重くなる」税なので、カードでしか答えを持てない側は、足りない分をカードで埋めた瞬間に必要量が上がる。** ここが今回いちばん構造的だった。
- 補足（コードで確認・未実測）: `playsThisTurn` を加算しているのは `combat.ts` のカードプレイ経路だけで、`gears.ts` は触っていない。**ギアを組んでも重りの倍率は上がらない。** つまりギアあり側なら、この局面は「重りを増やさずにブロック/回復を足す」唯一の手段を持っていたことになる。私はギアを持っていないので、これは推測ではなく仕様の確認にとどめる。

### 局面3 — 行3 ❓毒の三杯: 褒美は3つとも同じ、払える毒が1つも無い（HP15）
```
❓ 🍷 毒の三杯   （所持 38G・HP 15/80・レリック0・デッキ19）
 [0] 長い毒の杯（レリック+60G・烙印2）
 [1] 濁りの杯  （レリック+60G・負傷3）
 [2] 迅い毒の杯（レリック+60G・HP-18）   ← HP15なので即死
 [3] 立ち去る
```
- レリック0個の身には喉から手が出る取引だが、**[2]は自分のHPが払える額を超えている**（HP-18 > HP15）。残り2つは19枚デッキに恒久的な死に札を2〜3枚入れる＝これから15HPで戦う局面で引きの質を落とす。
- 立ち去って**変化なし**。低HPのプレイヤーにとって、この取引は「値札が全部読めるが、財布がどれにも届かない」状態だった。
- これも広い意味で「手札に答えが無い」局面で、しかも**ギアが埋めうる穴**（回復・清め）にちょうど重なっている。

### 局面4（おまけ・強制された賭け）
行4 ❓騎士の賭場は**立ち去るが無い**。賭け2つは50G要るが、直前に工房で100G払った直後で所持38G。残ったのは `自分が馬上に立つ（50%: +100G / 50%: 負傷2）` の1択のみ。**コインは勝った（+100G）**が、負けていれば15HPの身に負傷2が入っていた。工房の支払いが、2ノード先の選択肢を消していた。

## ④ この難易度・このHPでの緊張の質

**適正か／理不尽か／作業か → 「理不尽ではないが、緊張ではなく詰みの確認になっていた」。**

- **理不尽ではない。** 情報は完璧だった。実値公開で「攻撃29」と出て、重りは「今+10%」とライブで出て、大顎は固定ローテ（重り→噛み→三連爪→守り）が最初から全部見えていて、育つ技の現在値まで出ていた。**死ぬ前に自分が死ぬことを正確に計算できた。** 予告の質は高い。
- **ただし緊張が「決断」になっていない。** 2戦しかしていないが、被ダメを決めたターンは2回とも**選択肢が1つに潰れていた**（局面1＝最大ブロックが6で固定／局面2＝最小被ダメが17で固定）。難易度6の打点（×1.6）に対し、緑の1E帯ブロックが5〜7、2E帯が14という刻みなので、**「あと何点で完全に防げるか」の算数が成立する帯を通り越して、「1枚では届かない／2枚引けていれば届いた」の二値**になっている。悩みどころが消える。
- **60%スタートは「2戦目までに1回いい引きを要求する」設定。** 48HPは幕2の通常敵1体分の打点（29〜39）の1.2〜1.6倍しかない。つまり**ブロックを外したターンが2回来たら終わる**。実際1回外して(-33)、2回目で死んだ。焚き火が行7まで無い盤面だったので、1戦目の事故を戻す場所がどこにも無かった。
- **HP19%で入った戦闘の体感は「作業」。** 大顎に入る前から「T1は無料（重り）、T2の噛みを防げるかどうかが全部」と分かっていて、T2の手札を見た瞬間に結論が出た。そこから死ぬまでにやることは無い。**盤面が悪いのではなく、低HPだと選択肢が先に消える**のが効いている。
- **経路の作り方は良かった。** 「焚き火4回＋宝箱の枝に入るには重い単体1戦を19%で通るしかない」という盤面は、リスクの種類を選ばせる設計として正しく機能していた。私は通る方を選んで負けた。これは盤面のせいではない。

## 起きなかったこと（対照のため明記）

- 幕2ボス（双腕の巨蟹）には**到達していない**。ボス戦のデータは無い。
- 焚き火は**1回も踏んでいない**（行7が最初で、行5で死んだ）。回復は一度も発生していない。
- 宝箱・ショップ・レリックは**1つも取っていない**。レリック0個のまま死亡。
- 状態異常で溺れた局面は**無い**（受けたのは重り2のみ。負傷・火傷・弱体・脆弱は一度も入っていない）。
- 装甲が抜けない局面は**無い**（デッキが全部貫通で、甲虫の殻も予定どおり割れた）。
- 「余裕だった戦闘」は**無い**。ただし1戦目のT2・T3は被ダメ0だった——甲虫が潜伏で守りが隙に化け、影が防御を引いた結果で、**こちらの構築や判断ではなく敵のローテ抽選が作った無風**。同じ戦闘が「T1で−33、T2〜T3で−0」と割れているのは記録しておく。
- ギアは1個も取らず、1回も組んでいない（対照条件）。魔素1が余った。
