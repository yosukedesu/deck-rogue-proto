## 使い分けの規律

1. **真鍮は「価値と資源」に限る**: 選択中の札と狙っている敵の縁・決定のボタン（真鍮の紙）・G・エナジー（コスト玉・輪）・R の外線・HP バーの「行動が変わる線」・勢いと急所の印。置物の帯は鈍い黄（オリーブ）で真鍮から離す
2. **青緑は「からくりと光」に限る**: 仕込み札のトークン（縁と帯）・「仕込む」・斬撃の縁・舞台の露頭。エナジーには使わない（同日ユーザー「エナジー表記は黄色系がいい」）。割引の玉は苔のまま
3. **文字は墨か各色の「墨」版だけ**（中墨 7:1・真鍮の墨 7.5:1・青緑の墨 7.2:1）。淡い色は塗りにだけ使う（2026-09-09 の読みやすさの規約を継承）
4. **意味の色は4つだけ**: 薔薇＝HP／鋼青＝ブロック／苔＝成長・良い／藤＝状態異常。危険は「危険の墨」の文字で言い、朱の塗りは作らない
5. **リーダーの色（5色）は UI に出さない**
6. **夜は3つ**（舞台・札の窓・地）で固定。紙＝暖・夜＝寒の対比がこの UI の芯
7. **新しい色は足さない**。足したくなったら上の表の役割に当てる（当たらないなら役割を1つ増やして表に書く）
8. **紙は2段**（2026-09-16 ユーザー「全体の戦闘画面の色バランスは？」→ 同日）: **手札と確認の窓＝紙 #f4ecd6、情報の段（帳面・上部バーの札・からくりのトークン・置物の付箋・山札/捨て札の札）＝紙（濃）#eadfc4**（`PaperFx.Tag2`）。見出しと手番の札は紙（明）。均一なクリームで序列が消えていた戦闘画面に、手札を一段前に出す
9. **真鍮の塗りが出る場所は2つだけ**＝あなたの資源（コスト玉・エナジーの輪）とあなたの決定（決定のボタン・選択中と行動中の縁・対象のバナー）。予告の札・筋力の rider は紙（濃）＋真鍮の墨。コスト玉の絵は原本の彩度を2割落として真鍮側へ半歩（`docs/pixellab/ui/cost_orb_pixellab.png` が原本）

## 実装（2026-09-16 同日）

1. **`PaperFx` が唯一の出典**（上の表の名で定数。`UiKit.Col*`／`Theme.Bg/PanelFill/…/Gold` は PaperFx の別名＝段階的に消す）。`PaperFx.TypeColor`（帯）・`RarityEdge`・`RoleColor` も同じ表を読む
2. 生の値の掃除: 生きている画面（BattleScreen・RunUi・MapScreen・Presenter・FeedbackUi・WorkshopScreen・CardView・Shop/Event/Reward/End/Title・CardPopup）の `Hex("#…")` を役割の名へ。
   残るのは絵の色（Theme.cs のアイコンの字形・生成スプライト、Stage.cs の舞台の材質、MapScreen のノードの淡い色と落書きのペン）と、使われていない旧画面（RunScreens.cs・CombatScreen.cs）
3. エナジーは真鍮のまま（`BattleScreen` の energyOrb の輪・`CardView` のコスト玉と生成玉・`UiKit.ColEnergy`）。一度 青緑にして shots を見せたところ、ユーザー「カードのエナジー表記は緑より黄色系がいい」で同日に戻した
4. **からくりのトークン**: 縁＝準備中 中墨／今ターン Mana／あとN回 ManaLight、帯＝InkSoft／ManaInk／ManaBand（旧: 灰／蜂蜜／カーキ・緑／茶）
5. 浮き文字: 与ダメ＝真鍮の紙・敵の番＝薔薇・状態異常＝藤・急所と勢いと筋力↑＝真鍮・威圧と筋力↓＝鋼青・延焼＝Ember・罠の準備完了＝青緑の紙
6. Web（プロト）は検証用の暗い緑のテーマのまま＝対象外（絵本の肌は Unity だけ）
7. 確認: shots（戦闘ソロ・地図・報酬・工房・焚き火・ショップ）で墨版の文字と帯の対比を目視
8. **帳面の状態の札と頭上の rider（2026-09-29 戦闘画面の見直し p18）**: 塗りは紙（濃）のまま、役割は墨で分ける＝浮き文字（5.）と同じ対応（筋力+・急所＝真鍮の墨／筋力−・威圧＝鋼青の墨／混乱と自分へ付く状態異常の rider＝藤の墨と藤の紙／延焼・その他＝墨／ボスの特性＝中墨）。真鍮の紙・鋼青の紙の塗りは使わない（真鍮の塗りは規律9の2か所だけ・鋼青の紙はブロックの札の地）。札の縁は中墨1px（`PaperFx.TagThin`＝帳面の枠〔墨2px〕より弱い）。記号は1つの概念に1つ（`Theme.IconArt` の strength_up/down・weak・armor・turn・confuse・frail）で、墨を掛ける小さな札は `Theme.IconMono`（'#' と '+' を白・'-' を透明にした版＝墨を掛けても形が残る）。「同時にブロックN」の rider だけはブロックの札と同じ鋼青の紙＋鋼青の墨
9. **小さい文字の太らせ（2026-09-29 戦闘画面の見直し p19）**: 規律3の対比は指定色でなく描いた画素で守る。13〜15 の Klee One は線が約1px で、いちばん濃い画素でも中墨の指定（紙（濃）の上で 6.4:1）に届かず実効 3.4〜4.3:1 だった（SemiBold に替えても 0.2px しか太らない）。`UiKit.Txt`／`Deco` は実際に描く大きさ（`Fs`）が 15 以下の時だけ `UiKit.SmallMat`＝元の素材に FaceDilate（PC で Regular 0.12・SemiBold 0.08・装飾体 0.06、スマホは実寸の px でそろえて ×0.66）と Sharpness 0.4 を足した共有素材を当てる（キーワードは変えない＝ビルドで削られない・送り幅は不変。中墨のラベルのいちばん濃い画素が紙（濃）の上で PC 5.6〜6.4:1・スマホ 6.4:1）。長文の説明パネル（`Tooltip`）と用語の説明（`CardPopup`）は `UiKit.PlainWeight` で元の太さ。タイプの帯の文字は 16px の太字（SDF の合成太字）
10. **生の値の検査（2026-09-29 戦闘画面の見直し p26）**: 実装2 の掃除の続き。戦闘画面・ギア・灯・用語の説明・イベント・出立の店・工房・評価に残っていた `Hex("#…")`・`<color=#…>` を役割の名へ（リッチテキストの色は `UiKit.ColorTag(PaperFx.X, s)` だけで作る）。見た目が変わったのは古い値の2つ＝旧・金の墨 #7a4e12 → 真鍮の墨（からくり・ギアの説明・イベントの選択肢の注記。6.1:1 → 7.5:1）と旧・中墨 #574b48 → 中墨（用語の説明・灯の説明）、と暗幕を地にそろえたこと（窓 #141228 α0.68／0.72 → 地 α0.7）。藤の紙は表の #e9def3 に1本化（直書きの #eddbf7＝アーティファクトの判を撤去。差は RGB で 4 以内）。ほかは同じ役割の名へ寄せただけ（戦闘のエラーの札 → 警告の紙 roseLight・工房の「合成する」#f0d58a → 真鍮の紙。差は RGB で 10 以内）。演出の光で複数のファイルが同じ値を持っていたもの（灯の芯 #fff6d2・灯の光・斬撃の白い芯）は絵の側の `ThemeFx.LampCore／LampGlow／SlashCore` に名前を置いた（表には載せない）。**再発の検査**＝`npm run check:colors`（`scripts/check-unity-colors.ts`。`npm test` でも `src/sim/unity-colors.test.ts` が回る）: `unity/Assets/Game` の *.cs から ①16進の直書き ②PaperFx の色と各成分 6/255 以内の数値の `new Color`／`Color32` を探して落とす。除くのは実装2 で残してよいと決めた所（PaperFx.cs・Theme.cs・Stage*.cs・MapScreen.cs・MapDoodle.cs・RunScreens.cs・CombatScreen.cs）。白・黒・灰の掛け算と透明度、役割の色から離れた演出の光は落とさない
11. **最終の答え合わせの直し（2026-09-30）**: ①手番の帯（ターン開始の「あなたの番」「敵の番」）も上部バーの手番の札と同じ組＝あなたの番は紙に墨・敵の番は夜の札（`PaperFx.NightTag`）に紙の文字。苔と薔薇は帯の下の短い線だけ（旧は紙の上に苔 2.3:1・薔薇 3.3:1 の文字＝塗りの色で文字を書いていた）②出せない札・組めないギアの紙の乗算 `PaperFx.DimTint` を中立の灰 (0.88,0.90,0.96) に（旧 (0.92,0.90,0.86) は黄ばんだ紙に見えた）。出せない札のコスト玉は灰の写し（`ThemeFx.CostOrbMuted`）③自分の資源・状態の札（`SmallChip`）の地も頭上の rider と同じ細い縁の札（`PaperFx.TagThin`）に塗り1回＝状態異常は藤の紙そのもの #e9def3（旧は紙(濃)×藤の灰桃 #d6c2bb）。左の色の四角は撤去し、役割は墨（勢い＝真鍮の墨・成長＝良いの墨・状態異常＝藤の墨）④人形の足元の札の心の絵は HP の記号なので薔薇（数字は良いの墨のまま）⑤店の「★ レア枠」は夜の上の注記なので夜色の札 ⑥検査に**規則C＝引退した色**（`RETIRED`: 旧・蜂蜜 #e0b25a・旧・金の墨 #7a4e12・旧・中墨 #574b48・旧・藤の紙 #eddbf7・旧・窓の暗幕 #141228）を足した＝小数の `new Color` で書いた引退した値も落とす（一覧の選択の輪に旧・蜂蜜 (0.88,0.7,0.35) が残っていた→真鍮）
