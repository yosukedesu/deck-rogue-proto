## ① 結論3行

1. **面白いのは「敵の攻撃を敵に向ける」型だけが突き抜けている**（惑わし＝混乱3）。3体戦を被ダメ0にし、装甲18のソロ敵に48点を自分で払わせた。カードで代わりがきかない。

3. **効かない敵にも組めてしまい、魔素を捨てる**。鎮めの錘を割り込みを持たない敵に、錆びた楔を召喚を持たない敵に組めた（どちらも無反応で魔素だけ減った）。カードの伏せは条件を満たさなければ発動できないのに、ギアは空振りを止めない。

## ④「いま止める」と「次から効く」の区別は伝わったか

**使う前は伝わる。使った後は伝わらない。**

- 使う前: 締め紐と時の歯車の説明文に「**（いま宣言されている行動は止まらない）**」と明記されている。楔は「いま宣言されている行動を打ち消す」。ここは読めば分かる。取り違えは一度も起きなかった。
- 使った後: 差が露骨。

| | 組んだ瞬間 | 次のターン |
|---|---|---|
| 楔 | 意図が「打ち消し済み＝この行動は起きない」に変わる・被ダメ予測が即下がる | — |
| 惑わし | 「混乱3」タグが付く・被ダメ予測が即0になる | 混乱が3→2に減る |
| 締め紐 | **何も出ない** | 意図が「隙だらけ」 |
| 時の歯車 | **何も出ない** | 全員が「隙だらけ」 |
| 鎮めの錘 | **何も出ない**（予告チップも残る） | 予告チップがようやく消える |

**「次から効く」系は、組んだターンのあいだ自分の判断を確認する手段が無い**。締め紐を組んだ後、「本当に効いたのか、対象を間違えたのか」を確かめる方法が盤面に無く、次のターンまで待たされた。1ターン1個・魔素1という重い制約の下で、これは不安が残る。

処方（案）: 対象の敵に「次の行動は隙」「割り込みを鎮めた」「召喚を止めた」のチップを付ける。ログに「ギアを組んだ: 締め紐 → 弔いの獣」の1行を出す。鎮めの錘が立っている間は豹変の予告チップを消すか取り消し線にする。

## ⑤ 一度も使い所が無かったギア

**錆びた楔（2個）**。2ラン9戦で、召喚・分裂・孵化を持つ敵に一度も当たらなかった。

- 本ラン（幕3）で歩いた3戦: 狼と妖術師と太鼓／弔いの獣の番い／彫師と用心棒 — どれも無関係。
- 幕3の該当敵（蟲抱えの蛙鬼・絡繰の斧兵・不滅の骸兵・蘇る合成獣）は経路上に無かった。
- 補足 O3 で幕2の「苔の産み手と苔スライム」を目指して3戦歩いたが、到達前に倒れた。

**これは運の話ではなく構造の話**。錆びた楔と鎮めの錘は「その特性を持つ敵にだけ効く」ので、拾ってから刺さるまでの待ち時間が長く、その間ずっと持ち物の枠を占める。
一方で楔・締め紐・時の歯車・惑わしは**どの敵にも効く**ので、拾った次の戦闘で必ず仕事をした。
干渉系を太くするなら、この2種類は別物として扱うべき（出現率か、対象が居ない時の代替効果か、少なくとも「この敵には効かない」の表示）。

**空振りを止めない問題**（2例で確認）:
- O 行5 T2: 鎮めの錘を献身の彫師（割り込みを持たない）に組めた。「いまは組めない」に出ず、魔素3→2、敵に何の変化も無し。
- O3 T6: 錆びた楔を嘲る道化（召喚を持たない）に組めた。魔素5→4、無反応。

死線で1個1魔素を捨てるのは痛い。カードの伏せ（条件を満たさない札は発動できない）と揃えるべき。

## ⑦ 干渉系はこのゲームの独自要素として太くする価値があるか

**ある。ただし今の形のままでは半分しか働いていない。**

太くする根拠:
1. **カードで置き換えられない**のは実測で確か。混乱・隙・割り込み封じ・召喚封じは緑のカードに存在せず、打ち消しだけが伏せ札と競合する。しかも伏せ札は準備ターンが要るので、「いま宣言されている行動を今すぐ消す」はギアにしかできない。
2. **敵の予定表（行動の表・予告チップ・被ダメ予測）が全部画面に出ている**ので、「どの拍を外すか」の計算が成立する。山場2はその計算そのものが楽しかった。仕掛けを読む土台は既にある。
3. **惑わしは「装甲・ターン装甲に対する構造的な答え」になっていた**。敵の攻撃は敵の装甲を見ないので、混乱は量の器を迂回する唯一の出口だった（O2で48点）。単発デッキが装甲持ちに詰む問題に、カードを触らずに別解を足せる。

太くする前に潰すべき欠陥（優先順）:
1. **組んだ事実をログに出す**。今は魔素の残量でしか分からない。
2. **効かない相手には組めない**（理由つきで弾く）。カードの伏せと揃える。
3. **「次から効く」系は敵に印を付ける**。組んだターンに確認できないのは、1ターン1個の制約と噛み合わない。
4. **鎮めの錘は予告チップを消す**（62を割った後も残っていたのは表示の嘘）。
5. **撃破サマリーに干渉の功績を出す**。「敵に払わせたダメージ」「消した敵の行動」。今は惑わしで54点払わせても「総与ダメ127」としか書かれず、自分が何をしたのか記録に残らない。
6. **特性依存の2種（錆びた楔・鎮めの錘）は別扱い**にする。9戦で0回は死蔵ではなく供給の問題。

最後に手触りの序列を一行で: **惑わし（盤面が裏返る）＞ 時の歯車・楔（拍を買う）＞ 締め紐（拍を買うが確認できない）＞ 鎮めの錘（効いたか分からず、得かも分からない）＞ 錆びた楔（出番が来ない）**。
