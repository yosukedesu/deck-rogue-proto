# 白の語彙リネーム提案（2026-09-18。world.md「白黒の語彙は解凍時にリネーム」の白ぶん。ask_user 2ラウンドの裁定を反映）

## 0. 裁定（ask_user）

| 問い | 裁定 |
|---|---|
| 光耀の里の工房の正体 | **灯火の工房**（歌の要素は不要）。坑道の灯り（ランタン・光る鉱の加工）を作る職人衆。術＝光を操る |
| 「聖」の置き換え | **「灯」「光」** |
| 従者の正体 | **真鍮の小さなからくり（灯りで動く人形）**。型の名は**人形の役割名** |
| 軍隊系・城壁系の語 | **灯りの語**へ寄せる |
| 範囲 | **全82枚を光耀の語彙で統一** |
| ひなたの肩書・説明文 | **光耀の灯匠（とうしょう）**／「灯りに呼ばれて従者が駆けつける」（旧「光耀の聖歌士」「歌に呼ばれて」は撤回＝2026-09-10 の据え置き裁定の例外2人目） |

読み替えの骨格: 回復＝マナの光で傷を塞ぐ（緑の陽光の恵みと同じ読み）／威圧＝強い光で**眩ませる**／守り＝**光の壁**／従者＝灯りで動く**人形**（少年・乙女・猟犬・射手は人形の型）／召喚＝**点灯**（人形に灯を入れる）／登場誘発＝**鐘の人形**（灯が入ると鳴る）／アンセム＝**灯り増し**。

語彙の対応表: 聖印→灯印／聖光・聖盾→灯火・灯盾／聖歌・祈り・詩→灯り／聖域→灯りの庭／城壁・塁壁→光壁／城門→光門／集結・召集→灯の集い・点灯／号令・進軍→点灯の合図／軍旗・旗印→旗／裁き・断罪・威光→眩み・眩光／大聖堂→大灯台／奇跡→輝き／殉教→身代わり・捧げ／使徒→灯籠／聖杯→器／聖油→灯の油。
