## 2. 3本が一致した所見

1. **構えの拍は間延びしない**。2T決着が消え、構えのターンが「仕込む／殴る／宣言した個体から殺す」の分岐点になった。ターン数は物差し帯（幕1 3.4〜3.5T）。
2. **構えは「殴り得の休符」でもある**。構えのブロックは自ターンの攻撃の後に積まれ、圧は翌ターン。守るターンに敵が得るのは筋力+1だけで、それが **CLI の意図行に出ていなかった**（3本一致。`play.ts` の defend 行に `buff` が連結されていない）→ 是正済み。
3. **HPの幅は無害**。計算は現在HPから組むので影響ゼロ。幅に気づくのは同種が並んだ時だけ。「入る前に幅が見える場所」（敵行に公称）の要望が2本。
4. **罠×枠2は「構えに2枚仕込む→翌ターン完封→体勢崩し」が本物の設計になった**（AA2 は3回とも面白さ5）。ただし **「1行動1リアクション」が枠2の天井**（3本一致）: ソロ敵では pre が鳴ると post の2枚目は構造的に空振り。温存が少ない理由もここ。
5. **罠壊し**は準備ターン＝仕込んだ瞬間に伏せ破壊へ化けるので、罠モデルでは構造的に仕込めない敵（AA2）／1E の囮で16〜24の攻撃が消える囮スイッチが健在（AA）。
6. **返し系（被攻撃後）は構えの拍と相性が悪い**（AA: 茨の返し24回中発動0）。被攻撃前（守りの蔓・蔦槍）は鳴る。
