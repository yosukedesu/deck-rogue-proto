## 7. 表示の嘘・分かりにくい表示・バグ

1. **潮溜まりで0Eになった保持札の注記が違う**: 「⚠実コスト0E(印字1E・割引/無料=次に出す1枚だけ)」と出る。潮溜まりの軽減は「次に出す1枚だけ」ではなく、手札に残っている間ずっと。再現: 潮溜まりを場に置き、保持の札（沈思の一撃・書庫で残した札）を持って次のターンへ → CLI の手札行。
2. **潮溜まりは残るたびに重なるのに、文面は「コスト-1」だけ**: 賢者の泉（2E）を書庫で2ターン続けて残すと 1E→0E。`retainDiscount` が毎ターン加算される（本家 Establishment と同じ）なら、文面に「残るたび-1（重なる）」と書かないと読めない。
3. **蔦纏いの歩き木のフレーバーと実装が食い違う**: フレーバー「物理の一振りが一マナ重い。**呪文は絡まれない**」だが、重圧は `attacksOnly`＝ダメージを与える札すべて（呪文も）+1。青は攻撃が全部呪文なので全知の一撃が4E になる。再現: `npx tsx src/sim/play.ts new-battle "cards:blue_strike,blue_tide_drop,blue_current_lash,..." enemy_vine_walker 1 x.json` → 潮の一滴「実コスト1E(印字0E・重圧)」。特性タグ「攻撃カードのコスト+1」は正しい＝直すのはフレーバー。
4. **CLI のログに占術の結果が出ない**: `Scried` の出来事はあるが `play.ts` の renderBattle に行が無い（Web の `ui/log.ts` と Unity にはある）。ResolveScry の後の「直近の出来事」が空になる。
5. **CLI のログに打ち消しが出ない**: 対抗呪文の発動は「リアクション発動:対抗呪文」だけ、ギアの楔は「⚙ 楔 を組んだ」だけで、何が打ち消されたか（急降下18・網）が出ない。
6. **CLI で満ち潮の書庫を置いたまま `EndTurn` を送ると、黙って0枚残す**（既定＝残さない）。書庫がある時は「残す札を指定しなかった」注意か、既定で残す提案があると事故が減る（人間の画面は窓で選ぶはず）。

## 9. 設計への提案（短く）

1. **⭐沈思の一撃（知恵の重み×思案）が強すぎる**: 初期札の知恵の重み＋コモンの思案で幕1の工房から作れ、1E・保持・2枚引いてから数える＝レアの全知の一撃（3E）を上回る。11回で657点・最大101。幕2の短さ（平均2.0T）の主因。案: 数える前のドローを1に、または ×3 を鍛えで上げない（+ の継承で ×4 になる）。
2. **潮溜まりは保持の源と一緒に出す**: 幕1に2回、保持の源が無い時点でレア確定枠に出た。書庫を持っている時だけ出す（色ゲートと同じ仕組みで「保持の源あり」ゲート）か、潮溜まり自身に「登場時、手札1枚を保持」を足す。
3. **占術に「捨てるほど得」の理由を**: 抱え込みと占術は目的がぶつかる（枚数が火力なのに、占術は枚数を減らす）。払い出し（読み切り・渦見の鏡・潮読みの極み）が来ないと占術は「見るだけ」になる。先見の盾・浅瀬読みの側に「捨てた枚数×N 氷壁」など、捨てる行為そのものに小さな報酬を付けると柱が噛み合う。
4. 歩き木のフレーバーを「攻撃の一振りが重い（呪文でも）」に直す。
5. 円蓋を持つと魔素が溢れっぱなしでギアを組まなかった（意図が見えないと「今この行動を止める」判断が立たない）。円蓋と干渉系ギアの相性は記録として。
