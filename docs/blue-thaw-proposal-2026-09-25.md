## 3. 罠モデルへの当てはめ（13枚）と仕込み枠

**仕込み枠 1→2（推奨）**。このは・ひなたは2、かすみ（青黒）は3のまま。罠が13枚ある色で枠1つは、Opus Z の「枠1つが天井」がそのまま当たる。
2枠なら「今ターンに仕込む札」と「前のターンの罠」を重ねられる。1窓1枚と組むと、前の窓で氷壁・後ろの窓で霊気、が同じ行動に鳴る。

規則（`card-power.md` §66）: 数値は据え置き。足すのは「踏んだ行動への反応」型（しきい値・完全に防ぎ切った・倒せなければ）だけ。副次は期待値係数0.5。上限は被攻撃後の無条件 150%・被攻撃前の軽減 175%（1E＝8VP・2E＝14VP）。青の副次は青のパイ（霊気・反復・氷壁）で作る。**敵フェーズのドローは全捨てで消える**ので使わない。

## 4. 鍛えるの本家形

`upgrade.ts` の `V2_COLORS` に青を足した時、**旧3段と結果が変わる札は44枚**（全表は付録A）。読みどころ:

- 参照倍率+1 が効く札: 知恵の重み ×2→×3・全知の一撃 ×5→×6・奔流の連撃 ×3→×4・大漩渦 ×4→×5・巻き波・書庫の盾・万巻の砦 など。旧はコスト−1か「おまけ1ドロー」で、魂の数字が伸びなかった（白と同じ理由）。
- ドローの札: 水撃・早瀬の一撃・思案・賢者の泉・水鏡の書庫（旧は消滅が付いていたのが外れる）・集中・二重詠唱・こだまの大合唱＝ドロー+1。
- 霊気・反復の単位+1: 霜の帳・冷徹な観察・白波の壁・心眼・帯電の霧・霊気の呼吸・焚べ火。

**例外（推奨4件）**:
1. **打ち消し（無条件）3枚＝コスト−1**（対抗呪文・凍る静寂・魔力盗み。2E→1E）。本家形だと「霊気+1」だけで、打ち消しの魂は「何でも消せること」と「値段」。白の軍楽隊と同じ名指しの例外（`V2_COST_ONLY`）。
2. **打ち消し（条件つき）2枚＝条件を広げる**（マナ漏出 15以下→20以下・逆巻き 12以上→8以上）。これが札の個性の数字。本家形のしきい値ティアは下限（minGrowth 等）しか扱わないので、上限（maxActionValue）を広げる向きを足す。
3. **潮汐の書見台＝コスト−1**（本家形だと毎T 2ドロー。引く枚数が 6→8 になり、白の軍楽隊と同じ「ドローが青の定価を越える」）。
4. **懐深き外套＝コスト−1**（本家形だと毎T 手札×2の氷壁。手札8なら毎ターン16の氷壁が消えずに積もる）。

それ以外の40枚は本家形のまま通す。ゴールデン `leader_blue-9101` はボットが鍛えを使えば手が変わるので再生成し、C# `Upgrade.cs` も同形にする。

## 6. 実値公開・行動グラフ・ギアの下での点検（数値は触らない。記録）
