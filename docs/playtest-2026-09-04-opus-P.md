## 3. 設問への回答

### P1. 勢いの網は成長と別の手触りを作ったか / 多段に再収束しなかったか

**別の手触りは確かに立った。ただし今回それを作ったのは新8枚ではなく「大角の群長＋1E攻撃の列」**（新8枚は1枚しか手に入らなかった）。

- **動詞が違う。** 成長は *積む*（戦闘内で永続・ヒットごと）、勢いは *組む*（そのターンで消える・カードごと）。戦闘5・戦闘2では「打ち据え→打撃→打撃」の順に並べると 4/12/15 と階段になり、**手札を並べ替える作業が毎ターン発生した**。成長にはこの作業がない（撃つ順番が結果を変えない）。
- **「0の状態でも先に倍化を撃つ」という決断が生まれた。** 戦闘4の詰めで、勢い0のまま疾風の号砲（+1→×2＝勢い2）を撃ってから打撃→絡み蔦に繋ぎ 8+11=19 でちょうど17を削り切った。**倍化札は勢いが無くても「床2」として機能する**ので、温存でなく即撃ちが正解になる局面がある——これは面白い非直感だった。
- **多段への再収束は起きなかった。ただし「起きなかった」の内訳が重要。**
  - 蔦の連撃（X・5×Xヒット）は1回提示され、**HP14だったので樹皮の鎧を取った**＝勢いに勝ったのではなく防御に負けた。二連の蔦打ち・三連の角は0回提示。今回のランは多段との勝負が発生していない。
  - 構造的には**per-card と per-hit で参照軸が割れているので、再収束はしにくい設計になっている**。大角の群長は「攻撃カードをプレイするたび+2」＝**枚数**を数える。成長は**ヒット**を数える。勢いの網は「軽い札を何枚並べたか」を報酬にするので、多段1枚に全部を詰める方向とは逆を向く。ここは狙いどおり。
  - 逆に **新しいアンチシナジーを1つ見つけた**: 工房の圧縮（打撃2枚→真・打撃1枚）は**群長の誘発回数を減らす**。ラボで確認した通り勢いの吐き先（角の一突き・猛進の角）も「1発を大きくする」札なので、**勢い軸は「枚数を増やしたい」と「1発を太らせたい」が同じデッキの中で綱引きする**。これは成長にはない緊張で、面白さにもなるが、工房・大型札との相性は悪い。

### P3. 根付く勢い（勢い→成長）

**提示0回・未ピック**なので実測なし。付随の観察を2つ:
- 理想形デッキ `deck_momentum`（18枚）にも**根付く勢いは入っていない**。設計者自身が軸の中核と見ていないなら、この札の役割（勢いを成長に逃がす＝多段への橋）は**まさに「勢いを多段に戻す」導線**なので、P1の狙い（成長と別の軸にする）と正面から衝突しているように見える。
- 勢いは per-card、成長は per-hit。**根付く勢いは per-card で稼いだものを per-hit の通貨に両替する札**なので、多段札を1枚でも持っていれば常にこちらが正解になりうる。今回は確かめられなかったが、**再収束の唯一の入口はこの札**だと思う。優先的に人間ランで確かめる価値がある。

## 4. 新カードの不具合・表示の嘘

### 4-1.【重大・仕様の穴】角の一突きのオーバーキルで放出が丸ごと蒸発する（勢いは消費される）

ラボ実測（`deck_momentum` / seed99 / T3）:
- 勢い14の状態で 角の一突き を **HP12の敵**に撃った。
- 第1効果 `dealDamage 8 (pierce)` が **8+14＝22** で対象を撃破。
- 第2効果 `dischargeMomentumDamage 2` の **28ダメージは一切発生せず**、**勢いは0に消費された**（ログは `与ダメ22` の1行のみ／盤面から勢い表示が消える）。
- 隣の生存敵（HP9）には1点も飛んでいない。

「軽く積む→倍にする→吐く」の**吐く部分が、本体が仕事をしすぎると消える**。しかも警告も表示もない。単体放出（角の一突き）と全体放出（嵐の角、生存敵が全滅した場合）の両方で起きる。
最小の処方案は3つ:
1. 効果順を **[放出] → [本体]** に入れ替える（放出が先に解決＝本体に勢いが乗らなくなるので数値の再査定が要る）
2. **対象が倒れていたら放出は別の生存敵へ**（亡骸の単体効果が生存先頭へ自動解決するのと同じ既存則を流用できる）
3. **放出が空振りする時は勢いを消費しない**（いちばん安く、体験の理不尽だけ消える）

### 4-2.【表示の嘘】放出（discharge）分が手札の「実値」に入っていない

- 角の一突き（勢い14）: 表示 `［実値: 敵0:22(勢い+14)］` / 実際 **22＋28＝50**
- 嵐の角（勢い3）: 表示 `［実値: 敵0:7(勢い+3)］` / 実際 **7＋3＝10（各敵に）**
- 風の壁も同型（ブロック4のみ表示、勢い×1ブロックは非表示）と思われる。

`sim/play.ts` の実値行は `damageBreakdown(state, ei, e.amount, pierce)` を**代表の dealDamage 1件だけ**に対して呼んでいる。放出系は `amount` が倍率なので、そもそも計算に乗らない。**勢いの網は「札の価値の過半が放出側」なので、この表示は8枚中4枚で嘘になる**（角の一突き・嵐の角・風の壁・根付く勢い）。

### 4-3.【表示の嘘】猛進の角の momentumMultiplier が実値に反映されていない

- 勢い3の状態で 猛進の角: 表示 `［実値: 敵0:17(勢い+3)］` / 正しくは **14＋3×2＝20**。
- 原因は `engine/effects.ts` の `damageBreakdown()` に `momentumMultiplier` / `growthMultiplier` の引数が無いこと（実処理は `effects.ts:876-877` で `momentum × (N-1)` を別途足している）。**「実処理と同手順の純関数」という damageBreakdown の契約が、倍率つき効果で破れている**。大牙（成長×3）等の既存の倍率札も同じはず。

### 4-4.【表示の嘘・既存だが勢いの網で頻発】自分で付ける勢いを実値が数えない

- 踏み荒らし（勢い+3→16ダメ）: 表示 `実値16` / 実際 **19**。成長8のときは 表示20 / 実際23。
- 突進の助走も同型。
- 単体では小さいが、**新8枚のうち疾風の号砲・突進系との併用が前提なので、勢い軸の手札はほぼ全部が「表示より強い」**状態になる。過少表示なので事故にはならないが、「読んで計算する」ゲームとして毎ターン嘘をつかれる。

### 4-5.【軽微・既存】?イベント「枝を借りて鍛える」の結果が「変化なし」と表示される

行7の古木のうろで 大角の群長 を鍛えた（2E→1E に正しく適用済み）が、CLIの結果行は `📜 イベントの結果: 変化なし`。`describeEventOutcome` がレリック・カードのuid増減・HP・金しか差分を見ておらず、**同一uidの def 差し替え（鍛える・変成）を検出できない**。新カードとは無関係だが、ランの中で唯一「何が起きたか分からなかった」瞬間だった。

### 正しく動いていたもの（記録）
- 追い風の動的コスト表示 `⚠実コスト0E(印字1E・割引/無料)` は正確で、勢い5の境界がちゃんと見える。**8枚でいちばん表示が親切**。
- 「放出に勢い加算は乗らない」は仕様どおり（勢い3→放出2で**きっちり6**、勢い14→**きっちり28**）。
- 疾風の号砲の「+1してから2倍」＝勢い0でも床2が立つ、も仕様どおり。
- 大角の群長の誘発は**カードの効果解決後**（打撃を撃った本人には乗らず、次の攻撃から乗る）。これが順序パズルの土台になっていて良い。
- 蔦の陣を pre窓 で発動すると **ブロック10と返し8が同時に解決**される（「1枠に2つの仕事」は正しく機能）。

## 5. 提案

1. **【最優先】角の一突き／嵐の角のオーバーキル蒸発を塞ぐ**（§4-1）。推奨は案3「放出が空振りする時は勢いを消費しない」——エンジン変更が最小で、体験の理不尽（払ったのに何も起きない）だけが消え、数値査定に触らない。
2. **実値表示を効果列の畳み込みに変える**（§4-2/4-3/4-4）。`damageBreakdown` に `momentumMultiplier`/`growthMultiplier` を渡し、カードの effects を順に解決した見積り（自分で付ける勢い・放出を含む合計）を1行にする。**勢いの網は「表示された数字を足し算して撃つ順を決める」遊びなので、ここが嘘だと軸ごと成立しない。**
3. **入口コモンの供給を1〜2枚厚くする**（§P2）。8枚中4枚がコモンなのに24スロットで0枚は、分散の範囲内でも「軸にする判断が一度も発生しない」を生む。骨刃の入口コモン+2と同じ処方（普通に使える本体に勢いの生成が乗るコモン）を推す。
4. **根付く勢いの位置づけを再検討**（§P3）。理想形デッキにも入っておらず、機能としては「per-card で稼いだ勢いを per-hit の成長に両替する」＝**多段への再収束の唯一の入口**。勢いを成長と別軸にする、という今回の目的と正面から衝突する。撤去か、「成長にするが多段には乗らない」等の限定を検討したい。
5. **装甲との相性を裁定してほしい**（§P5）。勢いの吐き先（角の一突き・猛進の角・疾風の号砲）は全部「1発を太らせる」札なので、装甲25のボス（オーガ・門番・大亀）に対して**成長×多段より構造的に弱い**。「装甲は単発への問い」の定義どおりではあるが、**新軸の主役がボスで沈黙する**のは検証しておいたほうがいい。嵐の角（全体放出）が装甲へのアンサーになるかは、複数体戦での再測が要る。
6. **ナーフ提案は現時点でなし**（実測サンプルが疾風の号砲1枚のみ）。ただし監視項目として記録: ラボの **疾駆(0E)×2 → 疾風の号砲(1E) → 角の一突き(2E) = 3エナジーで50ダメージ**（本体22＋放出28）は幕1帯では明確に過剰。歯止めは①号砲の消滅 ②疾駆の枚数 の2つだけで、**0E生成札が増えると指数的に伸びる形**（0E×n → 号砲で×2 → 放出で×N）。0E生成札（疾駆）は現状1種だが、今後増やす時は cardrules 側で上限を切っておきたい。
7. （軸外）**幕1でレリック0個になるルートが成立する**。エリート4か所すべてに回避路があり、幕1の宝箱行は撤去済み、?は3回とも非宝箱だった。低リスク低リターンの走破は健全という既存裁定は理解しているが、**HP収支だけは低リスク側が明確に不利**（今回の敗因）。?の宝箱率2%は幕1では効いていない。
