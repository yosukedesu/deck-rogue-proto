## 一致した所見

1. **伏せの価値の本体は敵の反応（setAlt）**。両ランの面白さ5は「罰型の分岐を計算して踏む」オーガ戦。実値を見てから発動するか温存するかは、pre窓の軽減が「撃たなければ0点」なので実値に関係なく撃つのが正解で、迷いは複数体戦（どの攻撃で切るか）にしか出ない。
2. **弱腰型のsetAltは「1E（または0E）のスイッチ」**。D: 0Eの毒針の囮＋符師の懐で用心深い影・罠壊しを被ダメ0で無力化（片務的な必勝手順）。E: 要らない打撃1枚で道化+妖術師が両方無力分岐に切替（予測被ダメ28→実1）。全伏せは既存の穴を全デッキに開放しただけで、穴自体は現行にもある。
3. **罰型では見切りが逆向きに働く**（D）: 伏せ直すと強打、放置すれば見切られて弱い分岐＝「触らない」が最適で、家賃の設計が罰型には効かない。
4. **枠1つ＝リアクションは1〜2枚しか要らない**（D 73%見送り）。工房の茨の砦（1枠に pre 窓の守りと返しが同居）が両ランで最良の解答＝「1枠に2つの仕事」が専用札の正しい形。
5. **蜃気楼の面は作り直し後でも確認ウィンドウを「はい」ボタンに退化させる**（D #17）。

## 実験ルール固有の所見（E）

- 効果目当ての伏せは「同じ札を2倍の値段で1テンポ遅く使う」ので選ばれない。防御はブロックが敵ターンまで残る仕様なので伏せる意味が構造的にゼロ。
- 実際の用途は3つだけ: 分岐スイッチ（3回、全部成功）・囮（伏せ破壊に捨て札を食わせる）・**焼き切り**（伏せた蔦の楔を被攻撃前に発動して樽を落とし攻撃自体を消す＝唯一の新しい勝ち筋）。
- 発動時にエナジーを残す判断は「面倒」。非攻撃ターンの読みが要る点だけが面白かった。
- 報酬候補の多くが伏せ不可（X・モード・ドロー付き）で、手札の情報量だけ倍になった。

## 結論

全カード伏せ可は**「今撃つか構えるか」の決断を作らなかった**。作ったのは分岐スイッチと囮で、それは現行ルールの穴（弱腰型setAlt・0E伏せ）の露出でしかない。
実験フラグは残す（既定OFF）が本線にはしない。伏せの面白さは敵側の反応の設計と、専用札の「1枠に2つの仕事」で作る。

## 処方候補（裁定待ち）

1. **弱腰型setAltの廃止＝賭け型へ揃える**（伏せ札ありで「別の行動」になるが弱くならない、または罰型）。両ランの最大の穴
2. **罰型setAltは見切りを無視**（`setAlt.ignoreFreshness`: 伏せ札がある限り強打。「触らなければ弱い」の逆転を消す）
3. **敵は0Eで伏せた札に反応しない**（実際に払ったエナジー1以上の伏せだけが「気配」。毒針の囮の囮役は残るが無料スイッチではなくなる）
4. **専用リアクション13→8**（茨の爆ぜ・見切りの構え・窮鼠の大牙・跳ね返りの蔦・茨の茂み(置物)を撤去候補）＋**「1枠に2つの仕事」型を追加**（茨の砦のような pre 守り+post 返し、打ち消し+成長など）
5. **蜃気楼の面の撤去**（作り直し後も核を消す）
