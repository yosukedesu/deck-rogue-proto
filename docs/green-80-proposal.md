## 4. 制約チェック
- 床（green-floor）: 0〜1E率＝40%以上を維持（撤去13のうち1Eが7枚・2E以上が6枚、追加は1E×2・0E×1）。キャントリップ2（木漏れ日・見切り撃ち）・全体6（薙ぎ払い・開花の蔦・森羅の大嵐・薙ぎ角・大地の唸り・嵐の角＝森の大爆発撤去後も6）・1E置物3以上（棘の蔓・風渡り・芽守り・棘葉の茂み・眼光・根張り＋風の棘）・0E3以上（6）。
