# バランス運用規約（2026-09-02 制定）

出自: StS2のEA運用の実測（docs/sts2-reference.md §7）。ナーフパッチのたびにレビュー爆撃
（1日8千〜1.5万件）が起き、開発は複数回ロールバックした。一方で「Steamレビューより
インゲームのフィードバックとテレメトリが調整の指針として役立った」（Mega Crit）。
うちの既存裁定（ナーフは要許可・基本は上昇）を4原則に成文化する。

## 4原則

1. **ナーフは事前にユーザー裁定必須**（既存裁定の昇格）。引き上げ・追加・構造の処方は
   裁定不要で進めてよい。
2. **ナーフは単独コミット**。カード数値の変更と機構変更を同じコミットに混ぜると
   sim差分の原因が切り分けられなくなる（レアリティ導入をPhase 0として単独先行させた前例の一般化）。
3. **ナーフ案には必ず代替案を併記して選ばせる**——敵側の処方（ワクチン型: 装甲・帯の受け）・
   買い戻しバフ・供給側調整（レアリティ・提示頻度）。「カードは戻さず敵側で受ける」が既定路線。
4. **当てる前にロールバック条件を宣言する**（例: 人間ラン2本で面白さ低下が一致したら戻す）。
   StS2は宣言なしのナーフ→炎上→無条件ロールバックで二重に信頼を失った。

## 作り直し基準（ボス・エリート）

sim勝率が健全でも、**人間/LLMランで「特定アーキで構造的に不可能」の報告が独立2本一致したら、
数値調整でなく構造（問いの形）を作り直す**（StS2 Doormaker→Aeonglassの教訓——開発が
「統計上は最弱ボス」と説明しても不満は消えず、最終的に全面リワークになった。
平均勝率でなく分散が火種）。数値の言い訳で監視を続けない。

## タイマー敵の規約

タイマーの罰は **(a) 筋力の漸増**（威圧で剥がせる）**(b) 予告付き大技**（防御・打ち消し・
リアクションで受けられる）のみ。**専用札を引けないと敗北が確定する即死・敗北条件型の
タイマーは作らない**（StS2 TheInsatiable=タイマー切れ即死の恒常炎上。解決手段が
「専用札を引けるか」に依存すると、デッキ構築の失敗と理不尽の区別がプレイヤーに付かない）。
機械固定: `enemy-conventions.test.ts`。

## 敵追加のDone定義（壊れ検知チェックリスト）

1. `npm test` 緑（loop.test=ループ・膠着0、enemy-conventions.test=規約遵守を含む）
2. 壊れ検知sim（新敵×代表デッキ×60戦）でスタール0・クラッシュ0。
   勝率0%のセルが出たら既知の構造相性（例: 単体精密×頭数ギミック）として記録するか設計を見直す
3. チップ・意図予告・CLI表示・KEYWORD_HELP の4点セット（フェアネス「予告してから殺す」）
4. 体感はLLM 1ランに相乗り（新設問「この敵は何の問いか、答えられるか」）。機構検証はLLMに出さない
