## 4. 表示・説明で嘘や分かりにくさを感じた点

1. **庇うの対象指定がCLIでは素通りする**（幕2 行5）。射手は「⛔庇われ中（単体対象はこの敵を選べない）」と出ているのに、手札のダメージ内訳には **「実値: 敵0:33 / 敵1:33」と射手の欄も出る**。実際に `targetIndex:1` を指定してプレイできてしまい、**警告もなく従士に着弾**した（結果は正しい＝ルールどおり）。UI版は選択不可にしていると規約にあるが、CLIは①内訳に庇われている敵を出さない、②指定されたら「庇うで敵0へ向かう」と1行出す、のどちらかが要る。
2. **潜伏の殻に対する内訳が「0」としか出ない**。甲虫の殻12に打撃6を当てる時、表示は「敵0:0(潜伏の殻-6(HPには通らない))」。実際には**殻が12→6に減る**（＝進捗がある）のに、数字だけ見ると完全な無駄打ちに見える。「殻12→6」と残量の推移を出してほしい。ここは「割るために何点必要か」を数えるのが面白さの本体なので、表示が支えるべきところ。
3. **超過分の扱いが読み取れない**。「超過は捨てる」とは書いてあるが、殻4に増える蔦8を当てた時に**4が無駄になる**のは、事前に「この札では4しか通らない」と書かれていないと分からない。結果的に「0E札で割ってから大型」という正解に辿り着けたが、これは注記を読み込んだ結果で、内訳表示からは読めない。
4. **工房の触媒が一覧に出ない**（設問1参照）。⭐レシピだけが名前つきで列挙され、触媒は札の説明文にしか出ない。**触媒はレシピより発見が難しいのに、案内はレシピの方が厚い**という逆転。
5. 焚き火で **二連の蔦打ち+ が「【鍛えられない】」** と出るが理由が書かれていない（既に+だから）。「鍛え済み」と書けば1語で済む。
6. 幕1の工房が**100G固定**なのに、そこへ至る経路に戦闘が1つも無い配置があり得る（行4? → 行5ショップ → 行6工房）。**マップを見た時点で「払えないことが確定している工房」**が見えているのは、ノードの意味としてかなり苦しい。せめて工房に入った時ではなく**マップ上で「100G」と併記**してほしい（現状、工房の可否はツールチップ側にあるがCLIの簡易表示には出ない）。

**いちばん強く感じたこと**: 現状の緑は「保持つき4E大型を引けるか」で戦闘の長さが決まっている。装甲を持つオーガ戦だけが7ターンの良い戦闘になったのは偶然ではなく、**1ヒット上限が大型を殺した瞬間に、成長・急所・多段という緑の本体が動き出す**から。通常敵にも「量の器（ターン装甲）」でなく**一撃装甲の小さめの値（5〜10）**をもっと配ると、2ターン決着が減って伏せを置く余裕が出ると思う（幕1の鉄殻の溝貝＝装甲5は1戦目の教材として非常に良かった）。

**触媒については**、「素材にすると化ける」という発想自体は面白く、実際に大牙の乱撃+は今回のランの主役になった。問題は**取る判断が報酬画面では下せない**こと（残り工房数・所持金・素材候補の3つを同時に見る必要がある）と、**工房に着いてからも触媒の組み合わせが案内されない**こと。この2つが解けないと、触媒は「知っている人だけが強い札」のままだと思う。
