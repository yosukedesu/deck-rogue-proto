## 2. 構造所見（2本一致・独立）

1. **多段収束はカードでなく加算の形が原因（G）**。初期デッキから二連の蔦打ちを抜いても5戦目に自力で拾い直した。
   緑の加算（成長・勢い・急所）が全部 per-hit なので、ヒット数を増やす以外は数字で必ず負ける（二連22/1E 対 牙の一撃23/2E）。
   成長放出は「多段に食わせれば毎ターン換金される」ので構造的に選ばれない。F は勢い×1E札×置物（大角の群長・棘の蔓）へ収束＝同じ per-hit 加算の別経路。
2. **X札はどちらも軸にならず**。F=余りエナジーの受け皿（全額払いは一度も最適でない）、G=手札5枚とエナジー5が同時に切れるので見送り。
   全体X（森羅の大嵐）だけは敵2体以上で素直に強い。ロールバック条件〔成長デッキでXが撃つ価値を失う〕は成長デッキ自体が成立していないので未該当＝監視。
3. **上限参照は 4/5 に断層（G）**。上限4では幹撃16が牙の一撃17の下位互換で見送り、古根の杯で5になった瞬間に若幹・幹撃を両方ピック。
   守りの上限参照（木陰）だけは基準が防御5なので上限4でも成立。ランプ札は「長い戦闘限定」で16戦中1回しか置けず。**杯×このは（T2から5E）は「景色が変わる」と実測**。
4. **T1に上限3を読む落とし穴**（G）——上限5のつもりで組むと必ず1回滑る。CLI表示を改善（下記）。
5. **3枚提示**: 悩んだのは F 6/14・G 5/16。残りは即決。全ハズレ回に救済が無い（F 戦2: 成長ペイオフ3枚＝パッシブが成長でなくなった影響が提示にそのまま出た）。
