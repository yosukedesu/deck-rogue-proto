## 3. 設問への回答

### U1. 3体は何ターンかかったか／良い帯か耐久試験か／装甲が判断を生んだか

**ターン数**: 献身の彫師5T・罠壊し4T・雷球の巨頭6T（平均5.0T）。物差し「通常戦4〜6T」の**ど真ん中**。3体とも一度も2〜3ターンで終わらず、器としては完全に機能した。

**体感の帯**: **2体は良い帯・1体（罠壊し）は薄い。**

- **雷球の巨頭＝満点（巨面型）。** 良かったのは天井そのものではなく**天井と虚弱の噛み合わせ**だった。ターン装甲は「余ったエナジーを防御に回せ」という命令だが、この敵は同じターンに虚弱2を置いて**その防御を25%削ってくる**。守りに回した資源が目減りするので、「今ターンの上限35をどこまで使うか／残りで何ブロック立つか」が毎ターン別の答えになる。締切は筋力+2の積み上げで、6ターン目には攻撃33〜37まで育っていた。**天井（上限）と締切（成長）が両方あり、しかも締切が天井の使い道を殴りに来る**——巨面が良かった理由の上位互換になっている。
- **献身の彫師＝良い帯の下端。** 激昂+2/Tの締切は正しく効き、意図が7〜9→21〜24へ育つのは毎ターン見えていた。ただし**HP108÷装甲30＝3.6で天井が先に来て、5ターン目には彫師の火力が育ちきる前に終わる**。実被害11。「締切が見えるが間に合ってしまう」惜しい形。装甲を上げるより**HPを少し厚くして4→5ターン目まで確実に引っ張る**か、激昂を+3にすると噛む。
- **罠壊し＝いちばん薄い。耐久試験ではないが「4ターンの作業」に近い。** 理由がはっきりしていて、**この敵だけ時間軸の圧が何も無い**（激昂なし・育つ技なし・積み上げなし・行動は11〜15の抽選）。天井があるので短くはできない、でも長引いても何も悪くならない＝「上限だけあって締切が無い」。汚泥45（HP÷装甲5.5）の耐久試験とは別の失敗で、**長さでなく張力の欠如**。4Tと短いので苦痛ではないが、装甲を配った意味が「HPを増やさず2T決着を消す」だけで止まっている。処方候補は、たとえば**がらくた（junk）を毎ターン確実に混ぜる**——罠壊しは既にがらくたを持っているので、「長引くほど手札が腐る」＝時間の圧を自前の芸で作れる。

**装甲の上限は判断を生んだか → はっきり生んだ。** 具体的に起きたこと:

1. **殴る手が途中で止まる。** 彫師T2で巨象の突進（32貫通）を撃った時点で「与ダメ35／HP損失30／切り捨て5」。手札にはまだ22ダメの踏み荒らしがあったが**撃つ価値がゼロ**になり、余った2Eを樹皮の鎧（ブロック14）に回した。これは装甲が無ければ100%攻撃に使っていたエナジー。
2. **伏せる理由になった。** 彫師T3も同じ形で、余った2Eを「守りの蔓を伏せる1E＋防御1E」に使った。**伏せは余剰エナジーの置き場として一番効率が良い**（1Eで12〜18ブロック・虚弱の対象外）ので、ターン装甲は構造的に伏せの出番を増やす。ラン全体で伏せ7回・発動5回・温存2回。
3. **置物を置く判断も出た。** 罠壊しT1、「どうせ4ターンかかる」と読めたので大角の群長（2E・攻撃ごと勢い+2）を先に置いた。天井があると1ターン目の火力を捨てても総ターン数が増えないので、エンジンの設置コストが実質タダになる。
4. **逆に「積み上げ」が死ぬ。** 彫師T2で樹皮の鎧の成長+1が**完全に無意味**だった（巨象が既に天井超え）。ターン装甲は緑の成長・勢いの雪だるまを天井で切るので、**エンジン札の価値が下がり、防御札と単発の"ぴったり札"の価値が上がる**。ここは狙いどおりだと思うが、「トランプル理想形」を持ち込んだのに勢い加算がほぼ関係なくなる戦闘が3つ続いたのは、デッキの個性が消える方向でもある。
5. **"ぴったり収まる札"が主役になった。** 巨象の突進（4E・32貫通）は装甲30で「35→30」、装甲35で「38→35／34そのまま」と、**毎回天井のすぐ下**に着地して気持ちが良かった。逆に一撃装甲18/25の敵（石殻・オーガ）では同じ札が18/25に潰れて死に札になる。**ターン装甲＝大型単発の見せ場／一撃装甲＝大型単発の墓場**という対比がはっきり出ていて、2種類の装甲が別の問いを出せている。

### U2. 幕3全体の通常戦の平均ターンとボスのターン数・1ターン決着の有無

- **通常戦5戦の平均 4.8ターン**（5/4/4/6/5）。**1ターン決着ゼロ・2ターン決着ゼロ・最短4ターン。**
- **ボス7ターン**（3相 120/132/168。相を落とすたびに1ターンの隙が入るので実質は5ターンぶんの殴り合い）。
- 物差し（通常4〜6T／ボス6〜10T）に**全戦闘が収まった**。この幕は「速すぎ」がひとつも無い。
- ただし平均を押し上げているのは装甲勢だけではない。**装甲を持たない?→戦闘の2体（オーガ156HP・石殻130HP）も4Tと5Tかかっている**ので、幕3の敵HPの厚み自体が既に効いている。装甲3体の追加は「短い戦闘を消した」というより**下限を4Tで固定した**という効き方。
- テンポの体感は良い。4〜6Tは「準備→積む→刈る」が1戦の中に収まる長さで、退屈にはならなかった。

### U3. 表示は判断に足りたか

**足りた。ターン装甲まわりは今回いちばん出来が良い表示だった。** 嘘は1つも見つからなかった。

- **敵タグ** `ターン装甲30(1ターンのHP損失は30以下。残り30。延焼は無視)` — **「残りN」がその場で減っていく**のが決定的。「あと何点まで意味があるか」を暗算しなくていい。
- **手札のダメージ内訳が天井を織り込む。** `［実値: 敵0:16(成長+1・勢い+9・ターン装甲(残り16))］` のように、**残り装甲でクランプした後の値**が手札に出る。装甲を使い切ると `実値: 敵0:0(…ターン装甲(残り0))` と**0表示になる**ので、「この札を撃っても1点も入らない」が一目で分かる。これが無いと毎ターン電卓が要る。
- **ログの `与ダメ38(HP損失35)【ターン装甲で3切り捨て】`** — 事後の答え合わせとして正確。一撃装甲側は `【装甲で27切り捨て=本来45】` と**本来値まで出る**ので、「この敵に大型単発は無駄」の学習が1回で終わる。
- **「⚠今ターン倒せない(HP108>残り30)」** — 一度も嘘をつかなかった。彫師T4（HP34 > 残り30）で「あと4点足りないから今ターンは殺せない＝防御に寄せろ」と正しく教えてくれて、実際その判断で被害を減らせた。**残りHPが装甲をわずかに上回る時にいちばん効く警告**で、そこが体験の山になっている。消えるタイミング（HP ≤ 残り装甲）も正確。

**気になった表示（嘘ではない）:**
- **置物トリガーのダメージにプレビューが無い。** 購入した「風の棘（1E置物・勢い獲得ごと2ダメージ）」が、実際は**2＋成長＋勢い**で解決され、ボス戦では1回15〜17ダメージ出ていた（ログ `与ダメ15` `与ダメ17`）。ルール上は「成長は与ダメ全てに加算」なので正しい挙動だが、**カード文面「2ダメージ」と実出力が8倍**離れる。手札プレビューが置物には出ないので、買う時点ではこの強さが読めない。査定・表示どちらの観点でも一度確認したほうがいい（今回はこれがボスを削り切った主砲だった）。
- **罠壊しの意図注記** `攻撃13〜17(伏せ札ありでも今回は同じ行動・実値は下がる。※罰型=…)` の「実値は下がる」が何を指すのか読み取れなかった（罰型の説明と噛み合っていないように見える）。伏せなかったので未検証。

### U4. 各戦闘の評価と全体

戦闘ごとの強さ／面白さは §2 の表のとおり（強さ平均 3.0／面白さ平均 3.7）。

- **全体の面白さ: 4/5。** 「上限があるから殴る手を止めて守る」という判断が**毎ターン発生する**のは、この幕で初めて体験した種類の悩み。雷球の巨頭は今回の6戦で断然の1位（面白さ5・強さ5）で、装甲だけでなく虚弱と筋力積みが同じ方向を向いているのが理由。
- **全体のテンポ: 4/5。** 4〜6ターンは待たされ感が無く、どの戦闘も「2ターン目以降に何かが起きた」。減点は罠壊し4Tが張力ゼロだったことと、装甲戦では緑の勢い/成長エンジンが天井で無効化されてプレイが「大型1枚＋防御」に単純化しがちなこと。
- **配布の結論: 3体のうち2体は成功、罠壊しだけ器が空。** ターン装甲は単体では「2T決着を消す下限装置」でしかなく、**締切（激昂・育つ技・虚弱・筋力積み）と対で初めて面白さになる**——これは巨面（天井＋育つ圧殺）で既に分かっていたことの再確認で、雷球はその最良例、罠壊しは反例。**ターン装甲を配る時は必ず時間軸の圧とセットにする**を規約にしていいと思う。

## 4. 不具合・表示の嘘

**ターン装甲まわりの不具合・嘘はなし。**（残り装甲の減算・手札の実値クランプ・切り捨てログ・「今ターン倒せない」警告の出現/消失、すべて実挙動と一致）

その他、報告に値するもの:

1. **置物トリガーのダメージが成長・勢いを乗せるが、カード文面にもプレビューにも出ない。** 風の棘「勢い獲得ごと:2ダメージ」が実測15〜17。ルール（成長は全ての与ダメに加算）どおりだが、購入・ピック時に強さが読めない。**査定側の確認と、置物の量表示への注記**を推奨。
2. **`?`→ショップが所持43Gで発生し、全商品50G以上で何も買えなかった**（行12）。次の行が焚き火→ボスで固定ショップは無いのでルール違反ではないが、**幕終盤の?→ショップは実質「立ち去る」しか無いノード**になる。（本家の2連続禁止と同種の、金額側の先読みガードの余地）
3. **`古根の杯`（焚き火で休めない）を持った状態のチェックポイントは、幕3のHP経済が別ゲームになる。** 焚き火3回すべてが「鍛える」一択で、回復は狩人の恵み+8×2＝16点のみ。設問の検証には支障なかったが、**ターン装甲の「強さ」評価はこの前提で1〜2段甘く見るべき**（回復があれば雷球のHP27→1は起きなかった）。チェックポイントの既定レリックとしては噛みが強すぎるかもしれない。
4. 罠壊しの意図注記「実値は下がる」の意味が読み取れない（§U3末尾）。文言の確認を推奨。
