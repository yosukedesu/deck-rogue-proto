## 4. 設問への回答

### N1. 威圧

**回数と対象**: 5戦中4戦で使用、計8回（うち2回はアーティファクトに弾かれ不発）。対象はすべて「そのターンいちばん大きい攻撃を宣言している敵」＝用心深い影3、物真似の道化1、金切り顎2（不発）、嘲る道化2。

**表示で判断が変わったか — はい、変わった。** 「攻撃15〜20→威圧で11〜15」は暗算を全部やってくれるので、**ブロック計算に完全に組み込めた**。実際の意思決定は毎回こうだった：

> 素の15〜20に絡め捕る根のブロック12を当てても3〜8漏れる。威圧を乗せると11〜15になり、12でちょうど蓋ができる。だから「他の札で7ブロック足す」ではなく「絡め捕る根1枚で完結」を選ぶ。

つまり−25%の体感は「ダメージが減った」ではなく、**部分ブロックが完全ブロックに変わる**という形で出る。戦闘11のT3、戦闘15のT1はどちらもこれで被ダメ0になった。−25%単体だと4〜5点で地味だが、**ブロック12と同じ札に載っているので「4〜5点」が「0か3か」の境目にちょうど効く**。この抱き合わせは設計として当たりだと思う。

**多段の敵**: 物真似の道化（3〜5×手数）に乗せた時がいちばん気持ちよかった。**1行動で1消費なので、3ヒット全部に−25%が乗って9〜15が7〜11になる**。旧仕様（筋力−1永続）を知識として当てはめると、同じ場面で−1×3ヒット＝−3にしかならない。多段に対しては明確に新仕様の勝ち。金切り顎（8〜9×2）でも同じ効果を期待したが、**アーティファクト2に2回とも弾かれて一度も乗らなかった**——これは不満ではなく「そういう敵」として納得できた（タグに常時出ているので理不尽さは無い）。ただし結果として、**この戦闘だけ絡め捕る根が「2Eでブロック12だけの札」に痩せる**ので、価値の振れ幅は大きい。

**ボス**: 未到達。幕2ボスに使えなかったのが今回いちばんの心残り。ただし嘲る道化（15〜20+脆弱2）は打点的にはボス級で、そこでは**威圧1では足りなかった**——脆弱で+50%されると11〜15が16〜22に戻り、結局ブロック12を超える。**倍率デバフ同士は掛け合わされると打ち消し合う**ので、敵側が脆弱を積んでくる相手では威圧の価値が目減りする。

**絡め捕る根2枚は「取りたい札」だったか — はい。** 幕2を通していちばん打った札で、**引いたら必ず打つ**カードだった。3枚目が報酬に出た時に見送ったのは「2Eが渋滞するから」であって弱いからではない。旧仕様（筋力−1永続、3〜4ターン戦で総効果−4〜−8）と比べると、**「いつ効くか読めない持続デバフ」から「このターンの被ダメ計算に確実に入る数字」に変わった**のが決定的。旧仕様は打っても盤面表示が変わらないので、正直「打ったことを忘れる」札だった。今は打った瞬間に敵の意図表示が書き換わるので、**効いていることが見える**。これがいちばん大きい差だと思う。

### N4. 敵

- **潜伏**: 岩皮の甲虫に当たった（戦闘11）。**割った瞬間ではなく「次の行動が噛みつきに差し替わる」**仕様なので、**割ったターンに殺し切れば噛みつきごと消える**。これが「割るか、割らずに貫通で削るか」の即席の問いになって面白かった。実際にやったのは 牙17貫通でHP2まで削る → 蔦の楔で殻を割って止め、で、**噛みつきの予約を踏み倒す**手順を自力で見つけられた。
- **潜行する大地虫・因縁の亡霊**: 幕3に届かず未遭遇。
- **面白かった3つ**
  1. **眠れる鉄卵** — 眠り＝殻を積む2ターンが「削るか、置物を置くか」の完全な自由時間になり、起こした後の攻撃21〜25+weak2が急に本気になる落差が良い。装甲22も貫通デッキに「1発を太らせても無駄」と教えてくれる。
  2. **岩皮の甲虫（潜伏）** — 上記。小さいのに解き方が1つある敵。
  3. **物真似の道化** — 「何枚プレイするか」を毎ターン考えさせる。威圧との相性も含めて、こちらのデッキの形を直接問う敵。
- **退屈だった3つ**
  1. **金切り顎×2** — 63+63で行動が2種類しかなく、7ターンずっと同じ判断。アーティファクトも「デバフが通らない」だけで能動的な選択にならない。
  2. **用心深い影** — 伏せ分岐が「伏せると17〜22／無いと12〜16」の罰型固定で、**リアクションを持っていないと分岐が一生動かない**＝ただの12〜16の壁だった。
  3. **泥投げの妖術師（単体としての行動）** — 呪い＋がらくた／weak／攻撃のローテがどれも「こちらの手を1つ潰す」方向だけで、対抗の余地が無い。道化と組むと脅威度は跳ね上がるが、それは道化の脆弱が理由。

### N5. 完走と収支

HP推移: 80 → 59（甲虫+影） → 47（鏡道化） → 55（?イベントで最大HP+8） → 21（金切り顎） → **43（焚き火+22）** → 16（鉄卵） → **38（焚き火+22）** → 0

- **敗北。死因は HP収支**（構築でも理不尽でもない）。1戦あたりの損失が 21 / 12 / 34 / 27 / 38 に対し、回復は焚き火の +22 が2回だけ。**幕2の1戦の平均損失（約26）が焚き火1回の回復量（22）を上回っている**ので、焚き火を毎回踏んでも単調減少する。
- 直接の引き金は **脆弱の複利**。嘲る道化は毎ターン脆弱2を撒くので、3ターン目には脆弱5＝全被ダメ+50%が固定になり、**威圧−25%を打ち消して上回る**。2体編成でこれが来ると、防御可能量（ブロック12+10=22）を素の合計打点（25〜34→脆弱込み37〜51）が構造的に超える。
- 構築側の反省としては、**ブロック源が絡め捕る根2枚に集中していた**（他は防御5×3・木漏れ日7・絡み蔦7）。2Eの防御札は「毎ターン1枚しか打てない」ので、脆弱で数字が1.5倍になる相手には枚数で追いつけない。ショップで蔦の陣（被攻撃前ブロック10+返し8）を買わずに荒野の呼び声を買ったのは、**HP21の局面としては攻撃側に寄せすぎ**だったと思う。

### N6. 総評

- **威圧は「本家の Weak らしい」と感じたか — はい、はっきりと。** 旧仕様（筋力−1永続）は本家で言えば Weak ではなく「筋力デバフ」で、多段にしか効かず単発の大技には誤差だった。新仕様は**割合なので大技ほど効き、意図表示に反映されるので打った実感がある**——この2点が Weak の手触りそのものだった。「敵の攻撃の頭を1回だけ押さえて、そのターンのブロック計算を成立させる札」という役割がはっきりしている。
- **数値は足りていたか**: **威圧1（＝攻撃1回）は「ちょうど良いが、価値の振れ幅が大きい」**。
  - 単体戦・多段の敵には十分すぎるほど効く（1行動まるごと−25%）。
  - **足りないのは「1ターンに2体が殴ってくる編成」**。今回の死因もこれで、片方しか止められず、もう片方が素通しになる。
  - **2にすべきかは「ノー」**。回数を2にすると「1枚で2ターン蓋ができる」＝ブロック12との抱き合わせが強すぎる（実質2Eでブロック12+被ダメ−8〜10×2）。**足りない場面は回数ではなく枚数／全体化で解くべき**で、たとえば「威圧1を敵全体に、ブロックは6」の1E札があれば、今回の死に方に対する正しい答えになったと思う。
- **次に直す札 3枚**
  1. **絡め捕る根** — 触るなら数値ではなく**枚数の受け皿**。上記のとおり「全体威圧1＋小ブロック」の廉価版（1E・威圧1全体・ブロック5〜6）をコモンに1枚刷ってほしい。単体戦では明確に下位互換で、複数体戦だけで輝く＝棲み分けが立つ。
  2. **見切り撃ち** — 条件は良いが、**素の5貫通が1Eとして安すぎる**（蔦の楔が同じ1Eで粉砕+5）。条件不成立時が「打ちたくない札」になるので、素を6〜7貫通に上げて「条件が付いたら破格」ではなく「条件が付いたら気持ちいい」に寄せたい。
  3. **茨の返し**（スターター）— 返し10が**その攻撃で付いた弱体をそのまま食らって7になる**のが直感に反した。「殴られた結果の返し」なのだから、**同じ攻撃で付与されたデバフは返しに乗せない**（脆弱の justApplied ガードと同じ扱い）のが素直だと思う。

## 5. バグ・表示の違和感

1. **?イベント「朽ちた霊廟」の結果が一切表示されない（重）** — 「棺を開ける（レリック1個・50%で負傷1）」を選ぶと、出力がいきなりマップ画面に戻る。レリック名も、**負傷が入ったかどうかも分からない**。実際には負傷1が入っていたが、それに気づいたのは2戦あとに手札に来た時だった。イベント解決の結果行（獲得レリック名／負傷の有無／HP増減）は必ず出してほしい。
2. **潜伏の説明文と実挙動の言葉のずれ** — 敵カードのタグは「**割れた瞬間に噛みつき**」だが、実際のログは「**次の行動は噛みつきに差し替わる**」。前者だと「割ったら即座に殴られる」と読めるので、割るのを躊躇する。実際は割ったターンに倒せば無傷なので、**タグ側を「割ると次の行動が噛みつきになる」に直す**と、正しい駆け引きが最初から見える。
3. **絡め捕る根が targetIndex を要求する** — 効果は「威圧（対象）＋ブロック（自分）」なので当然ではあるが、敵が1体でも `要targetIndex` が出るのは他の自己完結札と揃っていない印象。生存1体なら自動でよさそう。
4. **威圧の表示そのものは非常に良い** — 「攻撃15〜20→威圧で11〜15+状態異常(vulnerable2)」のように、**setAlt の両分岐それぞれに威圧後の値が出る**のが正確で助かった。ここは直すところが無い。
5. **アーティファクトで弾かれた時のログが弱い** — 絡め捕る根を打つと敵のタグが「アーティファクト2→1」に変わるだけで、「威圧が弾かれた」という一行が出ない。**打った札の効果が消えたことは明示してほしい**（急所+2の時も同様に静かに消えた）。
6. **手札の「実値」注記が優秀** — 「敵0:15(成長+2・勢い+1・弱体-25%)」の内訳表示のおかげで、弱体を受けている間の「今殴るか、ブロックして弱体が切れるのを待つか」を数字で判断できた。多段札の「先頭ヒット基準」の但し書きも誠実で良い。
