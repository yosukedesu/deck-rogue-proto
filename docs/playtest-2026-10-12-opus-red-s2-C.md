## 4. 段2の札の手触り（5つの問い）

デッキに刈る札・くべる札・業火の炉が無いので、3つは「無かったので答えられない」が答えになる。

- **刈る**: 刈りの札が無い。火の渦は「チェインの回数」を刈る札で、待つか撃つかの悩みは少しあった（三人組 T3: 回数4で×5＝26、もう1回めくってから撃つか迷った）。延焼を消費する悩みはこのデッキでは生まれない
- **点く**: 2回とも燎原の火（全体延焼5）の本体で8を跨いだだけ。点いて何かが鳴る札（爆ぜ火・火の目覚め）が無いので、「🔥猛り火に点いた」の行が出ても何も起きない＝**「状態」のまま**。火の目覚めは報酬で1回・店で1回見たが、チェインのデッキでは点火が年に2回なので取らなかった
- **くべる**: くべる札は無い。**巨像戦の T1 に燃え上がる着想で衝動6枚を引き、野火（R）・火は火を呼ぶ・火口開き・着火・火纏い・灰の盾。エナジー2で火は火を呼ぶを置くので精一杯で、残り5枚が失効**＝この戦闘から消えた。ここに火にくべる・灰の息があれば野火をくべて全体4＋延焼3を撃てた＝くべるの存在理由をそのまま体験した場面。店で火にくべる（58G）を見たが、衝動の源が灰の盾2枚と着想だけなので見送った
- **火は火を呼ぶ**: 置いたのは2戦（道化戦 T2・巨像戦 T1）。同じコストに当たったのは**1回だけ**（火口開き→火口開き）。理由は単純で、**チェインの当たりの7割弱が 0E・1E の札で、同じコストの札より安い札の方が山札の上に先に来る**。野火（3E）・燎火の使い（2E）・連火弾（2E）は元から下に当たるので、火は火を呼ぶがあっても結果が変わらない。「同じコストに当たる」が効くのは 1E のチェイン（火口開き・火送りの一撃）で 0E を全部引いた後だけ＝体感は「たまに火口開きがもう1回めくる」。2E を払って置く価値は感じなかった（置くターンは殴れない）
- **業火の炉**: デッキに無い

## 8. 表示の嘘・分かりにくい表示・バグ疑い

1. **疑い（表示）**: 戦闘を終わらせた手のあと、`cmd` の出力が空になり（`sed -n '/直近/,$p'` で何も出ない）、`show` は報酬画面になるので**最後の手の出来事（チェインの当たり・与ダメ）が見えない**。例: 巨像戦 T4 `{"type":"PlayCard","cardUid":"red_cascade_bolt#0","targetIndex":0}`／三人組戦 T4 野火。`red-stats.ts` には載っている。勝利画面に「最後の手の出来事」を残してほしい
2. **疑い（仕様）**: チェインの当たりが対象を倒すと、本体の効果は空振りする（生きている敵へ移らない）。従士戦 T4 `{"type":"PlayCard","cardUid":"pick_a2_r6_red_cascade_ford","targetIndex":0}` → 「🔗チェイン:火渡り→火花」「☠敵0を倒した」で終わり、射手（庇われていた敵）に延焼7は行かなかった。MTG なら対象不適正で立ち消えるので正しいが、**被ダメ予測や札の注記に「当たりで倒すと本体は消える」が無い**ので読めない
3. 分かりにくい: 火の渦は「チェインが当たった回数×5」だが、**いま何回かが盤面に出ない**（札の［実値］も出ない）。数えて撃った。また、野火の当たりとして撃たれた火の渦は自分自身を回数に数えた（道化戦 T3: 前の当たり3回＋自分＝×4＝20）。仕様どおりなら OK、注記があると親切
4. 分かりにくい: 物真似の道化（手数×4）の「手数」にチェインの当たりが数わる（道化戦 T1: 4枚で攻撃16）。規則どおり（直接プレイ＝プレイ）だが、チェイン札の注記に無いので初見は驚く。問いとしては良い

## 9. 設計への提案

- **火は火を呼ぶ**: 0〜1E が厚いチェインのデッキでは同じコストに当たる場面が少ない（30回中1回）。案＝「チェインは同じコストにも当たる＋**チェインでめくった札のうち一番重い札に当たる**」（重さを選ぶ書き換え）か、1E に下げて置く負担を減らす（鍛え後の形を素に）。ロールバック線「5段を超える連鎖が常態」は今回 0 回で遠い
- **燃え上がる着想 × チェイン**: 衝動で引いた重い札が失効する事故は、チェインのデッキの燃え上がる着想で起きやすい。報酬の提示時に「衝動で引いた札は今ターンに使わないと消滅」の注記を強めるか、くべる札（火にくべる）をアンコモンの赤の衝動札と同じ提示に寄せる（くべるが拾える確率を上げる）
- **守りの供給**: 幕2の5戦で守りの札の提示は灰かぶり2回だけ。チェインのデッキの守りは連火の盾（C 2E ブロック11・チェイン）が本命なので、その札が一度も出なかったのは運。監視でよい
- **火の渦の盤面表示**: ［実値］に「チェイン N 回×5＝M」を出す（他の参照札と同じ）
