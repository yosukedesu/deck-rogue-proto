# レリック再設計の提案 — 本家を元に（2026-09-03）

出自: Opus H/I の再計測で「T1に効くレリック（早駆けの靴・成長の種・古根の杯）＋工房が幕2の2.5T化の上流」と判明。
ユーザー裁定「レリックは本家を元にすべて考え直そう」を受けた提案書。**同日「ok」で §3-1・§3-2・§3-3 の一部を実装済み**（層×供給源／ボスレリック6／在庫37。未実装=新機構が要る 古い地図・木の盾・羽根ペン・苔の護符・狩人の角笛・根の腕輪・読みの水鏡・配達人・呪いの偶像・血の祭壇の器）。

## 1. 本家（StS）のレリック設計の文法

1. **層と供給源が一体**: Common / Uncommon / Rare / Boss / Shop / Event（＋Starter）。
   通常宝箱・エリート＝C/U/R（本家比率 50/33/17）、**ボス撃破＝Boss 3択のみ**、ショップ＝Shop専売＋C/U/R、?＝Event。
2. **エナジー+1は必ずボスレリックで、必ず代償つき**（Cursed Key＝宝箱で呪い／Coffee Dripper＝休めない／
   Fusion Hammer＝鍛えられない／Busted Crown＝提示−2／Ectoplasm＝金が入らない／Philosopher's Stone＝敵全員 筋力+1／
   Velvet Choker＝1ターン6枚まで／Runic Dome＝意図が見えない／Sozu＝ポーション不可／Mark of Pain＝負傷2／Slaver's Collar＝エリート・ボス限定）。
   **代償なしの恒久+1Eは存在しない**。
3. **T1に効く小レリックは存在する**（Lantern＝T1のみ+1E／Bag of Preparation＝T1+2ドロー／Anchor＝T1ブロック10／Vajra＝筋力+1）。
   ただし全部 Common で「小さく単発」。積層は在庫の多さ（約180個）と層の抽選で自然に薄まる。
4. **クラス固有・アーキ固有のレリックが厚い**（Kunai／Shuriken／Ornamental Fan／Paper Frog…＝プレイ条件つきの常在）。
5. **経済レリックは Rare か Shop**（Golden Idol＝金+25%／Membership Card＝半額／Courier）。

## 3. 提案

### 3-1. 層と供給源を本家式に（構造）
- `rarity: common | uncommon | rare | boss | shop | event` を relics.json に追加。
- 供給源で抽選: 宝箱行・?→宝箱・エリート＝C/U/R（50/33/17）、**幕ボス3択＝boss のみ**、ショップ＝shop 1個＋C/U/R、イベント＝event。
- 候補列（relicQueue）は層ごとに分ける。同名なし・シード決定は維持。

### 3-2. エナジー系はボスレリックへ移し、代償を付ける
| 案 | 効果 | 代償（本家型） |
|---|---|---|
| 古根の杯（改） | 上限+1 | **焚き火で休めない**（Coffee Dripper） |
| 王冠の欠片 | 上限+1 | 報酬提示 −1（Busted Crown。3枚→2枚） |
| 呪いの鍵 | 上限+1 | 宝箱・?のレリックを取るたび**烙印1**（Cursed Key。烙印は実装済み） |
| 賢者の石 | 上限+1 | 敵全員 筋力+1 で開始（Philosopher's Stone） |
| 鎖の首輪 | 上限+1 | **エリート・ボス戦のみ**（Slaver's Collar） |
| 早駆けの靴 | 据え置き（Common・T1のみ） | 積層の対処は層の抽選で。**このはとの重複だけが問題なら「上限4以上ならT1の+1は無効」を検討** |

### 3-3. 在庫を17→40へ（本家の1/4）。追加候補
Common（8）: 鉄の靴＝開幕ブロック3（Anchor小）／薬草袋＝勝利時HP+3（Meat小）／古い地図＝マップで?の中身が1つ見える／
砥石の欠片＝ショップの鍛える −25G／羽根ペン＝ピック時に1枚だけ見送りで+10G／苔の護符＝延焼耐性1（敵からの延焼相当は無いので負傷を1減）／
蔦の指輪＝戦闘開始時 成長+1（緑固有・種のラダー）／木の盾＝完全ブロック時に1ドロー。
Uncommon（8）: 狩人の角笛＝敵の初回攻撃 -3／根の腕輪＝ランプ札をプレイするたびブロック4／勢いの鞭＝勢いを得るたび1ダメ（緑固有）／
読みの眼鏡＝**伏せた札が発動したターン**、次のカード-1（set-confirm固有）／回収の紐＝回収が0E（set-confirm固有）／
薬研＝焚き火で休むと最大HP+2／戦利品袋＝エリート勝利+20G／大工の道具＝工房の合成 −50G。
Rare（6）: 商人の秤（Rare へ）／大樹の心＝戦闘開始時 上限参照に+1（幹撃等が読む値だけ+1＝ランプの代替）／
不動の根＝HP50%以下で開始した戦闘は開幕ブロック10／読みの水鏡＝最初の伏せ発動で実値公開（蜃気楼の縮小版・1戦1回）／
鍛冶の砥石（Rare へ・2枚鍛えるは維持）／収穫の鎌＝成長放出のあと成長2が残る。
Boss（6）: 3-2 の5案＋「魔女の秤＝報酬提示+2、最大HP−10」（Busted Crown の逆）。
Shop（4）: 会員証＝ショップ半額（Membership Card）／配達人＝買った枠が補充される（Courier）／
金の靴＝勝利金 +50%（Golden Idol）／除去の鑿＝ショップ除去の逓増が+25。
Event（2）: 呪いの偶像（実装済みの黒曜の偶像の対価側）／血の祭壇の器。

### 3-4. 実装順（案）
1. rarity フィールド＋供給源別の抽選（構造。既存17個に層を付けるだけで積層が薄まる）
2. ボスレリック5案（杯の改修を含む。ナーフなので裁定確定後に単独コミット）
3. 在庫の追加（Common→Uncommon→Rare→Shop の順に各波でOpus 1本）

### 3-5. ロールバック条件
- 層の導入後、Opus 2本で「レリックが弱くて取る理由がない」が一致したら Common の量を+1段戻す。
- 杯の代償で「焚き火で休めない」が理不尽票を集めたら Busted Crown 型（提示−1）へ差し替える。
