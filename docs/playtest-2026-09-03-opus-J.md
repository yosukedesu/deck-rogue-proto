## 4. 設問への回答

### J1. 戦闘の長さ
- **幕1通常戦 3.17T（実質3.00T）／幕2通常戦 4.00T／エリート3T／ボス7T**
- **2ターン目以降に何か起きた戦闘 = 100%（11/11）。1ターンキルはゼロ。**
- 長さの出どころ: **厚み6 / 拍3 / 両方2**。
  - 「厚み」= 敵HP（オーガ176・用心深い影89・泥まとうもの65）と頭数（探り屋2体・茸+小泥2体）。
  - 「拍」= **こちらの手数を敵が奪う仕掛け**が本体だった。蔦纏いの歩き木の重圧（physical+1E＝私のデッキ全体が2E化）、大喰らいの蟲の山札喰いターン、物真似の道化の枚数罰。この3つは長さが「削り切れないから」ではなく「**打てる枚数が変わったから**」で、明確に面白い方の長さだった。
- 物差し（通常戦4〜6T）に対し、**幕2は初めて帯に入り（4.0T）、幕1はまだ短い（3.2T）**。

### J2. レリック
- **層タグは判断に効かなかった。** 効いたのは「自分のデッキに刺さるか」だけで、エリート3択では ◆アンコモン2枚を蹴って無印コモンの賢者の巻物を取った。タグが効いたのは**期待の調整**（★や👑が出た瞬間に「これは本命枠だ」と身構える）で、選択そのものは動かしていない。
- **幕ボスの3択は今回いちばん良い設問だった。** 3枚とも「上限+1（または提示+2）に別の値札」で、比較軸が代償だけに絞られている。選んだのは**賢者の石（敵全員が筋力+1）**。理由は上に書いたとおり、提示−1は複利で・最大HP−10は緑には払えないから。**代償は最後まで痛かった**（全戦闘で敵が+1）が、後悔はない＝良い値付け。
- **T1に効くレリック（靴・種・杯）は1個も入らなかった。** 結果、初手火力の中央値は幕1で17に留まり、幕2では**0**まで落ちた。幕2でT1火力が消えた理由は3つ重なっている: ①**上限参照札はT1だけ上限3を読む**（大幹の構え+ が T1=9ダメ／T2以降=15〜21ダメ）②敵に開幕ブロック6〜12がいる ③T1をランプ（芽吹き・天蓋の実り）に使うのが最適だった。
- 新顔で取りたかったのは**読みの眼鏡**（伏せ発動ごと次のカード−1＝伏せに初めて実入りが付いた。実際に毎戦1回発動して1E浮かせた）。要らないと感じたのは勢いの鞭・薬研（デッキ非適合）と会員証（到達回数的に回収不能）。

### J3. 工房と経済
- **工房は踏めたが合成できなかった。** 幕1の工房は行3の1個だけで、そこに着く時点の所持金は 50G(初期)+12G+17G = **79G**。合成は100G。**払う/払わないの判断以前に、判断が発生しない。** 真・打撃(1E・15ダメ)のプレビューまで見せられて21G足りない、は体験としてかなり悪い。
  - 「1幕に1回まで」と「100G固定」と「工房が前半行に落ちうる」の3つが噛み合っていない。工房が行7以降なら払えたはず（実際 幕2の工房は行7/9/10で、167Gあったので払えた……が到達前に死んだ）。
- **除去のショップ専売化（50G逓増）は、焚き火の判断を改善し、イベントの判断を悪化させた。**
  - 焚き火: 休む／鍛える の二択は *HPとテンポの直接交換* になり、行6の「鍛える（大幹の構え+）」は本ラン最良の悩みだった。三択時代の「とりあえず除去」という逃げ道が消えたのが効いている。
  - イベント: 「毒の三杯」（レリック+60G ↔ 烙印2／負傷3／HP-18）が**3杯とも購入不能**になった。負傷3を抜くのに 50+100+150=300G かかる計算になるので、汚染系の対価が実質「永久」に変わった。結果レリックを1個捨てた。
- **金の推移**: 行3で21G不足（慢性的欠乏）→ エリート撃破で157G（唯一の潤い）→ ショップで107G使って50G（再枯渇）→ 死亡時167G（**使い道が無いまま余った**）。**幕1にショップが1個しかないので、エリート報酬の50Gは行10まで死蔵される。** 工房のタイミング（行3）とショップのタイミング（行10）が、金の入り（エリート＝行8）を挟んで逆順になっているのが構造の問題。

### J4. ピック
- **悩んだのは10回中5回**（残り5回は明らかな1択）。
- **軸が決まったのは1回目のピック**（★大幹の構え＝上限参照）で、それを**幕1ボスの賢者の石（上限+1）と芽吹き・天蓋の実りが確定させた**。つまり軸は「レア1枚で決まり、ランプで固まった」。
- **「上限4では上限参照札が2E帯に負け、上限5で反転」は、私のケースでは再現しなかった。** 実測:
  - 大幹の構え+ は 上限4 で **12ダメ+12ブロック / 2E**。この時点ですでに2E帯（森の裁定=14ダメ or 14ブロック）を上回っている（攻防一体だから）。**負けていない。**
  - 上限5=15/15、上限7（天蓋の実り後）=**21/21**。ここは反転どころか別のカードになる。
  - 一方 **若幹の一撃（1E・上限×2）は 上限4で8ダメ＝1E帯の上端（荒角の一撃8貫通）と同着**で、優位は無かった。上限6以上（12ダメ）で初めて1E帯を抜けた。**「反転」が起きるのは ×2 の1E札であって ×3 の攻防一体札ではない**、というのが今回の分解。
  - **本当の落とし穴はコストでなくT1**。上限参照札は**必ずT1に上限3を読む**ので、T1だけ 9/9・6ダメ に縮む。上限が高くなるほどT1とT2の落差が開き、**幕2ではT1火力が中央値0まで落ちた**。「上限参照デッキは初手が最弱」という非対称は、レリックで初手を底上げできなかった今回、はっきり牙を剥いた。
- **「緑の加算がヒットごとなので多段へ収束」は再現しなかった。逆に「1枚で大きい数字」へ収束した。** 理由が2つあって、どちらも構造的:
  1. 多段札が10回の提示で**双牙の蔦の1回しか出なかった**（提示3枚化で1軸あたりの露出が薄い）
  2. **幕2に「手数の鏡」が2体（物真似の道化・写し身の魔人）いて、プレイ枚数が罰になる。** 上限参照は「1枚21点」なので鏡への構造的な解答になり、#10では実際にそれで勝った。**鏡は多段収束のワクチンとして効いている。**

**用心深い影の分岐は賭けとして読めたか → 読めた。**

### J6. 曲線
**変わったと感じる。今回のランは前回2本より明確に「長い」。**

**「幕2の短さ」はレリック由来か工房由来か → 今回の体感では、**主犯はレリック**（とくにT1に効く開幕系）で、工房は共犯。**

切り分けの根拠は、**私のランは工房もレリックも両方**手に入らなかったこと:
- **工房 = 0回**（100Gに21G届かず）→ 前回 I を牽引した「真・打撃 1E15ダメ」に相当する札が最後まで無かった
- **T1レリック = 0個**（靴・種・杯がどれも提示されず。幕1宝箱行の撤去でレリック総数が3個）

その状態で **幕1の初手火力中央値は 17 に落ち着いた**。これは H の 16 とほぼ同じで、**I の 34 とは倍の差**。I の 34 は「靴・種・砥石・工房の真・打撃+」の合算だったので、**そのうち靴と種（＝T1に無条件で乗る開幕系）を切っただけで、工房を取れていなくても H 水準に戻る**ことになる。つまり**初手火力を34まで押し上げていたのは主にレリック側**。

一方 **工房は「T1火力」でなく「1枚あたりの質」に効く**ので、効き方が違う。今回は工房が無いぶんデッキが最後まで「打撃3枚・防御3枚」を抱えたままで、**幕2で7エナジーあるのに手札が防御5×2しかなく、エナジーが余って何もできないターン（#9 T3、#10 T2）が発生した**。これは長さを伸ばした要因だが、初手火力とは別チャンネル。

**まとめると**: 供給側の絞り（提示3枚化・宝箱行撤去・レリック弱体）は**初手火力を確実に落とし、戦闘を1ターン近く伸ばした**。物差し（通常戦4〜6T）に対して幕2はついに帯に入った。ただし**代償として幕2でHP経済が破綻した**——今回の敗因は構築の失敗でも理不尽でもなく、**「短く終わらせる力が落ちたのに、敵1体あたりの打点はそのまま」**という単純な収支で、HP80のうち幕2の3戦で80を全部失った。**曲線を伸ばすなら、伸びたターン数ぶんの被弾をどこかで返す必要がある**（焚き火の回復量・幕2前半の打点・?の回復イベント密度のいずれか）。

## 5. バグ・表示の違和感

1. **伏せ場のタグが確認ウィンドウで矛盾する**（ボス戦T3）。自ターン中は
   `【見切られ中。ただし罰型の脳筋オーガは伏せ札がある限り反応する。破壊は来る】`
   と正しく出るが、敵フェーズの確認ウィンドウでは同じ札が
   `【見切られ=敵は反応しない。破壊は来る】`
   に戻る。分岐は「伏せ札あり」の17〜21で解決されているので、**表示だけが逆のことを言っている**。

2. **?イベント「苔むした籠」のレリックは3択でなく直接付与**で、層タグも出ない。他の供給源（宝箱・エリート・ボス・ショップ）は全部タグ付きの選択なので、ここだけ情報が欠ける。層の再設計を入れた以上、イベント付与にも層表示は欲しい（実際に付与されたのは新顔の読みの眼鏡だった）。

3. **エリート報酬のレア確定枠が「上限を超えるコストの札」を出す**。上限4の時点で `★レア 巨獣の踏みつけ(5E)【保持】50ダメージ` が提示された。CLAUDE.md の「リーダーのエナジー上限を超えるカードは提示しない（緑は+2まで許容）」の範囲内ではあるが、**保持（全捨てで手札に残る）が付いているので、撃てないまま手札を1枠恒久的に埋める**。同じ札がショップにも170Gで並んでいた。緑の+2許容と保持の組み合わせは、事実上の罠枠になっている。
