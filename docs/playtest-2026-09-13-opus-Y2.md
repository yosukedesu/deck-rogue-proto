## 3. 設問への回答

### 設問1: 合成の触媒

**提示されたら取るか** → **3回提示されて3回とも即決で取った**（軽石の盾・胞子の風・〔ショップの根付きの盾は工房が1回しか無かったので見送り〕）。理由ははっきりしていて、

- 触媒の本体は**わざと弱い**（1E ブロック5／1E 3ダメージ）。つまり「デッキに入れる価値」で判断すると必ず外れ札に見える。
- しかし**⚗タグの文言が効果として読める**ので、「工房が先にあるなら、これは1枚で工房の出力を跳ね上げるチケット」と即座に読み替えられた。カードの強さでなく**ノードの予定**で取るかが決まる、という新しいピック基準が生まれていて、これは良い。
- 逆に言うと、**工房がもう無いルートでは完全なゴミ**。幕1行11で2枚目の触媒（胞子の風）が出た時は、マップに🔨が残っていなかったので見送った。**取るか否かがマップ読みの問題になる**のは、この機構の一番面白いところだった。

**工房で何を選んだか（1回目・幕1行9、141G）**
候補を7通りプレビューして比べた:

| 組 | 結果 |
|---|---|
| **軽石の盾 × 牙の一撃+** | **皮牙の穿ち+ 1E: ブロック8＋26貫通** |
| 軽石の盾 × 三連の角 | 皮牙の乱撃 1E: ブロック5＋5×3貫通 |
| 軽石の盾 × 樹皮の鎧 | 蔦皮の盾 1E: ブロック19＋成長1 |
| 牙の一撃+ × 三連の角 | 大牙の乱撃+ 3E: 勢い+2＋26貫通＋8×3貫通 |
| 牙の一撃+ × 薙ぎ角 | 牙角の嵐+ 3E: 26貫通＋全体9貫通＋勢い+6 |
| ⭐打撃 × 防御 | 素振り 1E: ブロック5＋7ダメージ（条件で0E） |

選んだのは**軽石の盾 × 牙の一撃+**。比べ方は単純で、**触媒の−1は「相方が高い札ほど得」**なので、一番高くて一番強い札に貼るのが正解になる。結果として「1Eで26貫通＋ブロック8」という、明らかにコスト帯を壊した札が出た。
⭐レシピ（素振り）と置物ペアも見たが、**素振りは初期デッキ2枚を溶かして初期デッキ相当が出てくるだけ**で比較にすらならなかった。置物ペア（樹皮の芽が手に入る前）は候補が無かった。

**工房2回目（幕2行7、137G）**: **胞子の風 × 皮牙の穿ち+ → 大皮牙の嵐+（1E・全体5＋ブロック8＋全体26貫通）**。
これは**合成品にさらに触媒を重ねられる**という発見で、コストが `1+1−1=1` のままなので**完全上位互換が1Eで出てくる**。単体戦でも 5+26=31（従来26）なので**どの局面でも旧版より強い**。

> **バランス所見（強く報告したい1点）**: 触媒は「弱い本体＋1つの修飾」という値付けだが、**修飾が乗る先の札の値段を一切見ていない**。−1の触媒を2E札に貼れば実質2E→1Eの半額券、全体化の触媒を26貫通に貼れば実質×敵数。**触媒どうしの多段適用（今回のように合成品に重ねる）が止まっていない**のが一番効いている。処方案としては ①合成品（fused_）は触媒の対象外 ②全体化は「全体になるが量が半分」 ③−1は「結果のコストが素材の高い方以下になる」だけ、あたり。ただし**楽しさは本物**で、工房が「ランの目玉」という方針とは合っている。壊すつもりで壊れているなら現状維持もあり得る。

**工房のCLI表示で触媒の結果は見つけやすかったか** → **半分ノー**。
- 札に `【⚗触媒:素材にすると結果がコスト−1(0Eまで)】` と出るので**触媒であること自体は見逃しようがない**。
- ただし工房の一覧には **⭐レシピ候補の行はあるのに、⚗触媒の候補行が無い**。「[22]胞子の風 と組むと全体化」という案内が出ないので、**どの相方が一番得かは自分で FusePreview を総当たりするしかない**（今回は7〜8通り叩いた）。ここは⭐と同じ形で「⚗ 触媒: [22]胞子の風 — どの札と組んでも結果が全体化」の1行があるだけで、体感が大きく変わると思う。
- プレビュー自体は優秀。`※軽くなる触媒: 結果のコストがさらに−1` のように**どの規則が働いたかが必ず1行出る**ので、結果の根拠が読める。

**幕1ボスの👑3択は迷える設問だったか** → **はっきりYES。このランで一番長考した**。
- 3つとも「取った瞬間に効果が出る」形が違っていて、比較軸が揃わないのが良い。**小さな家＝即物的な安全（HP+8, 60G）／呪いの鍵＝恒久的な出力（上限+1）と後払いの税／星読みの盤＝デッキの質を3枚まとめて上げる賭け**。

**層タグ（◆/★/👑/🛒/❓）は判断に効いたか** → **ほぼ効かなかった**。理由は2つ。
1. 判断は結局「自分のデッキに効くか」で決まる。◆か★かはピック時の意思決定にほとんど入らなかった。
2. **コモンには印が付かない**（成長の種・古い金貨・小さな宝箱は無印）ので、「無印＝コモン」と知らないと層が読めない。3枚のうち1枚だけ◆が付いている時、**◆が強いのかコモンが弱いのかが直感的に分からない**。◇のような印をコモンにも付けるか、いっそ全部に付けないか、どちらかに寄せた方が読みやすい。

**取得時に何かが起きるレリックの手触り** → 今回触れたのは**呪いの鍵（onCombatStart）と 厄除けの札（受動）**と 成長の種のみ。翼の靴・ルーンの円蓋・角錐・祈りの車輪・呼び鈴・鳥籠・星読みの盤は**提示されたのが星読みの盤1回だけ**（それも見送った）で、体験できていない。

### 設問4: ターン数の手触り

**物差し（通常4〜6T／ボス6〜10T）に対して、幕1は明確に短い。**

- **幕1通常戦 平均2.4T（8戦中5戦が2ターン決着）**。2ターンで終わる戦闘は #1 小泥、#3 蛞蝓、#4 泥まとうもの、#5 胞子茸、#9 噛みつき果実。エリートの大鴉も2T。
- 特に悪いのは**#4 泥まとうもの**。「硬いが遅いタンクの教師」という役どころなのに、`打ち据え→牙の一撃+→打撃` の急所コンボで**2ターン目に52ダメージ**を出して終わった。HP65の敵が1ターンで溶けると、そもそも「硬い」という性質がプレイヤーに届かない。
- 原因は自分側にはっきりある: **幕1行4の?イベントで牙の一撃を鍛えて 2E/26貫通 にした**時点で、幕1の敵HP帯（38〜65）に対して**1枚で半分以上を消す札**が完成していた。さらに幕1行9の工房でそれが**1E**になった。曲線の上流は「敵のHP」ではなく**「無料の鍛え＋合成が幕1前半で重なる」**ことだと思う。
- **幕2は平均3.4Tで改善**（3,3,5,3,3）。ただしこれは敵のHPが厚いからで、拍で伸びているのは #14 樽（爆発の締切）と #15 岩虫（崩しの計算）だけ。#13 大苔スライムの5Tは**半分が単なる体力**だった。
- **ボスは6Tで帯の下端。**ここは良かった。6ターンとも「誰を殴るか」が変わり続けたので、長さが退屈にならなかった。

まとめると、**長さそのものより「長さの中身」の差が大きい**。同じ3ターンでも #7 うねる獣（面白さ2）と #15 岩虫（面白さ5）はまったく別物で、差は**締切（爆発・育つ技）と、こちらの手を変えさせる条件（完全ブロック・手数の鏡・殻）の有無**にある。

### 設問5: 幕1の「退屈だった提示」

**3枚とも見送りたかった提示は 0回**（10回の報酬提示中）。ただし**「1枚だけが明らかに正解で、残り2枚は読む価値もない」提示が4回**あった。

- r5（風の壁 / 深緑の刻 / 三連の角）: 風の壁は勢い参照、深緑の刻は成長3以上参照。**どちらも軸の札を1枚も持っていない段階で提示される**ので、実質1択。
- r8（★猛進の角 / 荒角の構え / 蔓の跳ね）: レア枠が「勢いが×2で乗る3E札」。勢い源が薙ぎ角1枚のデッキに来ても**レアが一番弱い**。ここが一番「3枚とも要らない」に近く、荒角の構え（防御の上位互換）を消去法で取った。
- 逆に**良かった提示**は r1（大樹の怒り4E36 / 追い風 / 薙ぎ角）と r10（樹皮の芽 / 疾風の蔓 / 大蛇の丸呑み）。**「今すぐ効く札」と「方針を決める札」が同居している**と必ず悩む。

つまり退屈の正体は「3枚とも弱い」ではなく、**軸参照の条件札が、その軸を持っていないプレイヤーに供給されること**。条件札は魅力的に見えないのではなく、**読む前に自分の札でないと分かる**ので、実質的に提示枚数が3→1に減る。

## 4. 表示・説明で嘘/分かりにくさを感じた点

1. **ログの敵インデックスが盤面と1ズレ**。盤面は `敵0/敵1/敵2` なのに、撃破ログは `☠敵1を倒した`（実際に倒したのは敵0）。複数体戦で「今どれを倒したか」を読む時に一瞬混乱する。
2. **厄除けの札が烙印を吸ったことが一切表示されない**（§設問2）。`relicState.brandWard` が黙って 2→1。呪いの鍵の税を踏み倒せたのかどうかがプレイヤーから見えない。
3. **工房に⚗触媒の候補行が無い**（⭐レシピにはある）。総当たりプレビューを強いられる。
4. **コモンのレリックに層タグが無い**ので、3択の中で◆が1枚だけ付いている時に「◆が上」なのか「無印が上」なのかが読めない。
5. **`エナジー 3/5` の読み違い**。このは＋呪いの鍵の合計+2が「次のターンから」なのは `上限参照は3を読む(今ターンのランプは次Tから)` で説明されているが、**その注記はエナジー行ではなく上限参照の注記**として出る。実際にT1で1枚ぶん余計に数えて、転がる岩虫のバランス崩しを2点差で逃した。`エナジー 3/5（今ターンは3。上限5は次Tから）` のように**使える量の側に書く**方が事故らない。
6. **良かった点（嘘が無い）**: 手札の `［実値: 敵0:26(貫通(ブロック無視))］`／`敵0:0(敵ブロック-6)`／`敵0:5(装甲上限5)` の内訳表示は完璧で、**表示を信じて計算すれば必ず合った**。同じく確認ウィンドウの `⚠ 発動すると伏せ枠が空く: 血族の踊り手の行動が【伏せなし】分岐 (筋力+2〜2) に変わる` は、**この警告があるから「温存」という選択肢が本物の選択肢になる**。ボス戦で6ターン温存し続けた判断は、この1行が無ければ成立していない。
7. **伏せ札の状態表示も良い**: `【見切られ中。ただし罰型の血族の踊り手は伏せ札がある限り反応する。破壊は来る】` は情報量が多いのに、**「だから伏せっぱなしで良い」という結論まで読める**。

### 一番強く言いたいこと（優先度順）

1. **触媒 × 合成品の多段適用が壊れている**（1E・全体5・ブロック8・全体26貫通）。楽しさは本物なので撤去ではなく、合成品を触媒の対象外にするか、全体化に量の減衰を付けるのが良いと思う。
2. **幕1の?イベント「デッキの1枚を鍛える」が早すぎる**。行4で牙の一撃を26貫通にした時点で幕1の敵HP帯が壊れた。焚き火の「鍛える」が休むに勝てない一方で、イベントの鍵は無料で配られている。
3. **工房に⚗触媒の候補行を**。⭐と同じ1行があるだけで、触媒の体験が「総当たり」から「選択」に変わる。
4. **取った瞬間に効くレリックは、効いた瞬間を必ず1行出す**。厄除けの札の無言発動は、レリック102個化の価値をそのまま溶かしている。
5. **軸参照の条件札は、その軸の入口札を持っていないプレイヤーには提示しない**か、少なくとも1枠は無条件の札を保証してほしい。退屈の正体は弱さではなく「読む前に自分の札でないと分かる」こと。
