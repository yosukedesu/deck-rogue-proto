### A. X化 — 非X素材の印字コストが完全に消える（33ペア）

`xCost` が片方でもあれば結果は必ず X 札になり、**もう片方の印字コスト（最大5E）が価格から消滅する**。
X札は「エナジー1以上を払えばプレイ可」なので、**1エナジーで5E札の全弾が撃てる**。

| ペア | 結果 | 実効 |
|---|---|---|
| 巨獣の踏みつけ × 蔦の連撃 | XE 50＋5×X（保持） | **X=1（1E）で55ダメ** |
| 大樹の怒り × 森羅の大嵐 | XE 36＋全体4×X＋成長1 | X=1 で36＋全体4 |
| 天蓋の実り × 樹皮の重鎧 | XE 上限+2＋2ドロー＋ブロック4＋6×X | **1Eで上限+2と2ドローが買える** |
| 大幹の構え × 蔦の連撃 | XE 上限×3ダメ＋上限×3ブロック＋5×X | 上限5なら1Eで15/15＋5 |
| 蔦の連撃 × 大樹の岐路 | XE 5×X＋モード{上限+1+2ドロー / 成長+3+ブロック6} | 3E相当のモードが1Eで |

### B. リアクション2E上限 — 3〜5E札の値引き機（112ペア）

`if (resultType === 'reaction') cost = Math.min(2, cost)` が、**出力を削らずにコストだけ切り下げる**。
リアクション化の変換規則は「onPlay効果をそのまま主窓へ移す」だけなので、大型札の全弾が2Eで伏せられる。

| ペア | 結果（すべて2E reaction） |
|---|---|
| 巨獣の踏みつけ × 根の紡ぎ | 敵行動時: **打ち消し ＋ 50ダメ ＋ 成長+2** |
| 巨獣の踏みつけ × 蔦の陣 | 被攻撃前: **50ダメ ＋ ブロック10** ／ 被攻撃後: 返し8 |
| 大樹の怒り × 大樹の守り手 | 被攻撃前: **36ダメ ＋ ブロック12 ＋ 成長+3** |
| 大収穫の儀 × 蔦の陣 | 被攻撃前: ブロック10 ＋ 成長放出×6 ／ 被攻撃後: 返し8 |
| 茨の返し × 巨象の突進 | 被攻撃後: **32ダメ貫通 ＋ 返し10** |

### C. 全体・貫通の無償伝播（115ペア）

`totalDmg` を合算して `pierce`／`target:'all'` を**全ヒットに配ってしまう**。
これは 2026-08-30 に旧モデルで一度潰した「伝播後の効果からVPを出したせいで全体×2・貫通×1.25が無料で乗った」バグの再来で、
**今回はコストすら上がらないぶん悪い**。全体札は緑に薙ぎ払い・薙ぎ角・嵐の角・大地の唸り・森羅の大嵐の5枚しかないので、
**この5枚のどれかを混ぜるだけで単体札が全体札に化ける**。

| ペア | 結果 | 素材の全体量 |
|---|---|---|
| 打撃(1E) × 薙ぎ払い(1E) | **1E 全体10** ＋全体(攻撃数×2) | 元は全体4 |
| 巨獣の踏みつけ(5E) × 薙ぎ角(2E) | **5E 全体56貫通** ＋勢い+2 | 元は全体6貫通 |
| 大樹の怒り(4E) × 薙ぎ角(2E) | 5E 全体42貫通＋成長1＋勢い+2 | 同上 |
| 大蛇の丸呑み(3E) × 薙ぎ角(2E) | 4E 全体40貫通（捨て1） | 同上 |
| 三連の角(2E) × 薙ぎ角(2E) | 3E **全体6貫通×4** ＋勢い+2 | 同上 |

同じ配管で **多段合算も価値を作っている**（`打撃 × 大蛇の丸呑み` → 3E **40ダメ**が「1ヒット」ではなく
`二連の蔦打ち × 大蛇の丸呑み` → 3E **15×3**＝成長・勢いが3回乗る）。単体34が15×3になる時点で成長デッキでは実質倍。

### D. 置物化の ÷3 が効いていない（14ペア＋周辺）

`Math.ceil(amount/3)` を**効果ごとに**掛けてから同種をマージするため、
**量1〜3の効果は無傷（ceil(1/3)=1）で、しかも合算される**。蔦の乱舞は `成長+1` が5行あるので **毎T成長+5** になる。

| ペア | 結果 |
|---|---|
| 蔦の乱舞 × 年輪の大樹 | 4E置物 毎T ダメ4＋**成長+6**（年輪の大樹は★レアで毎T成長+1） |
| 蔦の乱舞 × 狩人の眼光/棘の蔓/風渡り/風の棘/根張り/棘葉の茂み/芽守り | **3E置物 毎T ダメ4＋成長+5** |
| 年輪の大樹 × 共鳴する茨 | 2E置物 毎T **成長+3** |

### E. その他（式の帰結だが目に付くもの）

- **0E×0E → 0E非消滅**が11ペア。`落ち葉の刃 × 増える蔦` = 0E **11ダメ＋コピー1**（230%）、
  `真・落ち葉の刃` = 0E **14ダメ**（捨て2・非消滅）。0マナ規約は「ループしない」しか守らないので合法だが帯外。
- **条件0Eの抜け穴（18ペア）**: 消滅の自動付与は**印字コストしか見ない**ので、
  `追い風`（勢い5以上で0E）・`年輪`（手札物理のみ0E）を混ぜると **0Eで補充する非消滅札**ができる。
  `緑の閃き × 追い風` = 1E・6ダメ貫通＋**ドロー4**（捨て1）が勢い5で0E → 手札が毎回+2で山を掘り切る。
  `増える蔦 × 追い風` = 勢い5で **0E・10ダメ貫通＋自分のコピーを捨て札へ**。
- **査定の誤差なので壊れではないもの**: `真・弾け実の罠`(675%) 系は `onSetDestroyed:全体24` を
  card-audit が満額で数えているだけ。実戦では敵が伏せ破壊してこないと発火しない。名指しからは外した。

そもそも工房ノードを踏む理由が消える。

## 5. ルール提案

工房は「1幕に最大1回・100G」（`WORKSHOP_PATH_MAX=1` / `WORKSHOP_FUSE_PRICE=100`）なので、**1ランで3回しか合成できない**。
つまり本当の害は「全体が強すぎる」ことではなく、**3回の選択が A〜D の既知の抜け道に収束して、
合成が『どの穴を突くか』のクイズになる**ことだと考える。以下は強さを削る提案ではなく、
**穴を塞いで選択肢を平らにする**提案。優先度順。

### 提案1（最優先・A）: X札は「両方がX」の時だけX札にする
- **現状**: `xCost` が片方でもあれば結果はX。非X素材の印字コスト（最大5E）が消え、**1エナジーで5E札が撃てる**（実測55ダメ）。
- **案A（推奨）**: 片方だけXなら **X参照を典型X=3 の固定量に畳む**（`5ダメ×Xヒット` → `5ダメ×3ヒット`、`ブロック6×X` → `ブロック18`）。コストは通常どおり `合計−1`（X素材は3E相当で数える既存の `costAsMaterial` を流用）。
  「X札は他の札と混ざるとXでなくなる」は1行で説明できる。
- **案B**: 結果はXのままだが、**支払える最低X＝非X素材の印字コスト**にする（巨獣の踏みつけ×蔦の連撃は最低5E）。1E詐欺は消えるが「X札なのに最低5E」は読みにくい。
- **案C（最小）**: X札同士以外は合成不可。ただし「全ペア合成可」の方針に反するので非推奨。
- **ロールバック条件**: 案A適用後、次の緑ランで「Xを含む合成が一度も選ばれない」なら畳む典型値を X=4 に上げる。

### 提案2（B）: リアクション2E上限は「切り下げ」でなく「出力で払う」
- **現状**: コストだけ2Eに切り下げ、出力は無傷。5E札の全弾が2Eで伏せられる（実測62ダメ）。
- **案A（推奨）**: 切り下げた 1E につき **最大の量効果を −6（=1E相当のVP）** する（0未満にはしない）。
  旧モデルにあった「帯超過は出力を削って払う」装置の復活で、法体系も既存のまま。
  例: 巨獣の踏みつけ×先制の蔦槍 → 5E→2E なので −18 → 32＋12＝44ダメの2E罠（それでも強いが帯の中）。
- **案B**: 素材の合計コストが3E以上ならリアクション化しない（支配順位を無視して呪文/物理のまま出す）。
  「重い札は伏せられない」＝リアクション2E上限の趣旨に沿う。実装は1行だが、
  「大樹の守り手（2E反応）と混ぜたのに反応にならない」の説明が要る。
- **ナーフではない理由**: 素材の合計VPは保存される（コストが下がるぶんだけ量が減る）。プレイヤーの損は無い。

### 提案3（C）: 「特性の伝播」をやめ、ダメージ行を素材のまま並べる
- **現状**: `totalDmg` を合算 → `pierce`/`target:'all'` を全ヒットに配る。全体札5枚のどれかを混ぜるだけで
  単体札が全体化・貫通化する（無料）。2026-08-30 に一度潰した +49% 水増しの再来。
- **案A（推奨・実装も最小）**: `damageEffects` の合算・再分配をやめ、**各素材のダメージ行をそのまま `merged` に流す**。
  - 打撃 × 薙ぎ払い → 1E「6ダメ＋全体4＋全体(攻撃数×2)」（今は全体10）
  - 二連の蔦打ち × 大蛇の丸呑み → 3E「5・5・34」の3行（成長は3回乗る＝多段の旨味は残る）
  - 巨獣の踏みつけ × 薙ぎ角 → 5E「50 ＋ 全体6貫通 ＋ 勢い+2」
  **「合体」モデルなのだから、効果は混ぜずに並べるのが定義どおり**。特性の掛け合わせは旧・価値保存モデルの名残で、
  合体モデルには要らない。名前の `乱撃/嵐/穿ち` は行の内訳から今どおり付けられる。
- **案B（伝播を残す場合）**: 伝播が起きたら結果コスト+1、かつ全体化された量を ÷2。案Aより読みにくい。
- **副作用**: 多段合算（上限5）が消えるので「二連の蔦打ち×三連の角＝5ヒット」の派手さは失われる。
  派手枠が欲しければ**同名合成の時だけ多段合算を残す**（真・二連の蔦打ち＝5×4）のが折衷案。

### 提案4（D）: 置物化の ÷3 は「同種の合計」に対して掛ける
- **現状**: 効果ごとに `ceil(amount/3)` → その後マージ。量1〜3は無傷、しかも合算される（蔦の乱舞 → 毎T成長+5）。
- **案A（推奨）**: **先に同種効果をマージしてから ÷3**、かつ **切り捨て（`Math.floor`）**。
  合計が3未満で0になったものは「登場時に1回」（現行の量なし効果と同じ扱い）に落とす。
  - 蔦の乱舞 × 狩人の眼光 → 3E置物 毎T ダメ3＋**成長+1**（＝年輪の大樹の帯）
  - 木漏れ日 × 棘の蔓 → 1E置物 毎T ブロック2（ドロー1は0になるので登場時1ドロー）
- **案B**: ÷3 を ÷4 にする（お題の案）。切り上げが残るので量1〜3は依然無傷＝**蔦の乱舞は直らない**。単体では不十分。
- 併せて **`gainSetSlot` は置物化の対象外**（伏せ枠が毎ターン+1は明らかに想定外）。現状は素材が既に置物なので発生しないが、器としては塞いでおきたい。

### 提案5（E・バグ修正枠）: 文面と実装を一致させる
1. **`searchDeck / retrieveFromDiscard / upgradeInHand / addCopyToDiscard / growSelf` は `onPlay` 以外のトリガーに置かない**。
   - 置物化する時は **`onTurnStart` ではなく `onPlay`（登場時に1回）へ落とす**。置物の登場は playCard 経路を通るので実際に解決される（罠師の茂みの `gainSetSlot` と同じ）。
   - リアクション化する時は**その効果を落とす**（窓では playCard を通らないので原理的に解決できない）。落としたぶんは他の量効果に足す。
   - これで105ペアの「書いてあるのに何も起きない」が消え、同時に「毎ターン無限サーチ」の懸念も消える（実は死んでいた）。
2. **リアクション化で `drawCards` / `gainEnergy` / `discountNext` は落とす**（全捨て・全回復で消えるため）。72ペア。
3. **置物化で `negate` / `doubleGrowth` / `doubleMomentum` / 各種放出は「登場時1回」にしない**。
   量が0の参照なので死ぬ。落として他の効果に振るか、**その素材は従属側になれない＝支配順位を無視して非置物で出す**。78ペア。
4. **同名モード合成はモードを dedupe し、代わりに各モードの量を合算する**。
   真・絡み蔦＝`{ブロック14 / 14ダメ}`、真・道行きの選択＝`{勢い+6+6ダメ / 成長+4}`。
   これで「真・化」の趣旨（2枚ぶんの量を1枚に圧縮）がモード札にも通り、4件の完全無意味／損が消える。
5. **量を持たない同種効果（`negate` / `shatterBlock`）を1つに畳む時は、代わりに他の量効果を+する**。
   畳んだ効果1つにつき VP 12（打ち消し）/ 4（粉砕）ぶんを最大の量効果へ振る。
   真・根の紡ぎ・真・蔦の楔が「合成すると損」から抜ける。

### 提案6（歯止めの取りこぼし）: 条件0Eを消滅判定に入れる
- **現状**: `net - cost >= 0 && refills → 消滅` は**印字コストしか見ない**。
  `freeIfMomentumAtLeast`（追い風）・`freeIfHandAllPhysical`（年輪）を持つ結果は、条件成立時に0Eなのに非消滅で補充できる。
- **案（推奨）**: 判定コストを `(freeIf* を持つなら 0 : cost)` に変える。18ペアが消滅付きになる。
  ループはしない（自分を手札に戻さない）が、「0Eで山を掘り切る」は一貫性を壊すので消滅で1回きりにするのが既存規約と整合。

### 参考: コスト式そのものについて
`合計−1` は「2枚を1枚に、1E得」の分かりやすさとしては良いが、**低コスト帯では構造的に200%を割らない**
（1E+1E→1E は定価100%の素材でも200%）。工房が1幕1回・100Gのゲートを持つので**現状は許容範囲**と見るが、
提案3・4を入れてなお1E帯の合成だけが選ばれ続けるなら、次の一手は
**「結果コストは素材の高い方以上（＝`max(a,b) ≤ cost ≤ a+b−1`）」**を推す。
1E+1E→1E は据え置き（ここは楽しいところ）、5E+1E→5E も据え置きで、
1E+2E→2E のような「安いほうに寄る」ケースだけが締まる。数式1行で、旧モデルの「素材コスト合計を超えない」契約とも両立する。
