## 4. 段2の札の手触り

- **くべる（火にくべる・灰の息）**: 「失効の悔しさを選択に変えたか」→ **半分だけ変わった**。
  - 変わった所: 灰の衣・燃え残りが場にあると、失効も「ブロック3＋延焼3」を出す行為になり、「くべる（札の効果を取る）／失効させる（置物の効果を取る）／撃つ」の三択が毎ターン生まれた。戦#5 T6 の「3Eで撃てない野火を灰の息の燃料にしてブロック8」は設計どおりの瞬間で気持ちよかった。戦#4 T4 の「灰の息の8ブロックが重り1枚ぶん(+10%)を上回るか」の計算も良い。
  - 変わらなかった所: **燃料が無いターンは2枚とも死に札**（火にくべるが38ターン中24ターン手札に残った）。燃料＝灰の盾・火床の盾・鉄火の意志・熾火の一閃・取り出し・着想・鍛冶の炉の衝動で、引けないターンが多い。さらに**くべる札自身が衝動で引かれると、くべる札がくべる燃料を食い合う**（衝動の火にくべるで衝動の火にくべるを燃やすしかない場面が戦#1・#3）。
  - 灰の息は良い（ブロック8＋延焼2で赤の守りの穴を埋める）。火にくべるは「全体4＋延焼3」で、この人格では守りが足りずエナジーを回せなかった。
- **刈る（火掻き・焼き払い）**: デッキに無く、提示も無かった。答えなし。
- **点く（爆ぜ火・火の目覚め）**: 爆ぜ火は無し。火の目覚めは報酬#1で提示されたが灰の息を取った。点火6回は**全部ターン終了時の失効（燃え残り）か敵フェーズ**で起き、「点いた瞬間」は自分の手番の外。B の人格では点火は「状態」のまま。
- **火は火を呼ぶ・業火の炉**: デッキに無し・提示無し。
- **野火**（報酬で取った R）: 3E で、守りに全エナジーを使うこのデッキでは一度も撃てず、くべる燃料になった。

## 5. 未検証6枚の手触り（B のデッキにあった札）

- **灰の衣**（衝動の札が失効するたびブロック3）: このデッキの生命線。着想の後なら1ターンでブロック15〜18。ただし①敵が殴らないターンの失効は丸ごと無駄（巨像・奴隷商の防御ターン）②被ダメ予測に乗らない（下の §8）。**ブロックが「失効させる」ことに紐づくため、守るほど札が消滅して山札が痩せる**（§7 の最悪の場面の根）。
- **燠の守り**（失効する衝動の札のうち最も高いコストを1枚残す）: 着想（2E）を翌ターンへ持ち越せた時は最高（戦#2）。一方、**引いた札がほぼ 1E なので「どれが残るか」を選べず**、火床の盾を残したい時に熾火の一閃が残った（戦#4）。残した札は衝動でなくなるので、走り火も鳴らず・くべる燃料にもならない（仕様どおりだが「残した＝衝動の性質も残る」と読んだ）。
- 燻り・火勢倍し・連火の炉心・火は火を呼ぶ: デッキ外・提示なし。
- （参考）**燃え残り**（失効ごと先頭の敵に延焼+3）: 着想と組むと1ターンで延焼+15〜21。戦#1 は判断不要で敵が焼け落ちた＝強すぎ疑い。一方「先頭の敵」固定で、2体戦では落ちかけの敵に延焼が積まれ続け、危ない方（火薬樽）に乗らない。
- （参考）**鍛冶の炉**（店）: 毎ターン衝動2が燃料と失効の両方になり、この人格では一番の当たり。ただし後半は「残りの札を毎ターン2枚ずつ消滅させる装置」になった。

## 9. 設計への提案

1. **くべる札は「衝動が無ければ普通に撃てる（くべれば+）」の形へ**（設計書 §5 のロールバック線どおり）。火にくべるが38ターン中24ターン腐った。例: 火にくべる＝全体4、くべれば＋延焼3。灰の息＝ブロック5、くべれば8＋延焼2。
2. **燃え残り +3 → +2 へ戻すか、先頭でなく「延焼の最も多い敵／ランダム」へ**。着想（衝動6）と組むと1ターンで延焼+18〜21＝判断不要で通常戦が焼け落ちる（戦#1）。一方2体戦では先頭固定で落ちかけの敵に無駄撃ちする。
3. **消滅の自食いへの床**: 失効した衝動の札は「この戦闘の消滅」でなく捨て札へ（＝本家の Light Up the Stage は消滅しないのと同じ方向）にするか、灰の衣・燃え残りに「1ターン3回まで」を付けて「失効させるほど得」を抑える。戦#7 は消滅置き場21枚・デッキ3枚で詰んだ。
4. **燠の守りは残す札を選べるように**（EndTurn に `keepUid`）。満ち潮の書庫（`retainUids`）と同じ器で済む。
5. **被ダメ予測に「ターン終了時の失効ブロック（灰の衣×失効予定枚数）」を足す**か、注記「＋失効で最大N」。
