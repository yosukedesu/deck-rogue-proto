## 4. 見つかった欠陥（直した）

1. **地図で同じ敵が道の上に続く**（#19 の幕1 行1〜3 が「蜘蛛と噛みつき果実」3連続）。同族の回避は「直前2行の全ノード」で見て、候補が尽きるとプール全体から引いていた。弱枠（幕1は7編成・4列）では毎行尽きるので、**親子で同じ編成が 幕1 55%・幕2 46%・幕3 28% の地図に出ていた**（400シード）。既存のテストは「プレイヤーは1行1ノードしか踏まない」として弱枠を除外していたが、プレイヤーは親→子の道を歩くので反復はそのまま見える。
   - 直し: 避ける範囲を4段に（①直前2行と今の行の全ノード ②道の祖先＝親と祖父母 ③親だけ ④親と同じ編成だけ）。①で足りる地図は今までと同じ。
   - 結果（600シード）: 親子で同じ編成 **0**（3幕とも）。幕1は同族も0。幕2の弱枠は家族が実質2つ（甲虫・伏せ警戒の組と道化の組）なので同族の続きは残る（173辺）。
   - `map.test` に「道の上で同じ編成が親子に続かない（全行・弱枠込み）」を追加。C# `MapGen.cs` に同じ形で移植し、地図360枚（120シード×3幕）を TS と突き合わせて全一致（`dotnet run -- map-trace`）。ゴールデン13本を再生成・C# 13/13・セーブ往復 13/13。
2. **合成品を素材にした合成札の名前がログに id のまま**（#18「プレイ: fused_fusion_page_ambush__white_perm_bonfire」）。`resolveFusedDef` が素材を素のカードとしてしか引いていなかった → 素材も合成品・レシピ産として再帰で引く（TS・C#。`dotnet run -- resolve` で5件一致・`fusion.test` に追加）。
3. **Unity のログに型名がそのまま**（EnemyDied 70行・DeckShuffled 53行・CardsAddedToHand 34行）。Web のログにあって Unity に無かった18種を足した（`CardText.LogLine`。Unity コンパイル0エラー）。
