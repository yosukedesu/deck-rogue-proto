## 4. ストーム（本題）

### 4-1. 数字

| 項目 | 値 | どこで |
|---|---|---|

- 勝ち筋の形はほぼ毎回同じ: **引く札（ひらめき・集中・水鏡の書庫・記憶の渦）で山を掘る → 焚べ火で詠唱を積む → 反復+（0E）→ 巻き波+**。
- **エネルギーが唯一の天井**。3Eの幕1は「巻き波(2E)＋1E」しか組めず、詠唱4〜5で12〜20が上限。古根の杯（4E）・集中の割引・水鏡の書庫（実質1E）・貯め置き（ギア）が揃った幕2で一気に跳ねた。
- **反復+（0E）×巻き波+ の組み合わせが決定打**。0Eで詠唱が1増え、次の全体攻撃を2倍にする。焚き火で反復を0Eにした（行8）時点で幕1の残りと幕2の通常戦がほぼ1〜3Tになった。
- 知恵の重み（手札×2）は「掘った後の大きな手札」とよく噛み合う（#8 で20・#12 で22）。ストームと抱え込みの両立は、掘る札が多いと自然に起きる。
- 詠唱数は手で数えるしかない（7節 f）。巻き波の点数を出すたびに「この札の前に何枚出したか＋焚べ火の分」を数えた。

### 4-3. 天敵以外で気づいたこと

- **歩哨のがらくたは焚べ火・大焚火・記憶の渦の捨て札にちょうどいい**（#4）。知恵の重みもがらくたを手札の枚数に数える。

- 集中の「次のカード-2」は、青の報酬がほぼ1Eの札なので1が無駄になる場面が多い。2Eの巻き波・水鏡・大焚火に当てると効く。割引は重ねられる（集中＋魔力の火花＝次-4）。
- 氷壁（みぞれの能力＋霧の分身）は「たくさん撃ったターンは勝手に守れている」形で、ストームと喧嘩しない。ただし霧の分身は1Eの置物で、詠唱ターンには置く余裕がなく未使用5回。

## 10. 設計への提案（短く）

1. **幕2の通常戦が1〜2Tで終わる**（1.75T・2T目以降0%）。原因は「反復+（0E）×巻き波+（全体×4）」と古根の杯の4E。ストームの天井を下げるなら、反復の鍛え先を0Eにしない（反復+＝反復+2 等）か、反復が詠唱参照の全体攻撃を2倍にしない、のどちらか。敵側で受けるなら、幕2の通常プールに重圧・拘束・手数の鏡の敵をもう少し厚く。
2. **重圧（歩き木）はストームを完全に止める**。天敵として残すのは良いが、チップの言葉を「ダメージを与える札」に（9節 e）。
3. **CLI に詠唱数と巻き波・余波の実値を出す**（9節 f）。ストームの面白さは計算にあるので、数えるのが作業にならないように。
4. 集中の「-2」は1E中心の青では1が無駄になりがち。「次のカード-1を2枚」のような形の方が青の札と噛み合う（気になる程度）。
5. 嵐の目・引き潮の帰還は提示0。レアのストーム札2枚は評価できなかった（単発戦闘ではループなしを確認）。
