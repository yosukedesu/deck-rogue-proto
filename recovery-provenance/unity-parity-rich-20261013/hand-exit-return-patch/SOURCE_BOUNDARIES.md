## Presentation-safety adaptations

The source starts independent tweens. This package keeps the accepted port's single visual owner: retired cards leave the live dictionary before flying, pending deal/hover clocks are revoked, and every outgoing tick checks epoch, exact stored tile and current motion object, UID absence from the live hand, and the expected hand parent. Reuse/replacement, reset, route exit, modal opening, resize, or a missing tile cancels the old visual. Cancellation frees only its retired tile and never a live tile of the same UID. This is explicit port hardening, not a claim that Unity has these guards.

All new classes are plain managed helper/state classes or methods in existing GameUI. No new Godot-derived node or callback binding is required. The existing bound GameUI process callback advances these clocks with its existing scaled delta.
